# SonicDocs v1.7 交付核验（2026-11-02）

本报告针对本轮工作区的 v1.7，不沿用旧 v1.6 交付副本的通过记录。最终 `pnpm validate` 返回 0，构建输入文件哈希在运行前后未变。政策修订与文档验证已经完成，但下列运营事实缺项仍阻止把它作为已核实的线上欧盟合规服务交付。

## 1. 实际变更

- 完整修订简中《用户条款》《隐私政策》，同步其余九语言，共 20 篇政策。
- 明确免费、个人、非营利学习项目的服务范围；不额外承诺商业 SLA、永续运营、专职团队或认证，不作全面零责任和不可执行的概括赔偿约定。
- 保留不可排除的消费者、数据保护及人身损害等责任；补充适用时的合同撤回、供应与符合性、安全更新、变更通知、终止与内容取回。
- 按来源／目的／去向写明身份、连接、查询、画像、浏览器文件、公开评论、外部资源、可选推荐与告警数据；区分默认值、部署事实、部分重置及完整法定权利。
- 将 200 篇关联指南同步到 v1.7，修复旧主线与候选版混写、错误来源归属和已定位的翻译污染；部署示例钉定已核对候选提交，缩窄零毫秒切换及全面安全／不存储的过度保证。
- 新增 `scripts/check-policy-consistency.py` 并纳入 `pnpm validate`，检查法条白名单、政策提交／日期／技术字面值、语言链接、可选告警披露、指南来源和部署示例。
- 关闭 Git 自动“最近更新”页脚，避免旧提交日期与政策正文修订日冲突；修复 1280 像素桌面布局下右目录越界裁切。正文日期仍为修订日，不是线上生效证明。

## 4. 构建警告与页面验收

首轮预览构建出现 219 条 `Duplicate id` 警告。只读诊断发现 Astro 5.18.2 loader 对已有缓存中 digest 改变的同名条目报重复，没有判断是否为同一源文件；来源、缓存、路由均为 220 个唯一项目。将唯一的 `node_modules/.astro/data-store.json` 可逆移至忽略目录 `tmp_laws/` 保存后重新构建，最终重复警告为 0。没有改依赖或删除原始文件。

仍有依赖提示：Pagefind 不支持部分中日韩语言词干匹配，搜索索引仍成功；子进程 npm 对现有环境配置输出兼容性警告。未为消除提示擅自改用户全局环境。

浏览器检查覆盖中文隐私桌面及手机布局、手机数据表、英文条款手机／桌面浅色与深色展示。发现并修复桌面目录裁切，实际目录右边界约 1249 像素，位于 1280 像素视口内；重载最终构建后没有临时注入样式，也没有旧自动日期。目录的消费者撤回段落实际点击能够到达对应锚点。两次定位器点击超时后改用已核对屏幕目标完成点击，没有声称超时步骤通过。最终渲染检查确认 20 篇政策均为 v1.7 且含两版来源和告警说明。
