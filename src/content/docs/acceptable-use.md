## 1. 适用范围

1. 本政策适用于您使用托管 Sonic 网页播放器、公开 API、登录、搜索、播放、歌词、推荐和其他公开端点的行为。
2. 自行部署是独立实例。部署者应自行决定其政策、配置、法律和用户关系；本页不替自部署者承担运营或合同义务。
3. MIT 许可证允许对代码进行复制、修改、分发和商业使用。本政策保护的是托管实例及其资源，不构成对代码或所有 Sonic 部署的普遍商业使用禁令。
4. 本地音乐导入在当前核对中未发现把音频 Blob 上传至服务器的路径；歌词和推荐功能仍可能发送标题、艺人、专辑、时长或标识，详见[隐私政策](/privacy-policy/)。

## 2. 禁止行为

### 2.1 系统与接口滥用

1. 未经授权取得、使用或分享他人的帐号、会话、Cookie、API Key 或服务密钥，伪造凭证，或绕过托管实例的认证、限流、签名、SSRF 等访问控制。
2. 未经授权探测或利用托管实例的非公开端点、内部地址及凭证材料，或取得、披露他人私密资料；不得利用公共搜索建议收集、曝光或验证他人资料。
3. 通过大量抓取搜索结果、歌词、播放地址或接口响应占用共享资源，用于未获允许的转售、镜像或数据集；正常个人播放、适度 API 使用和经授权接入不在此限。
4. 将托管代理当作通用网络代理、扫描器或攻击跳板，或故意制造不必要的并发、流量、错误和缓存压力。

本政策不禁止阅读源码、在自有本地实例上使用合成或授权资料测试，或负责任地报告漏洞。对公共实例的主动安全测试应先取得适当授权，避免影响他人、获取其资料或扩大漏洞；可向 `admin@epocanvas.com` 私下提供最小复现，不要公开真实凭证。

### 2.2 内容与权利

1. 不得利用托管服务实施或促进盗版、规避付费或版权保护、侵犯著作权、商标权、肖像权、人格权、隐私权或其他权利的行为。
2. 不得利用服务传播违法内容、恶意软件、儿童性剥削材料或违法的恐怖主义宣传，或非法、未经授权披露他人的凭证及个人资料。这不禁止正常登录和必要的私下权利请求；本地音乐导入也不等于向 Sonic 上传文件。

1. 不得骚扰、威胁、诽谤、跟踪、歧视或攻击运营者、上游提供方、贡献者和其他用户，也不得利用公开缓存或建议功能暴露他人资料。

3. 不得违反您所在地适用法律或以不符合上游服务规则的方式使用内容接口。许可证允许的代码使用不自动授予第三方内容、帐号或音乐的权利。

## 3. 资源使用上限

托管实例可按匿名或认证状态、IP、会话、接口和事件批次设置限流；具体值由实际配置决定，不是本站对所有部署的统一合同承诺。超过限制时可能收到 `429`、延迟、拒绝或临时限制，不必然表示违规。

请使用合理的个人请求频率，避免并发抓取、重复重试、长时间占用音频流和无必要的行为事件上报。限流参数、凭证撤销和数据保留可能因环境变量、Compose 与源码默认值不同而不一致；不能仅凭页面推断运行状态。

## 4. 执行阶梯

运营者可依据行为的影响、意图、重复性、涉及资料和紧急程度采取一项或多项措施，并记录必要理由：

1. 提醒或要求停止相关行为；
2. 限制接口、并发、缓存、事件上报或其他资源使用；
3. 暂停帐号、会话、凭证或网络来源；撤销是否即时生效取决于实例的撤销存储、开关和请求是否成功；
4. 终止托管实例的访问，或阻止继续使用受影响的端点；
5. 在适用法律要求、有效请求或保护他人和系统所必需的范围内保存必要记录并提供给有权接收者。

对于正在进行的攻击、凭证盗用、严重安全威胁或明显违法内容，可以先采取必要的临时措施，再补充说明和复核。政策处置不替代行为人依法可能承担的责任，也不承诺自动报警、固定保存期、24 小时人员响应或永久删除所有相关记录。

## 5. 申诉与举报

- **申诉**：对限制、暂停或终止有异议，可向 `admin@epocanvas.com` 说明帐号、时间、相关端点和理由。运营者会在资源允许的合理期限内复核；这不影响适用法律规定的期限、权利和救济。不承诺固定时限、专职团队或必然恢复访问。请不要发送密码、完整令牌或无关个人资料。
- **举报**：可向同一邮箱报告疑似滥用、侵权、安全问题或对他人的伤害。请提供必要事实，不要转寄违法或敏感材料；运营者会依风险、资料最小化和适用法律判断是否采取措施或向有权机关披露。

隐私权、删除请求和资料外泄通知请使用 `privacy@epocanvas.com`。本政策只约束实际托管资源；自部署实例应提供自己的运营者和申诉渠道。
