## 1. 适用范围

本政策适用于您以任何方式使用本服务之行为，包括：

1. 网页播放器之全部功能（搜索、播放、歌词、推荐、下载、本地音乐导入）；
2. 经开放 API 之接入，包括您自建之第三方客户端与脚本；
3. 自行部署实例（自行部署运营者得修改本政策后适用，惟不得低于其所在地法律之要求）。

## 2. 禁止行为

### 2.1 系统与接口滥用

1. 规避或破坏限流、签名验证、熔断机制、SSRF 防御、域白名单或其他技术保护措施；
2. 伪造 API Key、重放已撤销之金钥识别码（jti）、盗用他人会话或金钥，或以任何方式绕过 fail-closed 校验；
3. 以自动化脚本大量抓取本服务之检索结果、歌词或播放地址，用于与本服务功能无关之转售、再分发或建立镜像数据集；
4. 探测、扫描或以其他方式获取本服务之内部拓扑、服务间密钥、金钥材料或非公开端点；
5. 利用本服务之代理端点（`/api/music/stream`、`/api/sonic/forward` 等）作为通用网络代理访问与音乐播放无关之目标。

### 2.2 内容与权利

1. 利用本服务提供之接口破解、绕过或干扰任何音乐平台之付费与版权保护机制；
2. 散布侵犯他人著作权、商标权、肖像权或人格权之内容；
3. 上传或传播违法内容，包括儿少性剥削素材、恐怖主义宣传内容；
4. 冒用他人名义或机构标识从事活动，或利用 `epocanvas`、`Sonic` 名称与标识暗示本服务背书之未经授权用途；
5. 上传以本服务分发之违法文件至本地音乐导入或下载功能。

### 2.3 他人权益

1. 干扰、破坏本服务或任何相关系统之正常运转，包括对熔断器与降级机制之蓄意触发；
2. 对运营者、上游服务提供方或其他用户实施骚扰、诽谤或攻击；
3. 将本服务用于任何违反您所在地法律或上游服务条款之用途；
4. 出售、转租或以商业转售为目的提供本服务之访问。

## 3. 资源使用上限

| 项目 | 上限 | 超限处置 |
| --- | --- | --- |
| 匿名请求 | 每分钟 240 次（缺省值） | 边缘层直接拒绝（429），不记录为违规 |
| 认证请求 | 每分钟 600 次（缺省值） | 边缘层直接拒绝（429），持续超限进入执行阶梯 |
| 认证端点（登录／金钥签发） | 每分钟每 IP 30 次 | 边缘层直接拒绝（429） |
| 行为事件上报 | 单批至多 50 条、请求体 64 KB | 超限请求整体拒绝 |
| 音频流 | 经边缘代理，或经您主动请求之直连模式 | 异常并发进入执行阶梯 |

正常个人使用不会触及上述上限；限流之技术目的为防滥用与服务稳定，非属处罚。限流参数为部署者可配置项，自部署实例之实际值以其配置为准。

## 4. 执行阶梯

运营者发现违规行为时，依情节轻重适用下列措施；每一级处置均记录理由：

1. **告知**：于播放器内发出警告并说明理由；
2. **限流**：调降该帐号或金钥之请求配额；
3. **暂停**：临时封锁该帐号之会话与 API Key（经 `jti` 撤销清单或即时撤销机制），资料暂时保留；
4. **终止**：终止使用权；行为资料于保存期限（90 日，下限 7 日）届满后销毁；
5. **证据保存与依法移送**：法律要求时，于必要范围内保存记录并经法定程序向有权机关提供。

下列情形不适用分级程序，运营者得立即暂停并移送或举报：儿少性剥削素材、恐怖主义宣传内容、进行中之系统攻击。

## 5. 申诉与举报

- **申诉**：您认为处置有误者，得致函 `admin@epocanvas.com` 申诉，说明处置所涉帐号与事由；运营者于合理期限内复核并答复。紧急处置（第 4 节零容忍情形）之申诉同样受理，复核期间不停止对您本人之误判救济。
- **举报**：任何人发现违反本政策之行为，得致函前述信箱举报；举报经核实前对被举报人保密。涉及儿少保护之举报不受保密承诺限制，依法定程序处理。

运营者依本政策所为之处置，不免除违规行为人依法应负之责任。
