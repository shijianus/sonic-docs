本页功能核对基于最新公开 RC `rc/sonic-20261031@a75f5cb`（2026-11-01 UTC）；较早默认分支 `main@ce443c8`（2026-10-27 UTC）仅作兼容性对照，不证明 RC 功能已部署。在线版本与配置未知。

本页汇总您在 Sonic 的主要数据：存于何处、目前可查询什么、如何清除，以及哪些数据没有产品内建的下载导出功能。法律依据与权利框架见[隐私政策](/privacy-policy/)第 4、6、9 节；技术措施见[数据处理与安全维护](/data-security/)。

## 1. 数据位置总览

| 数据 | 位置 | 关联身份 | 保存期限 |
| --- | --- | --- | --- |
| 收藏、歌单、偏好 | 主要在浏览器 localStorage；雷达另有远程路径 | 部分反馈与推荐上下文可能传送 | 本地副本至清除；远程另行处理 |
| 播放历史 | 浏览器 localStorage 及另外上报的播放事件 | 事件可能使用可关联假名识别码 | 本地清理不删除远程事件 |
| 下载与本地音乐 | 浏览器 IndexedDB | 未见音频文件主体上传；标题、艺人、专辑、标识及内嵌封面图片可能传送 | 本地至清除或浏览器回收；远程另行处理 |
| 行为事件与实体反馈 | 若实际启用，可能位于服务器端数据库或外部服务 | 假名识别码，不等于匿名 | RC 默认 90 日、下限 7 日；清理不完整且非逐笔到期销毁，不得承诺全面自动删除 |
| 搜索聚合与雷达画像 | 远程搜索存储，雷达耐久引擎存储未确认 | 搜索原文可能识别个人并公开显示 | 无经核验的统一自动期限，重置未完整涵盖 |
| 共享曲目目录与外部索引 | 服务器曲目库及可选推荐／检索系统 | 用户事件可带标题、艺人和内嵌封面；可供全站检索 | 未随个人画像重置完整清理，按可关联性处理 |
| 搜索历史（本地） | 浏览器 localStorage | 查询也传送供搜索，并可能进入统计／上下文 | 本地清理不移除远程副本 |

电子邮件地址与头像信息保留于浏览器 `auth`，签名凭证不是加密。原始 IP 键可进入 KV 或限流器，客户端地址、会话及上下文可转送引擎；表格没有 IP 字段不证明没有 IP 处理。不保证通用跨设备云端备份。

## 2. 查询：推荐画像概览

最新公开 RC 提供 `GET /api/sonic/events`（或设置页的画像区块）用于查询服务器端画像摘要；较早 `main@ce443c8` 仅作兼容性对照，不能证明 RC 已部署。即使实例提供摘要，它也不是完整个人数据导出或所有事件原始内容的副本；目前不得向用户承诺完整服务端事件下载。

## 3. 导出与备份

1. **浏览器数据**：收藏、歌单、偏好、下载与本地音乐主要保存在您的浏览器；部分反馈、元数据和上下文另行传送。本服务未提供通用的 localStorage 或 IndexedDB 导出工具，也未内建云端备份或跨设备导入；请依需求自行记录重要歌单、保留原始本地音乐文件，或使用浏览器／操作系统实际提供且您信任的备份能力；
2. **远程数据**：远程处理可能涉及事件、实体反馈、搜索数据与雷达同步路径，不仅是曲目事件；雷达耐久引擎存储未确认。摘要不是完整导出，重置也仅属部分删除；完整副本或较完整删除请通过第 5 节管道请求，必要时涵盖较早身份；
3. **推荐画像摘要**：相关功能启用且实例提供设置页或 API 时才可能查询摘要；在线可用性未核实，摘要不是完整导出，不能用来宣称已取得全部个人数据；
4. **本地音乐**：导入的原始文件仍在您的设备上，删除浏览器内副本不会影响原始文件。

## 4. 清除操作

| 操作 | 范围 | 生效 |
| --- | --- | --- |
| 重置推荐画像与不感兴趣记录 | 当前身份部分事件与反馈，可能遗漏旧识别码、雷达、聚合、外部服务及备份 | RC 路由为 `DELETE /api/sonic/events`；失败可能未显示，成功不证明完整删除 |
| 清除全部本地数据 | 请求浏览器存储清理及可能的部分远程重置；不应假定会清除 Cookie、URL 凭证或退出登录 | 须分别核对结果；清空设置后重载可能恢复默认状态，应重查选择 |
| 浏览器清除网站数据 | 仅浏览器端数据 | 依浏览器控制执行，不删除远程数据 |
| 退出登录 | 清理目前 Cookie，被复制的凭证须服务器撤销 | 远程效果依赖撤销存储设置与请求成功 |

## 5. 自行部署实例

自部署实例的用户应联系该实例运营者公布的权利请求渠道；不要将本文拟用的 Sonic 邮箱视为所有部署者的控制者渠道。托管实例用户的查询、更正、删除、限制处理、可携、反对或撤回同意请求，见[隐私政策](/privacy-policy/)第 9 节；本页不把现有摘要查询或清除功能扩张解释为完整数据下载。

自行部署者须盘点实际全部存储与接收者，不仅是 SQLite 磁盘区。保存设置本身不涵盖雷达、搜索数据、日志与备份；应落实必要期限及经验证的删除、隔离备份至到期清理，并在还原后重新套用删除记录。见[部署指南](/deployment/)第 3 节与[开源与自行部署法律](/open-source/)第 4 节。
