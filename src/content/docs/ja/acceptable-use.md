## 1. 適用範囲

1. ホスト型 Sonic ウェブプレイヤー、公開 API、ログイン、検索、再生、歌詞、推薦、その他の公開エンドポイントの利用行為に適用します。
2. 自己展開は独立したインスタンスです。展開者は自らのポリシー、設定、法律、ユーザー関係を判断すべきで、本ページはその運営・契約義務を代わりに引き受けません。
3. MIT はコードの複製、変更、配布、商用利用を許します。本ポリシーが保護するのはホスト型インスタンスとその資源であり、コードやすべての Sonic 展開の商用利用を一律に禁止しません。
4. 今回の確認では、ローカル音楽の音声 Blob をサーバーへアップロードする経路は見つかっていません。歌詞・推薦ではタイトル、アーティスト、アルバム、長さ、識別子を送る場合があります。[プライバシーポリシー](/ja/privacy-policy/)参照。

## 2. 禁止行為

### 2.1 システムとインターフェースの悪用

1. 他人のアカウント、セッション、Cookie、API Key、サービスキーを無断で取得・使用・共有すること、認証情報を偽造すること、ホスト型インスタンスの認証、レート制限、署名、SSRF 等のアクセス制御を回避すること。
2. ホスト型インスタンスの非公開エンドポイント、内部アドレス、認証情報を無許可で探査・悪用し、他人の私的データを取得・開示すること。公開検索候補を他人の情報の収集、暴露、確認に利用してはなりません。
3. 検索結果、歌詞、再生先、API 応答を大量取得し、無許可の転売、ミラー、データセットのため共有資源を占有すること。通常の個人再生、適度な API 利用、許可された接続は含みません。
4. ホスト型プロキシを汎用プロキシ、スキャナー、攻撃の踏み台として使い、または不要な同時接続、通信量、エラー、キャッシュ負荷を故意に生じさせること。

ソースコードの閲覧、自分のローカルインスタンスでの合成・許諾済みデータによるテスト、責任ある脆弱性報告は禁止しません。公開インスタンスの能動的な安全テストには事前に適切な許可を得て、他人への影響、データの取得、脆弱性の拡大を避けてください。`admin@epocanvas.com` に最小限の再現手順を非公開で提供でき、実際の認証情報を公開してはなりません。

### 2.2 コンテンツと権利

1. ホスト型サービスで海賊行為、課金・著作権保護の回避、著作権、商標権、肖像権、人格権、プライバシー等の権利侵害を実施・助長してはなりません。
2. サービスを利用して違法コンテンツ、マルウェア、児童性的搾取素材、違法なテロ宣伝を配布し、または他人の認証情報・個人データを違法・無許可で開示してはなりません。通常のログインや必要な非公開の権利行使要求を禁じるものではなく、ローカル音楽の取り込みも Sonic へのファイルアップロードではありません。
3. 他人や組織を装い、`Sonic`、`Epomail`、`EpoCanvas` の名称・ロゴで無許可の推奨、協力、安全認証を示唆してはなりません。
4. 他人の私的情報を含むと知りながら検索語、コメント、通報資料を提出してはなりません。公開コメントには他人の氏名、アバター、本文が含まれ得ます。localStorage へのコメント書き込みは投稿許可を得たことを意味しません。

### 2.3 他人の権利とサービスの安定

1. 運営者、上流提供者、貢献者、他のユーザーへの嫌がらせ、脅迫、名誉毀損、ストーキング、差別、攻撃をしてはならず、公開キャッシュや公開検索候補機能で他人の情報を暴露してはなりません。
2. ホスト型インスタンス、上流コンテンツ、認証サービス、ネットワークの可用性、完全性、安全性を妨害してはなりません。意図的なサーキットブレーカー、縮退、資源枯渇の発動も含みます。
3. 所在地の適用法に違反し、または上流サービスの規則に反する形でコンテンツ API を使ってはなりません。ライセンスが認めるコード利用は、第三者のコンテンツ、アカウント、音楽の権利を自動的に与えません。

## 3. 資源利用の上限

ホスト型インスタンスは、未認証・認証状態、IP、セッション、API、イベントバッチに応じてレート制限を設定できます。値は実際の設定によるもので、すべての展開への統一的な契約保証ではありません。超過時は `429`、遅延、拒否、一時制限があり得ますが、必ずしも違反を意味しません。

個人利用に合理的な頻度を守り、並列取得、反復リトライ、音声ストリームの長時間占有、不要なイベント送信を避けてください。制限、認証情報の失効、保存は環境変数、Compose、コード既定値の違いによって異なる場合があり、ページだけから運用状態を推定できません。

## 4. 措置の段階

運営者は行為の影響、意図、反復性、関係するデータ、緊急性に基づいて、以下の一つ以上を行い、必要な理由を記録できます。

1. 注意や行為停止の要求。
2. API、同時接続、キャッシュ、イベント送信等の資源利用の制限。
3. アカウント、セッション、認証情報、ネットワーク送信元の一時停止。失効の即時性はインスタンスの失効ストレージ、スイッチ、要求の成功に依存します。
4. ホスト型インスタンスへのアクセスの終了、または対象エンドポイントの継続利用の遮断。
5. 適用法の要求、有効な請求、他人やシステムの保護に必要な範囲での記録保存と、受領権限のある者への提供。

進行中の攻撃、認証情報の盗用、重大な脅威、明らかな違法コンテンツには、必要な暫定措置を先に講じ、後から説明と再審査を行えます。ポリシー上の措置は行為者の法的責任に代わらず、自動通報、固定保存期間、24時間の有人対応、全関連記録の永久削除を約束しません。

## 5. 申立てと通報

- **申立て**：制限、一時停止、終了に異議がある場合は、`admin@epocanvas.com` にアカウント、時刻、関係エンドポイント、理由を説明できます。運営者は資源が許す合理的な期間に再審査しますが、適用法上の期間、権利、救済は影響を受けません。固定期限、専任チーム、必ずアクセスを復旧することは約束しません。パスワード、完全なトークン、無関係な個人データを送らないでください。
- **通報**：悪用、権利侵害、安全上の問題、他人への危害の疑いは同じ窓口へ報告できます。必要な事実を提供し、違法・機微な素材は転送しないでください。運営者はリスク、データ最小化、適用法に従って措置や権限ある機関への開示を判断します。

プライバシーの権利、削除要求、データ侵害の連絡は `privacy@epocanvas.com` を使用してください。本ポリシーは実際のホスト資源だけを規律します。自己展開インスタンスは独自の運営者と申立て窓口を提供すべきです。
