## 1. 適用範囲

本ポリシーは、本サービスのあらゆる利用形態に適用されます。

1. ウェブプレイヤーの全機能（検索・再生・歌詞・レコメンド・ダウンロード・ローカル音楽取り込み）；
2. 公開 API 経由の接続。あなたが自建した第三者クライアントとスクリプトを含みます；
3. 自己ホストインスタンス（自己ホスト運営者は本ポリシーを修正して適用できますが、その所在地の法律の要求を下回ってはなりません）。

## 2. 禁止行動

### 2.1 システムとインターフェースの濫用

1. レート制限、署名検証、サーキットブレーカー、SSRF 対策、ドメイン許可リストその他の技術的保護措置の回避または破壊；
2. API キーの偽造、取り消し済み鍵識別子（jti）の再生攻撃、他人のセッションや鍵の盗用、またはいかなる方法による fail-closed 検証の回避；
3. 本サービスの機能と無関係な転售・再配布・ミラーデータセット構築を目的に、自動化スクリプトで検索結果・歌詞・再生アドレスを大量取得すること；
4. 本サービスの内部トポロジー、サービス間鍵、鍵素材、非公開エンドポイントの探索・走査その他の取得；
5. 本サービスのプロキシエンドポイント（`/api/music/stream`、`/api/sonic/forward` など）を、音楽再生と無関係な目標への汎用ネットワークプロキシとして利用すること。

### 2.2 コンテンツと権利

1. 本サービスのインターフェースを利用して、音楽プラットフォームの課金・著作権保護メカニズムを解読・回避・妨害すること；
2. 著作権・商標権・肖像権・人格権を侵害するコンテンツの拡散；
3. 児童性的搾取素材、テロ宣伝コンテンツを含む違法コンテンツのアップロード・拡散；
4. 他人または組織の名義・標章を冒用して活動すること、または `epocanvas`・`Sonic` の名称と標章を利用して本サービスが与えていない裏付けを示唆すること；
5. 違法ファイルをローカル音楽取り込みまたはダウンロード機能経由で配布するためにアップロードすること。

### 2.3 他人の権益

1. 本サービスまたは関連システムの正常な運転を妨害・破壊すること。サーキットブレーカーと降格メカニズムの意図的な発動を含みます；
2. 運営者、上流提供者、他の利用者への嫌がらせ、誹謗、攻撃；
3. あなたの所在地の法律または上流サービス規約に違反する用途への利用；
4. 本サービスのアクセスを販売、転貸し、または商業転售を目的に提供すること。

## 3. 資源利用の上限

| 項目 | 上限 | 超過時の処置 |
| --- | --- | --- |
| 匿名リクエスト | 毎分 240 回（既定値） | エッジ層で拒否（429）。違反として記録しません |
| 認証済みリクエスト | 毎分 600 回（既定値） | エッジ層で拒否（429）。継続的超過は執行段階へ |
| 認証エンドポイント（ログイン／鍵発行） | 毎分毎 IP 30 回 | エッジ層で拒否（429） |
| 行動イベント送信 | 1 バッチ最大 50 件、ボディ 64 KB | 上限超過のリクエストは全体として拒否 |
| 音声ストリーム | エッジプロキシ経由、またはあなたの能動的請求による直接モード | 異常な同時接続は執行段階へ |

通常の個人利用はこの上限に達しません。レート制限の目的は濫用防止とサービス安定であり、処罰ではありません。レート制限パラメータは展開者が設定でき、自己ホストインスタンスの実際値はその設定に従います。

## 4. 執行段階

運営者は違反を発見した場合、情節の軽重に応じて次の措置を適用し、各段階の処分理由を記録します。

1. **告知**：プレイヤー内で警告を表示し、理由を説明します；
2. **レート制限**：当該アカウントまたは鍵のリクエスト配額を引き下げます；
3. **停止**：当該アカウントのセッションと API キーを一時的に封鎖し（`jti` 取消リストまたは即時取消メカニズムによる）、データは当面保持します；
4. **利用終了**：利用権を終了します。行動データは保存期間（90 日、下限 7 日）の満了後に消去します；
5. **証拠保存と法的移送**：法律が要求する場合、必要な範囲で記録を保存し、法定手続きを通じて権限ある機関に提供します。

次の事態は段階的手続きを経ず、運営者は即時停止と移送・通報を行うことができます：児童性的搾取素材、テロ宣伝コンテンツ、進行中のシステム攻撃。

## 5. 申立てと通報

- **申立て**：処分に誤りがあると考える場合は、`admin@epocanvas.com` まで、処分対象のアカウントと事由を明記して申立てください。運営者は合理的期間内に再審し回答します。緊急処分（第4節のゼロトレランス事態）への申立ても同様に受理され、再審は誤判に対する救済を遅らせません。
- **通報**：本ポリシー違反を発見した方は、前記メールボックスまで通報してください。通報者の身元は、通報内容の確認が完了するまで秘密にされます。児童保護に関わる通報は当該秘密約束の制限を受けず、法定手続きに従って処理します。

本ポリシーに基づく運営者の処分は、違反行為者の法的責任を免除するものではありません。
