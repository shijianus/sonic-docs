**改訂日：2026年11月3日｜バージョン：1.9**

Sonic のアカウントの仕組みと、安全に利用するためのポイントを説明します。2026-11-02 に確認した最新の公開候補ブランチ（RC）`rc/sonic-20261031@a75f5cb`（2026-11-01 UTC）に基づく説明であり、正式な GitHub Release やオンラインでのデプロイを示すものではありません。稼働中のバージョンは不明です。旧 `main@ce443c8`（2026-10-27 UTC）には URL・ブラウザストレージで認証情報を扱う経路が残っており、以下の RC の state・PKCE、署名付き HttpOnly セッションや失効保護を同じように備えているとはいえません。RC のセッションは既定30日、OAuth の Cookie は約600秒で、サーバー側の失効は任意の KV 等の設定とリクエスト成功に依存します。技術的な実装の全体像は[データ処理とセキュリティ](/ja/data-security/)第3.2節、契約上のルールは[利用規約](/ja/terms-of-service/)第3節を参照してください。

## 1. ログイン方法

Epomail OAuth 2.0（PKCE）でログインし、独立した Sonic 登録はありません。サイドバーから Epomail 認可を経て戻り、state・PKCE 等の検証とレート制限があります。ログインは規約の有効な受諾や任意のプロファイリングへの同意ではなく、現在のログインフィールドでは年齢も確認できません。

## 2. セッションの仕組み

1. **セッション Cookie**：RC では、ログインに成功すると署名付きの HttpOnly セッション Cookie が発行され、既定の有効期間は30日です。HTTPS 環境では Secure が設定され、ローカル HTTP 環境では異なる場合があります。Cookie をスクリプトから直接読み取ることはできませんが、署名は暗号化ではありません；
2. **タブ間の同期**：同じブラウザのタブ間ではログイン状態が自動的に共有されます。いずれかのタブでログアウトすると、ほかのタブにも反映されます；
3. **保存の範囲**：API キーを URL や localStorage に保存しない設計と、ユーザー情報の保存は別です。`auth` localStorage はメール・アバター等を保持し、署名付きペイロードも暗号化ではありません。OAuth の Cookie は約600秒です。

## 3. API キーの管理

API キーは本人だけが使う認証情報です（形式 `sonic_live_v2.…`、HMAC-SHA256 署名）。

1. リクエストヘッダーでのみ送信し、URL に含めません；
2. 第三者に渡したり、公開するクライアントへ埋め込んだりしないでください；
3. 再発行には現在有効なキーが必要です。漏えいした可能性がある場合は直ちにログアウトし、取消しを依頼してください（第4節参照）。

## 4. 取消しとログアウト

| 操作 | 場所 | 効果 |
| --- | --- | --- |
| ログアウト | プレイヤー内 | 現在の Cookie を消去。複製済みキーの失効は設定と要求成功に依存 |
| キーの取消し | `POST /api/auth/revoke` | 失効保存先の設定と成功応答を確認。全展開で即時取消しが有効とは限らない |
| 一括無効化 | 展開者の設定 | jti リスト、主体リスト、発行時刻の全体的な下限を設定 |

## 5. 安全に利用するためのヒント

1. 共用端末ではログアウトし、必要に応じて `auth` を含むサイトデータも消去してください。Cookie 消去は複製済み認証情報の遠隔失効と同じではありません；
2. Epomail 側の設定で2段階認証を有効にすることをおすすめします；
3. 認証情報を共用しないでください。ただし認証情報の使用だけで全不正利用への反証不能な責任を負うわけではなく、責任は過失・事情・法律で判断します；
4. 見覚えのない再生履歴や不明なセッションに気付いたら、直ちにログアウトして `admin@epocanvas.com` へ連絡してください；
5. 本サービスはパスワードを収集しません。ログインは Epomail で行われるため、「Sonic のパスワード確認」を求める連絡はなりすましです。

## 6. アカウント管理の入口

サイドバー下部のアカウント入口にはログイン状態が表示されます。ログアウト中はログイン案内、ログイン後はアカウント名と、Epomail のプロフィール・受信トレイへ移動するアカウント管理リンクが表示されます。ログイン状態は同じブラウザのタブ間で自動的に共有されます。
