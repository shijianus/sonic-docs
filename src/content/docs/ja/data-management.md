**発効日：2026年11月2日｜バージョン：1.5**

Sonic で扱われるデータがどこに保存され、何を確認でき、どのような消去・請求の方法があるかをまとめます。本ページは、個人データ一式を完全に書き出せることを約束するものではありません。法的根拠と権利の枠組みは[プライバシーポリシー](/ja/privacy-policy/)第4、6、9節、技術的措置は[データ処理とセキュリティ](/ja/data-security/)を参照してください。

## 1. 保存場所の概要

| データ | 場所 | 身元との関連 | 保存期間 |
| --- | --- | --- | --- |
| お気に入り、プレイリスト、嗜好 | ブラウザの localStorage | アップロードなし | 消去するまで |
| 再生履歴 | ブラウザの localStorage | アップロードなし | 消去するまで |
| ダウンロードとローカル音楽 | ブラウザの IndexedDB | アップロードなし | 消去するまで |
| 行動イベント | サーバー側 SQLite（データプレーン） | 偽名化ハッシュ | 90日後に自動消去 |
| 全体集計統計 | サーバー側 SQLite | 個人と関連付けなし | データベースの保守に従う |
| 検索履歴（端末内） | ブラウザの localStorage | アップロードなし | 消去するまで |

メールアドレスなどのアカウント識別情報は、データベースに永続保存されず、セッション中だけ保持されます。データベースに IP アドレスの列はありません。

## 2. 照会：レコメンドプロファイルの概要

`GET /api/sonic/events` または設定ページのプロファイル欄から、サーバー上で現在関連付けられているプロファイルの概要を確認できます。表示されるのは、イベント総数、お気に入りと拒否の件数、よく聴くアーティスト、ジャンルの傾向、最近の検索語、保存形態です。この概要は個人データの完全なコピーでも、イベント一式の完全な書き出しでもありません。現在のプロファイルの範囲を確認するためのもので、イベントの全記録をダウンロードする機能はありません。

## 3. バックアップと請求の方法

1. **ブラウザデータ**：お気に入り、プレイリスト、ダウンロードはブラウザ内だけに保存されます。Sonic にはクラウドへの書き出し機能や、localStorage・IndexedDB を一般的にまとめてエクスポートする機能はありません。別の端末へ移す場合は、実際に利用できるブラウザの機能を確認したうえで、ご自身で内容を作り直すなどの方法を取ってください。一般的なエクスポートは保証されません；
2. **行動イベント**：サーバー側のイベントは偽名化して保存されますが、ダウンロードや書き出しの経路はありません。削除したい場合は第4節の消去操作を使ってください；
3. **ローカル音楽**：取り込む前の元ファイルは端末に残っています。ブラウザ内のコピーを削除しても、元ファイルは変わりません；
4. **手動請求**：その他のプライバシーに関する請求や消去の依頼は `privacy@epocanvas.com` へ連絡してください。対応は[プライバシーポリシー](/ja/privacy-policy/)第9節に従います。

## 4. 消去操作

| 操作 | 範囲 | 反映 |
| --- | --- | --- |
| レコメンドプロファイルと拒否記録をリセット | サーバー側のすべての行動イベント | 直ちに（`DELETE /api/sonic/events`） |
| 全ローカルデータの消去 | ブラウザの localStorage、sessionStorage、IndexedDB 全体とサーバー側プロファイル | 確認後、直ちに |
| ブラウザでサイトデータを消去 | 同上（ブラウザ側） | 直ちに |
| ログアウト | セッションとキー | 直ちに |

## 5. 自己ホストインスタンス

自己ホストインスタンスでは、データは展開者のデータプレーン（名前付き SQLite ボリューム）に保存されます。展開者は保存日数と保存先を設定できます（[展開ガイド](/ja/deployment/)第3節参照）。バックアップと告知の義務については[オープンソースと自己ホスト](/ja/open-source/)第4節にも記載しています。
