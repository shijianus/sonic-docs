Sonic で扱われるデータがどこに保存され、何を確認でき、どのような消去・請求の方法があるかをまとめます。機能説明は2026-11-02 に確認した最新の公開候補ブランチ（RC）`rc/sonic-20261031@a75f5cb`（2026-11-01 UTC）に基づきます。正式な GitHub Release ではなく、オンラインで稼働中のバージョンも不明です。旧 `main@ce443c8`（2026-10-27 UTC）では同じイベント保存・削除経路は確認できず、RC の保存期間や操作を適用できません。本ページは、個人データ一式を完全に書き出せることを約束するものではありません。法的根拠と権利の枠組みは[プライバシーポリシー](/ja/privacy-policy/)第4、6、9節、技術的措置は[データ処理とセキュリティ](/ja/data-security/)を参照してください。

## 1. 保存場所の概要

| データ | 場所 | 身元との関連 | 保存期間 |
| --- | --- | --- | --- |
| お気に入り、プレイリスト、嗜好 | 主に localStorage | 一部はフィードバック・推薦コンテキストとして送信。レーダーに遠隔同期経路あり | ローカルは消去まで。遠隔は別管理 |
| 再生履歴 | ブラウザ localStorage | ローカル履歴とは別に再生イベントが送られ得る | ローカルは消去まで。イベントは別管理 |
| ダウンロードとローカル音楽 | IndexedDB | 音声ファイル本体のアップロード経路は未確認。タイトル、アーティスト、アルバム、識別子、埋め込みカバー画像が送られ得る | ローカルは消去またはブラウザの回収まで。遠隔は別管理 |
| 行動イベント | サーバー SQLite | 仮名識別子も個人データになり得る | 既定90日、最低7日。起動・一部書き込み時に消去し、期限直後を保証しない  |
| 共有曲目カタログと外部インデックス | サーバーの曲目庫と任意の外部推薦・検索システム | イベントはタイトル、アーティスト、埋め込みカバーを含み、全サイト検索に返され得る | プロファイルリセットで完全には消去されず、関連付け可能性に応じて扱う |
| 検索集計・レーダー等 | サーバーストレージ | 検索原文は公開検索候補に出る場合があり、匿名とは限らない | 統一的な自動期限は未確認。既存の消去では未網羅 |
| 端末内の検索履歴 | localStorage | 別途検索要求・集計・推薦コンテキストが送られ得る | ローカルは消去まで。遠隔は別管理 |

`auth` localStorage はメールアドレスやアバターを保持し、署名付きセッションにもメール等が含まれ得ます。署名は暗号化ではありません。生 IP はレート制限の KV 等に入り、エンジンへの転送やインフラログもあり得るため、「アカウントはメモリのみ」「全体で IP を保存しない」とは言えません。

## 2. 照会：レコメンドプロファイルの概要

`GET /api/sonic/events` または設定ページのプロファイル欄から、関連機能が有効で、インスタンスがこの機能を提供する場合に限り、サーバー上のプロファイル概要を確認できます。オンラインでの提供状況は未確認です。表示されるのは、イベント総数、お気に入りと拒否の件数、よく聴くアーティスト、ジャンルの傾向、最近の検索語、保存形態です。この概要は個人データの完全なコピーでも、イベント一式の完全な書き出しでもありません。現在のプロファイルの範囲を確認するためのもので、イベントの全記録をダウンロードする機能はありません。

## 3. バックアップと請求の方法

1. **ブラウザデータ**：主な一覧とファイルはブラウザにあり、汎用エクスポートや永続的なクラウド復元は保証されません。レーダーの同期試行は全ライブラリのバックアップではありません。移行は利用可能な手段で行い、保存権限のある重要な原本を保持してください；
2. **行動イベント**：画面や API の概要は完全な写し・エクスポートではなく、リセットも一部だけです。共有曲目カタログ、検索、レーダー、外部サービス、旧識別子、バックアップは別途扱いが必要です。完全な写し、旧識別子の照合、遠隔削除は `privacy@epocanvas.com` に請求してください；
3. **ローカル音楽**：取り込む前の元ファイルは端末に残っています。ブラウザ内のコピーを削除しても、元ファイルは変わりません；
4. **手動請求**：その他のプライバシーに関する請求や消去の依頼は `privacy@epocanvas.com` へ連絡してください。対応は[プライバシーポリシー](/ja/privacy-policy/)第9節に従います。

## 4. 消去操作

| 操作 | 範囲 | 反映 |
| --- | --- | --- |
| プロファイルのリセット | 現在の識別子の一部イベント／フィードバック。旧匿名識別子、レーダー、集計、外部推薦、ログ、バックアップ等は未網羅 | `DELETE /api/sonic/events`。失敗が隠れる場合もあり成功表示は完全削除の証明ではない  |
| 全ローカルデータの消去 | localStorage、sessionStorage、IndexedDB と一部遠隔リセットの試行。HttpOnly Cookie は消さずログアウトではない | 完全な遠隔削除は保証せず、設定消去後の再読込で個人化が既定 ON に戻り得るため選択を再確認  |
| ブラウザでサイトデータを消去 | ブラウザ側のみ。遠隔は対象外 | ブラウザの対象範囲を確認。サーバー削除の代わりにはならない |
| ログアウト | 現在の Cookie。複製済み認証情報の失効は別 | サーバー失効は設定と要求成功に依存。`auth` の残存も確認 |

## 5. 自己ホストインスタンス

自己ホスト運営者は保存先、期間、ログ、レーダー、外部サービスを確認し実行可能な削除を整備する必要があります。バックアップを個別削除できない場合は隔離して通常利用を止め、明確な期限で消去し、復元時に削除記録を再適用すべきです。既存の自動処理の保証ではありません。[展開ガイド](/ja/deployment/)と[オープンソースと自己ホスト](/ja/open-source/)を参照してください。自己ホストのユーザーは、そのインスタンスの実際の運営者が公表する連絡窓口に請求してください。Sonic が提示する `privacy@epocanvas.com` は、すべての自己ホスト運営者または管理者の窓口ではありません。Sonic のホスト型インスタンスに関する権利請求は、[プライバシーポリシー](/ja/privacy-policy/)第9節を参照してください。
