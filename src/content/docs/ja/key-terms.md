## 1. 法的用語

| 用語 | 定義 |
| --- | --- |
| 個人データ | 特定または特定可能な自然人に関連するあらゆる情報（GDPR 第4条第1項）。Sonic ではログイン識別子・行動イベント記録などが該当します |
| 処理 | 個人データに対する収集・記録・保管・利用・伝送・削除などあらゆる操作（GDPR 第4条第2項） |
| 処理の制限 | 特定の情形において処理を一時停止し、データは保持する状態（GDPR 第4条第3項、第18条） |
| プロファイリング | 自動化処理により個人の特徴を評価し、それに基づく意思決定や分析を行う行為（GDPR 第4条第4項）。本サービスはレコメンド機能の必要範囲でのみ行い、ワンクリックで消去できます |
| 偽名化 | 追加情報がなければ特定の本人に帰属できないように処理すること（GDPR 第4条第5項）。Sonic は塩付き SHA-256 切詰めハッシュで実装します |
| データ管理者 | 処理の目的と手段を決定する自然人または法人（GDPR 第4条第7項）。ホストインスタンスは運営チーム、自己ホストは展開者 |
| 委託処理者 | 管理者のために個人データを処理する自然人または法人（GDPR 第4条第8項）。例：Cloudflare |
| 受領者 | 個人データが開示される自然人または法人（GDPR 第4条第9項）。第三者であるか否かを問いません |
| 第三者 | 本人、管理者、委託処理者および処理権限を授権された者以外の主体（GDPR 第4条第10項） |
| 同意 | 本人の自由意思による、明確に知悉した肯定的な意思表示（GDPR 第4条第11項、第7条）。同意の提供と同程度に容易な方法でいつでも撤回できます |
| データ漏洩 | セキュリティの不備により、個人データの偶発的または違法な破壊・消失・改ざん・無権限開示・接近を生じた事象（GDPR 第4条第12項） |
| 監督機関 | データ保護義務の履行を法的に監督する公権力機関（GDPR 第4条第19項）。EU の利用者は所在地の監督機関に申立てができます（GDPR 第77条） |
| 国際伝送 | EU と欧州経済領域外の第三国または国際機関への個人データの伝送（GDPR 第5章） |
| 特殊カテゴリのデータ | 人種・政治的意見・健康・性生活などを示すセンシティブな個人データ（GDPR 第9条）。本サービスは収集しません |
| 本人 | 個人データにより特定または特定可能な自然人（GDPR 第4条第25項）。すなわちあなたです |

## 2. 技術用語

| 用語 | 定義 |
| --- | --- |
| 制御プレーン | Cloudflare Pages Functions 上で動作するエッジゲートウェイ。ルーティング・レート制限・キャッシュ・サーキットブレーカーを担います |
| データプレーン | 運営者の自有 Linux ノード上の Docker Compose スタック。プロトコル解析・レコメンド計算・ストレージを担います |
| sonic-engine | データプレーンの本体コンテナ（Node.js 22）。サービス間鍵 X-Sonic-Engine-Key の検証を強制し、ホスト側はループバックにバインドします |
| ncm-api サイドカー | 内部ネットワーク限定の NetEase プロトコル補助コンテナ（`ncm-api:3000`）。compose 内部ネットワークからのみ到達可能です |
| OAuth 2.0 + PKCE | 認可コードフローに Proof Key for Code Exchange（S256）を加えたログイン方式。Epomail が本サービスのアイデンティティ提供者です |
| API キー | `sonic_live_v2.<header>.<payload>.<signature>` 形式の HMAC-SHA256 バージョン付き署名鍵。ペイロードは `sub`／`iat`／`exp`／`jti`／`kid`／`role`／`uid` を含み、リクエストヘッダーのみで伝送します |
| jti | API キー・ペイロード内の鍵識別子。取消リストとログアウト時の即時失効に使用します |
| fail-closed | 検証失敗時にサービスを拒否する安全方針。Sonic は無署名鍵・旧版鍵・本番ストレージ障害に対して fail-closed を採用します |
| SSRF 対策 | ループバックアドレス、RFC 1918 私設網、Docker ブリッジ、クラウドメタデータアドレスへの外向き通信の遮断。IPv4／IPv6 両スタック検証、リダイレクトのたびに再検証します |
| ドメイン許可リスト | 音声・カバー・転送プロキシは、管理された音楽 CDN ドメインリスト（`SONIC_ALLOWED_MUSIC_DOMAINS`）内の HTTPS 目標のみを許可します |
| SQLite WAL | データプレーンの行動イベント・実体重みの永続化ストレージ。Write-Ahead Logging モードで命名ボリューム `sonic-data` に保存します |
| サーキットブレーカー | 三状態ステートマシン（CLOSED／OPEN／HALF_OPEN）。連続 3 回の失敗または 4.5 秒予算の超過で作動し、30 秒冷却後にプローブします |
| エッジ降格モード | データプレーンのオフライン時に、エッジ層が公開歌詞・検索インターフェースへ直接接続する耐障害状態。応答は `X-Sonic-Degraded: 1` を標示し、画面に降格表示を表示します |
| エッジキャッシュ | `sonic:*` を鍵とするエッジキャッシュ。新鮮期間 8 分、失効後は容災延長状態です |
| Range 206 | HTTP の部分取得メカニズム。音声ストリームは既定でエッジプロキシが 206 Partial Content で応答します |
| 直接モード | `?mode=redirect` の 302 リダイレクト。あなたのブラウザが公式 CDN と直接接続します。ウェブプレイヤーは使用しません |
| YRC／QRC／KRC | NetEase・QQ・Kugou の文字単位歌詞フォーマット。暗号化・圧縮ラッパー（XOR + Deflate）を含めネイティブ解析します |
| TTML | AMLL 文字単位歌詞の時間軸マークアップ形式 |
| LRCLIB | 世界の公開同期歌詞ライブラリ。ローカル歌詞の欠落時の補完元です |
| 試聴検出 | 音声実体の長さとメタデータの検出により、公式 30 秒試聴の切詰めを識別し、常に透明に標示します |
| クロスソース補完 | 試聴トラックに対するクロスプラットフォーム全曲マッチング。既定有効で、成功時は代替ソースを標示します |
| 行動イベント | 再生・完聴・スキップ・お気に入り・拒否などのレコメンドシグナル記録。1 バッチ最大 50 件／64 KB。ノイズイベント（バッファ待ち、試聴切詰めによるスキップ）は保存しません |
| ワンクリックプロファイル消去 | `DELETE /api/sonic/events` により、レコメンドエンジン内のあなたの全行動特徴と記録を直ちに消去します |
| レコメンドプロファイル概要 | `GET /api/sonic/events` が返すプロファイル概要：イベント総数、お気に入りと拒否のカウント、よく聴くアーティスト、ジャンル傾向、最近の検索語、ストレージ形態 |
| X-Sonic-Context | レコメンドリクエストに随伴するクライアントローカルのコンテキスト（条数制限付きのお気に入り・最近のアーティスト・最近の検索語）。メモリ内でのみ使用しディスクに書き込みません |
| ノイズフィルタ | サーバー側が 6 類の非利用者原因の切替（network_stall／playback_error／trial_end／stream_unavailable／buffer_timeout／auto_switch_error）の重みをゼロにして保存しないメカニズム |

## 3. 解釈の基準

1. 法的用語は GDPR 公式テキストに、技術用語はソースコードの実装に拠って解釈します。ソースコードと本文書が一致しない場合はソースコードを優先し、本文書を修正してリポジトリの Issue に報告してください。
2. 本サイトの法ドキュメントは簡体字中国語版を正本とします。英語版・日本語版の訳語は本ページの対応関係に従います。
