## 1. 法的用語

| 用語 | 定義 |
| --- | --- |
| 個人データ | 識別された、または識別可能な自然人に関するあらゆる情報（GDPR 第4条第1項）。IP、Cookie、検索語、アバター URL、コメントの氏名や本文、関連付け可能な仮名識別子も該当し得ます。 |
| 処理 | 収集、記録、保存、照会、利用、移転、公開、制限、削除など、個人データに行うあらゆる操作（GDPR 第4条第2項）。 |
| 処理の制限 | 特定の状況でデータの利用を停止しながら、データ自体は保持すること（GDPR 第18条）。 |
| ユーザープロファイリング | 個人の特徴や行動の自動的な分析・評価。再生、検索、スキップ、お気に入り、拒否、コンテキストが推薦に使われ得ます。プロファイリングは、法的または同様に重大な影響を持つ決定と同義ではありません。 |
| 仮名化 | 追加情報なしでは特定の人に直接帰属させられない処理（GDPR 第4条第5項）。他の情報と組み合わせて識別できる場合があり、匿名化と同じではありません。 |
| データ管理者 | 単独または共同で処理の目的と手段を決定する自然人・法人（GDPR 第4条第7項）。ホスト型インスタンスでは実際の決定者に基づき判断し、コード作者、貢献者、運営者が同一とは限りません。 |
| 委託処理者 | 管理者に代わって個人データを処理する自然人・法人（GDPR 第4条第8項）。実際の目的、指示、取り決めに基づく役割であり、Cloudflare、Epomail 等が名称だけで自動的に該当するわけではありません。 |
| 受領者 | 個人データの開示を受ける自然人・法人（GDPR 第4条第9項）。ブラウザの直接接続で IP を受け取るサービスも受領者になり得ます。 |
| 第三者 | 本人、管理者、委託処理者、または管理者から処理権限を与えられた者以外の主体（GDPR 第4条第10項）。 |
| 同意 | 自由、特定、十分な情報に基づく、明確な肯定の意思表示（GDPR 第4条第11項、第7条）。与える時と同程度に容易な方法でいつでも撤回できます。ログイン、継続利用、既定 ON は任意のプロファイリングへの同意ではなく、同意記録がないことを理由に根拠のない処理の停止を拒めません。 |
| データ侵害 | 個人データの偶発的・違法な破壊、紛失、改変、不正開示、不正アクセスを生じさせる安全上の事象（GDPR 第4条第12項）。 |
| 管轄監督機関 | 法律に基づきデータ保護義務を監督する公的機関。GDPR 適用時は、本人は管轄機関に苦情を申し立てられます（GDPR 第77条）。 |
| 国際移転 | EU または欧州経済領域外の第三国・国際機関への個人データの移転。実際の場所、主体、保護措置で判断し、サーバー名から推定しません。 |
| 特別なカテゴリーのデータ | 人種・民族、政治的意見、宗教・哲学的信念、労働組合加入、遺伝情報、個人の一意識別を目的とする生体情報、健康、性生活、性的指向等を明らかにするデータ（GDPR 第9条）。音楽の好みや検索語も機微な特徴を間接的に示し得るため、一律に無リスクとは扱えません。 |
| 本人 | データが処理される、識別されたまたは識別可能な自然人。本ページの「あなた」は要求を行い、またはサービスを利用する関係する自然人を指します。 |

## 2. 技術・製品用語

| 用語 | 定義 |
| --- | --- |
| ホスト型インスタンス | プロジェクト運営者が実際にアクセスを提供する Sonic の展開。範囲、管理者、設定、連絡先は[プライバシーポリシー](/ja/privacy-policy/)を参照。 |
| 自己展開 | 他の人が運営する独立したインスタンス。展開者は管理者の身元、法律、設定、告知を独自に評価します。MIT コードの提供だけで本プロジェクトがその運営者になるわけではありません。 |
| 制御プレーン | ウェブページ、ルーティング、キャッシュ、レート制限、エッジ API を処理するコンポーネント。IP、Cookie、認証ヘッダー、User-Agent、パス、コンテキストに接する場合があります。 |
| データプレーン | エンジン、推薦計算、データベース、関連サービスを実行するコンポーネント。今回の監査では生 IP が Cookie、認証ヘッダー、コンテキストとともに転送され得るため、仮名データだけを受け取るとは言えません。 |
| Epomail OAuth | Epomail による PKCE を使う OAuth 2.0 ログイン。ユーザー識別子、メールと検証フラグ、ニックネーム、アバター URL、ロールを返す場合があります。 |
| API Key / `jti` | 署名と期限を持つ API 認証情報およびその一意識別子。署名検証は暗号化ではなく、Cookie、認証情報の複製、失効ストレージは別々に評価すべきです。 |
| fail-closed | 検証や必要なストレージが失敗した場合、黙って保護を弱めず要求を拒否すること。実環境で成立するかは設定の確認が必要です。 |
| SSRF 対策とドメイン許可リスト | 特定の内部ネットワーク、ループバック、クラウドメタデータ、リダイレクト、許可ドメインに対する送信チェック。ブラウザの直接接続やすべての上流 HTTP を網羅しません。 |
| SQLite / WAL | データプレーンの永続ストレージに使える SQLite と先行書き込みログ方式。プロファイル、ログ、バックアップ、レーダーがすべて同じデータベースや期間で削除される意味ではありません。 |
| サーキットブレーカー | 連続失敗やタイムアウト後、一時的に要求経路を変える仕組み。閾値、縮退、有効状態は実際の版と設定によります。 |
| 行動イベント | 再生、進捗、スキップ、お気に入り、拒否、検索、エンティティへのフィードバック等、推薦に使われ得るシグナル。バッチ上限、ノイズ除去、保存は版と設定によります。 |
| 公開検索候補 | 過去または統計上の検索語を他の訪問者に提供する経路。現在は検索原文の再利用によるリスクがあり、単に匿名集計とは呼べません。 |
| レーダー | ユーザーデータ・行動に基づく探索、推薦、同期機能と状態。現在は永続化エンジン経路が未確認で、同期や分離ストレージの試行があります。耐久的なデータベース記録の存在・不存在はいずれも約束できません。 |
| ローカル音楽 | ユーザー端末上のファイル・Blob。音声 Blob のサーバーアップロード経路は見つかっていませんが、歌詞照会や推薦でタイトル、アーティスト、アルバム、長さ、識別子が送られ得ます。 |
| ローカルコメント | 現在 localStorage に書かれる下書き・本文で、コメントサーバーへの投稿済みを意味しません。コメントの読み込みは他人の氏名、アバター、本文を取得し、公開キャッシュに入れる場合があります。 |
| 直接接続／プロキシ | プロキシはサーバーが代理要求し、直接接続はブラウザが CDN へ要求します。直接接続先にはブラウザの IP と接続情報が見え、ストリーム要求は固定値でなくブラウザの User-Agent を使う場合があります。 |
| バージョンと設定 | コードの既定値、`.env`、Compose、本番環境は異なる場合があります。GDStudio はコード上で未設定なら ON、環境や Compose では OFF にできます。実際の運用設定で検証すべきです。 |

## 3. 解釈の基準

1. 法的用語は実際に要件を満たす場合に用います。「個人プロジェクト」「無料」「オープンソース」は、管理者、委託処理者、同意、匿名化、安全上の適合性の同義語ではありません。
2. 技術用語はコード、実環境、提供者への要求経路を合わせて確認します。README の設計目標と文書が異なる場合、目標を保証と扱ってはなりません。コード、設定、ページが異なる場合は強い断定を止め、該当ページを修正すべきです。
3. 法律文書は簡体字中国語を維持管理基準とし、ほかの9言語は対照訳です。翻訳とルート版が異なる場合は速やかに同期すべきですが、強行法規と消費者の明確で理解しやすい説明を受ける権利は影響を受けません。
4. コードは MIT で公開され、本ページの定義はライセンスが許す複製、変更、配布、商用利用を制限しません。ホスト型インスタンスの[利用ポリシー](/ja/acceptable-use/)は、その実際のホスト資源とサービス上の行為だけを規律します。
