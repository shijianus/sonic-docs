## 1. お気に入りとコレクション

お気に入りには曲、プレイリスト、アルバム、アーティスト、MV がまとまり、主な一覧は localStorage の `library` に保存されます。ただしフィードバックや推薦コンテキストの一部は送られ得ます。汎用的な端末間同期・復元は約束されません。

## 2. 最近再生した項目

端末内の再生履歴は localStorage の `audio` に保存され、最大100曲を最近の再生から再生できます。再生履歴だけを止める独立したスイッチは見当たりません。この一覧とは別に再生・進捗・スキップ等のイベントが送られ得ます。未ログインやシークレットモードも無送信を保証しません。

## 3. ダウンロードリスト

曲の操作列または下部プレイヤーバーでダウンロードを選ぶと、曲と音質メタデータがブラウザの IndexedDB（`downloaded_music`）に保存されます。「ダウンロード」ページで管理でき、オフラインでも再生できます。ダウンロードはブラウザの保存容量を使用します。容量が足りない場合は新しいダウンロードが拒否されるため、古いダウンロードを削除するかブラウザの保存領域を整理してください。

## 4. ローカル音楽

ファイルを選択またはドロップすると、音声ファイル本体と埋め込みカバーは `local_music` に保存されます。音声本体のアップロード経路は見当たりませんが、埋め込みカバー画像はお気に入りイベントとともに共有曲目カタログへ送られる場合があります。歌詞照合、フィードバック、推薦でタイトル・アーティスト・アルバム・識別子も送られる場合があります。形式はブラウザに依存し、コピーを消しても原本は変わりません。取り込み・ダウンロードは既存の権利を拡張しません。

## 5. 保存場所の一覧

| 内容 | 保存場所 | ブラウザデータの消去で失われるか |
| --- | --- | --- |
| お気に入りとコレクション | localStorage（`library`） | はい |
| 再生履歴 | localStorage（`audio`） | はい |
| ダウンロードした曲 | IndexedDB（`downloaded_music`） | はい |
| ローカル音楽のコピー | IndexedDB（`local_music`） | はい |

保存権限のある重要な原本は自身でも保持してください。サイトデータ消去はローカル内容を失わせますが、遠隔イベント、レーダー、集計、バックアップ等の完全削除ではありません。アプリのローカル消去は HttpOnly Cookie を消さずログアウトでもなく、設定消去後の再読み込みは個人化を既定 ON に戻し得るため再確認してください（[データ管理](/ja/data-management/)参照）。
