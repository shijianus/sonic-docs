**発効日：2026年11月2日｜バージョン：1.5**

「マイミュージック」に含まれる4つの項目の管理方法と保存場所を説明します。これらのデータはすべて現在使用しているブラウザ内にのみ保存され、サーバーへアップロードされず、端末間でも同期されません。消去と問い合わせの方法は[データの管理と保存](/ja/data-management/)を参照してください。

## 1. お気に入りとコレクション

「お気に入り」には、好きな曲、保存したプレイリストとアルバム、フォローしたアーティスト、保存した MV がまとまります。曲の行、アルバムページ、アーティストページにあるハートボタンから操作できます。データはログインの有無にかかわらず、ブラウザの localStorage の `library` キーに直ちに保存されます。クラウド保存や端末間の同期は行いません。

## 2. 最近再生した項目

再生履歴はブラウザの localStorage の `audio` キーに自動的に保存され、「最近の再生」ページに新しい順で表示されます。項目をクリックするともう一度再生できます。履歴はこの端末にのみ保存され、サーバーとは同期されません。

## 3. ダウンロードリスト

曲の操作列または下部プレイヤーバーでダウンロードを選ぶと、曲と音質メタデータがブラウザの IndexedDB（`downloaded_music`）に保存されます。「ダウンロード」ページで管理でき、オフラインでも再生できます。ダウンロードはブラウザの保存容量を使用します。容量が足りない場合は新しいダウンロードが拒否されるため、古いダウンロードを削除するかブラウザの保存領域を整理してください。

## 4. ローカル音楽

「ローカル音楽」ページでは、クリックして音声ファイルを追加するか、ブラウザへドラッグ＆ドロップできます。取り込んだファイルは `local_music` に保存され、オンラインのライブラリと同じ画面で表示・再生できます。取り込みはブラウザ内で完結し、ファイルはアップロードされません。対応形式はブラウザのデコード機能によります。曲を削除してもブラウザ内のコピーが消えるだけで、元のファイルには影響しません。

## 5. 保存場所の一覧

| 内容 | 保存場所 | ブラウザデータの消去で失われるか |
| --- | --- | --- |
| お気に入りとコレクション | localStorage（`library`） | はい |
| 再生履歴 | localStorage（`audio`） | はい |
| ダウンロードした曲 | IndexedDB（`downloaded_music`） | はい |
| ローカル音楽のコピー | IndexedDB（`local_music`） | はい |

大切なプレイリストやダウンロードは、ご自身で控えを用意してください。ブラウザの「サイトデータを消去」または本サービスの「全ローカルデータの消去」を実行すると、上記の内容が削除されます（[データの管理と保存](/ja/data-management/)参照）。ローカル音楽の元ファイルは端末に残ります。
