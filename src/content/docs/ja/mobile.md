**改訂日：2026年11月3日｜バージョン：1.9**

スマートフォンのブラウザで Sonic を使うときのレイアウトとポイントを説明します。2026-11-02 に確認した最新の公開候補ブランチ（RC）`rc/sonic-20261031@a75f5cb`（2026-11-01 UTC）に基づく説明であり、正式な GitHub Release ではありません。旧 `main@ce443c8`（2026-10-27 UTC）とは実装が異なり、同じ機能を推定できません。オンラインで稼働中のバージョンは不明です。モバイル版とデスクトップ版は同じインスタンスとアカウントの仕組みを使い、機能も同等です。画面幅に応じて自動的にレイアウトが切り替わり、アプリをインストールする必要はありません。

## 1. レイアウトとナビゲーション

モバイル版では、デスクトップのサイドバーに代わって画面下部のタブナビゲーションを使います。入口はホーム、検索、最近の再生、設定の4つです。再生中は下部にミニプレイヤーバーが表示され、タップするとモバイル用プレイヤードロワー（`PlayerDrawerMobile`）が開きます。

## 2. プレイヤードロワー

モバイル用プレイヤードロワーでは、デスクトップ版と同じく、文字単位の歌詞（原文・翻訳・ローマ字）、音質メニュー、再生モード、ダウンロードを利用できます。ドロワーの背景はジャケットの基調色に合わせたグラデーションになり、再生位置の変更や歌詞への移動もスワイプで操作できます。

## 3. ホームとレーダー

モバイル版のホームはデスクトップ版と同じ構成です。カルーセル形式のおすすめ、スマートレコメンド、検索後に嗜好との一致を表示する音楽レーダー、おすすめプレイリストが並びます。おすすめの理由と嗜好シグナルのタグもモバイルで確認でき、カードは縦に並びます。

## 4. 保存と同期の範囲

主な一覧、ダウンロード、ローカル音楽はブラウザごとに保存され、ログイン状態も別です。音声ファイル本体のアップロード経路は見当たりませんが、埋め込みカバー画像、イベント、歌詞用メタデータ、推薦コンテキストは送られ得ます。レーダーに遠隔同期の試行経路はありますが、全データの永続的な端末間同期や復元は保証されません。

## 5. 利用時のヒント

1. サイトをホーム画面に追加すると、アプリに近い感覚で起動できます；
2. バックグラウンド再生はモバイルブラウザのメディアポリシーの影響を受けます。別のアプリへ切り替えるとシステムによって一時停止されることがありますが、ページに戻れば再開できます；
3. 省電力モードやデータセーバーによってバックグラウンド音声が制限される場合があります。これはブラウザの動作であり、本サービスの制限ではありません；
4. シークレットモードでは終了時にローカルデータが失われ得ますが、要求やイベント送信は止まりません。パーソナライズと Auto DJ の既定 ON は有効な同意ではありません。設定消去後は ON に戻り得るため選択を再確認し、[プライバシーポリシー](/ja/privacy-policy/)を参照してください。
