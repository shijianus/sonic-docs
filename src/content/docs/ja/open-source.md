## 2. プロジェクトの位置づけ

本プロジェクトは非商用のオープンソースプロジェクトです：検索・アグリゲーション・再生のツールであり、音楽ファイルを保存・ホスティングせず、課金回避の非正規コンポーネントを統合しません。本サービスの利用または自己ホスティングにあたっては、現地法、上流サービス規約、コンテンツ授権要件への適合を自ら確認してください（行動の境界は[受け入れ可能な利用ポリシー](/ja/acceptable-use/)を参照）。

## 4. 自己ホスト展開者の法的義務

自己ホスティングの時点から、展開者はその利用者のデータ管理者となります（役割の界定は[総覧](/ja/overview/)第2節を参照）。次を履行してください：

1. **告知義務**：利用者にデータ処理事項を告知します。本サイトの[プライバシーポリシー](/ja/privacy-policy/)を基礎テキストにできますが、自身の実際の設定に応じて加除修正する必要があります（無効の第三者リンクは告知から削除します）；
2. **記録と評価**：処理活動記録（GDPR 第30条）を維持し、高リスクの場合はデータ保護影響評価（GDPR 第35条）を実施します；
3. **セキュリティの維持**：[データ処理とセキュリティ](/ja/data-security/)第3節の措置を実装し、監督機関の監督を受けます；
4. **設定一致性**：環境変数の実際の値（保存日数、第三者スイッチ、レート制限）は、あなたのポリシーの約束と一致させなければなりません；
5. **管轄区域に応じた補完**：GDPR に加え、利用者の所在管轄区域に応じて UK GDPR、LGPD、CCPA-CPRA などの法定要件を補完します。

## 5. 本サイトドキュメントの採用

本サイトは「共通テンプレート + ホストインスタンス実文」の二本立て設計であり、自己ホスト運営者は本サイトの全ドキュメントを、自サイトの告知と規約の基礎として採用できます：

1. 身元情報の置換（ドメイン、連絡先メールアドレス、発効日とバージョン番号）；
2. 第三者リストと設定パラメータの開示が実情に合っていることの再確認；
3. 「簡体字中国語版を正本とする」を保持するか、あなたの正本とする言語に変更し、全文を一致させます；
4. 正式運用前に弁護士に相談してください。本サイトのドキュメントは法的意見を構成しません。
