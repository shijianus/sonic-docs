## 1. 適用範囲

本ポリシーは、本サービスの利用から生じる個人データ全般に適用されます。

1. 本サービスのサイト（`sonic.epocanvas.tech`、`sonic.epocanvas.com` または自己ホストインスタンスのドメイン）へのアクセス；
2. ウェブプレイヤーの全機能の利用（検索・再生・歌詞・レコメンド・ダウンロード・ローカル音楽取り込み）；
3. 公開 API 経由の第三者クライアントの利用。

本ポリシーは、本サービスがリンクまたは埋め込む第三者のサイトとサービス（上流音楽プラットフォームの自サイトなど）には適用されません。当該第三者には各自のプライバシーポリシーがあり、各自が責任を負います。Sonic を自己ホストする運営者は、展開の時点からその利用者のデータ管理者となり、その所在地の適用法上の告知義務を自ら履行します。本ポリシーはその告知の基礎テキストとして利用できます。

## 4. 収集する個人データ

### 4.1 アカウント識別データ（Epomail ログイン経由）

Epomail アカウントで OAuth 2.0（PKCE）によりログインすると、本サービスは Epomail の userinfo エンドポイントから次のフィールドを取得します。これ以外のアカウントデータは取得しません。

| フィールド | 用途 | ディスク保存 |
| --- | --- | --- |
| ユーザー識別子（`id`／`sub`） | セッション内の身元識別 | なし |
| 電子メールアドレス（検証済みが必要） | 偽名化ハッシュの派生。あなた本人に発行する API キーのペイロード内 `sub` クレーム | なし |
| ニックネームまたはユーザー名（`name`／`username`／`nickname`） | 画面表示 | なし |
| アバターリンク（`avatar`／`picture`） | 画面表示 | なし |
| アカウントロール（`role`） | 権限判定 | なし |

本サービスは独立した登録システムを設けず、電話番号・本名・住所・決済情報を収集しません。電子メールアドレスはログインセッション内で即時使用されるのみです。偽名化識別子（`usr_` 接頭辞の SHA-256 ハッシュ、16 進 12 文字に切詰め）、ユーザー識別ハッシュ、レート制限バケット鍵の派生に使用されます。派生されたハッシュ値から元の電子メールアドレスを復元することはできません。

### 4.2 行動イベント

レコメンドと Auto DJ 機能の提供のため、本サービスはトラック再生に関連する行動イベントを記録します。イベントタイプは 11 種類：検索・検索クリック・再生開始・再生進行・完聴・スキップ・リピート・お気に入り・お気に入り解除・拒否・拒否解除です。各イベントは次のいずれかの偽名化識別子で紐付けられます。

1. **ログインユーザー**：電子メールアドレスから派生した SHA-256 ハッシュ（`usr_` 接頭辞）；
2. **匿名参加者**：あなたのブラウザがローカルで生成したランダム識別子（`anon_` 接頭辞）をサーバー側で再ハッシュしたもの；
3. **公開モード**：パーソナライズが無効の場合、イベントは保存・永続化されず、サーバー側で直接廃棄されます。

イベント送信はバッチ方式です（1 バッチ最大 50 件、リクエストボディ上限 64 KB）。ページ非表示時に未送信キューを流し込みます。保存されるイベントの内容は、イベントタイプ、トラックの規範識別子、アーティスト識別子、ジャンルと言語タグ、検索語（該当時）、再生進行比率、シグナル重みに限られます。IP アドレス、デバイスフィンガープリント、自由記述内容は含みません。

ノイズと偽シグナルの浄化：ネットワーク遅延（network_stall）、デコード失敗（playback_error）、試聴切詰め（trial_end）、ストリーム不可（stream_unavailable）、バッファタイムアウト（buffer_timeout）、自動切替失敗（auto_switch_error）による切替は、重みが恒等的にゼロで保存されません。クライアントは、再生が正常で聴取時間が 0.5～25 秒の間の場合にのみ能動的スキップを送信します。

また、レコメンドリクエストにはクライアントローカルの少量のコンテキスト（条数制限付きのお気に入り・最近のアーティスト・最近の検索語）が随伴しますが、当該リクエストのメモリ内でのパーソナライズ順位にのみ使用され、ディスクに書き込まれず、ログにも入りません。

### 4.3 全体集計統計

本サービスは、いかなる利用者とも無関係な全体集計統計を、ヒートチャートと類似レコメンドのために別途維持します。

| 統計テーブル | 内容 | 個人との紐付け |
| --- | --- | --- |
| 検索語集計カウント | 検索語の全体頻度統計 | なし |
| トラック共起関係 | 一緒に聴かれたトラックの全体統計 | なし |

当該記録は個人識別子を含まず、あなたの身元と紐付けられず、「ワンクリックプロファイル消去」の範囲にも表示されません（そもそもいずれかの利用者に帰属しないためです）。

### 4.4 あなたのブラウザのローカルストレージ

次のデータはあなたのブラウザにのみ存在し、運営者のサーバーが完全なコピーを取得することはありません。ブラウザのシークレットモードでストレージが利用できない場合は、自動でメモリ内一時保存に降格します。

| 保存場所 | キー | 内容 |
| --- | --- | --- |
| localStorage | `audio` | プレイリスト、現在のトラック、再生モード、音量、ミュート状態、再生履歴 |
| localStorage | `library` | 好きな曲、お気に入りのプレイリスト、フォローアーティスト、好きな MV、お気に入りのアルバム、自建プレイリスト |
| localStorage | `global` | テーマ、言語設定、検索履歴（最大 10 件） |
| localStorage | `settings` | 画面設定（背景アニメーション、音質設定など） |
| localStorage | `recommend` | パーソナライズスイッチ、Auto DJ スイッチ、匿名識別子、拒否曲リスト |
| localStorage | `sonic-perf-mode` | パフォーマンスモードのスイッチ |
| IndexedDB | `SonicMusicPlayerDB` | 取り込んだローカル音楽ファイル（`local_music`）とダウンロード済みトラック（`downloaded_music`） |

### 4.5 自動処理される技術データ

- **レート制限**：匿名リクエストは IP バケットで制限します（毎分 240 回、既定値）。IP はレート制限鍵として一時的に使用されるのみです。エッジのネイティブ制限器はデータを保存せず、KV 記録は 120 秒で自動失効、メモリウィンドウは 60 秒（最大 4096 バケット）です。IP はデータベースにもアクセスログにも書き込まれません。認証済みリクエストは電子メールハッシュでバケット化し（毎分 600 回、既定値）、認証エンドポイントには毎分毎 IP 30 回の専用制限があります。
- **セッションと鍵**：ログイン後、`HttpOnly; Secure; SameSite=Lax` の `sonic_session` Cookie（最長 30 日）を発行し、署名済み API キーを含みます。鍵を URL・クエリパラメータ・localStorage に書き込むことはありません。OAuth 手続きには `sonic_oauth_state` と `sonic_oauth_verifier` トランザクション Cookie（600 秒有効、`/api/auth` パス限定）を使用します。API キーのペイロードは `sub`（電子メール）、`iat`、`exp`、`jti`、`kid`、`role`、`uid` を含みます。`jti` は取消リストとログアウト時の即時失効に使用します。
- **アクセスログ**：データプレーンのログは行区切り JSON で、リクエスト識別・メソッド・パス・ステータスコード・所要時間のみを含みます。クエリ文字列、IP、User-Agent、Cookie、Authorization、リクエストボディは記録しません。異常ログはリクエスト識別・エラー名・切詰めメッセージのみです。
- **音声プロキシ**：音声ストリームは既定で本サービスのエッジプロキシ経由で取得します。上流リクエストは User-Agent、CDN ごとの公式 Referer、Range ヘッダーのみを運び、Set-Cookie と認証ヘッダーは剥離します。上流 CDN にはプロキシサーバーのアドレスのみが見えます。あなたが能動的に `?mode=redirect` 直接モードを呼び出した場合、あなたのブラウザは公式 CDN と直接接続し、あなたの IP は当該 CDN から見えます（302 リダイレクトの固有の性質です）。ウェブプレイヤーはこのモードを使用しません。
- **エッジネットワーク**：Cloudflare は自社方針に従いネットワーク層のリクエストメタデータを処理します。

### 4.6 本サービスが収集しない項目

本サービスには、広告トラッキング、クロスサイト Cookie、第三者統計・分析スクリプト、デバイスフィンガープリント、行動広告プロファイルがありません。連絡先・フォトライブラリ・位置情報および音楽再生と無関係なデバイスデータは収集しません。個人データを販売せず、広告目的で利用せず、広告ネットワークに接続しません。

## 5. 法的根拠と処理の目的

各処理活動の法的根拠は次のとおりです。

| 処理活動 | 目的 | 法的根拠 |
| --- | --- | --- |
| Epomail ログイン・セッション維持・API キー発行と取消 | アカウント識別とサービス接続 | 契約の必要性（GDPR 第6条第1項第b号） |
| 行動イベントとレコメンドプロファイル（偽名化） | レコメンドと Auto DJ 機能 | 正当な利益（GDPR 第6条第1項第f号）。パーソナライズはいつでも無効化でき（第9節の反対権）、無効化後は直ちに収集を停止します |
| 全体集計統計 | ヒートチャートと類似レコメンド | 正当な利益（GDPR 第6条第1項第f号）。個人と紐付けられません |
| 匿名識別子イベント（匿名参加者） | レコメンド機能 | あなたの自主的選択。パーソナライズの無効化により終了します |
| IP レート制限・セッション保護・濫用防止 | サービスの安全と安定 | 正当な利益（GDPR 第6条第1項第f号）。該当する場合は法定義務でもあります（GDPR 第6条第1項第c号） |

あなたの個人データは、上記の目的と密接に関連する範囲でのみ利用されます。本サービスは、GDPR 第22条の意味における自動化意思決定（法的効果を生じ、または同様に重大に影響する意思決定）にあなたのデータを利用しません。レコメンドの影響はあなたが見る再生順序とチャート順位に限られ、いつでも無効化できます。

## 6. データの保存期間と消去

| データ区分 | 保存方針 |
| --- | --- |
| 行動イベント | 記録の日から 90 日で自動消去（展開者設定可能、下限 7 日）。書き込みカウントと起動時点で清理を発動。「ワンクリックプロファイル消去」で即時消去 |
| アカウント識別データ（電子メール・ニックネーム・アバターリンク・ロール） | ディスクに保存しません。セッション期間のみ存在 |
| セッション Cookie | 最長 30 日。ログアウトで即時失効 |
| OAuth トランザクション Cookie | 600 秒で自動失効 |
| レート制限カウンタ | ネイティブエッジ制限器は保存せず、KV 記録は 120 秒で自動失効、メモリウィンドウは 60 秒 |
| 鍵取消リスト | 展開者が設定した静的リスト（環境変数）または KV 即時取消記録 |
| データベースバックアップ | 偽名化行動データを含む一致性スナップショット。本番データと同等の保護が必要 |
| 全体集計統計 | 個人識別を含まず、データベース保守方針に従い処理 |
| ブラウザローカルストレージ | あなたのデバイスに残ります。消去するか「全ローカルデータの消去」を実行するまで |

## 7. 第三者との共有と国際伝送

本サービスは最小必要の原則に従い第三者と個人データを共有します。全情形は[第三者提供と国際伝送](/ja/sub-processors/)に掲載し、要旨は次のとおりです。

1. **委託処理**：Cloudflare（Pages ホスティング、Functions エッジ演算、Tunnel 暗号化トンネル、KV ストレージ、レート制限インフラ）；
2. **アイデンティティ提供者**：Epomail（ログイン時に識別子・電子メール・ニックネーム・アバターリンク・ロールを取得）；
3. **上流コンテンツソース**：NetEase・QQ・Kugou・Kuwo・AMLL・LRCLIB と各公式コンテンツ CDN。リクエストは歌曲クエリパラメータと固定 User-Agent／Referer のみを含み、あなたの身元や IP は含みません；
4. **法律の要求**：法定手続きによる権限ある機関の要求がある場合にのみ提供し、法律が許容する範囲であなたに通知します。

本サービスの制御プレーンは Cloudflare 世界エッジネットワークで動作するため、あなたの個人データは運営者所在国境外のノードで処理されることがあります。運営者は GDPR 第44条から第46条の保障メカニズム（EU 標準契約条項を含む）によりホスティング・委託処理関係を管理し、Cloudflare のデータ保護認証（SOC 2 Type II、ISO/IEC 27001）に依拠します。自己ホストの運営者は、その国際伝送がその所在地の法律の要求に適合することを自己評価・確保してください。

## 8. 児童の保護

本サービスは 16 歳未満の児童を対象とせず、児童の個人データを意図的に収集しません。あなたの所在地の法律が情報社会サービスの同意年齢をより低く定める場合（最低 13 歳、GDPR 第8条）はそれに従います。保護者が児童の個人データの提供を確認した場合は、運営者に削除を請求でき、確認後直ちに処理します。本サービスを利用して児童の身心健康に有害なコンテンツを拡散することはできません。関連する利用制限は[受け入れ可能な利用ポリシー](/ja/acceptable-use/)を参照してください。

## 9. 本人の権利と行使方式

あなたは個人データについて次の権利を享有します。

1. 接近とコピーの取得（GDPR 第15条）；
2. 訂正（GDPR 第16条）；
3. 消去（GDPR 第17条）；
4. 処理の制限（GDPR 第18条）；
5. データ可搬（GDPR 第20条）；
6. 反対（GDPR 第21条）。パーソナライズのいつでも無効化を含みます；
7. 自動化処理のみに基づく意思決定を受けない権利（GDPR 第22条）。本サービスはこの種の意思決定を行いません。
