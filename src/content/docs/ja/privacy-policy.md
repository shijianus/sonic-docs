本ポリシーの技術的事実は、本サービスのオープンソースコードの実際の実装に従います。本サイトの法ドキュメントは簡体字中国語版を正本とし、英語版と日本語版は対照訳とします。文義に疑義がある場合は正本に従います。本サービスは EU 一般データ保護規則（GDPR）を全利用者の最低限のデータ保護基準として適用します（第2節参照）。

## 1. 適用範囲

本ポリシーは、本サービスの利用から生じる個人データ全般に適用されます。

1. 本サービスのサイト（`sonic.epocanvas.tech`、`sonic.epocanvas.com` または自己ホストインスタンスのドメイン）へのアクセス；
2. ウェブプレイヤーおよび公開 API 経由の第三者クライアントの利用。

本ポリシーは、本サービスがリンクまたは埋め込む第三者のサイトとサービスには適用されません。当該第三者には各自のプライバシーポリシーがあり、各自が責任を負います。Sonic を自己ホストする運営者は、展開の時点からその利用者のデータ管理者となり、その所在地の適用法上の告知義務を自ら履行します。本ポリシーはその告知の基礎テキストとして利用できます。

## 4. 収集する個人データ

### 4.1 アカウント識別データ（Epomail ログイン経由）

Epomail アカウントで OAuth 2.0（PKCE）によりログインすると、本サービスは Epomail から、ユーザー識別子、電子メールアドレス（検証済みであることが必要）、ニックネーム、アバターリンク、アカウントロールを取得します。本サービスは独立した登録システムを設けず、電話番号・本名・決済情報を収集しません。

電子メールアドレスは本サービスのいかなるデータベースにも書き込まれません。その用途は次の二つに限られます：（a）その場で偽名化識別子とレート制限バケット鍵を派生させる SHA-256 ハッシュ；（b）あなた本人に発行する API キーのペイロード内の `sub` クレーム。派生されたハッシュ値から元の電子メールアドレスを復元することはできません。

### 4.2 行動イベント

レコメンドと Auto DJ 機能の提供のため、本サービスはトラック再生に関連する行動イベントを記録します。イベントタイプは、検索・検索クリック・再生開始・再生進行・完聴・スキップ・リピート・お気に入り・お気に入り解除・拒否・拒否解除です。各イベントは次のいずれかの偽名化識別子で紐付けられます。

1. **ログインユーザー**：電子メールアドレスから派生した SHA-256 ハッシュ（`usr_` 接頭辞）；
2. **匿名参加者**：あなたのブラウザがローカルで生成したランダム識別子をサーバー側で再ハッシュしたもの（`anon_` 接頭辞）；
3. **公開モード**：パーソナライズが無効の場合、イベントは保存・永続化されず、直接廃棄されます。

ネットワーク遅延・デコード失敗・試聴切詰めによるスキップイベントの重みは恒等的にゼロで、保存されません。また、レコメンドリクエストはクライアントローカルの少量のコンテキスト（条数制限付きのお気に入り・最近のアーティスト・最近の検索語）を運びますが、当該リクエストのメモリ内でのみ使用され、ディスクには書き込まれません。

### 4.3 全局集計統計

本サービスは、いかなる利用者とも無関係な全局集計統計（人気検索語のカウント、トラック共起関係）を、ヒートチャートと類似レコメンドのために別途維持します。当該記録は個人識別子を含まず、あなたの身元と紐付けられず、「ワンクリックプロファイル消去」の範囲にも表示されません（そもそもいずれかの利用者に帰属しないためです）。

### 4.4 あなたのブラウザのローカルストレージ

次のデータはあなたのブラウザにのみ存在し、運営者のサーバーが完全なコピーを取得することはありません。

| 保存場所 | 内容 |
| --- | --- |
| localStorage | プレイリストと再生履歴（`audio`）、お気に入りとフォロー（`library`）、テーマ・言語・検索履歴（`global`）、界面設定（`settings`）、パーソナライズスイッチと匿名識別子（`recommend`）、パフォーマンスモード（`sonic-perf-mode`） |
| IndexedDB | あなたが取り込んだローカル音楽ファイルとダウンロード済みトラック（`SonicMusicPlayerDB`） |

### 4.5 自動処理される技術データ

- **レート制限**：匿名リクエストは IP バケットで制限します（毎分 240 回）。IP はレート制限鍵として一時的に使用されるのみで（エッジのネイティブ制限器は保存せず、KV 記録は 120 秒で自動失効、メモリウィンドウは 60 秒）、データベースにもアクセスログにも書き込まれません。
- **セッション**：ログイン後、`HttpOnly; Secure; SameSite=Lax` のセッション Cookie（最長 30 日）を発行し、署名済み API キーを含みます。鍵を URL・クエリパラメータ・localStorage に書き込むことはありません。OAuth 手続きには 10 分間有効なトランザクション Cookie を使用します。
- **アクセスログ**：データプレーンのログは、リクエストパス・メソッド・ステータスコード・所要時間のみを含みます。クエリ文字列・IP・User-Agent・Cookie・リクエストボディは記録しません。
- **音声プロキシ**：音声ストリームは既定で本サービスのエッジプロキシ経由で取得され、上流 CDN にはプロキシサーバーのアドレスのみが見えます。あなたが能動的に `?mode=redirect` 直接モードを呼び出した場合、あなたのブラウザは公式 CDN と直接接続し、あなたの IP は当該 CDN から見えます（302 リダイレクトの固有の性質です）。

### 4.6 本サービスが収集しない項目

本サービスには、広告トラッキング、クロスサイト Cookie、第三者統計・分析スクリプト、デバイスフィンガープリントがありません。連絡先・フォトライブラリ・位置情報および音楽再生と無関係なデバイスデータは収集しません。個人データを販売せず、広告目的で利用しません。

## 5. 法的根拠と処理の目的

各処理活動の法的根拠は次のとおりです。

| 処理活動 | 目的 | 法的根拠 |
| --- | --- | --- |
| Epomail ログイン・セッション維持・API キー発行 | アカウント識別とサービス接続 | 契約の必要性（GDPR 第6条第1項第b号） |
| 行動イベントとレコメンドプロファイル（偽名化） | レコメンドと Auto DJ 機能 | 正当な利益（GDPR 第6条第1項第f号）。パーソナライズはいつでも無効化でき（第9節の反対権）、無効化後は直ちに収集を停止します |
| 全局集計統計 | ヒートチャートと類似レコメンド | 正当な利益（GDPR 第6条第1項第f号）。個人と紐付けられません |
| 匿名識別子イベント（匿名参加者） | レコメンド機能 | あなたの自主的選択。パーソナライズの無効化により終了します |
| IP レート制限・セッション保護・濫用防止 | サービスの安全と安定 | 正当な利益（GDPR 第6条第1項第f号）。該当する場合は法定義務でもあります（GDPR 第6条第1項第c号） |

あなたの個人データは、上記の目的と密接に関連する範囲でのみ利用されます。本サービスは、GDPR 第22条の意味における自動化意思決定（法的効果を生じ、または同様に重大に影響する意思決定）にあなたのデータを利用しません。レコメンドの影響はあなたが見る再生順序に限られ、無効化できます。

## 6. データの保存期間と消去

| データ区分 | 保存方針 |
| --- | --- |
| 行動イベント | 記録の日から 90 日で自動消去（展開者設定可能、下限 7 日）。「ワンクリックプロファイル消去」で即時消去 |
| アカウント識別データ（電子メール・ニックネーム） | ディスクに保存しません。セッション期間のみ存在 |
| セッション Cookie | 最長 30 日。ログアウトで即時失効 |
| レート制限カウンタ | ネイティブエッジ制限器は保存せず、KV 記録は 120 秒で自動失効、メモリウィンドウは 60 秒 |
| 全局集計統計 | 個人識別を含まず、データベース保守方針に従い処理 |
| ブラウザローカルストレージ | あなたのデバイスに残ります。消去するか「全ローカルデータの消去」を実行するまで |

## 7. 第三者との共有と国際伝送

本サービスは最小必要の原則に従い第三者と個人データを共有します。全情形は[第三者提供と国際伝送](/ja/sub-processors/)に掲載し、要旨は次のとおりです。

1. **委託処理**：Cloudflare（エッジコンピューティング・ホスティング・暗号化トンネル・レート制限インフラ）；
2. **アイデンティティ提供者**：Epomail（ログイン時に識別子・電子メール・ニックネーム・アバターリンク・ロールを取得）；
3. **上流コンテンツソース**：NetEase・QQ・Kugou・Kuwo・AMLL・LRCLIB など。リクエストは歌曲クエリパラメータと固定 User-Agent／Referer のみを含み、あなたの身元や IP は含みません；
4. **法律の要求**：法定手続きによる権限ある機関の要求がある場合にのみ提供し、法律が許容する範囲であなたに通知します。

本サービスの制御プレーンは Cloudflare 世界エッジネットワークで動作するため、あなたの個人データは運営者所在国境外のノードで処理されることがあります。運営者は GDPR 第44条から第46条の保障メカニズム（EU 標準契約条項を含む）によりホスティング・委託処理関係を管理し、Cloudflare のデータ保護認証（SOC 2 Type II、ISO/IEC 27001）に依拠します。自己ホストの運営者は、その国際伝送がその所在地の法律の要求に適合することを自己評価・確保してください。

## 8. 児童の保護

本サービスは 16 歳未満の児童を対象とせず、児童の個人データを意図的に収集しません。あなたの所在地の法律が情報社会サービスの同意年齢をより低く定める場合（最低 13 歳、GDPR 第8条）はそれに従います。保護者が児童の個人データの提供を確認した場合は、運営者に削除を請求でき、確認後直ちに処理します。

## 9. 本人の権利と行使方式

あなたは個人データについて次の権利を享有します。

1. 接近とコピーの取得（GDPR 第15条）；
2. 訂正（GDPR 第16条）；
3. 消去（GDPR 第17条）；
4. 処理の制限（GDPR 第18条）；
5. データ可搬（GDPR 第20条）；
6. 反対（GDPR 第21条）。パーソナライズのいつでも無効化を含みます。

行使方式：

1. **自助機能（即時効力）**：「レコメンドプロファイルの消去」はサーバー側の全行動イベントを即時消去します。「全ローカルデータの消去」はブラウザのローカルストレージと IndexedDB を即時消去します。レコメンドプロファイルの概要（イベント総数・お気に入りと拒否のカウント・よく聴くアーティストとジャンル・最近の検索語）は `GET /api/sonic/events` で照会できます。パーソナライズの無効化はイベント収集を直ちに停止します；
2. **人的請求**：その他の請求は `privacy@epocanvas.com` 宛に送付してください。運営者は受領後 1 か月以内に回答します（GDPR 第12条第3項）。

本サービスの処理があなたの権利を侵害したと考える場合は、運営者に救済を請求でき（GDPR 第79条）、運営者所在地の監督機関に申立てができます（GDPR 第77条）。EU と欧州経済領域の利用者は、常居住地・勤務地または侵害発生地の監督機関に申立てできます。

## 10. セキュリティ措置

運営者は GDPR 第32条に基づき、個人データの窃取・改ざん・破損・消失・漏洩を防止する適切な技術的・組織的措置を整備し、継続的に改善します。全経路 HTTPS/TLS、HMAC-SHA256 バージョン付き署名 API キー、PKCE OAuth フロー、セッション Cookie の HttpOnly／Secure／SameSite 属性と即時取消、データプレーンのループバック限定バインドと暗号化トンネル接続、全経路 SSRF 遮断、偽名化識別子、ログの最小化。完全なリストと既知の残余リスクの説明は[データ処理とセキュリティ](/ja/data-security/)を参照してください。

## 11. ポリシーの変更

本ポリシーは、サービスまたは法令の変動に伴い改定されます。重大な変更（第三者提供先の追加、保存方針や収集範囲の変更など）は、サイト内公告により事前に通知し、本ページ先頭の発効日とバージョンを更新します。変更の発効後に本サービスを継続利用した場合、改定後のポリシーに同意したものとみなされます。同意しない場合は利用を停止し、データを消去してください。歴次の重大改定はオープンソースリポジトリのバージョン記録に保存されます。
