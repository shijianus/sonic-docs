## 1. 製品の位置づけ

Sonic は独自開発のマルチソース音楽ストリーミングプラットフォームおよびアグリゲーションゲートウェイで、「Cloudflare エッジ制御プレーン + Linux ローカルプロトコルエンジン・データプレーン」の二層アーキテクチャで動作します。本プロジェクトはオープンソースソフトウェアであり、ソースコードは公開され、誰でも自己ホスティングできます。

| 項目 | 説明 |
| --- | --- |
| ホストインスタンス | `sonic.epocanvas.tech`（本サイト）と `sonic.epocanvas.com`（予備ミラー）。運営チームが運用します |
| 自己ホストインスタンス | オープンソースコードにより個人・団体が自有サーバーに展開する私有インスタンス。展開者がそのインスタンスの運営者かつデータ管理者となります |
| ソースライセンス | リポジトリルートの `LICENSE` ファイル（MIT License）に従います。本プロジェクトは非商用オープンソースとして位置づけられ、商標とブランドはソースライセンスに含まれません |
| ログイン | Epomail OAuth 2.0（PKCE）。独立した登録システムは持ちません |

## 2. システムアーキテクチャ

制御プレーン（Cloudflare Pages Functions）はルーティング、段階別レート制限（匿名 240 rpm、認証済み 600 rpm）、多層キャッシュ、三状態サーキットブレーカー（CLOSED／OPEN／HALF_OPEN）を担います。データプレーン（Linux ノード上の Docker Compose スタック）は sonic-engine 本体コンテナ、内部ネットワーク限定の ncm-api サイドカー、SQLite 3（WAL モード）永続化を動かします。データプレーンは Cloudflare Tunnel 暗号化チャネルで接続され、すべてのリクエストにサービス間鍵（X-Sonic-Engine-Key）の検証を強制します。

音源解析はローカルの純 TypeScript プロトコルモジュール（NetEase・QQ・Kugou・Kuwo の公式公開インターフェース）を主とし、歌詞チェーンは YRC／QRC／KRC の文字単位フォーマットをネイティブ解析し、AMLL TTML と LRCLIB が補完します。第三者無料アグリゲーション上流（GDStudio・Lyriva）は既定で厳格に無効です。音声ストリームは既定でエッジプロキシ経由で公式 CDN から HTTP Range 対応で取得され、運営者は 302 直接送出モードを有効化できます。

## 3. 中核機能

| 機能 | 説明 |
| --- | --- |
| マルチソース統合検索 | 簡体字・繁体字の正規化、ピンインと頭文字検索、別名対称マッチング、表記ゆれ許容。複数ソースの並列取得と正規化重複排除 |
| 文字単位ダイナミック歌詞 | NetEase YRC・QQ QRC・Kugou KRC のネイティブ解析、AMLL TTML と LRCLIB の補完、翻訳とローマ字対応 |
| 音質区分と試聴の透明性 | 完全版トラックと 30 秒試聴クリップを厳格に区分し、試聴を全曲と偽りません。試聴トラックのクロスソース補完は自動で発動できます（設定可能） |
| スマートレコメンドと Auto DJ | 再生・完聴・スキップ・お気に入り・拒否などの行動シグナルに基づくローカルレコメンドエンジン。シグナルの重みとノイズ除去規則はソースコードで公開 |
| ワンクリックプロファイル消去 | `DELETE /api/sonic/events` により、レコメンドエンジン内のあなたの全行動特徴と記録を即時に消去 |
| ゼロトラストセキュリティ | HMAC-SHA256 バージョン付き署名 API キー、PKCE OAuth、全経路 SSRF 対策、鍵はリクエストヘッダーのみで伝送 |

## 4. コンテンツと著作権の境界

Sonic は検索・アグリゲーション・再生のツールであり、音楽ファイルを保管・ホスティングしません。録音・歌詞・ジャケット・アーティスト画像などの権利は各自の権利者に帰属し、本プロジェクトは音楽コンテンツの再許諾を行いません。課金回避の非正規コンポーネントは統合しません。正規会員カタログは展開者が自有の認証情報でマウントし、公開カタログは公式の公開プロトコルに従います。

本サービスの利用にあたっては[受け入れ可能な利用ポリシー](/ja/acceptable-use/)を遵守してください。展開者はその利用形態が現地法・上流サービス規約・コンテンツライセンスに適合することを自己確認する責任を負います。
