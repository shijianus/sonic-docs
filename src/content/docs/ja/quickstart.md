**改訂日：2026年11月2日｜バージョン：1.8**

本ページでは、Sonic ホストインスタンス（`sonic.epocanvas.tech`）を利用するための最短経路を示します：サイトを開いてから検索・再生、ログイン、ローカルのお気に入り、ダウンロードとローカル音楽、モバイル利用まで。機能説明は2026-11-02 に確認した最新の公開候補ブランチ（RC）`rc/sonic-20261031@a75f5cb`（2026-11-01 UTC）に基づき、正式な GitHub Release ではありません。旧 `main@ce443c8`（2026-10-27 UTC）とは実装が異なり、同じ機能を推定できません。オンラインで稼働中のバージョンは不明です。画面の完全な案内は[画面と機能ガイド](/ja/interface/)にあります；本ページは自己ホスティングには触れません（展開は[展開ガイド](/ja/deployment/)を参照）。

## 1. ウェブサイトを開く

ブラウザで `sonic.epocanvas.tech`（予備 `sonic.epocanvas.com`）を開き、設定で言語やテーマを変更できます。基本の検索・再生は未ログインでも利用できますが、未ログインやシークレットモードは匿名・無収集を意味しません。

## 2. 検索と再生

1. 左サイドバー上部の検索ボックス（または「検索」ページ）に楽曲・アーティスト・アルバム・プレイリストのキーワードを入力します；検索は簡体字・繁体字の正規化、ピンイン頭文字、表記ゆれ許容に対応します；
2. 結果は「楽曲／プレイリスト／MV」の三タブに分かれます；楽曲をクリックすると再生が始まり、「すべて再生」で一覧を連続再生できます；
3. 下部プレイヤーバーには現在の曲、歌詞プレビュー行、音質バッジ（SQ ロスレスなど）が表示されます。カバーをクリックすると全画面プレイヤードロワーが開き、文字単位の歌詞（原文・翻訳・ローマ字）を個別に表示・非表示にできます。

30 秒試聴クリップに該当する楽曲では、プレイヤーが試聴であることを明示し、全曲と偽りません。既定で有効なクロスソース補完により、無料の全曲マッチングを自動で試みます。

## 3. ログインとローカルのお気に入り

Epomail アカウントにより OAuth 2.0（PKCE）でログインします。本サービスは独立した登録システムを持ちません：

1. サイドバー下部のログイン入口をクリックし、Epomail の認可ページへ移動して確認します；
2. お気に入り、プレイリスト、フォローの主な一覧は現在のブラウザに保存されますが、フィードバックや推薦コンテキストの一部は送信され得ます。汎用の端末間バックアップではありません；
3. パーソナライズと Auto DJ は最新公開 RC `rc/sonic-20261031@a75f5cb` で既定 ON です。ログインや既定値は任意のプロファイリングへの有効な事前同意ではありません。設定で無効化できますが、別経路の検索統計・公開検索候補や通常の通信まで止まりません。レーダーは遠隔同期を試みるものの、永続的な汎用クラウド同期は保証されません。

セッションは既定30日です。ログアウトの Cookie 消去と、複製された認証情報のサーバー失効は別で、後者は設定と要求成功に依存します。`auth` localStorage にメール等が残り、年齢も確認済みとはされません。[利用規約](/ja/terms-of-service/)第3節を参照してください。

## 4. ダウンロードとローカル音楽

1. **ダウンロード**：曲目の操作列または下部プレイヤーバーでダウンロードをクリックすると、楽曲は音質メタデータとともにブラウザの IndexedDB に保存され、「ダウンロード」ページで管理できます；オフラインでも再生できます；
2. **ローカル音楽**：音声ファイル本体と埋め込みカバーは IndexedDB に保存されます。音声本体のアップロード経路は見当たりませんが、埋め込みカバー画像はお気に入りイベントとともに送られ、歌詞照合、お気に入りフィードバック、推薦コンテキストでタイトル・アーティスト・アルバム・識別子も送られる場合があります；
3. 取得できても利用許諾が得られたとは限りません。許可された範囲で利用し、保護措置を回避しないでください。個人・非営利・学習目的は当然の著作権例外ではありません（[利用規約](/ja/terms-of-service/)参照）。

## 5. モバイルでの利用

スマートフォンでも同じ URL を利用し、下部タブとミニプレイヤー、歌詞を表示できます。主な一覧とファイルはブラウザごとに独立します。レーダーの同期経路は、全ライブラリの永続的な端末間同期・復元を保証しません。

## 6. プライバシー設定の最初の一歩

利用前に「設定 → プライバシーとローカルデータ」を確認してください。パーソナライズと Auto DJ が既定 ON であることだけでは適法な同意になりません。

1. **パーソナライズ**：無効化できますが、検索語の別集計・公開検索候補を含む全処理の停止スイッチではありません；
2. **自動連続ラジオ（Auto DJ）**：再生終了後の自動継続を制御します；
3. **リセット／ローカル消去**：現在の識別子の一部データのみで、旧匿名識別子、レーダー、集計、外部推薦、バックアップ等が漏れ、失敗が隠れる場合もあります。成功表示は完全な遠隔削除を証明しません。 アプリのローカル消去は HttpOnly セッション Cookie を消去せず、ログアウトでもありません。設定消去後の再読み込みでパーソナライズが既定 ON に戻り得るため、選択を再確認してください。

プライバシーに関する約束の完全な記述は[プライバシーポリシー](/ja/privacy-policy/)にあります。
