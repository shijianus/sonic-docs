**発効日：2026年11月2日｜バージョン：1.5**

本ページでは、Sonic ホストインスタンス（`sonic.epocanvas.tech`）を利用するための最短経路を示します：サイトを開いてから検索・再生、ログイン、ローカルのお気に入り、ダウンロードとローカル音楽、モバイル利用まで。画面の完全な案内は[画面と機能ガイド](/ja/interface/)にあります；本ページは自己ホスティングには触れません（展開は[展開ガイド](/ja/deployment/)を参照）。

## 1. ウェブサイトを開く

ブラウザで `sonic.epocanvas.tech`（予備ミラー `sonic.epocanvas.com`）にアクセスします。画面言語は既定でブラウザに従い、「設定 → 画面言語」で簡体字中国語、English、日本語を切替できます；テーマ（ライト／ダーク／システムに従う）も同じ場所で調整できます。ログインしなくてもすべての中核機能を利用できます。

## 2. 検索と再生

1. 左サイドバー上部の検索ボックス（または「検索」ページ）に楽曲・アーティスト・アルバム・プレイリストのキーワードを入力します；検索は簡体字・繁体字の正規化、ピンイン頭文字、表記ゆれ許容に対応します；
2. 結果は「楽曲／プレイリスト／MV」の三タブに分かれます；楽曲をクリックすると再生が始まり、「すべて再生」で一覧を連続再生できます；
3. 下部プレイヤーバーには現在の曲、歌詞プレビュー行、音質バッジ（SQ ロスレスなど）が表示されます。カバーをクリックすると全画面プレイヤードロワーが開き、文字単位の歌詞（原文・翻訳・ローマ字）を個別に表示・非表示にできます。

30 秒試聴クリップに該当する楽曲では、プレイヤーが試聴であることを明示し、全曲と偽りません。既定で有効なクロスソース補完により、無料の全曲マッチングを自動で試みます。

## 3. ログインとローカルのお気に入り

Epomail アカウントにより OAuth 2.0（PKCE）でログインします。本サービスは独立した登録システムを持ちません：

1. サイドバー下部のログイン入口をクリックし、Epomail の認可ページへ移動して確認します；
2. ログイン後、お気に入りの楽曲、お気に入りプレイリスト、フォローしたアーティストと自作プレイリストを利用できます（現在使用しているブラウザに保存され、クラウドや他の端末とは同期されません）；
3. ログインによりパーソナライズレコメンドと Auto DJ 連続再生も利用できます。いずれも「設定 → プライバシーとローカルデータ」で無効化できます。無効化後、レコメンドは公開情報だけのモードになり、行動イベントを記録しません。お気に入り、プレイリスト、設定は現在使用しているブラウザにのみ保存され、クラウドや他の端末とは同期されません。

セッションは最長 30 日有効で、ログアウトすると即時に無効になります。アカウントの規則は[利用規約](/ja/terms-of-service/)第3節を参照してください。お気に入り、プレイリスト、設定は端末間で同期されません。

## 4. ダウンロードとローカル音楽

1. **ダウンロード**：曲目の操作列または下部プレイヤーバーでダウンロードをクリックすると、楽曲は音質メタデータとともにブラウザの IndexedDB に保存され、「ダウンロード」ページで管理できます；オフラインでも再生できます；
2. **ローカル音楽**：「ローカル音楽」ページではクリックで追加するか、オーディオファイルをブラウザへドラッグ＆ドロップできます。取り込んだファイルも同様に IndexedDB に保存され、サーバーにはアップロードされません；
3. いずれも個人の聴取に限られ、再配布はできません（[受け入れ可能な利用ポリシー](/ja/acceptable-use/)参照）。

## 5. モバイルでの利用

スマートフォンのブラウザで同じアドレスにアクセスするとモバイルレイアウトになります。下部のタブナビゲーション（ホーム、検索、最近の再生、設定）とミニプレイヤーバーが表示され、プレイヤードロワーでは同じ文字単位の歌詞と音質メニューを使えます。お気に入り・プレイリスト・設定・ダウンロードは、モバイルとデスクトップでそれぞれ独立に保存されます（いずれも各ブラウザ内で、クラウド同期はありません）。

## 6. プライバシー設定の最初の一歩

初めての利用では、三つの制御項目を理解することをお勧めします（位置は「設定 → プライバシーとローカルデータ」）：

1. **スマート検索とパーソナライズレコメンド**：全体スイッチ。無効化後はイベントが収集されません；
2. **自動連続ラジオ（Auto DJ）**：再生終了後の自動継続を制御します；
3. **レコメンドプロファイルと拒否記録のリセット／全ローカルデータの消去**：即時に効く二つの削除ボタンです。

プライバシーに関する約束の完全な記述は[プライバシーポリシー](/ja/privacy-policy/)にあります。

## 7. よくある質問の早見表

| 質問 | 回答 |
| --- | --- |
| 有料ですか？ | 無料で、広告もアプリ内課金もありません |
| ログインしなくても使えますか？ | 中核機能は匿名で利用できます（レート制限は厳しめ） |
| データはどこに保存されますか？ | ブラウザローカル + サーバー側の偽名化行動イベント（90 日） |
| プロファイルはどう消去しますか？ | 設定 → レコメンドプロファイルのリセット。即時に効きます |
| なぜ 30 秒なのですか？ | 公式の試聴版が30秒で切られているためです。試聴であることを明示し、クロスソース補完を試みます |
| 音質の虚偽表示はありますか？ | バッジは現在のストリームの品質ランクを正確に反映します |

その他のご質問は[プロジェクト紹介](/ja/project/)第12節を、法律用語は[用語定義](/ja/key-terms/)を参照してください。
