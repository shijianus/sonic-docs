**改訂日：2026年11月2日｜バージョン：1.8**

Sonic の推薦シグナル、重み、並べ替え、制御方法を説明します。2026-11-02 に確認した最新の公開候補ブランチ（RC）`rc/sonic-20261031@a75f5cb`（2026-11-01 UTC）ではパーソナライズと Auto DJ が既定 ON ですが、正式な GitHub Release ではなく、オンラインで稼働中のバージョンも不明です。旧 `main@ce443c8`（2026-10-27 UTC）とは実装が異なり、同じ機能を推定できません。有効な事前同意を取得済みという意味ではありません。仮名識別子も個人データになり得ます。根拠と制約は[プライバシーポリシー](/ja/privacy-policy/)第4.2・5節を参照してください。

## 1. 行動シグナルと重み

| シグナル | 重み | 説明 |
| --- | --- | --- |
| favorite（お気に入りに追加） | +4.0 | 非常に強いプラス |
| replay（再度再生） | +3.5 | 強いプラス |
| play_complete（有効な再生完了） | +2.5 | 標準的なプラス |
| play_progress（再生の進み具合） | +0.2 ～ +1.8 | 聴いた割合に応じて段階的に加点 |
| skip（すぐにスキップ） | -0.8 | 半分以上聴いてからの曲変更は +0.25 として加点 |
| dislike（明確に拒否） | -5.0 | 利用可能な識別情報と機能の範囲内で一致するレコメンドのみを除外し、恒久的・全面的なブロックは保証しません |

**ノイズの除去**：ネットワーク停止（network_stall）、再生エラー（playback_error）、試聴終了（trial_end）、ストリーム利用不可（stream_unavailable）、バッファリングのタイムアウト（buffer_timeout）、自動切替エラー（auto_switch_error）による曲変更は、利用者がスキップしたものとは扱いません。重みは常に0で、保存もされません。

## 2. 人気度モデル

サイト内のトレンドランキングは、正常な再生（35％）、ユニーク視聴者（25％）、再生完了率（20％）、お気に入りへの転換（15％）、成長率（5％）の5要素を加重して算出します。さらに指数関数による時間減衰（24時間急上昇ランキングと7日間の累計ランキング）と、ベイズ／Wilson スコアによる平滑化を用い、再生数が少ないのに完了率だけ高い一時的な曲が不自然に上位へ来ることを抑えます。

## 3. セッションの意図と長期的な嗜好

ローカルの再生履歴は最大100曲、検索履歴は最大20件保存され、再生履歴だけを停止する独立したスイッチは見当たりません。パーソナライズを無効にしても、これらのローカル履歴や、要求コンテキストとして送られ得るデータが自動的に消えるわけではありません。推薦要求はお気に入り、最近のアーティスト、検索コンテキストを含む場合があり、検索原文は別途集計され公開候補に現れる場合があります。

## 4. 多様性のための並べ替えと Auto DJ

1. **類似度**：アーティストの関係グラフ、ジャンル・言語タグの集合類似度、音声特徴量のコサイン類似度を組み合わせます；
2. **MMR による並べ替え**：限界関連性によって「的確さ」と「新しさ」のバランスを取り、1人のアーティストや1つのジャンルだけに偏ることを避けます；
3. **Auto DJ**：プレイリストが自然に終わると、現在の曲のスタイルに応じて再生可能な曲を自動で続けます。設定から無効にできます。

## 5. 音楽・スタイルレーダー

レーダーは検索意図と嗜好に応じて表示し、エンティティへのフィードバックとプロファイルを扱います。パーソナライズを無効にしても、ログイン済みの同期処理が曲目、カバー、シグナルを含むペイロードを送信する場合があります。無効化標識によりサーバーが保存を拒否する場合でも、送信と保存は別です。既存のリセットや90日消去が全レーダーデータに及ぶとは限りません。

## 6. 利用者が変更できる項目

| 項目 | 場所 | 効果 |
| --- | --- | --- |
| パーソナライズ | 設定 → プライバシーとローカルデータ | 無効化しても Auto DJ の独立要求、別経路の検索統計・公開検索候補、通常の要求やレーダー送信までは停止しません |
| Auto DJ | 設定 → プライバシーとローカルデータ | 既定 ON の自動継続を制御。既定値はプロファイリングへの同意ではありません |
| プロファイルのリセット | 設定 → プライバシーとローカルデータ | 一部のみ削除。旧匿名識別子、レーダー、集計、外部推薦、バックアップ等が漏れ、失敗が隠れる場合もあります。設定全消去後は既定 ON の復帰にも注意 |
| 曲を拒否 | プレイヤー内の dislike | 利用可能な識別情報と機能の範囲内で一致するレコメンドのみを除外し、恒久的・全面的なブロックは保証しません |
