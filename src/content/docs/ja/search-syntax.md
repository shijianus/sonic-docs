**発効日：2026年11月2日｜バージョン：1.5**

Sonic の検索機能とルールをまとめます。どのような語を入力できるか、表記の違いをどう扱うか、検索結果がどう整理されるかを説明します。画面上の場所は[画面と機能ガイド](/ja/interface/)第2節を参照してください。

## 1. 検索対象

検索対象は、楽曲、アーティスト、アルバム、プレイリストの4種類です。結果画面は「楽曲／プレイリスト／MV」の3つのタブで構成されます。サイドバー上部と検索ページでは、サイト内でよく検索される語も候補として表示されます。

## 2. 表記ゆれと照合ルール

| ルール | 説明 | 例 |
| --- | --- | --- |
| 簡体字・繁体字の正規化 | 簡体字と繁体字の入力を同等に照合 | 「周杰伦」と「周杰倫」は同じ結果になる |
| ピンインと略称による検索 | ピンインの完全表記または頭文字の略称で照合 | 「zyy」で周杰伦に関連する曲が見つかる |
| 別名の相互照合 | アーティストの中国語名と英語名を相互に関連付ける | 英語名で検索して中国語名のアーティストを見つけられる |
| 編集距離による補正 | 編集距離に基づいて入力ミスを補正 | 近い文字列でも目的の結果が見つかる |
| バージョンの識別 | スタジオ版、ライブ版、カバーなどを区別 | 結果にバージョンを表示する |

## 3. 複数ソースへの並列検索と重複除去

検索リクエストは有効になっている上流ソースへ並列に送られ、結果は正規化して統合されます。同じ曲名・同じ楽曲の複数ソースの記録は1件にまとめ、再生時に利用可能な再生先を優先して取得します。上流ソースの一覧と既定のスイッチは[第三者提供と国際伝送](/ja/sub-processors/)第3節に記載しています。

## 4. 検索結果の操作

楽曲一覧の各行には、再生、MV（提供される場合）、お気に入り、ダウンロード、その他の操作があります。上部の「すべて再生」を押すと、結果の順番に連続再生します。プレイリストの結果からはプレイリスト詳細へ、MVの結果からはMV一覧へ移動します。

## 5. 検索とプライバシー

検索語は次のように処理されます。

1. **ローカル**：直近の検索語（最大10件）はブラウザの localStorage にのみ保存され、「全ローカルデータの消去」で削除できます；
2. **サーバー側の集計**：検索語は個人を識別しない全体集計に加えられ、人気検索語のランキングに使用されます；
3. **パーソナライズ**：パーソナライズを有効にしている場合、検索結果のクリックが偽名化されたレコメンド信号として90日間記録されます。無効にするとイベントは記録されません。

詳しくは[プライバシーポリシー](/ja/privacy-policy/)第4節と[レコメンドアルゴリズムの説明](/ja/recommendation/)を参照してください。
