Sonic の検索機能とルールをまとめます。どのような語を入力できるか、表記の違いをどう扱うか、検索結果がどう整理されるかを説明します。画面上の場所は[画面と機能ガイド](/ja/interface/)第2節を参照してください。

## 1. 検索対象

検索対象は、楽曲、アーティスト、アルバム、プレイリストの4種類です。結果画面は「楽曲／プレイリスト／MV」の3つのタブで構成されます。サイドバー上部と検索ページでは、サイト内でよく検索される語が候補として表示される場合があります。

## 2. 表記ゆれと照合ルール

| ルール | 説明 | 例 |
| --- | --- | --- |
| 簡体字・繁体字の正規化 | どちらの字形も試せますが、実際の照合はインデックスと上流ソースの可用性に依存します | 「周杰伦」と「周傑倫」を比較する |
| ピンインと略称による検索 | 完全なピンインまたは頭文字の略称を試せます。すべてのソースで結果が出るとは限りません | 「zjl」で周杰伦／周傑倫に関連する曲を試す |
| 別名の相互照合 | サイトが中国語名と外国語名を関連付ける場合があります。実際の結果はインデックスに依存します | 外国語名で検索して中国語名のアーティストを試す |
| 編集距離による補正 | 近い文字列が候補として扱われる場合があります。すべての入力ミスが補正されるわけではありません | 近い文字列を入力し、実際の結果を確認する |
| バージョンの識別 | スタジオ版、ライブ版、カバーなどを区別する場合があります | 結果に表示されたバージョンを確認する |

## 3. 複数ソースへの並列検索と重複除去

検索リクエストは、その時点で有効かつ利用可能な上流ソースへ送られ、正規化ルールに従って結果が統合されます。同じ曲名・同じ楽曲の複数ソースの記録は1件にまとめられる場合があり、再生時に利用可能な再生先を取得します。上流ソースの一覧と既定のスイッチは[第三者提供と国際伝送](/ja/sub-processors/)第3節に記載しています。

## 4. 検索結果の操作

楽曲一覧の各行には、再生、MV（提供される場合）、お気に入り、ダウンロード、その他の操作が表示される場合があります。上部の「すべて再生」は結果の順番に連続再生する場合があります。プレイリストの結果からはプレイリスト詳細へ、MV の結果からは MV 一覧へ移動します。実際の操作は結果とインスタンス設定に依存します。

## 5. 検索とプライバシー

検索語は次のように処理されます。

1. **端末履歴**：最近の履歴は localStorage に保存され得ますが、検索要求として送られ、推薦コンテキストに一部の履歴が伴う場合があります。端末で消去しても、すでに作成された遠隔コピーは削除されません；
2. **統計と公開検索候補**：検索原文が別途集計または保存され、公開検索候補に表示される場合があります。個人化を無効にしても、この経路がないとはいえません。個人・機微情報を含み得るため匿名とは限らず、入力しないでください。フィルタリング、表示閾値、保存管理、インスタンス設定は別途確認が必要です；
3. **パーソナライズ**：検索・クリックが仮名識別子に関連付けられ得ます。個人化の設定はすべての検索統計経路を制御しません。90日設定やリセット機能も、すべての検索集計やコピーが同じ予定で削除されることを意味しません。
