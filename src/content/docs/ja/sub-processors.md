## 1. 委託処理者（常時稼働）

| 提供先 | サービス内容 | 対象データ | 保障メカニズム |
| --- | --- | --- | --- |
| Cloudflare（Pages、Functions、Tunnel、KV、レート制限器） | エッジホスティング、ルーティング、キャッシュ、暗号化トンネル、レート制限インフラ | リクエストメタデータ、レート制限の一時記録（IP 鍵は 120 秒で失効）、セッション Cookie の処理 | GDPR 第28条の委託処理条項。SOC 2 Type II、ISO/IEC 27001。EU 標準契約条項 |

Cloudflare は委託処理者として、運営者の指示に従ってのみデータを処理します。Cloudflare が自社方針により処理するネットワーク層のリクエストメタデータについては、そのプライバシーポリシーの説明を参照してください。

## 3. 上流コンテンツソース（クエリ駆動、利用者の身元を含まない）

次の提供先が受けるリクエストは、歌曲クエリパラメータ、固定 User-Agent、対応公式サイトの Referer のみを含み、**あなたのアカウントデータ、Cookie、IP アドレスは含みません**。

| 提供先 | サービス内容 | 既定状態 |
| --- | --- | --- |
| NetEase Cloud Music（`music.163.com` など、データプレーン内部サイドカー含む） | 検索、再生アドレス、文字単位歌詞（YRC）、カバー | 有効 |
| QQ Music（`c.y.qq.com`、`u.y.qq.com`、`y.gtimg.cn` など） | 検索、再生アドレス、文字単位歌詞（QRC）、カバー | 有効 |
| Kugou Music（`mobilecdn.kugou.com`、`lyrics.kugou.com` など） | 検索、再生アドレス、文字単位歌詞（KRC） | 有効 |
| Kuwo Music（`www.kuwo.cn`、`search.kuwo.cn` など） | 検索、再生アドレス、カバー | 有効 |
| AMLL（`api.amll.dev`） | 文字単位歌詞（TTML）補完 | 有効 |
| LRCLIB（`lrclib.net`） | 同期歌詞補完 | 有効 |
| 各公式コンテンツ CDN（`music.126.net`、`ws.stream.qqmusic.qq.com` など） | 音声ストリームとカバー（既定で本サービスのエッジプロキシ経由で取得） | 有効 |

説明：

1. 上流リクエストの出口 IP は、展開者が設定したプレースホルダーアドレス（既定は RFC 5737 文書アドレス）であり、いかなる利用者の IP でもありません；
2. 音声ストリームは既定でエッジプロキシ経由で取得され、上流 CDN にはプロキシサーバーのアドレスのみが見えます。あなたが能動的に `?mode=redirect` 直接モードを呼び出した場合、あなたのブラウザは当該 CDN と直接接続し、あなたの IP は当該 CDN から見えます（302 リダイレクトの固有の性質です）；
3. 展開者は自有の会員認証情報（`NETEASE_COOKIE` など）でその認証カタログをマウントできます。当該認証情報は展開者のアカウントデータであり、エンドユーザーとは無関係です。

## 5. 法律の要求による共有

運営者は、リクエストが具体的な法的根拠を持つ場合にのみ個人データを提供します。リクエストの合法性と範囲を検証し、範囲を超える内容を自発的に提供せず、法律が許容する範囲で影響を受ける本人に事前に通知します（法令が通知を禁止する場合を除く）。本サービスは法的根拠のない恣意的な調取を受け付けません。法定請求による提供の全過程は記録します。

## 6. 国際伝送

本サービスの制御プレーンは Cloudflare 世界エッジネットワークで動作し、行動イベントは運営者のデータプレーンノードに保存されます。あなたの個人データは、運営者所在国境外のノードで処理されることがあります。伝送保障メカニズム：

1. GDPR 第44条から第46条に基づき、欧州委員会の十分性認定（第45条）または承認済みの標準契約条項（第46条第2項第c号）をホスティング・委託処理関係の基礎とします；
2. Cloudflare のデータ保護認証（SOC 2 Type II、ISO/IEC 27001）とそのデータ処理付添文書に依拠します；
3. 上流コンテンツソースへのリクエストは個人データを含まず、個人データの国際伝送を構成しません（第3節参照）。

自己ホストの運営者は、自らの展開形態における国際伝送を自己評価し、その所在地の法律の要求（GDPR 第5章またはその現地対応法制）への適合を確保してください。

## 7. リストの維持

1. 新しい共有先の追加前に、運営者は本ページに登記し、発効日とバージョンを更新します。重大な変更はサイト内公告により事前に通知します；
2. 本リストとソースコード設定が一致しない場合はソースコードを優先し、直ちに本ページを修正します；
3. 自己ホスト運営者は、自らの実際の設定に応じて自サイトの第三者リストを維持してください。有効化していない経路は告知から削除し、過剰開示と虚偽開示の両方を避けます。
