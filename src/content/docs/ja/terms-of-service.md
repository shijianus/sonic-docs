## 1. 定義

1. **本サービス**：ある Sonic インスタンス上で動作する全機能。ウェブプレイヤー、エッジゲートウェイ、ローカルプロトコルエンジン、公開 API および関連コンポーネントを含みます。
2. **運営者**：利用するインスタンスを展開・運用する個人またはチーム。ホストインスタンス（`sonic.epocanvas.tech`、`sonic.epocanvas.com`）は運営チーム、自己ホストインスタンスはその展開者を指します。
3. **あなた（利用者）**：ログインまたはその他の方法で本サービスを利用する自然人または組織。
4. **契約の成立**：どのインスタンスでログインしたかにより、そのインスタンスの運営者と契約が成立します。本規約は共通テンプレートであり、ホストインスタンスは直接適用し、自己ホスト運営者は修正のうえ自サイトの規約とし、その所在地の適用法に基づき利用者に告知義務を履行します。

## 2. サービスの説明

本サービスは、マルチソース統合検索、文字単位歌詞、音質区分再生、スマートレコメンドと Auto DJ 連続再生、行動イベント管理、エッジプロキシ音声ストリーミングなどの機能を提供します。実際に利用できる機能はインスタンスが有効化したものによります。本サービスは検索・アグリゲーション・再生のツールであり、音楽ファイルを保管・ホスティングしません。音声コンテンツは公式 CDN と上流の公開インターフェースから取得します。

本サービスはオープンソースプロジェクトを基盤とし、オープンソースを継続します。ソースコードは公開・監査可能で、自己展開により同等の能力を得られます。ソフトウェアは「現状有姿」で提供され、そのライセンスは本規約の責任条項と一致します（第10節）。

## 3. アカウントの取得と保護

1. **ログイン方式**：本サービスは Epomail アカウントによる OAuth 2.0（PKCE）でログインし、独立した登録システムを持ちません。Epomail とのアカウント関係は当該サービスの規約に従います。
2. **資格**：16 歳以上であることが必要です。あなたの所在地の法律が情報社会サービスの同意年齢をより低く定める場合（最低 13 歳）はそれに従い、児童の場合は保護者の同意が必要です。年齢はログインした Epomail アカウントの資料により確認し、本サービスは独立した年齢検証を設けません。
3. **認証情報の管理**：Epomail アカウントの認証情報、API キー、セッションの安全はあなたの管理責任です。あなたの認証情報により行われた操作は、あなた本人の行為と推定されます。
4. **セッションの仕組み**：ログイン成功後、`HttpOnly; Secure; SameSite=Lax` のセッション Cookie を発行します。API キーを URL・クエリパラメータ・localStorage に書き込むことはありません。いつでもログアウトでき、ログアウトは現在のセッションと対応する鍵識別子（jti）を直ちに取り消します。
5. **鍵の発行**：API キーは HMAC-SHA256 バージョン付き署名形式です。無署名または取り消し済みの鍵は一律に拒否します。鍵の再発行には現行の有効な鍵の提示が必要です。

## 4. サービスの提供と変更

1. **可用性**：運営者は合理的努力をもって可用性を維持しますが、特定の稼働率、バッファ速度、復旧時間を約束せず、サービス水準合意（SLA）も提供しません。
2. **降格メカニズム**：データプレーンノードのオフラインやタイムアウト時、エッジ層は自動で降格モード（公開歌詞・検索インターフェースへの直接接続）に切り替え、界面に降格提示を表示します。降格期間中は一部機能が利用できないことがあります。これは設計された耐障害動作であり、債務不履行ではありません。
3. **機能の変更**：オープンソースプロジェクトは継続的に発展し、機能は追加・調整・削除されることがあります。データ削除能力に関わる重大な変更は事前に公告します。
4. **保守と中断**：運営者はアップグレード・修復・濫用処分のため、一部または全部のサービスを一時停止できます。Cloudflare、上流音楽インターフェース、CDN の障害による利用不能は、運営者の債務不履行ではありません。

## 5. あなたのコンテンツと行動データ

1. **お気に入りと設定**：あなたが作成したお気に入り・プレイリスト・プレイヤー設定はブラウザのローカルストレージに保存されます。ブラウザデータの消去とともに削除され、運営者はその消失に責任を負いません。
2. **行動イベント**：レコメンド機能の提供のため、本サービスはあなたがトラックを再生・完聴・スキップ・お気に入り・拒否した際に行動イベントを記録します（シグナルの区分と重みはソースコードで公開）。「ワンクリックプロファイル消去」（または `DELETE /api/sonic/events`）により、いつでも全行動記録を直ちに消去できます。イベント送信を無効化するか、純ローカル／シークレット再生を利用すれば、新しいイベント記録は発生しません。
3. **コンテンツの責任**：あなたが能動的に提出したコンテンツ（カスタムプレイリスト名、API 呼び出し行為など）の責任はあなたにあり、当該コンテンツから生じる紛争と法的責任はあなたが負担します。
4. **音楽コンテンツ**：録音・歌詞・ジャケットなどの権利は各自の権利者に帰属します。本サービスは音楽コンテンツの再許諾を行わず、あなたの所在地で合法的に聴取する責任はあなた自身にあります。

## 6. 第三者のサービス

1. **上流音楽ソース**：検索・再生アドレス・歌詞は、NetEase・QQ・Kugou・Kuwo などの公式公開インターフェース、および AMLL・LRCLIB などの公開歌詞ライブラリから取得します。第三者インターフェースは変更・制限・停止されることがあり、運営者は上流の可用性を保証しません。
2. **エッジプロキシ**：音声ストリームは既定でエッジプロキシ経由で取得され、上流 CDN はあなたの IP アドレスを知りません。`?mode=redirect` 直接送出モードを能動的に利用した場合、あなたのブラウザは公式 CDN と直接接続します。
3. **認証**：Epomail は本サービスのアイデンティティ提供者であり、そのデータ処理は[第三者提供と国際伝送](/ja/sub-processors/)に記載します。

## 8. データの保存・削除と利用の終了

1. **あなたの終了**：いつでも本サービスの利用を停止できます。「ワンクリックプロファイル消去」で行動記録を消去し、ログアウトでセッションを取り消します。Epomail アカウント自体の解約は Epomail の規則に従います。
2. **行動記録**：行動イベントはデータプレーンの SQLite に保存され、削除・消去の請求時に直ちに消去されます。自動で長期の商業プロファイルを作成することはありません。
3. **運営者による終了**：[受け入れ可能な利用ポリシー](/ja/acceptable-use/)に違反した場合、運営者は当該ポリシーに従い利用権を停止・終了できます。
4. **法定保存**：法令または司法手続きにより保存が必要な場合、運営者は必要な範囲で削除を延期し、法定手続きに従って処理できます。
