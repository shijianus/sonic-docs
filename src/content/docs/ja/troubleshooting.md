**発効日：2026年11月2日｜バージョン：1.5**

よくある問題の見分け方と対処方法をまとめます。解決しない場合は `admin@epocanvas.com` へ連絡するか、GitHub リポジトリで Issue を報告してください。

## 1. 再生に関する問題

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 曲に「試聴」と表示され、30秒後に止まる | 公式の試聴版であり、故障ではない | クロスソース補完を有効にして無料のフルバージョンを自動検索するか、別のソースのバージョンを再生する |
| 音質バッジが低い段階を示す | 上流で実際に提供されている段階を表示している | 音質メニューで別の段階を試す。利用できる段階は上流の availability により変わる |
| 再生が途切れた後に続きから再生できない | 上流の直接再生 URL が期限切れになった | 曲をもう一度選び、再生先を再取得する |

## 2. 降格モード

画面上部に琥珀色の「エッジ降格モード」という表示が出た場合、データプレーンが一時的に停止しているか、応答がタイムアウトしています。エッジ層が公開 API へ直接接続するため、検索と歌詞は引き続き利用できますが、完全な音源解析やレコメンドの更新は制限されることがあります。通常は数十秒で自動復旧します（30秒の冷却後に稼働確認）。すでに読み込んだ曲には影響せず、ページを更新する必要もありません。

## 3. 検索に関する問題

1. **検索結果がない**：上流 API が一時的に利用できないことがあります。しばらく待って再試行してください。降格モードではエッジから公開 API へ直接検索するため、対象範囲が少し狭くなる場合があります；
2. **結果が重複する、または足りない**：複数ソースの重複除去は標準化された識別子で行います。上流のメタデータに問題があると統合できないことがあるため、検索語を添えて Issue を報告してください。

## 4. ログインに関する問題

1. **ログイン直後にログアウト状態へ戻る**：ブラウザが第三者 Cookie をブロックしているか、セキュリティ拡張機能が Cookie を削除している可能性があります。サイトを許可リストに追加して再試行してください；
2. **Epomail 側のアカウントが凍結されている**：ログインは中断されます。まず Epomail 側のアカウント状態を確認してください；
3. **共有端末で他の人が再生できる**：セッション Cookie は最長30日残ります。共有端末では利用後にログアウトしてください（[アカウントとセキュリティのガイド](/ja/account-security/)第5節参照）。

## 5. 保存に関する問題

1. **お気に入りやダウンロードが消えた**：ブラウザのサイトデータ消去やシークレットモードによってローカル保存が削除された可能性があります（[データの管理と保存](/ja/data-management/)第1節参照）。大切なプレイリストはご自身で控えてください；
2. **ダウンロードに失敗する**：ブラウザの保存容量がいっぱいです。古いダウンロードを削除するか保存領域を整理して、もう一度試してください；
3. **ローカル音楽を取り込めない**：ブラウザが対応していない形式か、ファイルが保存容量の上限を超えている可能性があります。

## 6. レート制限とエラーコード

| 症状 | 意味 | 対処 |
| --- | --- | --- |
| 429（匿名） | 匿名リクエストが毎分240回を超えた | ログインすると、より高い上限（毎分600回）を利用できます |
| 429（認証済み） | 毎分600回を継続的に超えている | クライアントがリクエストをループ送信していないか確認する |
| 501（取消し操作） | インスタンスで即時取消しが設定されていない | 展開者が KV またはリスト方式を設定する必要がある |
| ログアウトが繰り返される | キーが取り消されたか、発行時刻の全体的な下限が変更された | もう一度ログインして新しいキーを取得する |

## 7. 解決しない場合

Issue には、発生時刻、利用したページと操作、画面に表示された内容（降格表示ならスクリーンショット）、ブラウザ名とバージョンを添えてください。セッション Cookie や API キーは絶対に添付しないでください。
