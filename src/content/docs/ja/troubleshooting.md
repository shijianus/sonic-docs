機能説明は2026-11-02 に確認した公開候補ブランチ（RC）`rc/sonic-20261031@a75f5cb`（2026-11-01 UTC）に基づきます。旧 `main@ce443c8`（2026-10-27 UTC）とは実装が異なり、同じ挙動を推定できません。RC は正式な GitHub Release ではなく、オンラインで稼働中のバージョンと設定も不明です。

よくある問題と対処をまとめます。解決しない場合は `admin@epocanvas.com` または GitHub リポジトリの Issue を利用してください。報告には機微でない再現語だけを使ってください。公開検索文字列には個人情報や機微情報が含まれることがあります。

## 1. 再生に関する問題

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 曲に「試聴」と表示され、30秒後に止まる | 公式の試聴版であり、故障ではない | 画面にクロスソース補完がある場合は別のフルバージョンを試すか、別のソースのバージョンを再生する。ただし成功は保証されない |
| 音質バッジが低い段階を示す | 上流で実際に提供されている段階を表示している | 音質メニューで別の段階を試す。利用できる段階は上流の availability により変わる |
| 再生が途切れた後に続きから再生できない | 上流の直接再生 URL が期限切れになった可能性がある | 曲をもう一度選び、再取得を試す。復旧は保証されない |

## 2. 降格モード

画面上部の「エッジ縮退モード」は、データプレーンが停止またはタイムアウトし、代替経路を使用している可能性を示します。代替経路も失敗することがあり、検索・歌詞・再生は制限されるか利用できない場合があります。サーキットブレーカーの冷却後30秒は次の確認を行うための時間にすぎず、復旧を保証しません。すでにバッファリングされたコンテンツが続く場合もありますが、再生継続は保証されません。この表示から自動復旧や更新不要とは判断できません。

## 3. 検索に関する問題

1. **検索結果がない**：上流 API が一時的に利用できないことがあります。しばらく待って再試行してください。降格モードでは代替検索も失敗または利用不能になる場合があり、対象範囲が少し狭くなることがあります；
2. **重複・不足**：上流メタデータや照合が原因の場合があります。機微でない再現語だけで報告してください。公開検索文字列には個人情報や機微情報が含まれることがあるため、公開 Issue に原文を貼らないでください。

## 4. ログインに関する問題

1. **ログイン直後にログアウト状態へ戻る**：サイト自身のセッション Cookie を設定・保持できるか、拡張機能が削除していないか、HTTPS・OAuth コールバック URL・関連する OAuth 設定が一致しているかを確認してください。必要なら影響している拡張機能の設定だけを消去または無効化し、ブラウザの保護機能をすべて無効にしないでください；
2. **Epomail 側のアカウントが凍結されている**：ログインは中断されます。まず Epomail 側のアカウント状態を確認してください；
3. **共用端末**：確認した RC では、サイトのセッション Cookie の既定有効期間は30日です。これはオンラインの設定や、複製された認証情報その他のコピーの保存・失効期間を確認するものではありません。共用端末の利用後はログアウトしてください（[アカウントとセキュリティ](/ja/account-security/)参照）。

## 5. 保存に関する問題

1. **データの消失**：ブラウザ消去、容量回収、シークレットモード終了でローカルデータが失われ得ます。汎用クラウド復元は保証されず、シークレットモードもネットワーク要求やイベントを止めません。ローカル消去やリセット成功は完全な遠隔削除を証明しません（[データ管理](/ja/data-management/)参照）；
2. **ダウンロードに失敗する**：ブラウザの保存容量がいっぱいです。古いダウンロードを削除するか保存領域を整理して、もう一度試してください；
3. **ローカル音楽を取り込めない**：ブラウザが対応していない形式か、ファイルが保存容量の上限を超えている可能性があります。

## 6. レート制限とエラーコード

| 症状 | 意味 | 対処 |
| --- | --- | --- |
| 429（匿名） | RC の既定値である毎分240回の匿名上限を超えた。オンラインの設定は異なる場合があります | 画面の案内を確認して後で再試行するか、インスタンスの設定を確認する |
| 429（認証済み） | RC の既定値である毎分600回を継続的に超えている。オンラインの設定は異なる場合があります | クライアントがリクエストをループ送信していないか確認する |
| 501（取消し操作） | 対応する遠隔失効が設定されていない | ログアウトでブラウザ Cookie だけが消える場合がある。運営者に失効設定と複製された認証情報の拒否を確認してもらう |
| ログアウトが繰り返される | キーが取り消されたか、発行時刻の全体的な下限が変更された | もう一度ログインして新しいキーを取得する。実際の原因はインスタンスのログと設定で確認する必要がある |

## 7. 解決しない場合

公開 Issue には時刻、ページ、操作、ブラウザと版、必要なら秘匿情報を除いた表示のスクリーンショットを添え、機微でない再現語だけを使ってください。公開検索文字列には個人情報や機微情報が含まれることがあります。公開前にメールアドレス、個人情報やプロフィール情報、機微な検索語、セッション Cookie、API キー、スクリーンショット内の同じ情報を削除またはマスキングしてください。完全な削除やデータコピーの請求は公開 Issue ではなく `privacy@epocanvas.com` へ送ってください。リセット成功表示はすべての記録が削除された証明ではありません。
