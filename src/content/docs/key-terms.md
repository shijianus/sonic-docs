本页定义本站法律文档所用之法律名词与技术名词。同一用语于全部文档中含义一致；有定义者依定义解释，未定义者依其通常语义。法律名词以欧盟《通用数据保护条例》（GDPR）之定义为基础。

## 1. 法律名词

| 用语 | 定义 |
| --- | --- |
| 个人资料 | 与已识别或可识别自然人相关之任何信息（GDPR 第 4 条第 1 项）；在 Sonic 中例如登录标识符、行为事件记录 |
| 处理 | 对个人资料所为之任何操作，包括收集、记录、存储、使用、传输、删除等（GDPR 第 4 条第 2 项） |
| 处理限制 | 于特定情形下暂时停止处理、资料仍予保留之状态（GDPR 第 4 条第 3 项、第 18 条） |
| 用户画像 | 以自动化处理评估个人特征并据此决策或分析之行为（GDPR 第 4 条第 4 项）；本服务仅于推荐功能必要范围内为之，且您得一键清空 |
| 假名化 | 以额外信息方可识别特定当事人之方式处理个人资料（GDPR 第 4 条第 5 项）；Sonic 以加盐 SHA-256 截断哈希实现 |
| 数据控制者 | 决定处理目的与手段之自然人或法人（GDPR 第 4 条第 7 项）；托管实例为运营团队，自部署实例为部署者 |
| 受托处理者 | 为控制者处理个人资料之自然人或法人（GDPR 第 4 条第 8 项），例如 Cloudflare |
| 接收者 | 取得个人资料之自然人或法人（GDPR 第 4 条第 9 项），无论是否为第三方 |
| 第三方 | 当事人、控制者、受托处理者及经授权处理权限者以外之主体（GDPR 第 4 条第 10 项） |
| 同意 | 当事人依自由意思、明确知悉而作之肯定表示（GDPR 第 4 条第 11 项、第 7 条）；得随时以不低于给予时之便利方式撤回 |
| 资料外泄 | 导致个人资料被意外或非法破坏、丢失、篡改、未经授权披露或接近之安全事件（GDPR 第 4 条第 12 项） |
| 主管监督机关 | 依法监督资料保护义务履行之公权力机关（GDPR 第 4 条第 19 项）；欧盟用户得向其所在地之监督机关申诉（GDPR 第 77 条） |
| 国际传输 | 个人资料向欧盟与欧洲经济区以外之第三国或国际组织之传输（GDPR 第五章） |
| 特殊类别资料 | 揭示种族、政治观点、健康、性生活等敏感属性之个人资料（GDPR 第 9 条）；本服务不收集 |
| 当事人 | 个人资料所识别或可识别之自然人（GDPR 第 4 条第 25 项），即您 |

## 2. 技术名词

| 用语 | 定义 |
| --- | --- |
| 控制面 | 运行于 Cloudflare Pages Functions 之边缘闸道，负责路由、限流、缓存与熔断 |
| 数据面 | 运行于运营者自有 Linux 节点之 Docker Compose 堆叠，负责协议解析、推荐计算与存储 |
| sonic-engine | 数据面之主容器（Node.js 22），强制验证服务间密钥 X-Sonic-Engine-Key，宿主侧仅绑定回环地址 |
| ncm-api sidecar | 内网封闭之网易协议辅助容器（`ncm-api:3000`），仅经 compose 内部网络可达 |
| OAuth 2.0 + PKCE | 授权码模式加代码交换证明（S256）之登录流程；本服务以 Epomail 为身份提供方 |
| API Key | 格式 `sonic_live_v2.<header>.<payload>.<signature>` 之 HMAC-SHA256 版本化签名金钥；载荷含 `sub`／`iat`／`exp`／`jti`／`kid`／`role`／`uid`；仅经请求标头传递 |
| jti | API Key 载荷中之金钥识别码，用于撤销清单与登出即时失效 |
| fail-closed | 校验失败即拒绝服务之安全策略；Sonic 对无签名金钥、旧版金钥与生产环境存储故障均采 fail-closed |
| SSRF 防御 | 对回环地址、RFC 1918 私网、Docker 网桥与云端中继资料地址之出站拦截，IPv4／IPv6 双栈校验，重定向时重新校验 |
| 域白名单 | 音频、封面与转发代理仅允许受控音乐 CDN 域名清单（`SONIC_ALLOWED_MUSIC_DOMAINS`）内之 HTTPS 目标 |
| SQLite WAL | 数据面行为事件与实体权重之持久化存储，采 Write-Ahead Logging 模式，落于命名卷 `sonic-data` |
| 熔断器 | 三态状态机（CLOSED／OPEN／HALF_OPEN）；连续 3 次失败或超过 4.5 秒预算进入熔断，冷却 30 秒后探活恢复 |
| 边缘降级模式 | 数据面离线时，边缘层直接连接公开歌词与检索接口之容灾状态；响应标头标明 `X-Sonic-Degraded: 1`，界面显示降级提示 |
| 边缘缓存 | 以 `sonic:*` 为键之边缘缓存，新鲜期 8 分钟，过期后进入容灾延长状态 |
| Range 206 | HTTP 分段加载机制；音频流默认经边缘代理以 206 Partial Content 回应 |
| 直连模式 | `?mode=redirect` 之 302 重新导向，由您的浏览器与官方 CDN 直接建立连接；网页播放器不使用 |
| YRC／QRC／KRC | 网易、QQ、酷狗之逐字歌词格式；本服务原生解析其加密与压缩封装（XOR + Deflate） |
| TTML | AMLL 逐字歌词之时间轴标记语言格式 |
| LRCLIB | 全球开放同步歌词库，作为本地歌词缺失时之补位来源 |
| 试听侦测 | 对音频实体长度与元数据之探测，识别官方 30 秒试听截断并以标识明示 |
| 跨源补齐 | 试听曲目触发之跨平台全曲匹配机制，缺省开启，匹配成功即标明替代来源 |
| 行为事件 | 播放、完播、跳过、收藏、拒绝等推荐信号记录；单批至多 50 条、64 KB；噪声事件（卡顿、试听截断切歌）不入库 |
| 一键清空画像 | `DELETE /api/sonic/events` 立即销毁您在推荐引擎中之全部行为特征与记录 |
| 推荐画像概览 | `GET /api/sonic/events` 返回之画像摘要：事件总数、喜爱与拒绝计数、常听歌手、流派倾向、最近搜索词、存储形态 |
| X-Sonic-Context | 推荐请求随附之客户端本地上下文（限条数之收藏、最近艺人、最近搜索词），仅内存使用不落盘 |
| 噪声过滤 | 服务端对 6 类非用户原因切歌（network_stall／playback_error／trial_end／stream_unavailable／buffer_timeout／auto_switch_error）权重归零不入库之机制 |

## 3. 解释基准

1. 法律名词之解释以 GDPR 官方文本为基准；技术名词之解释以源码实现为准，源码与本文档不一致时，应修正文档并向代码库提报 Issue。
2. 本站法律文档以简体中文版本为正式版本；英文与日文版本中术语之译名以本页对应关系为准。
