## 1. 法律名词

| 用语 | 定义 |
| --- | --- |
| 个人数据 | 与已识别或可识别自然人有关的任何信息（GDPR 第 4 条第 1 项）。IP、Cookie、搜索词、头像 URL、评论中的姓名或文字，以及可关联的假名标识，均可能属于个人数据。 |
| 处理 | 对个人数据进行的任何操作，包括收集、记录、存储、查询、使用、传输、公开、限制或删除（GDPR 第 4 条第 2 项）。 |
| 处理限制 | 在特定情形下暂停数据的使用，同时保留数据（GDPR 第 18 条）。 |
| 用户画像 | 对个人特征或行为进行自动化分析或评估。播放、搜索、跳过、收藏、拒绝和上下文可能用于推荐；画像不等于具有法律或类似重大影响的决定。 |
| 假名化 | 不使用额外信息就不能直接归属于某人的处理方式（GDPR 第 4 条第 5 项）。假名化数据仍可能被结合识别，不等于匿名化。 |
| 数据控制者 | 单独或共同决定处理目的和方式的自然人或法人（GDPR 第 4 条第 7 项）。托管实例由实际决定处理目的和方式的人或组织判断；代码作者、贡献者和运营者不必是同一主体。 |
| 受托处理者 | 代表控制者处理个人数据的自然人或法人（GDPR 第 4 条第 8 项）。是否属于该角色要看实际目的、指示和安排；Cloudflare、Epomail 或其他供应商不因名称自动成为受托处理者。 |
| 接收者 | 向其披露个人数据的自然人或法人（GDPR 第 4 条第 9 项）。浏览器直连收到 IP 的服务也可能是接收者。 |
| 第三方 | 不是当事人、控制者、受托处理者或经控制者授权处理人员的主体（GDPR 第 4 条第 10 项）。 |
| 同意 | 自由、特定、知情且明确的肯定表示（GDPR 第 4 条第 11 项、第 7 条），可随时以不难于给予时的方式撤回。登录、继续使用或默认开启不构成可选画像同意；不能以缺少同意记录为由拒绝停止无依据的处理。 |
| 数据泄露 | 导致个人数据意外或非法破坏、丢失、改变、未经授权披露或访问的安全事件（GDPR 第 4 条第 12 项）。 |
| 主管监督机关 | 依法监督数据保护义务的公权力机关。适用 GDPR 时，当事人可向有管辖权的机关投诉（GDPR 第 77 条）。 |
| 国际传输 | 向欧盟或欧洲经济区以外第三国或国际组织传输个人数据；须按实际地点、主体和保障判断，不以服务器名称推定。 |
| 特殊类别数据 | 揭示种族或民族、政治观点、宗教或哲学信仰、工会成员、遗传数据，或用于唯一识别自然人的生物识别数据、健康、性生活或性取向等数据（GDPR 第 9 条）。音乐偏好和搜索词也可能间接揭示敏感特征，不能一概当作无风险。 |
| 当事人 | 被处理的已识别或可识别自然人；本页用“您”指称提出请求或使用服务的相关自然人。 |

## 2. 技术与产品名词

| 用语 | 定义 |
| --- | --- |
| 托管实例 | 项目运营者实际提供访问的 Sonic 部署；适用范围、控制者、配置和联系方式见[隐私政策](/privacy-policy/)。 |
| 自行部署 | 由其他人运行的独立实例。部署者独立评估控制者身份、法律、配置和告知；本项目不因提供 MIT 代码而成为其运营者。 |
| 控制面 | 处理网页、路由、缓存、限流或边缘 API 的部署组件；可能接触 IP、Cookie、认证头、User-Agent、路径和上下文。 |
| 数据面 | 运行引擎、推荐计算、数据库和相关服务的组件。当前审计发现原始 IP 可能随 Cookie、认证头或上下文转发到引擎，不能称其为只收假名数据。 |
| Epomail OAuth | 通过 Epomail 进行的 OAuth 2.0 登录流程，使用 PKCE；可能返回用户标识、邮箱及其验证标记、昵称、头像 URL 和角色。 |
| API Key / `jti` | 带签名和期限的 API 凭证及其唯一标识。签名验证不是加密；Cookie、凭证复制和撤销存储应分别评估。 |
| fail-closed | 校验或必要存储失败时拒绝请求，而不是静默降级；是否在实际环境成立须核对配置。 |
| SSRF 防御与域白名单 | 对特定内网、回环、云元数据地址、重定向或允许域的出站检查；不覆盖浏览器直连和所有上游 HTTP。 |
| SQLite / WAL | 可作为数据面持久化存储的 SQLite 数据库及其写前日志模式；不代表画像、日志、备份或雷达数据均在同一库或同一期限删除。 |
| 熔断器 | 在连续失败或超时后暂时改变请求路径的机制；阈值、降级和是否启用由实际版本与配置决定。 |
| 行为事件 | 播放、进度、跳过、收藏、拒绝、搜索或实体反馈等可能用于推荐的信号。单批限制、噪声过滤和保存方式依版本与配置。 |
| 公共搜索建议 | 将历史或统计搜索词提供给其他访客的功能路径。当前存在复用原始搜索词的风险，不能仅称为匿名聚合。 |
| 雷达 | 根据用户数据或行为产生的探索、推荐或同步功能及其状态。当前未确认持久化引擎路径；存在同步或隔离存储尝试，不能承诺有或没有耐久数据库记录。 |
| 本地音乐 | 用户设备上的文件或 Blob。未发现把本地音频 Blob 上传至服务端的路径；歌词查询和推荐上下文仍可能发送标题、艺人、专辑、时长或标识。 |
| 本地评论 | 当前写入 localStorage 的评论草稿或内容；这不等于已经发布到评论服务器。读取评论可能取得其他人的姓名、头像和文字，并进入公共缓存。 |
| 直连 / 代理 | 代理由服务端代请求；直连由浏览器向内容 CDN 请求。直连会让目标服务看到浏览器 IP 和连接信息，且流请求可能使用浏览器 User-Agent，不一定是固定值。 |
| 版本与配置 | 源码缺省值、`.env`、Compose 和生产环境可能不同。GDStudio 代码未设置时默认开启，但环境或 Compose 可设为关闭；应以实际运行配置核验。 |

## 3. 解释基准

1. 法律名词只在实际要件满足时使用；“个人项目”“免费”“开源”不是控制者、受托处理者、同意、匿名化或安全合规的同义词。
2. 技术用语以源码、实际环境和供应商请求路径共同核对；README 设计目标与文档不一致时，不得把目标当成保证。发现源码、配置和页面不一致，应停止较强声明并修正相应页面。
3. 本站法律文档以简体中文版本为维护基准；其余九种语言为对照版本。翻译与根目录版本不一致时，应尽快同步，但强制法律和消费者的清楚、易懂权利不受影响。
4. 代码以 MIT 许可证发布；本页定义不限制许可证允许的复制、修改、分发或商业使用。托管实例的[可接受使用政策](/acceptable-use/)只约束其实际托管资源和服务行为。
5. 来源核对：公开候选分支 `rc/sonic-20261031@a75f5cb`／2026-11-01 UTC；旧 `main@ce443c8`／2026-10-27 UTC 仅作版本对照。本页于 2026-11-02 核对，不证明在线版本或合规。
