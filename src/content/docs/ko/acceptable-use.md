## 1. 적용 범위

1. 호스팅 Sonic 웹 플레이어, 공개 API, 로그인, 검색, 재생, 가사, 추천, 기타 공개 엔드포인트를 이용하는 행위에 적용됩니다.
2. 셀프 호스팅은 독립 인스턴스입니다. 배포자는 정책, 설정, 법률, 사용자 관계를 스스로 결정해야 하며 이 페이지가 운영·계약 의무를 대신 부담하지는 않습니다.
3. MIT는 코드 복제, 수정, 배포, 상업적 이용을 허용합니다. 이 정책은 호스팅 인스턴스와 자원을 보호하며 코드나 모든 Sonic 배포의 상업적 이용을 포괄 금지하지 않습니다.
4. 이번 확인에서 로컬 음악의 오디오 Blob을 서버에 업로드하는 경로는 발견되지 않았습니다. 가사·추천은 여전히 제목, 아티스트, 앨범, 길이, 식별자를 보낼 수 있습니다. [개인정보 처리방침](/ko/privacy-policy/) 참조.

## 2. 금지 행위

### 2.1 시스템과 인터페이스 악용

1. 타인의 계정, 세션, Cookie, API Key, 서비스 키를 무단 취득·사용·공유하거나 자격 증명을 위조하거나 호스팅 인스턴스의 인증, 요청 제한, 서명, SSRF 등 접근 통제를 우회하는 행위.
2. 비공개 엔드포인트, 내부 주소, 자격 증명을 무단 탐색·악용하거나 타인의 사적 정보를 취득·공개하는 행위. 공개 검색 제안으로 타인의 정보를 수집·노출·검증해서는 안 됩니다.
3. 검색 결과, 가사, 재생 주소, API 응답을 대량 수집하여 허가받지 않은 재판매·미러·데이터셋에 공유 자원을 점유하는 행위. 정상 개인 재생, 적정 API 이용, 허가된 연동은 제외합니다.
4. 호스팅 프록시를 범용 네트워크 프록시, 스캐너, 공격 경유지로 사용하거나 불필요한 동시 요청, 트래픽, 오류, 캐시 부담을 고의로 만드는 행위.

소스 코드 열람, 자신의 로컬 인스턴스에서 합성·허가 데이터로 하는 테스트, 책임 있는 취약점 신고는 금지하지 않습니다. 공개 인스턴스의 능동적 보안 테스트는 사전에 적절한 허가를 받고 타인에 대한 영향, 정보 취득, 취약점 확대를 피해야 합니다. `admin@epocanvas.com`으로 최소 재현 방법을 비공개로 제공할 수 있으며 실제 자격 증명은 공개하지 마십시오.

### 2.2 콘텐츠와 권리

1. 호스팅 서비스로 불법 복제, 유료·저작권 보호 우회, 저작권·상표권·초상권·인격권·프라이버시 등 권리 침해를 실행하거나 조장해서는 안 됩니다.
2. 서비스로 불법 콘텐츠, 악성코드, 아동 성착취물, 불법 테러 선전을 유포하거나 타인의 자격 증명·개인정보를 불법 또는 무단 공개해서는 안 됩니다. 정상 로그인이나 필요한 비공개 권리 요청을 금지하지 않으며 로컬 음악 가져오기도 Sonic으로의 파일 업로드와 같지 않습니다.
3. 타인·기관을 사칭하거나 `Sonic`, `Epomail`, `EpoCanvas` 이름·표시로 무단 보증, 협력, 보안 인증을 암시해서는 안 됩니다.
4. 타인의 사적 정보가 포함된 것을 알면서 검색어, 댓글, 신고 자료를 제출해서는 안 됩니다. 공개 댓글에 다른 사람의 이름, 아바타, 글이 포함될 수 있으며 localStorage 댓글 쓰기가 게시 허락을 얻었다는 뜻은 아닙니다.

### 2.3 타인의 권리와 서비스 안정

1. 운영자, 업스트림 제공자, 기여자, 다른 사용자를 괴롭히거나 협박·명예훼손·스토킹·차별·공격해서는 안 되며 공개 캐시·제안으로 타인의 정보를 노출해서는 안 됩니다.
2. 호스팅 인스턴스, 업스트림 콘텐츠·신원 서비스, 네트워크의 가용성·무결성·보안을 방해해서는 안 됩니다. 고의적인 서킷 브레이커, 저하, 자원 고갈 유발도 포함됩니다.
3. 소재지의 적용 법률을 위반하거나 업스트림 규칙에 어긋나게 콘텐츠 인터페이스를 이용해서는 안 됩니다. 라이선스상 코드 이용이 제3자 콘텐츠, 계정, 음악의 권리를 자동 부여하지는 않습니다.

## 3. 자원 사용 한도

호스팅 인스턴스는 비인증·인증 상태, IP, 세션, 인터페이스, 이벤트 배치에 따라 요청 제한을 정할 수 있습니다. 값은 실제 설정에 따르며 모든 배포에 대한 통일된 계약 약속이 아닙니다. 초과 시 `429`, 지연, 거부, 임시 제한이 있을 수 있으나 반드시 위반을 뜻하지는 않습니다.

합리적인 개인 요청 빈도를 사용하고 동시 대량 수집, 반복 재시도, 오디오 스트림의 장시간 점유, 불필요한 이벤트 전송을 피하십시오. 요청 제한, 폐기, 보존은 환경 변수, Compose, 코드 기본값의 차이에 따라 달라질 수 있으므로 페이지만으로 실행 상태를 추정할 수 없습니다.

## 4. 단계별 조치

운영자는 행위의 영향, 의도, 반복성, 관련 정보, 긴급성에 따라 다음 중 하나 이상을 취하고 필요한 이유를 기록할 수 있습니다.

1. 주의 또는 해당 행위 중단 요구.
2. 인터페이스, 동시 요청, 캐시, 이벤트 전송 등 자원 이용 제한.
3. 계정, 세션, 자격 증명, 네트워크 출처 일시 중지. 즉시 폐기되는지는 인스턴스의 폐기 저장소, 스위치, 요청 성공에 달려 있습니다.
4. 호스팅 인스턴스 접근 종료 또는 해당 엔드포인트의 계속 이용 차단.
5. 적용 법률, 유효한 요청, 타인·시스템 보호에 필요한 범위에서 기록을 보존하고 수령 권한이 있는 자에게 제공.

진행 중인 공격, 자격 증명 도용, 중대한 보안 위협, 명백한 불법 콘텐츠에는 먼저 필요한 임시 조치를 하고 이후 설명·재검토할 수 있습니다. 정책상 조치는 행위자의 법적 책임을 대신하지 않으며 자동 경찰 신고, 고정 보존 기간, 24시간 인력 대응, 모든 관련 기록의 영구 삭제를 약속하지 않습니다.
