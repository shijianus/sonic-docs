**시행일: 2026년 11월 1일｜버전: 1.4**

본 정책은 Sonic 서비스(이하 「본 서비스」) 사용의 행동 경계를 정하고 금지 행위와 운영자의 조치를 설명합니다. 본 정책은 [이용약관](/ko/terms-of-service/) 7절이 가리키는 행동 규범이므로 본 서비스를 사용하면 준수해야 합니다. 동의하지 않으면 본 서비스 사용을 중단하십시오.

![Sonic 집행 사다리: 고지, 요청 제한, 일시 정지, 이용 종료의 4단계 조치에 이어 증거 보존과 법에 따른 이송. 아동·청소년 보호와 테러 콘텐츠 무관용 경로는 즉시 조치하며, 이의 제기 회로로 당사자가 재검토를 청구할 수 있음](/images/sonic/aup-ladder.svg)

*그림: 운영자의 조치는 정상의 경중에 따라 사다리식으로 적용되며 단계마다 사유를 기록합니다. 무관용 경로에는 단계별 절차를 적용하지 않습니다. 당사자는 어떤 조치에도 이의를 제기할 수 있습니다.*

## 1. 적용 범위

본 정책은 사용자가 어떤 방식으로든 본 서비스를 사용하는 행위에 적용됩니다. 다음을 포함합니다.

1. 웹 플레이어의 전체 기능(검색, 재생, 가사, 추천, 다운로드, 로컬 음악 가져오기).
2. 개방 API로의 접속. 사용자가 직접 만든 제3자 클라이언트와 스크립트를 포함합니다.
3. 셀프 호스팅 인스턴스(셀프 호스팅 운영자는 본 정책을 수정해 적용할 수 있으나 자신 소재지 법률의 요건보다 낮을 수 없습니다).

## 2. 금지 행위

### 2.1 시스템과 인터페이스 남용

1. 요청 제한, 서명 검증, 서킷 브레이커, SSRF 방어, 도메인 화이트리스트 등 기술적 보호 조치의 회피 또는 파괴.
2. API Key 위조, 폐기된 키 식별자(jti)의 재사용, 타인의 세션이나 키 도용, 또는 어떤 방식으로든 fail-closed 검증 우회.
3. 자동화 스크립트로 본 서비스의 검색 결과, 가사, 재생 주소를 대량 수집하여 본 서비스 기능과 무관한 재판매, 재배포, 미러 데이터셋 구축에 사용.
4. 본 서비스의 내부 토폴로지, 서비스 간 키, 키 자료, 비공개 엔드포인트의 탐지, 스캔 또는 기타 방식의 획득.
5. 본 서비스의 프록시 엔드포인트(`/api/music/stream`, `/api/sonic/forward` 등)를 범용 네트워크 프록시로 삼아 음악 재생과 무관한 대상에 접근.

### 2.2 콘텐츠와 권리

1. 본 서비스가 제공하는 인터페이스로 음악 플랫폼의 유료·저작권 보호 메커니즘을 해독, 우회 또는 방해.
2. 타인의 저작권, 상표권, 초상권 또는 인격권을 침해하는 콘텐츠의 유포.
3. 불법 콘텐츠의 업로드 또는 유포. 아동·청소년 성착취 소재, 테러 선전 콘텐츠를 포함합니다.
4. 타인의 명의나 기구 식별을 사칭한 활동, 또는 `epocanvas`, `Sonic` 이름과 식별물로 본 서비스의 보증을 암시하는 무단 용도.
5. 본 서비스로 유포할 불법 파일을 로컬 음악 가져오기 또는 다운로드 기능에 업로드.

### 2.3 타인의 권익

1. 본 서비스나 관련 시스템의 정상 운행 방해와 파괴. 서킷 브레이커와 저하 메커니즘의 고의 트리거를 포함합니다.
2. 운영자, 업스트림 서비스 제공자, 기타 사용자에 대한 괴롭힘, 명예 훼손, 공격.
3. 소재지 법률이나 업스트림 서비스 약관을 위반하는 어떤 용도로의 본 서비스 사용.
4. 본 서비스 접근의 판매, 전대 또는 상업적 재판매 목적의 제공.

## 3. 자원 사용 상한

| 항목 | 상한 | 초과 시 조치 |
| --- | --- | --- |
| 익명 요청 | 분당 240회(기본값) | 엣지 계층이 직접 거부(429). 위반으로 기록하지 않음 |
| 인증 요청 | 분당 600회(기본값) | 엣지 계층이 직접 거부(429). 지속 초과 시 집행 사다리로 진입 |
| 인증 엔드포인트(로그인/키 발급) | 분당 IP당 30회 | 엣지 계층이 직접 거부(429) |
| 행동 이벤트 보고 | 한 배치 최대 50건, 요청 본문 64 KB | 초과 요청은 전체 거부 |
| 오디오 스트림 | 엣지 프록시 경유 또는 능동적으로 요청한 직접 연결 모드 | 비정상 동시 접속 시 집행 사다리로 진입 |

정상적인 개인 사용은 위 상한에 닿지 않습니다. 요청 제한의 기술적 목적은 악용 방지와 서비스 안정이며 처벌이 아닙니다. 요청 제한 매개변수는 배포자가 설정할 수 있으므로 셀프 호스팅 인스턴스의 실제 값은 그 구성을 따릅니다.

## 4. 집행 사다리

운영자는 위반을 발견하면 정상의 경중에 따라 다음 조치를 적용하며, 각 단계의 조치마다 사유를 기록합니다.

1. 고지: 플레이어 안에서 경고를 표시하고 사유를 설명합니다.
2. 요청 제한: 해당 계정이나 키의 요청 할당량을 조정합니다.
3. 일시 정지: 해당 계정의 세션과 API Key를 임시 차단합니다(`jti` 폐기 목록 또는 즉시 폐기 메커니즘 경유). 데이터는 일시 보존합니다.
4. 종료: 사용권을 종료합니다. 행동 데이터는 보존 기간(90일, 하한 7일)이 끝나면 파기됩니다.
5. 증거 보존과 법에 따른 이송: 법률이 요구하면 필요한 범위에서 기록을 보존하고 법정 절차로 권한 있는 기관에 제공합니다.

아동·청소년 성착취 소재, 테러 선전 콘텐츠, 진행 중인 시스템 공격에는 단계별 절차를 적용하지 않으며, 운영자는 즉시 일시 정지하고 이송 또는 신고할 수 있습니다.

## 5. 이의 제기와 신고

- 이의 제기: 조치가 잘못되었다고 판단하면 `admin@epocanvas.com`으로 조치 대상 계정과 사유를 밝혀 이의를 제기할 수 있습니다. 운영자는 합리적 기한 안에 재검토하고 답변합니다. 긴급 조치(4절의 무관용 사례)에 대한 이의 제기도 똑같이 접수하며, 재검토 기간에도 사용자 본인에 대한 오인 구제가 중단되지 않습니다.
- 신고: 누구든 본 정책 위반을 발견하면 앞서 말한 우편함으로 신고할 수 있습니다. 신고는 확인 전까지 피신고인에게 비밀로 합니다. 아동·청소년 보호와 관련된 신고는 비밀 유지 약속의 제한을 받지 않으며 법정 절차로 처리합니다.

운영자가 본 정책에 따라 행한 조치는 위반 행위자가 법에 따라 부담할 책임을 면제하지 않습니다.
