Sonic 계정 체계의 작동 방식과 안전한 이용 방법을 설명합니다. 보호 조치와 구현 한계는 [데이터 처리 및 보안 유지](/ko/data-security/), 약정 내용은 [이용약관](/ko/terms-of-service/) 3절을 참조하십시오.

## 1. 로그인 방식

본 서비스는 Epomail 계정으로 OAuth 2.0(PKCE) 로그인을 제공하며 별도의 회원가입 시스템을 두지 않습니다. 사이드바의 계정 진입점 선택 → Epomail 인가 페이지 확인 → 본 서비스 복귀 순서입니다. 2026-11-02에 검토한 최신 공개 후보 브랜치(RC) `rc/sonic-20261031@a75f5cb`(2026-11-01 UTC)에는 state·PKCE 검증과 인증 요청 제한이 있습니다. 이는 정식 GitHub Release가 아니며 실제 인스턴스의 배포·설정·보안 상태를 확인한 것도 아닙니다. 실제 서비스 버전은 알 수 없습니다. 이전 `main@ce443c8`(2026-10-27 UTC)에는 URL과 브라우저 저장소를 통한 자격 증명 처리 경로가 남아 있어 RC와 같은 보호를 가정할 수 없습니다. OAuth 범위는 `openid profile email`이며 로그인은 연령 검증, 이용약관의 유효한 수락 또는 선택적 프로파일링 동의와 같지 않습니다.

## 2. 세션 메커니즘

1. 세션 쿠키: `sonic_session`에는 서명된 자격 증명이 들어가며 기본 유효 기간은 30일입니다. HttpOnly는 스크립트의 직접 읽기를 제한하지만 서명은 암호화가 아니므로 페이로드의 이메일·신원 정보가 비밀이 되지는 않습니다. HTTPS 구성에서는 Secure를 사용하며 로컬 HTTP 개발 환경은 다를 수 있습니다.
2. 탭 간 동기화: 같은 브라우저의 탭 사이에서 로그인 상태를 동기화합니다. 화면의 로그아웃 반영이 다른 기기나 복사된 토큰의 서버 측 무효화를 증명하지는 않습니다.
3. 키와 사용자 정보의 저장 경계: 키의 URL·쿼리·localStorage 저장을 피하는 구현과 별개로, `auth` localStorage에는 사용자 ID, 이메일, 닉네임, 아바타, 역할이 남습니다. OAuth 트랜잭션 쿠키의 기본 유효 기간은 약 600초입니다.

## 3. API Key 보관

API Key는 사용자의 개인 인증 정보입니다(형식 `sonic_live_v2.…`, HMAC-SHA256 서명).

1. 요청 헤더로만 전달하며 URL에는 절대 넣지 않습니다.
2. 제3자에게 넘기거나 공개 배포 클라이언트에 포함하지 마십시오.
3. 재발급에는 현재 유효한 인증이 필요합니다. 유출 시 로그아웃하고 운영자에게 폐기를 요청하되, 새 키를 받거나 로컬 쿠키를 지운 것만으로 이전 키가 무효화되었다고 가정하지 마십시오(4절 참조).

## 4. 폐기와 로그아웃

| 작업 | 위치 | 효과 |
| --- | --- | --- |
| 로그아웃 | 플레이어 안 | 현재 세션 쿠키를 정리하고 폐기를 시도함; 복사된 토큰의 즉시 무효화는 보장하지 않음 |
| 키 폐기 | `POST /api/auth/revoke` | KV·폐기 스위치와 요청 성공 여부에 따름; 미구성 시 지원하지 않을 수 있음 |
| 일괄 무효화 | 배포자 설정 | jti 목록, 주체 목록, 전역 발급 시점 하한 지원; 적용 설정과 캐시 전파 확인 필요 |

「모든 로컬 데이터 삭제」는 HttpOnly 세션 쿠키를 지우거나 로그아웃하지 않습니다. 로그아웃·토큰 만료·서버 측 폐기는 서로 다른 작업이며, 유출된 토큰은 폐기가 확인되거나 만료될 때까지 유효할 수 있습니다. 서버 자료 삭제도 별도 작업이므로 완전한 원격 자료 요청은 `privacy@epocanvas.com`으로 보내십시오.

## 5. 안전한 이용 방법

1. 공용 기기에서는 사용 후 로그아웃하고 브라우저에 남은 사용자 자료도 별도로 정리하십시오. 설정을 지우면 다시 로드할 때 개인화 기본값이 켜질 수 있으므로 확인하십시오.
2. Epomail에서 제공하는 추가 인증 수단을 확인하여 사용하십시오. 현재 아바타 생성 경로는 DiceBear URL의 seed에 URL 인코딩된 이메일을 넣을 수 있으며, 인코딩은 암호화가 아닙니다. 이는 운영자가 수정해야 할 노출 경로입니다.
3. 계정을 빌려주거나 공유하지 마십시오. 공유 계정에서 발생한 데이터 혼재는 구분하거나 복구할 수 없습니다.
4. 이상한 재생 기록이나 출처를 알 수 없는 세션을 발견하면 즉시 로그아웃하고 `admin@epocanvas.com`으로 연락하십시오.
5. 본 서비스는 비밀번호를 수집하지 않습니다. 로그인은 Epomail에서 처리하므로 「Sonic 비밀번호 확인」을 요구하는 연락은 사칭입니다.

## 6. 계정 관리 진입점

사이드바 하단의 계정 진입점에서 현재 로그인 상태를 확인할 수 있습니다. 로그아웃 상태에서는 로그인 안내가, 로그인 후에는 계정 닉네임과 Epomail의 프로필·받은편지함으로 연결되는 계정 관리 링크가 표시됩니다. 로그인 상태는 같은 브라우저의 탭 사이에서 자동으로 동기화됩니다.
