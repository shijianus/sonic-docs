**시행일: 2026년 11월 1일｜버전: 1.4**

이 페이지는 Sonic 각 기능의 동작 방식과 설계 판단을 심층적으로 설명합니다. 화면 위치는 [인터페이스 및 기능 안내](/ko/interface/)에, 행동 신호와 추천 모델의 기술 설명은 [프로젝트 소개](/ko/project/) 5절에, 기능 이용의 계약 조건은 [이용약관](/ko/terms-of-service/)에 있습니다.

## 1. 음질 등급과 미리듣기 투명성

Sonic은 온전한 곡과 미리듣기 구간을 엄격히 구분합니다.

1. 음질 등급: 음원에서 얻을 수 있는 등급(SQ 무손실, HQ 고품질, 표준 등)은 업스트림이 실제로 발급한 직접 링크가 결정하며, 음질 메뉴는 실제 사용 가능한 항목만 나열하고 배지는 현재 스트림을 사실대로 표기합니다.
2. 미리듣기 탐지: 오디오 엔티티 길이와 메타데이터를 검사하여 공식 30초 미리듣기 절단본을 식별하고, 식별 결과는 미리듣기 표시로 나타납니다. 절대 미리듣기를 온전한 곡처럼 보이게 하지 않습니다.
3. 교차 소스 보완: 켜면 미리듣기 곡에 대해 QQ/KuGou/Kuwo의 무료 온전 곡을 자동으로 매칭하고, 성공하면 부드럽게 전환하며 대체 출처를 표시합니다. 매칭되지 않으면 미리듣기를 유지하고 끝나면 자연스럽게 다음 곡으로 넘어갑니다.
4. 엄격한 경계: 본 서비스는 유료 저작권을 우회하는 어떤 구성 요소도 통합하지 않습니다. 합법 회원 카탈로그는 배포자가 자신의 자격 증명으로 마운트합니다.

## 2. 글자 단위 가사 파이프라인

가사는 3단계 우선순위로 가져옵니다.

| 우선순위 | 출처 | 형식 |
| --- | --- | --- |
| 1 | 로컬 네이티브 파싱(NetEase/QQ/KuGou) | YRC/QRC/KRC 글자 단위 타임라인 |
| 2 | AMLL | TTML 글자 단위 형식 |
| 3 | LRCLIB | 싱크 줄 단위 가사 |

가사 패널은 원문, 번역, 로마자 세 경로의 독립 스위치를 지원하고, 가사 줄을 클릭하면 해당 재생 위치로 이동하며, 글자 단위 애니메이션은 재생 진도에 맞춰 동기화됩니다. 가사 데이터도 엣지 캐시를 거치며, 로컬 네이티브 가사가 없으면 자동으로 글로벌 가사 라이브러리로 저하됩니다.

## 3. 추천과 Auto DJ

1. 당신을 위한 추천: 완주율, 즐겨찾기, 세션 검색 의도와 MMR 다양성 재정렬을 융합한 개인 추천입니다. 카드에 추천 이유(예: 「자주 듣는 아티스트」)가 표시되고 모바일에서는 선호 신호 태그가 추가로 표시됩니다.
2. 사이트 내 트렌드 차트: 24시간 급상승 차트와 7일 누적 인기 차트로, 사이트 전체의 실제 재생 신호에 기반합니다.
3. 장르 탐색 레이더: 장르별 탐색이며 온도 매개변수로 탐색 폭을 조절할 수 있습니다.
4. Auto DJ: 재생 목록이 자연스럽게 끝나면 현재 곡의 스타일에 따라 재생 가능한 곡을 자동으로 이어 재생합니다. 설정에서 끌 수 있습니다.
5. 신호 정화: 버퍼링, 디코딩 실패, 미리듣기 절단 등 6류의 비사용자 원인 곡 전환은 추천 데이터 풀에 계산되지 않습니다.
6. 데이터 제어: 모든 행동 이벤트는 가명 처리 식별자로 연결되고 90일 후 자동 파기되며 원클릭으로 삭제할 수 있습니다([개인정보 처리방침](/ko/privacy-policy/) 9절 참조).

## 4. 다운로드와 로컬 음악

1. 다운로드: 곡이 음질 메타데이터와 함께 브라우저 IndexedDB(`downloaded_music`)에 저장되고 다운로드 목록 페이지에서 관리되며 오프라인에서도 재생됩니다.
2. 로컬 음악: 로컬 오디오 파일을 드래그 앤 드롭하거나 선택해 브라우저로 가져옵니다(`local_music`). 온라인 곡 라이브러리와 통일되게 표시됩니다.
3. 경계: 둘 다 사용자의 브라우저에만 저장되고 서버로 업로드되지 않으며, 개인 청취에만 사용할 수 있고 재배포할 수 없습니다.

## 5. 순위 차트와 공식 차트

순위 차트 페이지는 신곡 속보와 공식 차트 두 유형을 제공하며 각각 전체/중화권/서구권/일본/한국 다섯 분류로 나뉩니다. 차트는 원클릭 연속 재생을 지원합니다. 홈의 트렌드 차트와 차트 페이지는 같은 인기도 모델(5인자 가중 합산 + 시간 감쇠 + 베이지안 평활)을 공유하며, 자세한 내용은 [프로젝트 소개](/ko/project/) 5절을 참조하십시오.

## 6. MV 재생

검색 결과와 곡 페이지에서 MV 플레이어로 바로 이동할 수 있습니다. MV는 업스트림 공식 인터페이스에서 오며 가용성은 업스트림에 따라 바뀌고, 사용할 수 없으면 화면이 사실대로 안내합니다.

## 7. 검색 내결함성

검색 경로에는 다단계 내결함성이 내장되어 있습니다. 간체/번체 글자 형태 정규화, 병음과 약어 검색, 가수 중문·영문 별칭 상호 매칭, 편집 거리 기반 오타 허용, 버전 식별이며, 멀티 소스 병렬 검색 후 정규식으로 중복을 제거하고 병합합니다. 키워드를 잘못 입력해도 보통은 대상에 적중합니다.

## 8. 저하 모드

데이터 플레인 노드가 오프라인이거나 시간 초과되면 엣지 계층이 자동으로 저하 모드로 전환합니다. 검색과 가사는 엣지에서 공개 인터페이스에 직접 연결되고 화면에 「엣지 저하 모드」 안내가 표시되며, 이미 로드된 곡은 영향을 받지 않습니다. 저하 기간에는 온전한 음원 파싱과 추천 갱신을 사용하지 못할 수 있고, 복구되면 자동으로 닫힙니다(재해 대응 메커니즘 설명은 [데이터 처리 및 보안 유지](/ko/data-security/) 3.1절 참조).
