**시행일: 2026년 11월 1일｜버전: 1.4**

이 페이지는 Sonic 웹 플레이어의 화면 구성과 기능 위치를 안내하고 각 기능의 위치와 동작을 설명합니다. 본문의 스크린샷은 호스팅 인스턴스의 실제 실행 화면입니다(인터페이스 언어는 간체 중국어이며, 제품은 인터페이스 언어 전환을 지원합니다). 인터페이스는 버전 발전에 따라 조정될 수 있고, 기능의 실제 사용 가능 범위는 인스턴스에서 활성화한 것을 따릅니다. 법적 약정은 [이용약관](/ko/terms-of-service/)과 [개인정보 처리방침](/ko/privacy-policy/)에 있습니다.

![Sonic 플레이어 홈: 왼쪽 내비게이션 바(탐색, 내 음악, 시스템 3개 구역), 메인 영역은 캐러셀 추천, 스마트 추천과 음악 레이더, 추천 플레이리스트, 하단은 미니 재생 바](/images/sonic/ui/ui-home.png)

*그림: 데스크톱 홈. 왼쪽 사이드바는 「탐색」(홈, MV, 순위 차트, 아티스트, 신보 발매, 검색)과 「내 음악」(즐겨찾는 곡, 최근 재생, 다운로드 목록, 로컬 음악) 두 구역으로 나뉩니다. 메인 영역은 위에서부터 캐러셀 추천, 스마트 추천과 음악 레이더, 추천 플레이리스트 순이며 하단에는 미니 재생 바가 상주합니다.*

## 1. 홈과 스마트 추천

홈은 세 개의 콘텐츠 구역을 모아 보여줍니다.

1. 캐러셀 추천: 신곡과 신보를 표시하며, 카드에는 「sonic 신곡」 등의 출처 표시가 붙고 클릭하면 바로 재생 또는 상세로 이동합니다.
2. 스마트 추천과 음악 레이더: 「당신을 위한 추천」, 「사이트 내 트렌드 차트」, 「장르 탐색 레이더」 세 가지 보기를 제공하며 「다른 추천 보기」와 「추천 목록 재생」 작업이 따릅니다. 추천 카드에는 추천 이유가 표시됩니다(예: 「개인화 추천」 배지와 「자주 듣는 아티스트」, 「당신이 선호하는 장르와 비슷함」 등의 설명). 모바일 홈에는 현재 세션의 선호 신호 태그(아티스트, 장르 등)도 표시됩니다. 추천 근거 신호의 범주는 [개인정보 처리방침](/ko/privacy-policy/) 4.2절을 참조하십시오.
3. 추천 플레이리스트와 인기 곡: 사이트 전체의 실제 청취 트렌드로 생성되며 재생 횟수가 카드에 표시됩니다.

추천 정렬은 보이는 재생 순서에만 영향을 줍니다. 설정에서 개인화를 끌 수 있으며(7절 참조) 끄면 추천이 순수 공개 모드로 전환됩니다.

## 2. 검색

![Sonic 검색 결과 페이지: 「周杰伦」 검색 결과 총 52건, 곡·플레이리스트·MV 세 개 분류 탭, 전체 재생 버튼, 결과 목록에는 커버, 가수, 앨범, 길이, 작업 열이 있음](/images/sonic/ui/ui-search.png)

*그림: 검색 결과 페이지. 상단에 분류 탭(곡·플레이리스트·MV)과 「전체 재생」이 있습니다. 목록 열은 커버, 곡, 가수, 앨범, 길이, 작업(재생, MV, 좋아요, 다운로드)입니다. 검색창은 간체/번체 정규화, 병음 약어, 오타 허용을 지원합니다.*

검색 진입점은 왼쪽 사이드바 상단과 검색 페이지에 있으며 곡, 가수, 앨범, 플레이리스트 키워드를 지원합니다. 멀티 소스 결과는 정규식 중복 제거와 병합 후 관련도순으로 정렬됩니다. 미리듣기 구간이 적중한 곡은 [음질과 미리듣기 표시](/ko/project/#4-음원-및-가사-파이프라인)에 따라 사실대로 표기하며 절대 미리듣기를 온전한 곡처럼 보이게 하지 않습니다.

## 3. 순위 차트와 공식 차트

![Sonic 순위 차트 페이지: 신곡 속보와 공식 차트 두 탭, 전체·중화권·서구권·일본·한국 다섯 분류 차트, 차트 목록에는 순위, 커버, 곡, 가수, 앨범, 길이가 있음](/images/sonic/ui/ui-charts.png)

*그림: 순위 차트 페이지. 왼쪽은 차트 선택기(신곡 속보·공식 차트와 그 아래 전체·중화권·서구권·일본·한국 분류), 오른쪽은 차트 목록과 「전체 재생」입니다. 차트 데이터는 업스트림 공식 차트와 사이트 내 실제 청취 트렌드에서 옵니다.*

홈의 「사이트 내 트렌드 차트」와 순위 차트 페이지는 같은 인기도 모델을 공유합니다. 유효 재생, 고유 청취자, 완주 지표, 즐겨찾기 전환, 성장 기울기 다섯 인자를 가중 합산하고 지수 시간 감쇠와 베이지안 평활을 보조로 사용합니다(모델 설명은 [프로젝트 소개](/ko/project/) 5절 참조).

## 4. 아티스트와 앨범 라이브러리

![Sonic 아티스트 라이브러리 페이지: 유형(전체, 남성 가수, 여성 가수, 밴드)과 지역(중화권, 서구권, 일본, 한국, 기타) 이중 차원 필터, 이니셜 A–Z와 인기 검색, 아티스트 카드에는 앨범 수가 표시됨](/images/sonic/ui/ui-artists.png)

*그림: 아티스트 라이브러리 페이지. 유형, 지역, 이니셜 세 차원으로 아티스트를 필터링합니다. 카드에는 아티스트 아바타, 이름, 앨범 수가 표시됩니다. 아티스트 페이지에 들어가면 인기 곡과 앨범 목록을 볼 수 있고, 앨범 페이지에는 트랙이 나열됩니다.*

가수, 앨범, 곡 상세 페이지는 통일된 커버 프록시와 색온도 분석을 공유하며(커버 주색이 페이지 그라데이션을 따름), 전체 목록 데이터는 업스트림 공식 개방 인터페이스에서 가져와 캐시와 중복 제거 후 표시됩니다.

## 5. 재생 제어(하단 재생 바)

![Sonic 하단 재생 바: 「晴天」 재생 중 가사 미리보기 줄, 이전 곡, 재생, 다음 곡, 재생 모드, 음질 메뉴(SQ 무손실), 다운로드, 볼륨 제어가 표시됨](/images/sonic/ui/ui-player.png)

*그림: 재생 중인 하단 재생 바. 왼쪽은 커버와 현재 곡 정보, 가사 미리보기 줄입니다. 가운데는 재생 제어와 재생 모드 전환, 오른쪽은 음질 메뉴(현재 배지 「SQ 무손실」), 다운로드, 볼륨 슬라이더, 재생 목록 진입점입니다. 커버 영역을 클릭하면 전체 화면 플레이어 드로어가 펼쳐집니다.*

하단 재생 바는 모든 페이지에 상주하며 다음을 제공합니다.

1. 음질 메뉴: 현재 음원에서 실제로 사용 가능한 등급을 나열합니다(예: SQ 무손실, HQ 고품질, 표준). 배지는 현재 스트림의 음질을 사실대로 반영하며 허위 표시를 하지 않습니다.
2. 가사 미리보기 줄: 현재 글자 단위 가사의 진행 중 문장을 표시합니다.
3. 재생 모드: 목록 반복, 한 곡 반복, 무작위 등의 모드 전환.
4. 다운로드: 현재 곡을 브라우저(IndexedDB)에 저장하며 자세한 내용은 5절을 참조하십시오.

## 6. 플레이어 드로어와 글자 단위 가사

![Sonic 전체 화면 플레이어 드로어: 왼쪽은 바이닐 레코드 커버 애니메이션과 곡 정보, 오른쪽은 스크롤 가사 패널, 배경은 커버 색조에 따라 그라데이션되고 오른쪽 위에 배경과 시각화 모드 전환이 있음](/images/sonic/ui/ui-player-drawer.png)

*그림: 전체 화면 플레이어 드로어. 왼쪽은 커버 표시(바이닐 레코드 애니메이션)와 재생 제어, 오른쪽은 글자 단위 가사 스크롤 패널입니다. 배경은 커버 주색에 따라 실시간으로 그라데이션됩니다. 드로어는 하단 재생 바의 커버를 클릭하면 펼쳐집니다.*

플레이어 드로어는 다음을 제공합니다.

1. 글자 단위 가사: YRC·QRC·KRC 글자 단위 타임라인을 우선 표시하고 AMLL TTML과 LRCLIB를 보조로 사용합니다. 가사 패널은 「원문」, 「번역」, 「로마자」 세 개의 독립 스위치를 지원하고(설정에서도 제어 가능) 가사 줄을 클릭하면 해당 재생 위치로 이동합니다.
2. 커버 모드: 바이닐 레코드와 원형 스펙트럼 등의 커버 애니메이션 모드.
3. 오디오 시각화: 막대 그래프, 파형, 원형 등의 스펙트럼 시각화 모드로, 드로어 배경 또는 하단 플레이어에 적용됩니다(설정에서 구성).
4. 드래그 이동: 진행 바 드래그를 지원하며 가사는 재생 위치에 맞춰 동기화 스크롤됩니다.

## 7. 내 음악

「내 음악」 구역에는 네 항목이 있습니다.

| 페이지 | 내용 | 저장 위치 |
| --- | --- | --- |
| 즐겨찾는 곡 | 좋아요한 곡과 즐겨찾기한 플레이리스트, 앨범, 아티스트, MV | 브라우저 localStorage(`library`) |
| 최근 재생 | 재생 기록 | 브라우저 localStorage(`audio`) |
| 다운로드 목록 | 다운로드된 오프라인 곡(음질 메타데이터 포함) | 브라우저 IndexedDB(`downloaded_music`) |
| 로컬 음악 | 직접 가져온 로컬 오디오 파일(브라우저로의 드래그 앤 드롭 업로드 지원) | 브라우저 IndexedDB(`local_music`) |

위 내용은 모두 사용자의 브라우저에만 저장되고 서버로 업로드되지 않습니다. 브라우저 데이터를 지우거나 「모든 로컬 데이터 삭제」를 사용하면 삭제됩니다. 다운로드와 로컬 가져오기 파일은 개인 청취에만 사용할 수 있으며 재배포할 수 없습니다([허용 가능 사용 정책](/ko/acceptable-use/) 참조).

## 8. 설정

![Sonic 설정 페이지: 테마 모드(시스템 따르기), 인터페이스 언어(중국어), 배경 유형, 음질, 하단 플레이어 가사, 오디오 시각화 등의 구성 카드](/images/sonic/ui/ui-settings.png)

*그림: 설정 페이지는 카드로 모든 선호 항목을 구성합니다. 각 카드는 한 유형의 설정에 해당합니다. 테마 모드(라이트·다크·시스템 따르기), 인터페이스 언어(중국어·English·日本語), 배경 유형, 음질 선호, 하단 플레이어 가사 표시, 오디오 시각화 모드 등입니다.*

설정 항목은 즉시 적용되어 브라우저 로컬 저장소(`settings`, `global` 등의 키)에 저장되며, 계정과 묶이지 않고 서버로 업로드되지 않습니다.

## 9. 프라이버시와 데이터 제어

![Sonic 설정 페이지의 프라이버시와 로컬 데이터 구역: 브라우저 로컬 저장소와 IndexedDB 설명, 스마트 검색과 개인화 추천 스위치, 자동 연속 라디오(Auto DJ) 스위치, 추천 프로필 및 관심 없음 기록 초기화 버튼](/images/sonic/ui/ui-privacy.png)

*그림: 설정 페이지의 「프라이버시와 로컬 데이터」 구역. 구역 설명은 「다음 데이터는 사용자의 브라우저에만 저장되며 서버로 업로드되지 않습니다」입니다. 「스마트 검색과 개인화 추천」 스위치는 끄면 즉시 순수 공개 모드로 전환되어 어떤 행동 이벤트도 기록하지 않는다고 설명하고, 「추천 프로필 및 관심 없음 기록 초기화」 버튼은 서버 행동 데이터를 즉시 지웁니다.*

이 구역은 [개인정보 처리방침](/ko/privacy-policy/) 9절에서 설명하는 셀프서비스 권리의 화면 구현입니다.

1. 스마트 검색과 개인화 추천 스위치: 끄면 이벤트가 수집되지 않고 추천이 순수 공개 모드로 전환됩니다.
2. 자동 연속 라디오(Auto DJ) 스위치: 재생 목록이 끝난 뒤의 자동 이어 재기를 제어합니다.
3. 추천 프로필 및 관심 없음 기록 초기화: 서버에서 사용자와 연결된 모든 행동 이벤트를 즉시 파기합니다(`DELETE /api/sonic/events`).
4. 모든 로컬 데이터 삭제: 확인 대화상자를 거쳐 브라우저 로컬 저장소와 IndexedDB 전체를 지우고 서버 프로필도 함께 초기화합니다.

## 10. 모바일

![Sonic 모바일 홈: 캐러셀, 스마트 추천과 음악 레이더, 선호 신호 태그(周杰伦, mandopop, r&b), 개인화 추천 카드와 추천 이유, 하단은 미니 재생 바와 탭 내비게이션(홈, 검색, 최근 재생, 설정)](/images/sonic/ui/ui-mobile-home.png)

*그림: 모바일 레이아웃. 카드에는 개인화 추천 이유와 「자주 듣는」, 「당신이 선호하는 장르와 비슷함」 설명이 표시됩니다. 선호 신호는 태그로 나타나며 하단에 탭 내비게이션과 미니 재생 바가 있습니다. 모바일 플레이어 드로어(PlayerDrawerMobile)는 동등한 글자 단위 가사와 음질 메뉴를 제공합니다.*

모바일과 데스크톱은 같은 계정 체계와 데이터 저장 규칙을 공유합니다. 추천 이유 표시는 데스크톱과 같은 투명성 원칙을 따릅니다.
