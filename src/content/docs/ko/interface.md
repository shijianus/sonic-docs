**개정일: 2026년 11월 3일｜버전: 1.9**

이 페이지는 Sonic 웹 플레이어의 화면 구성과 기능 위치를 안내합니다. 기능 설명은 2026-11-02에 검토한 최신 공개 후보 브랜치(RC) `rc/sonic-20261031@a75f5cb`(2026-11-01 UTC)에 근거하며, 정식 GitHub Release가 아닙니다. 이전 `main@ce443c8`(2026-10-27 UTC)과는 구현이 다르므로 같은 기능을 가정할 수 없고, 실제 서비스 버전은 알 수 없습니다. 기존 스크린샷은 간체 중국어 인터페이스를 보여 주는 위치 안내이며 배포 커밋이나 문구의 정확성을 인증하지 않습니다. 기능과 실제 데이터 처리는 버전·설정에 따라 달라질 수 있으므로 특히 9절의 제어 한계를 함께 읽으십시오. 이 사이트는 간체 중국어를 유지·관리 기준으로 삼으며 나머지 9개 언어는 번역본입니다. 강행법규, 소비자에게 유리한 해석과 이해하기 쉬운 고지가 우선합니다. 서비스 조건과 데이터 안내는 [이용약관](/ko/terms-of-service/)과 [개인정보 처리방침](/ko/privacy-policy/)을 참조하십시오.

## 1. 홈과 스마트 추천

홈은 세 개의 콘텐츠 구역을 모아 보여줍니다.

1. 캐러셀 추천: 신곡과 신보를 표시하며, 카드에는 「sonic 신곡」 등의 출처 표시가 붙고 클릭하면 바로 재생 또는 상세로 이동합니다.
2. 스마트 추천과 음악 레이더: 「당신을 위한 추천」, 「사이트 내 트렌드 차트」, 「장르 탐색 레이더」 세 가지 보기를 제공하며 「다른 추천 보기」와 「추천 목록 재생」 작업이 따릅니다. 검색을 한 번 완료하면 레이더가 검색 의도와 선호 신호에 따라 일치 결과를 동적으로 표시합니다. 추천 카드에는 추천 이유가 표시됩니다(예: 「개인화 추천」 배지와 「자주 듣는 아티스트」, 「당신이 선호하는 장르와 비슷함」 등의 설명). 모바일 홈에는 현재 세션의 선호 신호 태그(아티스트, 장르 등)도 표시됩니다. 추천 근거 신호의 범주는 [개인정보 처리방침](/ko/privacy-policy/) 4.2절을 참조하십시오.
3. 추천 플레이리스트와 인기 곡: 사이트 전체의 실제 청취 트렌드로 생성되며 재생 횟수가 카드에 표시됩니다.

![Sonic 홈의 음악 및 스타일 레이더: 검색을 완료하면 레이더가 선호 신호에 따라 일치 결과를 표시하며 인기 곡과 형태가 정렬됨](/images/sonic/ui/ui-radar.png)

*그림: 검색 후의 음악 및 스타일 레이더. 레이더 결과는 「인기 곡」 카드와 형태가 정렬되고 추천 이유와 선호 신호 태그가 투명하게 표시됩니다.*

추천 순위는 보통 콘텐츠 순서에 영향을 주지만 현재 코드는 엔티티 피드백과 레이더 프로필도 처리합니다. 개인화와 Auto DJ는 기본으로 켜져 있지만 명시적 동의가 아닙니다. 설정에서 개인화를 끄는 것만으로 독립적인 검색 통계나 모든 레이더 경로를 중단할 수는 없습니다(9절 참조). 유효한 근거가 없는 선택적 처리는 중단해야 합니다.

### 1.1 사이드바: 접기 모드와 계정 진입점

사이드바 상단의 브랜드 로고가 접기 스위치입니다. 클릭하면 사이드바가 좁은 막대(아이콘 모드)로 접히고 다시 클릭하면 펼쳐집니다. 사이드바 하단에는 Epomail 계정 진입점이 통합되어 있습니다. 로그아웃 상태에서는 로그인 안내가 표시되고, 로그인 후에는 계정 닉네임과 진입점이 표시되며, 로그인 상태는 탭 사이에서 동기화됩니다.

## 2. 검색

![Sonic 검색 결과 페이지: 「周杰伦」 검색 결과 총 52건, 곡·플레이리스트·MV 세 개 분류 탭, 전체 재생 버튼, 결과 목록에는 커버, 가수, 앨범, 길이, 작업 열이 있음](/images/sonic/ui/ui-search.png)

*그림: 검색 결과 페이지. 상단에 분류 탭(곡·플레이리스트·MV)과 「전체 재생」이 있습니다. 목록 열은 커버, 곡, 가수, 앨범, 길이, 작업(재생, MV, 좋아요, 다운로드)입니다. 검색창은 간체/번체 정규화, 병음 약어, 오타 허용을 지원합니다.*

검색 진입점은 왼쪽 사이드바 상단과 검색 페이지에 있으며 곡, 가수, 앨범, 플레이리스트 키워드를 지원합니다. 멀티 소스 결과는 정규식 중복 제거와 병합 후 관련도순으로 정렬됩니다. 미리듣기 구간이 적중한 곡은 [음질과 미리듣기 표시](/ko/project/#4-음원-및-가사-파이프라인)에 따라 사실대로 표기하며 절대 미리듣기를 온전한 곡처럼 보이게 하지 않습니다.

## 3. 순위 차트와 공식 차트

![Sonic 순위 차트 페이지: 신곡 속보와 공식 차트 두 탭, 전체·중화권·서구권·일본·한국 다섯 분류 차트, 차트 목록에는 순위, 커버, 곡, 가수, 앨범, 길이가 있음](/images/sonic/ui/ui-charts.png)

*그림: 순위 차트 페이지. 왼쪽은 차트 선택기(신곡 속보·공식 차트와 그 아래 전체·중화권·서구권·일본·한국 분류), 오른쪽은 차트 목록과 「전체 재생」입니다. 차트 데이터는 업스트림 공식 차트와 사이트 내 실제 청취 트렌드에서 옵니다.*

홈의 「사이트 내 트렌드 차트」와 순위 차트 페이지는 같은 인기도 모델을 공유합니다. 유효 재생, 고유 청취자, 완주 지표, 즐겨찾기 전환, 성장 기울기 다섯 인자를 가중 합산하고 지수 시간 감쇠와 베이지안 평활을 보조로 사용합니다(모델 설명은 [프로젝트 소개](/ko/project/) 5절 참조).

## 4. 아티스트와 앨범 라이브러리

![Sonic 아티스트 라이브러리 페이지: 유형(전체, 남성 가수, 여성 가수, 밴드)과 지역(중화권, 서구권, 일본, 한국, 기타) 이중 차원 필터, 이니셜 A–Z와 인기 검색, 아티스트 카드에는 앨범 수가 표시됨](/images/sonic/ui/ui-artists.png)

*그림: 아티스트 라이브러리 페이지. 유형, 지역, 이니셜 세 차원으로 아티스트를 필터링합니다. 카드에는 아티스트 아바타, 이름, 앨범 수가 표시됩니다. 아티스트 페이지에 들어가면 인기 곡과 앨범 목록을 볼 수 있고, 앨범 페이지에는 트랙이 나열됩니다.*

가수·앨범·곡 상세 페이지는 커버 색상에 맞춘 그라데이션을 사용합니다. 커버는 직접 연결을 먼저 시도하고 실패하면 프록시를 사용할 수 있어 모든 이미지가 프록시를 거치는 것은 아닙니다. 목록은 업스트림에서 가져와 캐시·중복 제거 후 표시하며, 해당 인터페이스의 사용 가능성이 콘텐츠 이용 허락을 뜻하지는 않습니다. Google Fonts, 이메일을 seed로 사용하는 DiceBear 아바타, MV·커버 직접 요청은 외부에 IP나 이메일을 전달할 수 있습니다.

## 5. 재생 제어(하단 재생 바)

![Sonic 하단 재생 바: 「晴天」 재생 중 가사 미리보기 줄, 이전 곡, 재생, 다음 곡, 재생 모드, 음질 메뉴(SQ 무손실), 다운로드, 볼륨 제어가 표시됨](/images/sonic/ui/ui-player.png)

*그림: 재생 중인 하단 재생 바. 왼쪽은 커버와 현재 곡 정보, 가사 미리보기 줄입니다. 가운데는 재생 제어와 재생 모드 전환, 오른쪽은 음질 메뉴(현재 배지 「SQ 무손실」), 다운로드, 볼륨 슬라이더, 재생 목록 진입점입니다. 커버 영역을 클릭하면 전체 화면 플레이어 드로어가 펼쳐집니다.*

하단 재생 바는 모든 페이지에 상주하며 다음을 제공합니다.

1. 음질 메뉴: 현재 음원에서 실제로 사용 가능한 등급을 나열합니다(예: SQ 무손실, HQ 고품질, 표준). 배지는 현재 스트림의 음질을 사실대로 반영하며 허위 표시를 하지 않습니다.
2. 가사 미리보기 줄: 현재 글자 단위 가사의 진행 중 문장을 표시합니다.
3. 재생 모드: 목록 반복, 한 곡 반복, 무작위 등의 모드 전환.
4. 다운로드: 현재 곡을 브라우저(IndexedDB)에 저장하며 오프라인 다운로드 자료는 [음악 라이브러리 관리](/ko/library/) 3절을 참조하십시오.

## 6. 플레이어 드로어와 글자 단위 가사

![Sonic 전체 화면 플레이어 드로어: 왼쪽은 바이닐 레코드 커버 애니메이션과 곡 정보, 오른쪽은 스크롤 가사 패널, 배경은 커버 색조에 따라 그라데이션되고 오른쪽 위에 배경과 시각화 모드 전환이 있음](/images/sonic/ui/ui-player-drawer.png)

*그림: 전체 화면 플레이어 드로어. 왼쪽은 커버 표시(바이닐 레코드 애니메이션)와 재생 제어, 오른쪽은 글자 단위 가사 스크롤 패널입니다. 배경은 커버 주색에 따라 실시간으로 그라데이션됩니다. 드로어는 하단 재생 바의 커버를 클릭하면 펼쳐집니다.*

플레이어 드로어는 다음을 제공합니다.

1. 글자 단위 가사: YRC·QRC·KRC 글자 단위 타임라인을 우선 표시하고 AMLL TTML과 LRCLIB를 보조로 사용합니다. 가사 패널은 「원문」, 「번역」, 「로마자」 세 개의 독립 스위치를 지원하고(설정에서도 제어 가능) 가사 줄을 클릭하면 해당 재생 위치로 이동합니다.
2. 커버 모드: 바이닐 레코드와 원형 스펙트럼 등의 커버 애니메이션 모드.
3. 오디오 시각화: 막대 그래프, 파형, 원형 등의 스펙트럼 시각화 모드로, 드로어 배경 또는 하단 플레이어에 적용됩니다(설정에서 구성).
4. 드래그 이동: 진행 바 드래그를 지원하며 가사는 재생 위치에 맞춰 동기화 스크롤됩니다.

## 7. 내 음악

「내 음악」 구역에는 네 항목이 있습니다.

| 페이지 | 내용 | 저장 위치 |
| --- | --- | --- |
| 즐겨찾는 곡 | 좋아요한 곡과 즐겨찾기한 플레이리스트, 앨범, 아티스트, MV | 브라우저 localStorage(`library`) |
| 최근 재생 | 재생 기록 | 브라우저 localStorage(`audio`) |
| 다운로드 목록 | 다운로드된 오프라인 곡(음질 메타데이터 포함) | 브라우저 IndexedDB(`downloaded_music`) |
| 로컬 음악 | 직접 가져온 로컬 오디오 파일(브라우저로의 드래그 앤 드롭 업로드 지원) | 브라우저 IndexedDB(`local_music`) |

위 표는 로컬 저장 위치를 보여 줄 뿐 정보가 전혀 외부로 전송되지 않는다고 보장하지 않습니다. 로컬 오디오 파일 본체 업로드 경로는 발견되지 않았지만 내장 커버 이미지, 제목, 아티스트, 앨범, 곡 식별자, 즐겨찾기 피드백과 추천 맥락은 전송될 수 있습니다. 브라우저 정리는 로컬 사본을 삭제하는 것이며 모든 원격 기록을 삭제하지는 않습니다. 범용 클라우드 백업도 보장하지 않습니다. 다운로드와 가져오기는 추가적인 콘텐츠 권리를 부여하지 않습니다([허용 가능 사용 정책](/ko/acceptable-use/) 참조).

## 9. 프라이버시와 데이터 제어

![Sonic 설정 페이지의 프라이버시와 로컬 데이터 구역: 브라우저 로컬 저장소와 IndexedDB 설명, 스마트 검색과 개인화 추천 스위치, 자동 연속 라디오(Auto DJ) 스위치, 추천 프로필 및 관심 없음 기록 초기화 버튼](/images/sonic/ui/ui-privacy.png)

*그림: 설정 페이지의 「프라이버시와 로컬 데이터」 구역. 스크린샷의 「업로드되지 않음」과 즉시 삭제된다는 설명은 지나치게 넓습니다. 메타데이터와 맥락은 전송될 수 있으며 초기화는 부분 삭제이고 실패가 표시되지 않을 수도 있습니다. 스크린샷은 동의, 완전한 삭제 또는 개선 조치의 배포를 입증하지 않습니다.*

이 제어는 [개인정보 처리방침](/ko/privacy-policy/) 6·9절의 일부 작업만 포함하며 완전한 자료 열람·삭제를 대신하지 않습니다. 브라우저 시크릿 모드도 요청이나 이벤트를 중단하지 않습니다.

1. 스마트 검색과 개인화 추천 스위치: 해당 범위의 추천 처리를 제어하며 독립적인 검색어 집계나 공개 검색 제안 가능성을 제어하지는 않습니다. 검색에 개인정보나 민감한 문구를 입력하지 마십시오.
2. 자동 연속 라디오(Auto DJ) 스위치: 재생 목록이 끝난 뒤 자동 이어 재생을 제어합니다. 기본 활성화는 동의가 아닙니다.
3. 추천 프로필 및 관심 없음 기록 초기화: `DELETE /api/sonic/events`로 현재 신원의 일부 이벤트와 피드백 삭제를 시도합니다. 로그인 전 익명 식별자, 레이더, 검색 집계, 외부 추천 서비스, 백업은 포괄하지 않으며 실패해도 성공 표시가 나올 수 있습니다.
4. 모든 로컬 데이터 삭제: 브라우저 저장소와 IndexedDB 삭제 및 일부 프로필 초기화를 시도합니다. 차단된 삭제가 완료로 처리될 수 있고, HttpOnly 세션 쿠키를 지우거나 로그아웃하지 않습니다. 설정이 비워진 뒤 다시 로드하면 개인화 기본값이 다시 켜질 수 있으므로 확인하십시오.

완전한 원격 삭제나 여러 신원의 자료 확인은 `privacy@epocanvas.com`으로 요청하십시오. 비밀번호나 전체 토큰을 보내지 마십시오.
