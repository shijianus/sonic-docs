## 1. 법률 용어

| 용어 | 정의 |
| --- | --- |
| 개인정보 | 식별되었거나 식별 가능한 자연인에 관한 모든 정보(GDPR 제4조 제1항). IP, Cookie, 검색어, 아바타 URL, 댓글의 이름·글, 연결 가능한 가명 식별자도 해당할 수 있습니다. |
| 처리 | 수집, 기록, 저장, 조회, 이용, 전송, 공개, 제한, 삭제 등 개인정보에 수행하는 모든 작업(GDPR 제4조 제2항). |
| 처리 제한 | 특정 상황에서 정보를 보존하면서 이용을 중단하는 것(GDPR 제18조). |
| 사용자 프로파일링 | 개인 특성이나 행동의 자동 분석·평가. 재생, 검색, 건너뛰기, 즐겨찾기, 거부, 맥락을 추천에 사용할 수 있습니다. 프로파일링이 법적 또는 유사하게 중대한 영향을 주는 결정과 같지는 않습니다. |
| 가명 처리 | 추가 정보 없이는 특정인에게 직접 귀속할 수 없게 하는 처리(GDPR 제4조 제5항). 다른 정보와 결합해 식별할 수 있으므로 익명화와 다릅니다. |
| 데이터 컨트롤러 | 단독 또는 공동으로 처리 목적과 수단을 결정하는 자연인·법인(GDPR 제4조 제7항). 호스팅 인스턴스는 실제 결정하는 사람·조직에 따라 판단하며 코드 작성자, 기여자, 운영자가 동일할 필요는 없습니다. |
| 수탁 처리자 | 컨트롤러를 대신해 개인정보를 처리하는 자연인·법인(GDPR 제4조 제8항). 실제 목적, 지시, 약정에 따라 판단하며 Cloudflare, Epomail 등도 이름만으로 자동 해당하지 않습니다. |
| 수신자 | 개인정보가 공개되는 자연인·법인(GDPR 제4조 제9항). 브라우저 직접 연결로 IP를 받는 서비스도 수신자일 수 있습니다. |
| 제3자 | 정보주체, 컨트롤러, 수탁 처리자 또는 컨트롤러가 처리 권한을 부여한 사람이 아닌 주체(GDPR 제4조 제10항). |
| 동의 | 자유롭고 구체적이며 정보를 제공받은 상태의 명확한 긍정적 의사표시(GDPR 제4조 제11항, 제7조). 부여할 때보다 어렵지 않은 방법으로 언제든 철회할 수 있습니다. 로그인, 계속 이용, 기본 활성화는 선택적 프로파일링 동의가 아니며, 동의 기록이 없다는 이유로 근거 없는 처리의 중단을 거부할 수 없습니다. |
| 개인정보 침해 | 개인정보의 우발적·불법적 파괴, 분실, 변경, 무단 공개 또는 접근을 일으키는 보안 사고(GDPR 제4조 제12항). |
| 관할 감독 기관 | 법에 따라 데이터 보호 의무를 감독하는 공권력 기관. GDPR이 적용되면 정보주체는 관할 기관에 불만을 제기할 수 있습니다(GDPR 제77조). |

| 특수 범주 데이터 | 인종·민족, 정치 견해, 종교·철학적 신념, 노동조합 가입, 유전 정보, 자연인의 고유 식별을 위한 생체 정보, 건강, 성생활·성적 지향 등을 드러내는 정보(GDPR 제9조). 음악 취향과 검색어도 민감한 특성을 간접적으로 드러낼 수 있으므로 일괄적으로 무위험이라 볼 수 없습니다. |
| 정보주체 | 정보가 처리되는 식별되었거나 식별 가능한 자연인. 이 페이지의 “사용자”는 요청을 제출하거나 서비스를 이용하는 관련 자연인을 뜻합니다. |

## 2. 기술·제품 용어

| 용어 | 정의 |
| --- | --- |
| 호스팅 인스턴스 | 프로젝트 운영자가 실제 접근을 제공하는 Sonic 배포. 범위, 컨트롤러, 설정, 연락처는 [개인정보 처리방침](/ko/privacy-policy/) 참조. |
| 셀프 호스팅 | 다른 사람이 실행하는 독립 인스턴스. 배포자는 컨트롤러 신원, 법률, 설정, 고지를 독립 평가하며 MIT 코드 제공만으로 본 프로젝트가 그 운영자가 되지는 않습니다. |
| 컨트롤 플레인 | 웹페이지, 라우팅, 캐시, 요청 제한, 엣지 API를 처리하는 구성 요소. IP, Cookie, 인증 헤더, User-Agent, 경로와 맥락을 접할 수 있습니다. |
| 데이터 플레인 | 엔진, 추천 계산, 데이터베이스, 관련 서비스를 실행하는 구성 요소. 이번 감사에서는 원본 IP가 Cookie, 인증 헤더, 맥락과 함께 엔진에 전달될 수 있어 가명 정보만 받는다고 할 수 없습니다. |
| Epomail OAuth | PKCE를 사용하는 Epomail OAuth 2.0 로그인. 사용자 식별자, 이메일과 검증 표시, 닉네임, 아바타 URL, 역할을 반환할 수 있습니다. |
| API Key / `jti` | 서명과 만료 기간이 있는 API 자격 증명 및 고유 식별자. 서명 검증은 암호화가 아니며 Cookie, 자격 증명 복제, 폐기 저장소를 별도로 평가해야 합니다. |
| fail-closed | 검증이나 필수 저장소 실패 시 조용히 보호 수준을 낮추지 않고 요청을 거부하는 것. 실제 환경에서 성립하는지는 설정 확인이 필요합니다. |
| SSRF 방어와 도메인 허용 목록 | 특정 사설망, 루프백, 클라우드 메타데이터 주소, 리다이렉트, 허용 도메인에 대한 아웃바운드 검사. 브라우저 직접 연결과 모든 업스트림 HTTP를 포괄하지는 않습니다. |
| SQLite / WAL | 데이터 플레인의 영구 저장소로 사용할 수 있는 SQLite와 쓰기 전 로그 모드. 프로필, 로그, 백업, 레이더가 모두 같은 DB나 기간에 삭제된다는 뜻은 아닙니다. |
| 서킷 브레이커 | 연속 실패나 시간 초과 후 일시적으로 요청 경로를 바꾸는 장치. 임계값, 저하 동작, 활성화는 실제 버전과 설정에 따릅니다. |
| 행동 이벤트 | 재생, 진행률, 건너뛰기, 즐겨찾기, 거부, 검색, 엔터티 피드백 등 추천에 쓰일 수 있는 신호. 배치 제한, 노이즈 필터, 보존은 버전·설정에 따릅니다. |
| 공개 검색 제안 | 과거 또는 통계 검색어를 다른 방문자에게 제공하는 경로. 현재 검색 원문 재이용의 위험이 있어 단순한 익명 집계라고 할 수 없습니다. |
| 레이더 | 사용자 정보·행동에 기반한 탐색, 추천, 동기화 기능과 상태. 영구 저장 엔진 경로는 현재 미확인이고 동기화나 격리 저장 시도가 있습니다. 내구성 있는 DB 기록의 존재·부재 모두 약속할 수 없습니다. |
| 로컬 음악 | 사용자 기기의 파일 또는 Blob. 오디오 Blob을 서버에 업로드하는 경로는 발견되지 않았지만 가사 조회·추천 맥락은 제목, 아티스트, 앨범, 길이, 식별자를 전송할 수 있습니다. |
| 로컬 댓글 | 현재 localStorage에 쓰는 댓글 초안·내용이며 댓글 서버에 이미 게시되었다는 뜻은 아닙니다. 댓글 읽기는 다른 사람의 이름, 아바타, 글을 가져와 공개 캐시에 넣을 수 있습니다. |
| 직접 연결 / 프록시 | 프록시는 서버가 대신 요청하고 직접 연결은 브라우저가 콘텐츠 CDN에 요청합니다. 직접 연결 대상은 브라우저 IP와 연결 정보를 보며, 스트림 요청도 고정값이 아닌 브라우저 User-Agent를 사용할 수 있습니다. |
| 버전과 설정 | 코드 기본값, `.env`, Compose, 운영 환경이 다를 수 있습니다. GDStudio는 코드상 미설정이면 활성화되지만 환경·Compose에서는 끌 수 있습니다. 실제 실행 설정으로 검증해야 합니다. |

1. 법률 용어는 실제 요건이 충족될 때만 사용합니다. “개인 프로젝트”, “무료”, “오픈 소스”는 컨트롤러, 수탁 처리자, 동의, 익명화, 보안 준법의 동의어가 아닙니다.
2. 기술 용어는 코드, 실제 환경, 공급업체 요청 경로를 함께 확인합니다. README 설계 목표와 문서가 다르면 목표를 보장으로 취급해서는 안 됩니다. 코드·설정·페이지가 다르면 더 강한 주장을 중단하고 해당 페이지를 수정해야 합니다.
3. 법률 문서는 간체 중국어가 유지 관리 기준이며 나머지 9개 언어는 대조 번역입니다. 번역과 루트 버전이 다르면 신속히 동기화해야 하지만 강행법규와 소비자의 명확하고 이해하기 쉬운 설명을 받을 권리는 영향을 받지 않습니다.
4. 코드는 MIT로 공개됩니다. 이 정의는 라이선스가 허용하는 복제, 수정, 배포, 상업적 이용을 제한하지 않습니다. 호스팅 인스턴스의 [허용 가능 사용 정책](/ko/acceptable-use/)은 실제 호스팅 자원과 서비스 행위만 규율합니다.
