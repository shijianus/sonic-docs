**개정일: 2026년 11월 2일｜버전: 1.8**

「내 음악」에 포함된 네 가지 항목의 관리 방법과 저장 위치를 설명합니다. 설명은 2026-11-02에 검토한 최신 공개 후보 브랜치(RC) `rc/sonic-20261031@a75f5cb`(2026-11-01 UTC)에 근거하며, 정식 GitHub Release가 아닙니다. 이전 `main@ce443c8`(2026-10-27 UTC)과는 구현이 다르므로 같은 기능을 가정할 수 없고 실제 서비스 버전은 알 수 없습니다. 로컬 오디오 파일 본체 업로드 경로는 발견되지 않았지만 메타데이터, 내장 커버 이미지, 피드백과 추천 맥락은 전송될 수 있습니다. 로컬 저장만으로 원격 처리가 없다고 볼 수 없으며 일반적인 클라우드 백업이나 기기 간 복원 기능으로 보아서도 안 됩니다. 지우기와 삭제 범위는 [데이터 내보내기 및 저장](/ko/data-management/)을 참조하십시오.

## 1. 좋아요와 즐겨찾기

「즐겨찾는 곡」 페이지에는 좋아요한 곡, 즐겨찾기한 플레이리스트와 앨범, 팔로우한 아티스트, 즐겨찾기한 MV가 모입니다. 곡 행, 앨범 페이지, 가수 페이지의 하트 버튼으로 조작합니다. 목록은 로그인 여부와 관계없이 localStorage의 `library` 키에 저장되지만 일부 항목은 추천 요청 맥락이나 엔티티 피드백으로 전송될 수 있습니다. 레이더의 별도 동기화 시도도 일반 라이브러리의 영구 클라우드 백업을 뜻하지 않습니다.

## 2. 최근 재생

「최근 재생」 페이지는 localStorage의 `audio`에서 자동 저장된 최근 최대 100곡을 최신순으로 읽습니다. 이 로컬 기록만 별도로 끄는 스위치는 발견되지 않았습니다. 별도의 재생 이벤트와 최근 아티스트 맥락은 추천을 위해 전송될 수 있으므로 로컬 기록 목록이 서버에 기록이 없다는 뜻은 아닙니다. 개인화의 기본 활성화는 동의가 아니며 브라우저 시크릿 모드도 이벤트 전송을 막지 않습니다.

## 3. 다운로드 목록

곡 행이나 하단 재생 바에서 다운로드를 누르면 음질 메타데이터와 함께 브라우저 IndexedDB의 `downloaded_music`에 저장됩니다. 「다운로드 목록」 페이지에서 관리하며 오프라인에서도 재생할 수 있습니다. 다운로드는 브라우저 저장 공간을 사용합니다. 할당량이 부족하면 브라우저가 새 다운로드를 거부하므로 오래된 다운로드를 지우거나 브라우저 저장 공간을 정리하십시오.

## 4. 로컬 음악

「로컬 음악」 페이지는 선택하거나 끌어다 놓은 오디오 파일을 IndexedDB의 `local_music`으로 가져옵니다. 오디오 파일 본체 업로드 경로는 발견되지 않았지만 가사 매칭, 즐겨찾기 피드백과 추천 맥락을 통해 제목, 아티스트, 앨범 또는 곡 식별자가 전송될 수 있습니다. 내장 커버 이미지도 즐겨찾기 이벤트와 함께 원격 공유 곡목 카탈로그에 들어갈 수 있으며, 개인 프로필 초기화로 해당 카탈로그가 정리된다고 보장하지 않습니다. 지원 형식은 브라우저의 디코딩 기능에 따릅니다. 로컬 사본 삭제는 원본 파일에 영향을 주지 않으며 관련 원격 데이터를 삭제하거나 콘텐츠 권리를 부여하지도 않습니다.

## 5. 저장 위치 한눈에 보기

| 내용 | 저장 위치 | 브라우저 데이터 삭제 시 손실 |
| --- | --- | --- |
| 좋아요와 즐겨찾기 | localStorage(`library`) | 예 |
| 재생 기록 | localStorage(`audio`) | 예 |
| 다운로드한 곡 | IndexedDB(`downloaded_music`) | 예 |
| 로컬 음악 복사본 | IndexedDB(`local_music`) | 예 |

중요한 목록과 보관 권한이 있는 파일은 별도로 보관하십시오. 브라우저 동기화는 사이트 localStorage·IndexedDB의 백업을 보장하지 않습니다. 로컬 삭제는 차단되거나 실패할 수 있으며, 프로필 초기화의 성공 표시도 현재 신원 이외의 익명 기록·레이더·검색 집계·외부 서비스·백업까지 삭제되었음을 뜻하지 않습니다. 「모든 로컬 데이터 삭제」는 HttpOnly 쿠키를 지우거나 로그아웃하지 않고, 다시 로드하면 개인화 기본값이 켜질 수 있습니다. 원격 자료 사본·삭제는 `privacy@epocanvas.com`으로 요청하십시오([데이터 내보내기 및 저장](/ko/data-management/) 참조). 로컬 음악 원본은 기기에 남습니다.
