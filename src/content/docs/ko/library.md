**시행일: 2026년 11월 2일｜버전: 1.5**

「내 음악」에 포함된 네 가지 항목의 관리 방법과 저장 위치를 설명합니다. 모든 데이터는 사용자의 브라우저에만 저장되며 서버로 업로드되지 않습니다. 지우기와 삭제 작업은 [데이터 내보내기 및 저장](/ko/data-management/)을 참조하십시오.

## 1. 좋아요와 즐겨찾기

「즐겨찾는 곡」 페이지에는 좋아요한 곡, 즐겨찾기한 플레이리스트와 앨범, 팔로우한 아티스트, 즐겨찾기한 MV가 모입니다. 곡 행, 앨범 페이지, 가수 페이지의 하트 버튼으로 조작합니다. 데이터는 로그인 여부와 관계없이 브라우저 localStorage의 `library` 키에 즉시 저장되며, 클라우드 저장이나 기기 간 동기화는 제공하지 않습니다.

## 2. 최근 재생

재생 기록은 브라우저 localStorage의 `audio` 키에 자동으로 저장되고 「최근 재생」 페이지에 최신순으로 표시됩니다. 항목을 클릭하면 다시 재생할 수 있습니다. 기록은 이 기기에만 저장되며 서버와 동기화되지 않습니다.

## 3. 다운로드 목록

곡 행이나 하단 재생 바에서 다운로드를 누르면 음질 메타데이터와 함께 브라우저 IndexedDB의 `downloaded_music`에 저장됩니다. 「다운로드 목록」 페이지에서 관리하며 오프라인에서도 재생할 수 있습니다. 다운로드는 브라우저 저장 공간을 사용합니다. 할당량이 부족하면 브라우저가 새 다운로드를 거부하므로 오래된 다운로드를 지우거나 브라우저 저장 공간을 정리하십시오.

## 4. 로컬 음악

「로컬 음악」 페이지에서 클릭으로 추가하거나 오디오 파일을 브라우저로 끌어다 놓아 가져올 수 있습니다. 파일은 `local_music`에 저장되고 온라인 음악 목록과 함께 표시·재생됩니다. 가져오기는 브라우저 안에서만 처리되며 파일은 업로드되지 않습니다. 지원 형식은 브라우저의 디코딩 기능에 따릅니다. 곡을 삭제해도 브라우저 안의 복사본만 삭제되고 원본 파일에는 영향을 주지 않습니다.

## 5. 저장 위치 한눈에 보기

| 내용 | 저장 위치 | 브라우저 데이터 삭제 시 손실 |
| --- | --- | --- |
| 좋아요와 즐겨찾기 | localStorage(`library`) | 예 |
| 재생 기록 | localStorage(`audio`) | 예 |
| 다운로드한 곡 | IndexedDB(`downloaded_music`) | 예 |
| 로컬 음악 복사본 | IndexedDB(`local_music`) | 예 |

중요한 플레이리스트와 다운로드는 직접 백업하십시오. 브라우저의 사이트 데이터 삭제나 서비스의 「모든 로컬 데이터 삭제」를 실행하면 위 내용이 삭제됩니다([데이터 내보내기 및 저장](/ko/data-management/) 참조). 로컬 음악의 원본 파일은 기기에 남습니다.
