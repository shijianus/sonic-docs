**개정일: 2026년 11월 2일｜버전: 1.8**

휴대전화 브라우저에서 Sonic을 사용할 때의 레이아웃과 이용 요령을 설명합니다. 설명은 2026-11-02에 검토한 최신 공개 후보 브랜치(RC) `rc/sonic-20261031@a75f5cb`(2026-11-01 UTC)에 근거하며, 정식 GitHub Release가 아닙니다. 이전 `main@ce443c8`(2026-10-27 UTC)과는 구현이 다르므로 같은 기능을 가정할 수 없고 실제 서비스 버전은 알 수 없습니다. 모바일과 데스크톱은 같은 인스턴스와 계정 체계를 사용하며 기능은 동등합니다. 화면 너비에 따라 인터페이스가 자동으로 바뀌고 별도 앱을 설치할 필요가 없습니다.

## 1. 레이아웃과 탐색

모바일에서는 데스크톱 사이드바 대신 화면 하단 탭 내비게이션을 사용합니다. 홈, 검색, 최근 재생, 설정 네 가지 진입점이 있습니다. 현재 재생 중인 곡은 하단 미니 재생 바에 계속 표시되며, 누르면 모바일 플레이어 드로어(`PlayerDrawerMobile`)가 열립니다.

## 2. 플레이어 드로어

모바일 플레이어 드로어는 데스크톱과 같은 기능을 제공합니다. 글자 단위 가사(원문·번역·로마자), 음질 메뉴, 재생 모드와 다운로드를 사용할 수 있습니다. 드로어 배경은 커버의 주 색상에 맞춰 그라데이션으로 표시되며 재생 위치를 끌거나 가사 위치로 이동할 수 있습니다.

## 3. 홈과 레이더

모바일 홈은 데스크톱과 같은 구성을 사용합니다. 캐러셀 추천, 스마트 추천과 음악 레이더(검색 후 선호도 일치 결과 표시), 추천 플레이리스트가 제공됩니다. 추천 이유와 선호 신호 태그도 확인할 수 있고 카드는 세로로 쌓입니다. 레이더 앨범·곡·신호의 원격 동기화 시도는 있으나 표준 라우트와 영구 저장에 제한이 있어 일반적인 클라우드 동기화로 볼 수 없습니다.

후보 코드에서 개인화와 Auto DJ는 기본으로 켜져 있으며 이 기본값은 명시적 동의가 아닙니다. 개인화를 꺼도 독립적인 검색 통계나 모든 레이더 경로가 중단되지는 않습니다. 선택적 처리의 제어와 한계는 [개인정보 처리방침](/ko/privacy-policy/) 5절을 참조하고, 사적인 정보나 민감한 내용을 검색어로 입력하지 마십시오.

## 4. 저장 및 동기화 범위

모바일과 데스크톱 브라우저의 저장소는 서로 독립적이며, 범용 기기 간 클라우드 동기화, 백업이나 내보내기를 보장하지 않습니다. 음악 오디오 파일 본체 업로드 경로는 발견되지 않았지만 내장 커버 이미지, 메타데이터, 피드백과 추천 맥락은 전송될 수 있습니다. 레이더에는 별도의 원격 동기화 경로가 있으나 이용 가능성에 한계가 있습니다. 로그인 상태는 브라우저마다 유지됩니다. 브라우저나 기기 간 이전은 각 도구의 기능에 달려 있으므로 Sonic의 모든 자료가 복원된다고 가정해서는 안 됩니다. [개인정보 처리방침](/ko/privacy-policy/)을 참조하십시오.

로그인 상태는 브라우저별로 유지되고 이메일 등 사용자 정보는 `auth` localStorage에도 남습니다. 「모든 로컬 데이터 삭제」는 HttpOnly 쿠키를 지우거나 로그아웃하지 않으며, 다시 로드하면 지워진 설정 대신 개인화 기본값이 켜질 수 있습니다. 로그아웃과 로컬 정리를 구분하고, 완전한 원격 삭제·자료 확인은 `privacy@epocanvas.com`으로 요청하십시오.

## 5. 이용 팁

1. 사이트를 홈 화면에 추가하면 앱에 가까운 실행 환경을 이용할 수 있습니다.
2. 백그라운드 재생은 모바일 브라우저의 미디어 정책에 영향을 받습니다. 다른 앱으로 전환하면 시스템이 재생을 일시 정지할 수 있으며 페이지로 돌아오면 이어서 재생할 수 있습니다.
3. 절전 모드와 데이터 절약 모드가 백그라운드 오디오를 제한할 수 있습니다. 이는 브라우저의 동작이며 본 서비스의 제한이 아닙니다.
4. 시크릿 모드는 세션 종료 시 로컬 자료를 지울 수 있지만 요청이나 이벤트를 차단하지 않습니다. 개인화와 Auto DJ의 기본 활성화는 명시적 동의가 아닙니다. 해당 제어와 부분 초기화에는 데스크톱과 같은 한계가 있으며 실패가 표시되지 않을 수도 있습니다.
