## 2. 프로젝트 지향

본 프로젝트는 비상업 오픈 소스 프로젝트입니다. 검색, 애그리게이션, 재생 도구로서 음악 파일을 저장하거나 호스팅하지 않고, 유료 저작권을 우회하는 어떤 구성 요소도 통합하지 않습니다. 본 서비스를 사용하거나 직접 배포할 때 현지 법률, 업스트림 서비스 약관과 콘텐츠 라이선스 요건에 부합하는지 스스로 확인해야 합니다(행동 경계는 [허용 가능 사용 정책](/ko/acceptable-use/) 참조).

## 3. 제3자 감사의 말과 의존성

연구 개발과 멀티 소스 애그리게이션 실천은 다음 오픈 소스 커뮤니티 프로젝트를 참고했으며 감사를 전합니다. Meting, Meting-API-Serverless, ourcraft-music-api, music-lib, NeteaseCloudMusicApi, QQMusicApi, AMLL TTML API, LRCLIB, GDStudio Music API와 Linux.do 커뮤니티입니다. 전체 의존성과 선언은 저장소 `THIRD_PARTY_NOTICES.md`에 있으며, 각 업스트림 서비스의 약관은 각자에게 귀속됩니다.

## 4. 셀프 호스팅 배포자의 법적 의무

셀프 호스팅 시점부터 배포자는 자신의 사용자의 데이터 컨트롤러이며(역할 정의는 [개요](/ko/overview/) 2절 참조) 다음을 이행해야 합니다.

1. 고지 의무: 사용자에게 데이터 처리 사항을 고지합니다. 본 사이트 [개인정보 처리방침](/ko/privacy-policy/)을 기초 문안으로 삼을 수 있으나 자신의 실제 구성에 따라 삭제·수정해야 합니다(켜지 않은 제3자 경로는 고지에서 삭제).
2. 기록과 평가: 처리 활동 기록을 유지하고(GDPR 제30조) 고위험 시 데이터 보호 영향 평가를 시행합니다(GDPR 제35조).
3. 보안 유지: [데이터 처리 및 보안 유지](/ko/data-security/) 3절의 조치를 실현하고 관할 기관의 감독을 받습니다.
4. 구성 일치성: 환경 변수의 실제 값(보존 일수, 제3자 스위치, 요청 제한)은 사용자의 정책 약속과 일치해야 합니다.
5. 관할별 보완: GDPR 외에 사용자 소재 관할에 따라 UK GDPR, LGPD, CCPA-CPRA 등 법정 요건을 보완합니다.

본 사이트는 「공통 템플릿 + 호스팅 인스턴스 실문」의 이중 트랙 설계이며, 셀프 호스팅 운영자는 본 사이트의 전체 문서를 자신의 사이트 고지와 약관의 기초로 채택할 수 있습니다.
