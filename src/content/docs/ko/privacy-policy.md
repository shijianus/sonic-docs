**시행일: 2026년 11월 1일｜버전: 1.4**

본 방침은 Sonic 서비스(이하 「본 서비스」)가 사용자의 개인 데이터를 어떻게 수집, 처리, 전송하는지와 운영자가 데이터 보호에 대해 따르는 기준과 약속을 설명합니다. 로그인하거나 본 서비스를 사용하기 전에 본 방침을 먼저 읽으십시오. 본 방침의 어느 내용에도 동의하지 않는 경우 본 서비스를 사용하지 마십시오.

본 방침이 설명하는 기술적 사실은 본 서비스 오픈 소스 코드의 실제 구현을 따릅니다. 본 사이트의 법률 문서는 간체 중국어 버전이 공식 버전이며, 영어, 일본어, 한국어 버전은 대조용 참조 번역본입니다. 문언에 의문이 있을 때는 공식 버전을 따릅니다. 본 서비스는 EU 「일반 데이터 보호 규정」(GDPR)을 전체 사용자의 최소 데이터 보호 기준으로 삼습니다(2절 참조).

![Sonic 개인정보 처리방침 5개 기둥: 적법성, 목적 제한, 최소화와 보존 기간, 보안, 사용자의 권리가 GDPR급 보호 기준선 위에 섬](/images/sonic/privacy-pillars.svg)

*그림: 본 방침의 다섯 축. 적법성은 GDPR 제6조의 법적 근거에 고정되고, 목적 제한은 광고 프로필을 배제하며, 최소화는 가명 처리와 원클릭 삭제로 실현됩니다. 보안 조치는 10절에, 권리는 9절에 따라 행사하며, 다섯 가지 모두 GDPR급 기준선을 바탕으로 합니다.*

## 1. 적용 범위

본 방침은 사용자가 어떤 방식으로든 본 서비스를 사용하면서 생기는 개인 데이터에 적용됩니다. 다음을 포함합니다.

1. 본 서비스 웹사이트 방문(`sonic.epocanvas.tech`, `sonic.epocanvas.com` 또는 셀프 호스팅 인스턴스의 도메인).
2. 웹 플레이어의 전체 기능 사용(검색, 재생, 가사, 추천, 다운로드, 로컬 음악 가져오기).
3. 개방 API로 본 서비스에 접속하는 제3자 클라이언트.

본 방침은 본 서비스가 링크하거나 삽입한 제3자 웹사이트와 서비스(예: 업스트림 음악 플랫폼의 자체 사이트)에는 적용되지 않습니다. 해당 제3자는 각자의 개인정보 처리방침을 두며 그 책임도 각자에게 있습니다. Sonic을 셀프 호스팅하는 운영자는 배포 시점부터 자신의 사용자의 데이터 컨트롤러이며, 자신 소재지의 적용 법률에 따라 사용자에게 고지 의무를 직접 이행해야 합니다. 본 방침은 그 고지의 기초 문안으로 삼을 수 있습니다.

## 2. 데이터 컨트롤러와 데이터 보호 기준선

| 사용하는 인스턴스 | 데이터 컨트롤러 | 설명 |
| --- | --- | --- |
| 호스팅 인스턴스(`sonic.epocanvas.tech`, `sonic.epocanvas.com`) | 운영 팀 | 행동 이벤트, 로그인, 보안 기록에 관하여 운영 팀이 데이터 컨트롤러입니다 |
| 셀프 호스팅 인스턴스 | 해당 인스턴스의 배포자 | 오픈 소스 코드에는 텔레메트리 메커니즘이 없습니다. 운영자가 직접 구성한 외부 서비스를 제외하면 업스트림 저자나 제3자에게 인스턴스 데이터를 회신하지 않습니다 |

**데이터 보호 기준선**: 본 서비스는 사용자가 세계 어디에 계시든 GDPR을 전체 사용자의 최소 데이터 보호 기준으로 삼습니다. 개인 데이터에 대한 고지, 열람, 정정, 삭제, 처리 제한, 이동, 반대, 불만 제기 등의 권리는 GDPR이 정한 수준 이상입니다. EU와 유럽 경제 지역(EEA)에 계신 사용자에게는 GDPR이 직접 적용되고, 다른 지역의 사용자에게는 본 서비스가 GDPR 기준을 계약 의무로 이행합니다. 사용자 소재지 법률이 부여하는 더 강한 보호는 그 범위에서 우선 적용됩니다.

| 고지 사항 | 본 서비스의 고지 내용 |
| --- | --- |
| 1. 컨트롤러 이름 | 운영자(2절 참조. 셀프 호스팅 인스턴스는 그 배포자) |
| 2. 수집 목적 | 계정 식별과 로그인 세션. 재생, 검색, 추천 기능의 제공. 악용과 사기 방지. 요청 제한과 서비스 보안 유지(자세한 내용은 5절의 대응표) |
| 3. 개인 데이터의 범주 | 계정 식별류(Epomail 사용자 식별자, 이메일 주소, 닉네임, 아바타 링크, 계정 역할). 행동과 선호류(재생, 완주, 건너뛰기, 즐겨찾기, 거부, 검색어 등의 이벤트, 가명 처리 식별자로 연결). 기술류(요청 제한에 필요한 IP 임시 사용, 세션 쿠키, OAuth 트랜잭션 쿠키). 자세한 내용은 4절 |
| 4. 이용 기간, 지역, 대상 및 방식 | 기간: 행동 이벤트는 기록일부터 90일 후 자동 파기(배포자 설정 가능, 하한 7일). 계정 식별 데이터는 저장하지 않고 세션 기간에만 존재합니다. 지역: 컨트롤 플레인은 Cloudflare 글로벌 엣지 네트워크에서, 데이터 플레인은 운영자의 자체 Linux 노드에서 실행됩니다(7절 참조). 대상: 운영자와 그 수탁 처리자, 법적 요구에 따른 권한 있는 기관(7절 참조). 방식: 자동화 방식의 가명 처리 저장과 통계 계산이며, 사람의 검열이 없고 콘텐츠 심사도 하지 않습니다 |
| 5. 행사할 수 있는 권리와 방식 | 열람, 정정, 삭제, 처리 제한, 이동, 반대, 불만 제기 등의 권리. 행사 방식은 9절을 참조하십시오 |
| 6. 개인 데이터 미제공의 영향 | 본 서비스의 기본 기능(검색, 재생, 가사)은 로그인 없이, 행동 이벤트를 보고하지 않는 상태로 이용할 수 있습니다. 로그인은 즐겨찾기 클라우드 동기화 등 계정 기능에 필요하며, 개인화 추천은 선택 기능입니다 |

## 4. 수집하는 개인 데이터

### 4.1 계정 식별 데이터(Epomail 로그인 경유)

Epomail 계정으로 OAuth 2.0(PKCE) 로그인할 때 본 서비스는 Epomail의 userinfo 엔드포인트에서 다음 필드를 가져오며, 그 외 어떤 계정 데이터도 취득하지 않습니다.

| 필드 | 용도 | 저장 여부 |
| --- | --- | --- |
| 사용자 식별자(`id`/`sub`) | 세션 내 신원 식별 | 아니요 |
| 이메일 주소(검증 필수) | 가명 처리 해시 파생. 사용자 본인에게 발급되는 API Key 페이로드의 `sub` 클레임 | 아니요 |
| 닉네임 또는 사용자 이름(`name`/`username`/`nickname`) | 화면 표시 | 아니요 |
| 아바타 링크(`avatar`/`picture`) | 화면 표시 | 아니요 |
| 계정 역할(`role`) | 권한 판정 | 아니요 |

본 서비스는 별도의 회원가입 시스템을 두지 않으며 전화번호, 실명, 주소, 결제 데이터를 수집하지 않습니다. 이메일 주소는 로그인 세션 안에서 즉시 사용됩니다. 가명 처리 식별자 파생(`usr_` 접두어의 SHA-256 해시, 16진수 12문자 절취), 사용자 식별 해시 파생, 요청 제한 버킷 키 파생입니다. 파생된 해시 값으로 원래의 이메일 주소를 복원할 수 없습니다.

### 4.2 행동 이벤트

추천과 Auto DJ 기능을 제공하기 위해 본 서비스는 곡 재생과 관련된 행동 이벤트를 기록합니다. 이벤트 유형은 총 11종입니다. 검색, 검색 클릭, 재생 시작, 재생 진도, 완주, 건너뛰기, 다시 재생, 즐겨찾기, 즐겨찾기 취소, 거부, 거부 취소입니다. 각 이벤트는 다음 가명 처리 식별자 중 하나로 연결됩니다.

1. 로그인 사용자: 이메일 주소에서 파생된 SHA-256 해시(`usr_` 접두어).
2. 익명 참여자: 사용자 브라우저에서 로컬 생성된 무작위 식별자(`anon_` 접두어)를 서버에서 재해시한 것.
3. 공개 모드: 개인화가 꺼져 있으면 이벤트가 저장되지 않고, 서버에서 즉시 폐기됩니다.

이벤트 보고는 배치 방식을 사용합니다(한 배치 최대 50건, 요청 본문 상한 64 KB)하며 페이지가 숨겨질 때 발송 대기열을 플러시합니다. 각 이벤트가 기록하는 내용은 이벤트 유형, 곡 표준 식별자, 가수 식별자, 장르와 언어 태그, 검색어(해당 시), 재생 진도 비율, 신호 가중치에 한정됩니다. IP 주소도 기기 지문도 자유 텍스트 콘텐츠도 포함하지 않습니다.

노이즈와 가짜 신호 정화: 네트워크 지연(network_stall), 디코딩 실패(playback_error), 미리듣기 절단(trial_end), 스트림 불가(stream_unavailable), 버퍼링 초과(buffer_timeout), 자동 전환 실패(auto_switch_error)로 인한 곡 전환은 가중치가 항상 0이며 저장되지 않습니다. 클라이언트는 재생이 정상이고 청취 시간이 0.5초에서 25초 사이일 때만 능동적 건너뛰기를 보고합니다.

또한 추천 요청에는 사용자 클라이언트 로컬의 소량 컨텍스트(일부 즐겨찾기 곡, 최근 아티스트, 최근 검색어, 각각 건수 제한)가 함께 전송되며, 해당 요청의 메모리 안에서만 개인화 정렬에 사용되고 저장되지 않으며 로그에도 들어가지 않습니다.

### 4.3 전역 집계 통계

본 서비스는 별도로 어떤 사용자와도 무관한 전역 집계 통계를 유지하며, 인기 차트와 유사 추천에 사용합니다.

| 통계 테이블 | 내용 | 개인과의 연관 |
| --- | --- | --- |
| 검색어 집계 카운트 | 검색어의 전역 빈도 통계 | 없음 |
| 곡 공기 관계 | 곡이 함께 청취되는 전역 통계 | 없음 |

이 기록에는 개인 식별자가 없고 사용자의 신원과 연결되지 않으며, 「원클릭 프로필 삭제」의 범위에도 나타나지 않습니다(본래 어떤 사용자에게도 귀속되지 않기 때문입니다).

### 4.4 브라우저의 로컬 저장소

다음 데이터는 사용자의 브라우저에만 저장되며 운영자의 서버는 완전한 사본을 받지 않습니다. 브라우저 프라이빗 모드에서 저장소를 사용할 수 없으면 자동으로 메모리 임시 저장으로 저하됩니다.

| 저장 위치 | 키 | 내용 |
| --- | --- | --- |
| localStorage | `audio` | 재생 목록, 현재 곡, 재생 모드, 볼륨, 음소거 상태, 재생 기록 |
| localStorage | `library` | 좋아요한 곡, 즐겨찾기한 플레이리스트, 팔로우한 아티스트, 즐겨찾기한 MV, 즐겨찾기한 앨범, 직접 만든 플레이리스트 |
| localStorage | `global` | 테마, 언어 선호, 검색 기록(최대 10건) |
| localStorage | `settings` | 인터페이스 선호(배경 애니메이션, 음질 선호 등의 설정 항목) |
| localStorage | `recommend` | 개인화 스위치, Auto DJ 스위치, 익명 식별자, 거부 곡 목록 |
| localStorage | `sonic-perf-mode` | 성능 모드 스위치 |
| IndexedDB | `SonicMusicPlayerDB` | 가져온 로컬 음악 파일(`local_music`)과 다운로드한 곡(`downloaded_music`) |

### 4.5 자동 처리되는 기술 데이터

- 요청 제한: 익명 요청은 IP로 버킷 제한합니다(분당 240회, 기본값). IP는 요청 제한 키로 잠시 사용될 뿐입니다. 엣지 네이티브 제한기는 데이터를 보존하지 않거나, 120초 자동 만료의 KV 기록으로 임시 저장하거나, 60초 메모리 창 안에 임시 저장합니다(최대 4096 버킷). IP는 데이터베이스에 기록되지 않고 액세스 로그에도 기록되지 않습니다. 인증 요청은 이메일 해시로 버킷 제한합니다(분당 600회, 기본값). 인증 엔드포인트에는 분당 IP당 30회의 전용 요청 제한이 별도로 적용됩니다.
- 세션과 키: 로그인 성공 후 `HttpOnly; Secure; SameSite=Lax` 속성의 `sonic_session` 쿠키(유효 기간 최대 30일)를 발급하며 그 안에 서명된 API Key가 들어 있습니다. 키는 URL, 쿼리 매개변수, localStorage에 기록하지 않습니다. OAuth 과정에는 `sonic_oauth_state`와 `sonic_oauth_verifier` 트랜잭션 쿠키를 사용합니다(유효 기간 600초, `/api/auth` 경로 한정). API Key 페이로드에는 `sub`(이메일), `iat`, `exp`, `jti`, `kid`, `role`, `uid`가 포함되며, `jti`는 폐기 목록과 로그아웃 즉시 무효화에 사용됩니다.
- 액세스 로그: 데이터 플레인 액세스 로그는 줄 단위 JSON이며 요청 식별자, 메서드, 경로, 상태 코드, 소요 시간만 포함합니다. 쿼리 문자열, IP, User-Agent, Cookie, Authorization, 요청 본문은 일절 기록하지 않습니다. 예외 로그에는 요청 식별자, 오류 이름, 절취된 오류 메시지만 담깁니다.
- 오디오 프록시: 오디오 스트림은 기본적으로 본 서비스의 엣지 프록시로 가져오며, 업스트림 요청에는 User-Agent, CDN 설정에 따른 공식 사이트 Referer, Range 헤더만 담기고 Set-Cookie와 자격 증명 헤더는 제거합니다. 업스트림 CDN에는 프록시 서버의 주소만 보입니다. 사용자가 `?mode=redirect` 직접 연결 모드를 능동적으로 호출하면 브라우저가 공식 CDN과 직접 연결을 맺고 사용자의 IP가 그 CDN에 보입니다(302 리다이렉트의 고유한 의미입니다). 웹 플레이어는 이 모드를 사용하지 않습니다.
- 엣지 네트워크: Cloudflare가 자체 정책에 따라 네트워크 계층 요청 메타데이터를 처리합니다.

### 4.6 본 서비스가 수집하지 않는 항목

본 서비스에는 광고 추적, 교차 사이트 쿠키, 제3자 통계나 분석 스크립트, 기기 지문, 행동 광고 프로필이 없습니다. 연락처, 사진첩, 위치, 음악 재생과 무관한 어떤 기기 데이터도 수집하지 않습니다. 개인 데이터를 판매하지 않고 광고 목적으로 이용하지 않으며 어떤 광고 네트워크에도 접속하지 않습니다.

## 5. 법적 근거와 처리 목적

각 처리 활동의 법적 근거는 다음과 같습니다.

| 처리 활동 | 목적 | 법적 근거 |
| --- | --- | --- |

| 행동 이벤트와 추천 프로필(가명 처리) | 추천과 Auto DJ 기능 | 정당한 이익(GDPR 제6조 제1항 f호). 개인화는 언제든 끌 수 있으며(9절의 반대권) 끄면 즉시 수집이 중단됩니다 |
| 전역 집계 통계 | 인기 차트와 유사 추천 | 정당한 이익(GDPR 제6조 제1항 f호). 개인과 연관 없음 |
| 익명 식별자 이벤트(익명 참여자) | 추천 기능 | 사용자의 자발적 선택. 개인화를 끄면 종료 |
| IP 요청 제한, 세션 보안, 악용 방지 | 서비스 보안과 안정 | 정당한 이익(GDPR 제6조 제1항 f호). 해당 시 법정 의무에도 해당(GDPR 제6조 제1항 c호) |

개인 데이터는 위 목적과 그와 밀접히 관련된 범위에만 사용됩니다. 본 서비스는 자동화 의사결정(GDPR 제22조에서 말하는 법적 효과를 발생시키거나 이와 유사하게 중대한 영향을 미치는 의사결정)을 위해 사용자의 데이터를 이용하지 않습니다. 추천 결과의 영향은 보이는 재생 순서와 차트 정렬에 한정되며 언제든 끌 수 있습니다.

## 7. 제3자와의 공유 및 국제 전송

본 서비스는 최소 필요 원칙에 따라 제3자와 개인 데이터를 공유합니다. 전체 사례는 [제3자 공유 및 전송 목록](/ko/sub-processors/)에 있으며 요지는 다음과 같습니다.

1. 수탁 처리: Cloudflare(Pages 호스팅, Functions 엣지 연산, Tunnel 암호화 터널, KV 저장, 요청 제한 인프라).
2. 신원 제공자: Epomail(로그인 시 식별자, 이메일, 닉네임, 아바타 링크, 역할을 취득).
3. 업스트림 콘텐츠 출처: NetEase, QQ, KuGou, Kuwo, AMLL, LRCLIB 및 각 공식 콘텐츠 CDN. 요청에는 곡 검색 매개변수와 고정 User-Agent·Referer만 포함되며 사용자의 신원이나 IP는 포함되지 않습니다.
4. 법적 요구: 법정 절차에 따라 권한 있는 기관이 요구할 때만 제공하고, 법률이 허용하는 범위에서 사용자에게 통지합니다.

본 서비스의 컨트롤 플레인은 Cloudflare 글로벌 엣지 네트워크에서 실행되므로 개인 데이터가 운영자 소재국 외 노드에서 처리될 수 있습니다. 운영자는 GDPR 제44조 내지 제46조의 보장 메커니즘(EU 표준 계약 조항 포함)으로 위탁과 수탁 처리 관계의 국제 전송을 관리하고, Cloudflare의 데이터 보호 조치(SOC 2 Type II, ISO/IEC 27001 인증)에 의존합니다. 셀프 호스팅 운영자는 자신의 국제 전송이 자신 소재지의 법적 요건에 부합하는지 스스로 평가하고 보장해야 합니다.

## 8. 아동의 보호

본 서비스는 16세 미만 아동을 대상으로 하지 않고 아동의 개인 데이터를 의도적으로 수집하지도 않습니다. 사용자 소재지 법률이 정보사회 서비스의 동의 연령에 더 낮은 규정을 두는 경우(최저 13세, GDPR 제8조) 그 규정을 따릅니다. 보호자가 아동이 개인 데이터를 제공했다고 판단하면 운영자에게 연락해 삭제를 요청할 수 있으며, 확인 후 즉시 처리합니다. 누구도 본 서비스를 이용해 아동·청소년에게 심신 건강에 유해한 콘텐츠를 퍼뜨릴 수 없습니다. 관련 이용 제한은 [허용 가능 사용 정책](/ko/acceptable-use/)을 참조하십시오.

## 9. 정보주체 권리와 행사 방식

사용자는 자신의 개인 데이터에 대해 다음 권리를 갖습니다.

1. 열람과 사본 수령(GDPR 제15조).
2. 정정(GDPR 제16조).
3. 삭제(GDPR 제17조).
4. 처리 제한(GDPR 제18조).
5. 데이터 이동(GDPR 제20조).
6. 반대(GDPR 제21조), 개인화의 언제든 종료 포함.
7. 자동화 처리에만 근거한 의사결정에 구속되지 않을 권리(GDPR 제22조). 본 서비스는 이런 의사결정을 하지 않습니다.

   - 「모든 로컬 데이터 삭제」: 브라우저 localStorage, sessionStorage와 IndexedDB 전체 데이터베이스를 즉시 지우고 서버 프로필도 함께 파기합니다.

## 10. 보안 유지 조치

운영자는 GDPR 제32조에 따라 적절한 기술적·조직적 조치를 수립하고 지속적으로 개선하여 개인 데이터의 도용, 변조, 훼손, 멸실, 유출을 방지합니다. 전 구간 HTTPS/TLS. HMAC-SHA256 버전 관리 서명 API Key와 상수 시간 비교. PKCE OAuth 흐름과 트랜잭션 쿠키 시간 제한. 세션 쿠키의 HttpOnly·Secure·SameSite 속성과 즉시 폐기. 데이터 플레인은 루프백 주소에만 바인딩하고 암호화 터널로 접속. 전 구간 SSRF 차단과 도메인 화이트리스트. 가명 처리 식별자와 IP 없는 데이터베이스 설계. 로그 최소화. fail-closed 키 검증. 전체 목록, 처리 매트릭스와 알려진 한계의 설명은 [데이터 처리 및 보안 유지](/ko/data-security/)를 참조하십시오.
