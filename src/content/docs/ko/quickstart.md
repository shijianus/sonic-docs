**시행일: 2026년 11월 2일｜버전: 1.5**

이 페이지는 Sonic 호스팅 인스턴스(`sonic.epocanvas.tech`) 이용의 최단 경로를 제공합니다. 사이트 열기부터 검색과 재생, 로그인, 로컬 즐겨찾기, 다운로드와 로컬 음악, 모바일 이용까지입니다. 화면의 전체 안내는 [인터페이스 및 기능 안내](/ko/interface/)에 있으며, 이 페이지는 셀프 호스팅을 다루지 않습니다(배포는 [배포 가이드](/ko/deployment/) 참조).

## 1. 사이트 열기

브라우저에서 `sonic.epocanvas.tech`(예비 미러 `sonic.epocanvas.com`)에 접속합니다. 인터페이스 언어는 기본적으로 브라우저를 따르며 「설정 → 인터페이스 언어」에서 간체 중국어, English, 日本語로 전환할 수 있습니다. 테마(라이트/다크/시스템 따르기)도 같은 곳에서 조정합니다. 로그인 없이도 전체 핵심 기능을 이용할 수 있습니다.

## 2. 검색과 재생

1. 왼쪽 사이드바 상단의 검색창(또는 「검색」 페이지)에 곡, 가수, 앨범 또는 플레이리스트 키워드를 입력합니다. 검색은 간체/번체 정규화, 병음 약어, 오타 허용을 지원합니다.
2. 결과는 「곡/플레이리스트/MV」 세 개 탭으로 나뉩니다. 곡을 클릭하면 재생이 시작되고, 「전체 재생」으로 목록 전체를 연속 재생할 수 있습니다.
3. 하단 재생 바에는 현재 곡, 가사 미리보기 줄, 음질 배지(SQ 무손실 등)가 표시됩니다. 커버를 클릭하면 전체 화면 플레이어 드로어가 펼쳐지며 글자 단위 가사(원문/번역/로마자 세 경로를 각각 온·오프 가능)를 볼 수 있습니다.

30초 미리듣기 구간을 만나면 플레이어는 미리듣기 표시로 사실대로 표기하며 온전한 곡처럼 보이게 하지 않습니다. 교차 소스 보완을 켜면 무료 온전 곡 매칭을 자동으로 시도합니다.

## 3. 로그인과 로컬 즐겨찾기

Epomail 계정으로 OAuth 2.0(PKCE) 로그인하며, 본 서비스는 별도의 회원가입 시스템을 두지 않습니다.

1. 사이드바 하단의 로그인 진입점을 클릭하여 Epomail 인가 페이지로 이동한 뒤 확인합니다.
2. 로그인하면 좋아요한 곡, 즐겨찾기한 플레이리스트, 팔로우한 아티스트, 직접 만든 플레이리스트를 이용할 수 있습니다(현재 사용하는 브라우저에만 저장되며 클라우드나 다른 기기와 동기화되지 않음).
3. 로그인과 동시에 개인화 추천과 Auto DJ 연속 재생도 이용할 수 있습니다. 둘 다 「설정 → 프라이버시와 로컬 데이터」에서 끌 수 있으며, 끄면 추천이 공개 정보만 사용하는 모드로 전환되어 행동 이벤트를 기록하지 않습니다. 즐겨찾기, 플레이리스트, 선호 설정은 현재 사용하는 브라우저에만 저장되며 클라우드나 다른 기기와 동기화되지 않습니다.

세션 유효 기간은 최대 30일이며 로그아웃하면 즉시 무효화됩니다. 즐겨찾기, 플레이리스트, 선호 설정은 기기 간에 동기화되지 않습니다. 계정 규칙은 [이용약관](/ko/terms-of-service/) 3절을 참조하십시오.

## 4. 다운로드와 로컬 음악

1. 다운로드: 곡 작업 열 또는 하단 재생 바에서 다운로드를 클릭하면 곡이 음질 메타데이터와 함께 브라우저 IndexedDB에 저장되고 「다운로드 목록」 페이지에서 관리됩니다. 오프라인에서도 재생할 수 있습니다.
2. 로컬 음악: 「로컬 음악」 페이지에서는 클릭으로 추가하거나 오디오 파일을 브라우저로 드래그 앤 드롭할 수 있습니다. 가져온 파일도 마찬가지로 IndexedDB에 저장되며 서버로 업로드되지 않습니다.
3. 둘 다 개인 청취에만 사용할 수 있으며 재배포할 수 없습니다([허용 가능 사용 정책](/ko/acceptable-use/) 참조).

## 5. 모바일 이용

휴대폰 브라우저로 같은 주소에 접속하면 모바일 레이아웃이 됩니다. 하단 탭 내비게이션(홈, 검색, 최근 재생, 설정)과 미니 재생 바가 있고, 플레이어 드로어는 동등한 글자 단위 가사와 음질 메뉴를 제공합니다. 즐겨찾기, 플레이리스트, 선호 설정, 다운로드는 모바일과 데스크톱에서 각각 독립적으로 저장됩니다(모두 각자의 브라우저 안에 있으며 클라우드 동기화는 없음).

## 6. 프라이버시 설정 첫걸음

처음 사용할 때는 세 가지 제어 항목을 알아두는 것이 좋습니다(위치는 「설정 → 프라이버시와 로컬 데이터」).

1. 스마트 검색과 개인화 추천: 총괄 스위치로, 끄면 이벤트가 더 이상 수집되지 않습니다.
2. 자동 연속 라디오(Auto DJ): 재생이 끝난 뒤의 자동 이어 재기를 제어합니다.
3. 추천 프로필 및 관심 없음 기록 초기화/모든 로컬 데이터 삭제: 즉시 적용되는 두 개의 삭제 버튼입니다.

프라이버시 약속의 전체 내용은 [개인정보 처리방침](/ko/privacy-policy/)을 참조하십시오.

## 7. 자주 묻는 질문 빠른 참조

| 질문 | 답변 |
| --- | --- |
| 유료인가요? | 무료, 광고 없음, 인앱 결제 없음 |
| 로그인 없이 쓸 수 있나요? | 핵심 기능은 익명 이용 가능(요청 제한은 더 엄격) |
| 데이터는 어디에 저장되나요? | 브라우저 로컬 + 서버의 가명 처리 행동 이벤트(90일) |
| 프로필은 어떻게 삭제하나요? | 설정 → 추천 프로필 초기화, 즉시 적용 |
| 왜 30초인가요? | 공식 미리듣기 절단으로 사실대로 표기하며 최선을 다해 교차 소스 보완 |
| 음질 허위 표시가 있나요? | 배지는 현재 스트림 등급을 사실대로 반영 |

더 많은 질문은 [프로젝트 소개](/ko/project/) 12절을, 법률 용어는 [용어 정의](/ko/key-terms/)를 참조하십시오.
