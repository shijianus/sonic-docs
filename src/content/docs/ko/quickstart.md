**개정일: 2026년 11월 2일｜버전: 1.8**

이 페이지는 Sonic 호스팅 테스트 인스턴스(`sonic.epocanvas.tech`)에서 검색·재생, 로그인, 로컬 즐겨찾기와 음악을 사용하는 경로를 안내합니다. 2026-11-02에 검토한 최신 공개 후보 브랜치(RC) `rc/sonic-20261031@a75f5cb`(2026-11-01 UTC)에 근거하며, 정식 GitHub Release가 아닙니다. 이전 `main@ce443c8`(2026-10-27 UTC)과는 구현이 다르므로 같은 기능을 가정할 수 없고 실제 서비스 버전은 알 수 없습니다. 즐겨찾기, 플레이리스트와 선호는 주로 현재 브라우저에 저장되며 범용 기기 간 클라우드 동기화를 보장하지 않습니다. 일부 피드백이나 맥락은 전송될 수 있습니다. 이 사이트는 간체 중국어를 유지·관리 기준으로 삼으며 나머지 9개 언어는 번역본입니다. 강행법규, 소비자에게 유리한 해석과 이해하기 쉬운 고지가 우선합니다. 화면 안내는 [인터페이스 및 기능 안내](/ko/interface/), 셀프 호스팅은 [배포 가이드](/ko/deployment/)를 참조하십시오.

## 1. 사이트 열기

브라우저에서 `sonic.epocanvas.tech`(예비 미러 `sonic.epocanvas.com`)에 접속합니다. 인터페이스 언어는 기본적으로 브라우저를 따르며 「설정 → 인터페이스 언어」에서 간체 중국어, English, 日本語로 전환할 수 있습니다. 테마(라이트/다크/시스템 따르기)도 같은 곳에서 조정합니다. 로그인 없이도 전체 핵심 기능을 이용할 수 있습니다.

## 2. 검색과 재생

1. 왼쪽 사이드바 상단의 검색창(또는 「검색」 페이지)에 곡, 가수, 앨범 또는 플레이리스트 키워드를 입력합니다. 검색은 간체/번체 정규화, 병음 약어, 오타 허용을 지원합니다.
2. 결과는 「곡/플레이리스트/MV」 세 개 탭으로 나뉩니다. 곡을 클릭하면 재생이 시작되고, 「전체 재생」으로 목록 전체를 연속 재생할 수 있습니다.
3. 하단 재생 바에는 현재 곡, 가사 미리보기 줄, 음질 배지(SQ 무손실 등)가 표시됩니다. 커버를 클릭하면 전체 화면 플레이어 드로어가 펼쳐지며 글자 단위 가사(원문/번역/로마자 세 경로를 각각 온·오프 가능)를 볼 수 있습니다.

미리듣기로 판별된 구간에는 해당 표시가 나타나며 교차 소스 보완은 다른 재생 가능한 버전을 찾는 시도입니다. 결과·음질·전체 곡 제공이나 콘텐츠 권한을 보장하지 않습니다. 검색어는 개인화 설정과 별개로 서버에 집계되어 공개 제안에 나타날 수 있으므로 이름·이메일·민감한 내용을 입력하지 마십시오. 오디오 프록시와 별개로 Google Fonts, 이메일 seed의 DiceBear 아바타, MV·커버 직접 요청은 IP나 이메일을 외부에 전달할 수 있습니다.

## 3. 로그인과 로컬 즐겨찾기

Epomail 계정으로 OAuth 2.0(PKCE) 로그인하며, 본 서비스는 별도의 회원가입 시스템을 두지 않습니다.

1. 사이드바 하단의 로그인 진입점을 클릭하여 Epomail 인가 페이지로 이동한 뒤 확인합니다. 로그인은 선택적 프로파일링에 대한 동의가 아닙니다.
2. 좋아요한 곡, 즐겨찾기한 플레이리스트, 팔로우한 아티스트, 직접 만든 플레이리스트는 주로 브라우저 저장소를 사용합니다. 일부 즐겨찾기 피드백과 추천 맥락은 전송될 수 있습니다. 범용 기기 간 클라우드 동기화를 보장하지 않으며 레이더의 원격 경로도 실제 배포에 따라 확인해야 합니다.
3. 개인화와 Auto DJ는 현재 기본으로 켜져 있지만 이것이 명시적 동의를 받은 것은 아니며 로그인도 동의가 아닙니다. 「설정 → 프라이버시와 로컬 데이터」에서 끌 수 있지만 독립적인 검색 통계나 모든 레이더 경로까지 중단되지는 않습니다. 유효한 근거가 없는 선택적 처리는 중단해야 합니다.

세션은 서명된 자격 증명으로 기본 유효 기간은 30일입니다. 서명은 암호화가 아니며, 사용자 정보와 이메일은 `auth` localStorage에도 남습니다. 로그아웃 시 현재 쿠키를 정리하지만 복사된 토큰의 원격 무효화는 KV와 폐기 설정, 요청 성공 여부에 달려 있습니다. 실제 인스턴스의 설정은 별도 확인이 필요합니다([계정 및 보안 안내](/ko/account-security/) 참조). 서비스 이용 기준은 만 16세 이상이지만 로그인으로 연령이 검증되지는 않습니다. [이용약관](/ko/terms-of-service/) 3절을 참조하십시오.

## 4. 다운로드와 로컬 음악

1. 다운로드: 곡 작업 열 또는 하단 재생 바에서 다운로드를 클릭하면 곡이 음질 메타데이터와 함께 브라우저 IndexedDB에 저장되고 「다운로드 목록」 페이지에서 관리됩니다. 저장이 완료되고 브라우저가 지원하면 오프라인 재생이 가능합니다.
2. 로컬 음악: 오디오 파일을 선택하거나 끌어다 놓아 IndexedDB로 가져옵니다. 오디오 파일 본체 업로드 경로는 발견되지 않았습니다. 가사 매칭, 즐겨찾기 피드백과 추천 맥락을 통해 제목, 아티스트, 앨범 또는 곡 식별자가 전송될 수 있으며, 내장 커버 이미지도 이벤트와 함께 전송될 수 있습니다.
3. 가져오기나 다운로드는 콘텐츠 이용·재배포 권한을 부여하지 않습니다. 허락받은 범위와 적용 법률을 준수하십시오([허용 가능 사용 정책](/ko/acceptable-use/) 참조).

## 5. 모바일 이용

휴대폰 브라우저로 같은 주소에 접속하면 모바일 레이아웃이 됩니다. 하단 탭 내비게이션(홈, 검색, 최근 재생, 설정)과 미니 재생 바가 있고, 플레이어 드로어는 동등한 글자 단위 가사와 음질 메뉴를 제공합니다. 로컬 음악 라이브러리와 다운로드는 각 브라우저에 독립적으로 보관됩니다. 범용 기기 간 동기화를 보장하지 않으며 메타데이터 전송이나 별도의 레이더 동기화 경로를 배제하지도 않습니다.

## 6. 프라이버시 설정 첫걸음

처음 사용할 때는 세 가지 제어 항목을 알아두는 것이 좋습니다(위치는 「설정 → 프라이버시와 로컬 데이터」).

1. 스마트 검색과 개인화 추천: 해당 범위의 추천 처리를 제어하며 모든 네트워크 요청이나 독립적인 검색어 재이용을 제어하지는 않습니다. 검색 원문이 공개 검색 제안에 나타날 수 있으므로 사적인 정보나 민감한 정보를 입력하지 마십시오.
2. 자동 연속 라디오(Auto DJ): 재생이 끝난 뒤 자동으로 이어 재생하는 기능을 제어합니다. 기본 활성화는 동의가 아닙니다.
3. 추천 프로필 및 관심 없음 기록 초기화/모든 로컬 데이터 삭제: 부분적인 초기화 수단입니다. 프로필 초기화는 현재 신원만 대상으로 하며 이전 익명 신원·레이더·검색 집계·외부 시스템·백업을 포괄하지 않고, 실패해도 성공 표시가 나올 수 있습니다. 로컬 삭제는 HttpOnly 쿠키를 지우거나 로그아웃하지 않으며 다시 로드하면 개인화 기본값이 켜질 수 있습니다.

시크릿 모드도 요청과 이벤트 전송을 막지 않습니다. 완전한 원격 삭제나 자료 확인은 `privacy@epocanvas.com`으로 요청하십시오. 기본값에 관한 설명은 유효한 동의나 배포 개선이 이루어졌다는 뜻이 아닙니다. 자세한 내용은 [개인정보 처리방침](/ko/privacy-policy/)을 참조하십시오.
