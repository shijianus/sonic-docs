Sonic 추천 엔진의 신호, 가중치, 정렬과 사용자 제어 항목을 설명합니다. 2026-11-02에 검토한 최신 공개 후보 브랜치(RC) `rc/sonic-20261031@a75f5cb`(2026-11-01 UTC)에서는 개인화와 Auto DJ가 기본으로 켜져 있으며, 정식 GitHub Release가 아니며 실제 서비스 버전은 알 수 없습니다. 이전 `main@ce443c8`(2026-10-27 UTC)과는 구현이 다르므로 같은 기능을 가정할 수 없습니다. 사전의 별도 동의 절차는 확인되지 않았습니다. 아래 곡 신호 외에도 검토한 코드에는 아티스트, 앨범, 플레이리스트, MV 피드백과 레이더 프로필이 포함됩니다. 기본값, 로그인과 계속 이용은 명시적 동의가 아니며 유효한 근거가 없는 선택적 프로파일링은 중단해야 합니다. 이메일 파생 해시와 `anon_` 식별자는 연결 가능한 가명이지 익명화가 아닙니다. 실제 배포 상태와 구별하여 읽고, 처리 범위와 필요한 선택 절차는 [개인정보 처리방침](/ko/privacy-policy/) 4.2절과 5절을 참조하십시오.

## 1. 행동 신호와 가중치

| 신호 | 가중치 | 설명 |
| --- | --- | --- |
| favorite(즐겨찾기 추가) | +4.0 | 매우 강한 긍정 |
| replay(다시 재생) | +3.5 | 강한 긍정 |
| play_complete(유효 완주) | +2.5 | 표준 긍정 |
| play_progress(진도 청취) | +0.2 ~ +1.8 | 청취 비율에 따라 단계별 점수 |
| skip(빠른 건너뛰기) | -0.8 | 절반 이상 들은 뒤의 곡 전환은 +0.25 |
| dislike(명시적 거부) | -5.0 | 사용 가능한 신원·기능 범위에서 일치하는 추천만 필터링하며 영구적·전면 차단을 약속하지 않음 |

**노이즈 정제**: 네트워크 지연(network_stall), 디코딩 실패(playback_error), 미리듣기 절단(trial_end), 스트림 불가(stream_unavailable), 버퍼링 초과(buffer_timeout), 자동 전환 실패(auto_switch_error)로 인한 여섯 유형의 비사용자 곡 전환은 가중치가 항상 0이며 저장되지 않습니다.

## 2. 인기 모델

사이트 내 트렌드 차트는 유효 재생(35%), 고유 청취자(25%), 완주 지표(20%), 즐겨찾기 전환(15%), 성장 기울기(5%)의 다섯 요소를 가중 합산합니다. 여기에 지수 시간 감쇠(24시간 급상승 차트와 7일 누적 인기 차트)와 베이지안·Wilson Score 평활을 보조로 적용하여, 재생 수는 적지만 완주율만 높은 우연한 항목이 비정상적으로 상위에 고정되지 않도록 합니다.

## 3. 세션 의도와 장기 선호

추천은 세션 검색 의도와 완주·즐겨찾기 등 장기 선호 신호를 구분하여 가중치를 적용합니다. 그러나 이 모델 구분이 검색어의 원격 저장을 막는 것은 아닙니다. 스마트 검색은 개인화 설정과 별개로 정규화·표시용 검색어, 횟수와 시간을 누적하고 공개 제안으로 반환할 수 있습니다. 검색어 자체에 개인정보가 있을 수 있으므로 이름·이메일·민감한 내용을 입력하지 마십시오. 추천 요청에는 일부 로컬 즐겨찾기·아티스트·검색 맥락도 포함될 수 있고 엔티티 피드백은 원시 맥락 JSON을 저장할 수 있습니다.

## 4. 다양성 재정렬과 Auto DJ

1. 유사도: 가수 관계 그래프, 장르 및 언어 태그의 집합 유사도, 오디오 특성의 코사인 유사도를 결합합니다.
2. MMR 재정렬: 한계 관련성으로 「정확성」과 「새로움」의 균형을 잡아 한 가수나 한 장르의 정보 필터 버블에 머무르지 않도록 합니다.
3. Auto DJ: 플레이리스트가 자연스럽게 끝나면 현재 곡의 스타일에 맞는 재생 가능한 곡을 자동으로 이어 붙입니다. 설정에서 끌 수 있습니다. 해당 스위치는 개인화와 독립적이므로 개인화를 꺼도 시드와 제외할 곡을 전송할 수 있습니다.

## 5. 음악 및 스타일 레이더

홈 레이더는 검색 의도와 선호 신호를 사용합니다. 코드에는 로컬 레이더 상태, 프로필과 원격 동기화 경로가 있으므로 저장된 자료를 전혀 바꾸지 않는 단순 표시 기능이 아닙니다. 개인화를 끈 뒤에도 곡, 커버와 신호가 포함된 동기화 페이로드를 전송할 수 있으며 서버는 비활성화 표시를 근거로 저장을 거부할 수 있습니다. 요청 전송과 저장 성공은 각각 판단해야 합니다. 원격 경로의 이용 가능성에도 한계가 있으며 범용 클라우드 동기화를 보장하지 않습니다. 이벤트 정리나 프로필 초기화가 레이더 자료 전체를 포함하지도 않습니다.

## 6. 사용자의 제어 항목

| 제어 항목 | 위치 | 효과 |
| --- | --- | --- |
| 개인화 전체 스위치 | 설정 → 프라이버시와 로컬 데이터 | 해당 범위의 추천 이벤트를 제어하며 독립적인 검색 통계나 모든 레이더 경로를 제어하지는 않음 |
| Auto DJ 스위치 | 설정 → 프라이버시와 로컬 데이터 | 재생 종료 후 자동 이어 재생을 제어함. 기본 활성화는 동의가 아님 |
| 추천 프로필 초기화 | 설정 → 프라이버시와 로컬 데이터 | 현재 신원의 일부 이벤트·피드백을 삭제함. 이전 식별자, 레이더, 집계, 외부 서비스와 백업이 누락될 수 있으며 실패가 표시되지 않을 수도 있음 |
| 곡 거부 | 플레이어의 dislike | 사용 가능한 신원·기능 범위에서 일치하는 추천만 필터링하며 영구적·전면 차단을 약속하지 않음 |

초기화는 원격 실패를 무시하고 로컬 거부 기록을 지우거나 익명 식별자를 바꾼 뒤 성공으로 표시할 수 있습니다. 기본 90일 보존 설정도 모든 자료의 정확한 만료·파기를 보장하지 않습니다. 완전한 원격 삭제·자료 확인은 `privacy@epocanvas.com`으로 요청하십시오. 「모든 로컬 데이터 삭제」는 HttpOnly 세션 쿠키를 지우거나 로그아웃하지 않으며, 설정을 비운 뒤 다시 로드하면 개인화 기본값이 켜질 수 있습니다. 시크릿 모드 자체도 전송을 막지 않습니다.

소스 코드 확인은 문서를 바로잡기 위한 것이며 잘못된 고지의 책임을 면제하거나 적법한 근거를 대신하지 않습니다. 확인 절차는 [개발 가이드](/ko/development/) 4절을 참조하십시오.
