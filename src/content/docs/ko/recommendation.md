**시행일: 2026년 11월 2일｜버전: 1.5**

Sonic 추천 엔진의 구성을 설명합니다. 어떤 신호가 모델에 들어가고 어떻게 가중치를 적용해 순서를 정하는지, 사용자가 어떤 제어권을 갖는지를 다룹니다. 모든 규칙은 소스 코드에 공개되어 있습니다. 데이터 수집의 법적 근거와 범위는 [개인정보 처리방침](/ko/privacy-policy/) 4.2절과 5절을 참조하십시오.

## 1. 행동 신호와 가중치

| 신호 | 가중치 | 설명 |
| --- | --- | --- |
| favorite(즐겨찾기 추가) | +4.0 | 매우 강한 긍정 |
| replay(다시 재생) | +3.5 | 강한 긍정 |
| play_complete(유효 완주) | +2.5 | 표준 긍정 |
| play_progress(진도 청취) | +0.2 ~ +1.8 | 청취 비율에 따라 단계별 점수 |
| skip(빠른 건너뛰기) | -0.8 | 절반 이상 들은 뒤의 곡 전환은 +0.25 |
| dislike(명시적 거부) | -5.0 | 하드 필터 후 블랙리스트 등록 |

**노이즈 정제**: 네트워크 지연(network_stall), 디코딩 실패(playback_error), 미리듣기 절단(trial_end), 스트림 불가(stream_unavailable), 버퍼링 초과(buffer_timeout), 자동 전환 실패(auto_switch_error)로 인한 여섯 유형의 비사용자 곡 전환은 가중치가 항상 0이며 저장되지 않습니다.

## 2. 인기 모델

사이트 내 트렌드 차트는 유효 재생(35%), 고유 청취자(25%), 완주 지표(20%), 즐겨찾기 전환(15%), 성장 기울기(5%)의 다섯 요소를 가중 합산합니다. 여기에 지수 시간 감쇠(24시간 급상승 차트와 7일 누적 인기 차트)와 베이지안·Wilson Score 평활을 보조로 적용하여, 재생 수는 적지만 완주율만 높은 우연한 항목이 비정상적으로 상위에 고정되지 않도록 합니다.

## 3. 세션 의도와 장기 선호

세션 단위 검색 의도(연속 검색어, 클릭한 가수와 장르)는 단기 가중치를 높게 적용해 즉시 정렬에 반영하고 장기 선호와 분리합니다. 완주나 즐겨찾기 같은 가치가 높은 행동만 장기 프로필에 쌓이며, 우연한 검색 하나가 장기 프로필을 즉시 바꾸지는 않습니다.

## 4. 다양성 재정렬과 Auto DJ

1. 유사도: 가수 관계 그래프, 장르 및 언어 태그의 집합 유사도, 오디오 특성의 코사인 유사도를 결합합니다.
2. MMR 재정렬: 한계 관련성으로 「정확성」과 「새로움」의 균형을 잡아 한 가수나 한 장르의 정보 필터 버블에 머무르지 않도록 합니다.
3. Auto DJ: 플레이리스트가 자연스럽게 끝나면 현재 곡의 스타일에 맞는 재생 가능한 곡을 자동으로 이어 붙입니다. 설정에서 끌 수 있습니다.

## 5. 음악 및 스타일 레이더

검색을 한 번 완료하면 홈 레이더가 검색 의도와 선호 신호에 따라 일치하는 결과를 인기 곡과 같은 형태로 바로 보여 줍니다. 레이더는 표시되는 추천 순서만 바꾸며 저장된 데이터는 변경하지 않습니다.

## 6. 사용자의 제어 항목

| 제어 항목 | 위치 | 효과 |
| --- | --- | --- |
| 개인화 전체 스위치 | 설정 → 프라이버시와 로컬 데이터 | 끄면 이벤트를 더 수집하지 않고 추천이 순수 공개 모드로 전환됨 |
| Auto DJ 스위치 | 설정 → 프라이버시와 로컬 데이터 | 재생 종료 후 자동으로 이어 갈지 제어함 |
| 추천 프로필 초기화 | 설정 → 프라이버시와 로컬 데이터 | 서버에 저장된 행동 이벤트를 즉시 모두 파기함 |
| 곡 거부 | 플레이어의 dislike | 하드 필터링하여 추천에 다시 표시하지 않음 |

알고리즘의 기술적 사실은 소스 코드와 함께 바뀔 수 있습니다. 이 문서와 소스 코드가 다르면 소스 코드를 기준으로 문서를 수정합니다. 확인 절차는 [개발 가이드](/ko/development/) 4절을 참조하십시오.
