**시행일: 2026년 11월 1일｜버전: 1.4**

본 약관은 사용자와 사용 중인 인스턴스의 운영자 사이의, Sonic 서비스(이하 「본 서비스」) 이용에 관한 약정입니다. 로그인을 완료하거나 다른 방식으로 본 서비스를 사용하면 본 약관의 전체 내용을 읽고 동의한 것으로 간주되며, 동의하지 않으면 본 서비스를 사용하지 마십시오.

본 약관은 표준 약관으로 전문이 공개되어 검토할 수 있고 역대 버전은 오픈 소스 코드 저장소에 보관됩니다. 전자 방식으로 한 동의는 실물 문서와 서명과 동등한 효력을 갖습니다. 적용 법률상 표준 약관으로 배제하거나 제한할 수 없는 권리는 본 약관으로 인해 영향을 받지 않습니다. 본 사이트의 법률 문서는 간체 중국어 버전이 공식 버전이며, 영어, 일본어, 한국어 버전은 대조용 참조 번역본입니다. 문언에 의문이 있을 때는 공식 버전을 따릅니다.

## 1. 정의

1. 본 서비스: 어느 Sonic 인스턴스 위에서 실행되는 전체 기능. 웹 플레이어, 엣지 게이트웨이, 로컬 프로토콜 엔진, 개방 API와 관련 구성 요소를 포함합니다. 화면 구성과 기능 위치는 [인터페이스 및 기능 안내](/ko/interface/)를 참조하십시오.
2. 운영자: 사용 중인 인스턴스를 배포하고 운영하는 개인 또는 팀. 호스팅 인스턴스(`sonic.epocanvas.tech`, `sonic.epocanvas.com`)라면 운영 팀을, 셀프 호스팅 인스턴스라면 그 배포자를 가리킵니다.
3. 사용자(이용자): 로그인하거나 다른 방식으로 본 서비스를 사용하는 자연인 또는 조직.
4. 계약 성립: 어느 인스턴스에 로그인했는지에 따라 그 인스턴스의 운영자와 계약이 성립합니다. 본 약관은 공통 템플릿입니다. 호스팅 인스턴스에 직접 적용되며, 셀프 호스팅 운영자는 수정 후 자신의 사이트 약관으로 삼을 수 있고 자신 소재지의 적용 법률에 따라 사용자에게 고지 의무를 이행해야 합니다.
5. 데이터 플레인: 사용 중인 인스턴스에 프로토콜 파싱과 추천 계산을 제공하는 Linux 노드. 오프라인이 되어도 4절 2항에 따라 받는 저하 서비스에는 영향이 없습니다.

## 2. 서비스의 설명과 범위

본 서비스는 검색, 애그리게이션, 재생 도구이며 어떤 음악 파일도 저장하거나 호스팅하지 않습니다. 오디오 콘텐츠는 공식 CDN과 업스트림 개방 인터페이스에서, 가사는 네이티브 파싱과 공개 가사 라이브러리에서 가져옵니다. 각 기능의 범위와 데이터 위치는 다음과 같습니다.

| 기능 범주 | 포함 기능 | 데이터 저장 위치 | 로그인 필요 |
| --- | --- | --- | --- |
| 핵심 기능(익명 이용 가능) | 멀티 소스 애그리게이션 검색, 글자 단위 가사, 음질 등급 재생, 미리듣기 표시, 순위 차트, MV | 브라우저 로컬(재생 상태) | 아니요 |
| 계정 기능 | 즐겨찾기와 플레이리스트 클라우드 동기화, 개인화 추천과 Auto DJ, 행동 이벤트 관리 | 서버에는 가명 처리된 행동 이벤트만 저장. 즐겨찾기 선호는 브라우저에 저장 | 예 |
| 개인 데이터 기능 | 다운로드 목록, 로컬 음악 가져오기와 관리 | 브라우저 IndexedDB | 아니요 |
| 개방 API | 제3자 클라이언트가 서명 API Key로 접속 | 서버 세션과 폐기 목록 | 예 |

본 서비스는 오픈 소스 프로젝트를 기반으로 구축되고 오픈 소스를 계승합니다. 소스 코드가 공개되어 감사할 수 있고 직접 배포해 동등한 능력을 얻을 수 있습니다. 소프트웨어 자체는 「있는 그대로」 제공되며, 그 라이선스 조항은 본 약관의 책임 약정과 일치합니다(10절 참조).

## 3. 계정의 취득과 보안

1. 로그인 방식: 본 서비스는 Epomail 계정으로 OAuth 2.0(PKCE) 로그인하며 별도의 회원가입 시스템이 없습니다. Epomail과의 계정 약정에는 해당 서비스의 약관을 적용합니다. Epomail 계정이 동결되거나 해지되면 본 서비스에 대한 로그인도 중단됩니다.
2. 자격: 16세 이상이어야 합니다. 사용자 소재지 법률이 정보사회 서비스의 동의 연령을 달리 정하면 그 더 낮은 연령을 따릅니다(최저 13세). 다만 아동인 경우 여전히 보호자의 동의를 받아야 합니다. 연령은 로그인한 Epomail 계정 정보를 기준으로 하며, 본 서비스는 별도의 연령 검증 메커니즘을 두지 않습니다.
3. 일인 일계정: 계정을 대여, 임대, 판매하거나 타인과 공유할 수 없습니다. 계정 공유로 생긴 분쟁과 데이터 혼재에 대해 운영자는 구분과 복구를 책임지지 않습니다.
4. 자격 증명 보관: Epomail 계정 자격 증명, API Key, 세션 보안에 대한 보관 책임은 사용자에게 있습니다. 사용자의 자격 증명으로 행해진 조작은 본인의 행위로 추정합니다. 세션 쿠키에 서명 키가 포함되므로 공용 기기에서 로그인한 뒤 로그아웃하지 않는 일이 없도록 하십시오. 자격 증명 유출을 발견하면 즉시 로그아웃하고 폐기를 요청해야 합니다.
5. 세션 메커니즘: 로그인 성공 후 `HttpOnly; Secure; SameSite=Lax` 속성의 세션 쿠키(유효 기간 최대 30일)를 발급합니다. API Key는 URL, 쿼리 매개변수, localStorage에 기록하지 않습니다. 언제든 로그아웃할 수 있으며 로그아웃하면 현재 세션과 대응 키 식별자(jti)가 즉시 폐기됩니다.
6. 키 발급: API Key는 HMAC-SHA256 버전 관리 서명 형식으로, 발급 유효 기간은 30일, 검증 상한은 90일입니다. 서명이 없거나 폐기된 키는 일괄 거부됩니다. 키를 재발급하려면 현재 유효한 키를 제공해야 합니다. API Key는 개인 사용 자격 증명이므로 제3자에게 넘기거나 공개 배포 클라이언트에 내장할 수 없습니다.
7. 로그인 보호: OAuth 콜백은 state, PKCE, 인가 코드, 재전송의 4중 검증을 거칩니다. 인증 엔드포인트에는 분당 IP당 30회의 요청 제한이 있습니다.

## 4. 서비스의 제공과 변경

1. 가용성: 운영자는 합리적 노력으로 가용성을 유지하지만 특정 가용률, 버퍼링 시한, 장애 복구 시한을 약속하지 않으며 서비스 수준 협약(SLA)을 제공하지 않습니다.
2. 저하 메커니즘: 데이터 플레인 노드가 연속 3회 실패하거나 한 번의 호출이 4.5초 예산을 초과하면 엣지 계층이 차단하고 자동으로 저하 모드(공개 가사와 검색 인터페이스 직접 연결)로 전환합니다. 30초 냉각 후 활성 확인으로 복구됩니다. 저하 기간에는 화면에 「엣지 저하 모드」 안내가 표시되며 일부 기능(온전한 음원 파싱, 추천 갱신 등)을 사용하지 못할 수 있습니다. 이것은 시스템 설계상의 재해 대응 동작이며 계약 위반이 아닙니다.
3. 음질과 미리듣기 표시: 플레이어의 음질 배지(SQ 무손실, HQ 고품질 등)는 현재 오디오 스트림의 실제 등급을 사실대로 반영합니다. 공식이 제공하는 30초 미리듣기 구간은 미리듣기 표시로 명시하며 온전한 곡처럼 보이게 하지 않습니다. 업스트림 음원 등급이 바뀌면 실제로 얻을 수 있는 음질도 함께 바뀌며 이것은 계약 위반이 아닙니다.
4. 기능 변경: 오픈 소스 프로젝트는 계속 발전하며 기능이 추가, 조정, 제거될 수 있습니다. 데이터 삭제 능력과 관련된 중대 변경은 사전 공지합니다.
5. 유지 보수와 중단: 운영자는 업그레이드, 수리, 악용 조치로 서비스의 일부 또는 전부를 일시 중지할 수 있습니다. Cloudflare, 업스트림 음악 인터페이스, CDN 장애로 인한 불가용은 운영자의 계약 위반이 아닙니다.
6. 실험적 기능: 실험 표시 또는 테스트 기간의 기능은 있는 그대로 제공되며 불안정할 수 있고 언제든 조정하거나 중단할 수 있습니다.

## 5. 사용자의 콘텐츠와 행동 데이터

1. 즐겨찾기와 선호: 만든 즐겨찾기, 플레이리스트, 플레이어 선호는 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터를 지우거나 「모든 로컬 데이터 삭제」를 사용하면 삭제되며, 운영자는 그 분실에 책임지지 않으므로 중요한 플레이리스트는 직접 기록해 두십시오.
2. 로컬 음악과 다운로드: 가져온 로컬 음악 파일과 다운로드한 곡은 브라우저의 IndexedDB에 저장됩니다. 그 콘텐츠는 사용자에게 귀속되며 운영자의 서버는 사본을 저장하지 않습니다. 다운로드와 로컬 가져오기 파일은 개인 청취에만 사용할 수 있고 재배포, 공개 전파, 상업 목적 사용을 할 수 없습니다.
3. 행동 이벤트 인가: 추천 기능 제공을 위해 본 서비스는 곡을 재생, 완주, 건너뛰기, 즐겨찾기 또는 거부할 때 행동 이벤트를 기록합니다(신호 범주와 가중치는 소스 코드에 공개). 개인화를 끄거나 순수 로컬/시크릿 모드를 사용하면 새 이벤트 기록이 생기지 않습니다. 켜져 있는 기간의 위 인가는 추천 기능에 필요한 범위로 한정되며, 「원클릭 프로필 삭제」로 전체 기록을 파기하면 인가도 종료됩니다.
4. 콘텐츠 책임: 능동적으로 제출한 콘텐츠(사용자 지정 플레이리스트 이름, API 호출 행위 등)의 책임은 사용자에게 있으며, 그 콘텐츠로 생긴 분쟁과 법적 책임은 사용자가 부담합니다.
5. 음악 콘텐츠: 녹음물, 가사, 커버 등 콘텐츠의 권리는 각 권리자에게 귀속됩니다. 본 서비스는 어떤 음악 콘텐츠의 재라이선스도 부여하지 않으며, 소재지에서 합법적으로 청취할 책임은 사용자가 부담합니다.

## 6. 제3자 서비스

1. 업스트림 음악 출처: 검색, 재생 주소, 가사는 NetEase, QQ, KuGou, Kuwo 등 공식 개방 인터페이스와 AMLL, LRCLIB 등 공개 가사 라이브러리에서 가져옵니다. 제3자 인터페이스는 변경, 요청 제한, 서비스 중단이 있을 수 있으며 운영자는 업스트림 가용성을 보증하지 않습니다.
2. 엣지 프록시: 오디오 스트림은 기본적으로 엣지 프록시로 가져오며 업스트림 CDN은 사용자의 IP 주소에 접촉하지 않습니다. `?mode=redirect` 직접 연결 모드를 능동적으로 사용하면 브라우저가 공식 CDN과 직접 연결을 맺고 사용자의 IP가 그 CDN에 보입니다.
3. 신원 검증: Epomail은 본 서비스의 신원 제공자이며 그 데이터 처리는 [제3자 공유 및 전송 목록](/ko/sub-processors/)을 참조하십시오.
4. 제3자 약관: 위 서비스를 사용할 때 그 제3자의 서비스 약관에도 구속됩니다.

## 7. 허용 가능 사용

본 서비스를 사용할 때 [허용 가능 사용 정책](/ko/acceptable-use/)의 전체 규정을 준수해야 합니다. 인터페이스 자원의 남용, 시스템 공격, 불법 콘텐츠 유포, 타인 이용 방해의 금지가 포함됩니다. 위반 시 운영자는 그 정책이 정한 절차에 따라 사용권 종료에 이르는 조치를 할 수 있고, 법에 따라 증거를 보존하여 권한 있는 기관의 조사에 협조합니다.

## 8. 데이터의 보존, 제거와 이용 종료

1. 사용자에 의한 종료: 언제든 본 서비스 사용을 중단할 수 있습니다. 「원클릭 프로필 삭제」로 행동 기록을 삭제하고 로그아웃으로 세션을 폐기합니다. Epomail 계정 자체의 해지에는 Epomail의 규칙을 적용합니다.
