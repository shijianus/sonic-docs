**시행일: 2026년 11월 2일｜버전: 1.5**

흔한 문제를 식별하고 해결하는 방법을 정리합니다. 여기서 해결되지 않으면 `admin@epocanvas.com`으로 문의하거나 GitHub 저장소에 Issue를 등록하십시오.

## 1. 재생 문제

| 현상 | 원인 | 대응 |
| --- | --- | --- |
| 곡에 「미리듣기」가 표시되고 30초 뒤 멈춤 | 공식 미리듣기 절단이며 오류가 아님 | 교차 소스 보완을 켜 무료 온전 곡을 자동으로 매칭하거나 다른 출처의 버전을 재생 |
| 음질 배지가 낮은 등급을 표시함 | 업스트림이 실제로 발급한 등급을 표시함 | 음질 메뉴에서 다른 등급을 시도; 업스트림의 availability에 따라 등급이 바뀔 수 있음 |
| 재생이 중단된 뒤 이어서 재생되지 않음 | 업스트림 직접 주소가 만료됨 | 곡을 다시 눌러 재생 주소를 새로 해석 |

## 2. 저하 모드

화면 상단에 「엣지 저하 모드」 앰버색 안내가 나타나면 데이터 플레인 노드가 일시적으로 오프라인이거나 시간 초과된 상태입니다. 엣지 계층이 공개 인터페이스에 직접 연결하므로 검색과 가사는 계속 사용할 수 있지만 온전한 음원 해석과 추천 갱신은 제한될 수 있습니다. 보통 수십 초 안에 자동 복구됩니다(서킷 브레이커 냉각 30초 후 활성 확인). 이미 불러온 곡에는 영향이 없으며 새로 고칠 필요도 없습니다.

## 3. 검색 문제

1. 검색 결과가 없음: 업스트림 API가 잠시 사용할 수 없는 경우가 많습니다. 잠시 후 다시 시도하십시오. 저하 모드에서는 엣지가 공개 인터페이스에 직접 연결하므로 검색 범위가 조금 좁을 수 있습니다.
2. 결과가 중복되거나 빠짐: 다중 소스 중복 제거는 표준 식별자로 통합합니다. 업스트림 메타데이터에 문제가 있으면 통합이 누락될 수 있으니 검색어를 함께 적어 Issue를 등록하십시오.

## 4. 로그인 문제

1. 로그인 직후 로그아웃 상태로 돌아감: 브라우저가 제3자 쿠키를 차단했거나 보안 확장 프로그램이 쿠키를 삭제했을 가능성이 큽니다. 사이트를 허용 목록에 추가한 뒤 다시 시도하십시오.
2. Epomail 계정이 동결됨: 로그인이 중단됩니다. 먼저 Epomail 측 계정 상태를 처리하십시오.
3. 공용 기기에서 다른 사람이 재생할 수 있음: 세션 쿠키는 최대 30일 유지됩니다. 공용 기기에서는 사용 후 로그아웃하십시오([계정 및 보안 안내](/ko/account-security/) 5절 참조).

## 5. 저장 문제

1. 즐겨찾기나 다운로드가 사라짐: 브라우저의 사이트 데이터 삭제 또는 시크릿 모드로 로컬 저장소가 삭제되었을 수 있습니다([데이터 내보내기 및 저장](/ko/data-management/) 1절 참조). 중요한 플레이리스트는 직접 기록하십시오.
2. 다운로드 실패: 브라우저 저장 할당량이 가득 찼습니다. 오래된 다운로드를 삭제하거나 브라우저 저장 공간을 정리한 뒤 다시 시도하십시오.
3. 로컬 음악 가져오기 실패: 브라우저가 해당 파일 형식을 디코딩하지 못하거나 파일이 저장 할당량을 초과했을 수 있습니다.

## 6. 요청 제한과 오류 코드

| 현상 | 의미 | 대응 |
| --- | --- | --- |
| 429(익명) | 익명 요청이 분당 240회를 초과함 | 로그인하면 더 높은 한도(분당 600회)를 이용할 수 있음 |
| 429(인증됨) | 분당 600회를 계속 초과함 | 클라이언트에 요청 반복 루프가 있는지 확인 |
| 501(폐기 작업) | 인스턴스에 즉시 폐기가 구성되지 않음 | 배포자가 KV 또는 목록 방식을 구성해야 함 |
| 로그아웃 반복 | 키가 폐기되었거나 전역 발급 시점 하한이 조정됨 | 다시 로그인해 새 키를 발급받음 |

## 7. 그래도 해결되지 않는 경우

Issue를 등록할 때 발생 시각, 사용한 페이지와 조작, 화면 안내(저하 안내라면 스크린샷), 브라우저와 버전을 적으십시오. 세션 쿠키나 API Key는 절대 첨부하지 마십시오.
