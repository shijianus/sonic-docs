기능 설명은 2026-11-02에 검토한 공개 후보 브랜치(RC) `rc/sonic-20261031@a75f5cb`(2026-11-01 UTC)에 근거합니다. 이전 `main@ce443c8`(2026-10-27 UTC)과는 구현이 다르므로 같은 동작을 가정할 수 없습니다. RC는 정식 GitHub Release가 아니며 실제 서비스 버전과 설정은 알 수 없습니다.

흔한 문제를 식별하고 해결하는 방법을 정리합니다. 여기서 해결되지 않으면 `admin@epocanvas.com`으로 문의하거나 GitHub 저장소에 Issue를 등록하십시오. 신고할 때는 민감하지 않은 재현용 검색어만 사용하십시오. 공개 검색 문구에는 개인 정보나 민감한 정보가 포함될 수 있습니다.

## 1. 재생 문제

| 현상 | 원인 | 대응 |
| --- | --- | --- |
| 곡에 「미리듣기」가 표시되고 30초 뒤 멈춤 | 공식 미리듣기 절단이며 오류가 아님 | 화면에 교차 소스 보완이 있으면 다른 온전한 버전을 시도하거나 다른 출처의 버전을 재생하십시오. 성공을 보장하지 않습니다 |
| 음질 배지가 낮은 등급을 표시함 | 업스트림이 실제로 발급한 등급을 표시함 | 음질 메뉴에서 다른 등급을 시도하십시오. 업스트림의 availability에 따라 등급이 바뀔 수 있습니다 |
| 재생이 중단된 뒤 이어서 재생되지 않음 | 업스트림 직접 주소가 만료되었을 수 있음 | 곡을 다시 눌러 재생 주소를 다시 해석해 보십시오. 복구를 보장하지 않습니다 |

## 2. 저하 모드

화면 상단의 「엣지 저하 모드」 안내는 데이터 플레인이 중단되었거나 시간 초과되어 대체 경로를 사용하고 있을 수 있음을 뜻합니다. 대체 경로도 실패할 수 있으며 검색·가사·재생이 제한되거나 이용 불가할 수 있습니다. 서킷 브레이커 냉각 후 30초는 다음 탐색을 위한 시간일 뿐 복구를 보장하지 않습니다. 이미 버퍼링된 콘텐츠가 계속될 수 있지만 재생 지속은 보장되지 않습니다. 이 안내만으로 자동 복구나 새로 고침 불필요를 의미하지 않습니다.

## 3. 검색 문제

1. 검색 결과가 없음: 업스트림 API가 잠시 사용할 수 없는 경우가 많습니다. 잠시 후 다시 시도하십시오. 저하 모드에서는 대체 검색도 실패하거나 이용 불가할 수 있고 검색 범위가 조금 좁을 수 있습니다.
2. 결과가 중복되거나 빠짐: 다중 소스 식별자나 메타데이터 문제로 병합이 누락될 수 있습니다. 민감하지 않은 재현용 검색어만 사용하십시오. 공개 검색 문구에는 개인 정보나 민감한 정보가 포함될 수 있으므로 공개 Issue에 원문을 붙여 넣지 마십시오.

## 4. 로그인 문제

1. 로그인 직후 로그아웃 상태로 돌아감: 사이트 자체의 세션 쿠키를 설정하고 유지할 수 있는지, 확장 프로그램이 삭제하지 않는지, HTTPS·OAuth 콜백 주소·관련 OAuth 설정이 일치하는지 확인하십시오. 영향을 주는 확장 프로그램 설정만 지우거나 비활성화하고 브라우저 보호 기능을 모두 해제하지 마십시오.
2. Epomail 계정이 동결됨: 로그인이 중단됩니다. 먼저 Epomail 측 계정 상태를 처리하십시오.
3. 공용 기기에서 다른 사람이 재생할 수 있음: 확인한 RC에서 사이트 세션 Cookie의 기본 유효 기간은 30일입니다. 이는 실제 서비스의 설정이나 복사된 인증 정보 및 기타 사본의 보존·만료 기간을 확인하는 말이 아닙니다. 공용 기기 사용 후 로그아웃하십시오([계정 및 보안 안내](/ko/account-security/) 참조).

## 5. 저장 문제

1. 즐겨찾기나 다운로드가 사라짐: 브라우저의 사이트 데이터 삭제·저장 공간 회수 또는 시크릿 세션 종료로 로컬 데이터가 사라질 수 있습니다. 일반적인 클라우드 복원은 보장되지 않으며 시크릿 모드도 네트워크 요청이나 이벤트를 막지 않습니다. 로컬 삭제나 초기화 성공은 완전한 원격 삭제를 증명하지 않습니다([데이터 내보내기 및 저장](/ko/data-management/) 참조).
2. 다운로드 실패: 저장 할당량, 네트워크·상류 오류 또는 브라우저 제한을 확인하십시오. 다른 자료를 먼저 보관한 뒤 불필요한 다운로드만 지우십시오.
3. 로컬 음악 가져오기 실패: 파일 형식이 브라우저의 디코딩 범위를 벗어나거나 파일이 저장 공간 할당량보다 클 수 있습니다.

## 6. 요청 제한과 오류 코드

| 현상 | 의미 | 대응 |
| --- | --- | --- |
| 429(익명) | RC 기본값인 분당 240회 익명 한도를 초과함. 실제 서비스 설정은 다를 수 있음 | 화면 안내를 따르고 나중에 다시 시도하거나 인스턴스 설정을 확인 |
| 429(인증됨) | RC 기본값인 분당 600회를 계속 초과함. 실제 서비스 설정은 다를 수 있음 | 클라이언트에 요청 반복 루프가 있는지 확인 |
| 501(폐기 작업) | 지원되는 원격 폐기가 구성되지 않음 | 로그아웃으로 브라우저 Cookie만 지워질 수 있음. 운영자에게 폐기 설정과 복사된 인증 정보의 거부를 확인하도록 요청 |
| 로그아웃 반복 | 키가 폐기되었거나 전역 발급 시점 하한이 조정됨 | 다시 로그인해 새 키를 발급받으십시오. 실제 원인은 인스턴스 로그와 설정으로 확인해야 합니다 |

## 7. 그래도 해결되지 않는 경우

공개 Issue에는 발생 시각, 사용한 페이지와 조작, 브라우저와 버전, 필요한 경우 개인정보를 가린 화면 안내 스크린샷을 적으십시오. 민감하지 않은 재현용 검색어만 사용하십시오. 공개 검색 문구에는 개인 정보나 민감한 정보가 포함될 수 있으므로 게시 전에 이메일 주소, 개인 정보·프로필 정보, 민감한 검색어, 세션 Cookie, API Key와 스크린샷 속 같은 정보를 삭제하거나 가리십시오. 완전한 삭제 또는 자료 사본 요청은 공개 Issue가 아니라 `privacy@epocanvas.com`으로 보내십시오. 초기화 성공 안내는 모든 기록이 삭제되었다는 증명이 아닙니다.
