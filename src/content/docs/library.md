本页说明“我的音乐”四项内容的本地存储。功能核对基于最新公开 RC `rc/sonic-20261031@a75f5cb`（2026-11-01 UTC）；较早默认分支 `main@ce443c8`（2026-10-27 UTC）仅作兼容性对照，不证明 RC 功能已部署，在线版本未知。未见本地音频文件主体上传路径，但元数据、内嵌封面图片、反馈及推荐上下文可能传送；本地存储不证明没有远程处理，也不是通用云端备份。清理与删除限制见[数据管理与存储](/data-management/)。

## 1. 喜爱与收藏

“我喜欢的”聚合您标记的内容：喜爱歌曲、收藏歌单、收藏专辑、关注歌手与收藏 MV。操作入口：曲目列、专辑页与歌手页的心形按钮。数据存于浏览器 localStorage（`library` 键），即时生效，无需登录。

## 2. 最近播放

“最近播放”页从 localStorage（`audio`）依时间倒序读取自动保存的最近最多 100 首，未见单独关闭该本地历史的开关。另外的播放事件与最近艺人上下文可能传送供推荐，本地历史清单不表示服务器没有记录。个性化默认开启不是同意；浏览器无痕模式不阻止事件传送。

## 3. 下载列表

在曲目列或底部播放列点击下载，歌曲连同音质元数据写入浏览器 IndexedDB（`downloaded_music`）；“下载清单”页管理已下载内容，离线状态亦可播放。下载占用浏览器存储配额，配额不足时浏览器会拒绝新下载——请先删除旧下载或清理浏览器存储空间。

## 4. 本地音乐

“本地音乐”页将选取或拖放的音频文件导入 IndexedDB（`local_music`）。未见音频文件主体上传路径，但歌词匹配、收藏反馈及推荐上下文可传送标题、艺人、专辑或歌曲标识；内嵌封面图片可能随收藏事件进入远程共享曲目目录，个人画像重置不保证清理该目录。格式依浏览器解码能力；删除本地副本不影响原始文件，也不删除相关远程数据或授予内容权利。

## 5. 存储位置一览

| 内容 | 存储位置 | 随清除浏览器数据遗失 |
| --- | --- | --- |
| 喜爱与收藏 | localStorage（`library`） | 是 |
| 最近播放 | localStorage（`audio`） | 是 |
| 下载歌曲 | IndexedDB（`downloaded_music`） | 是 |
| 本地音乐副本 | IndexedDB（`local_music`） | 是 |

重要歌单与下载内容请妥善备份：浏览器“清除全部数据”或网站“清除全部本地数据”都会删除上述内容（见[数据导出与存储](/data-management/)）。本地音乐的原始文件仍保留于您的设备。
