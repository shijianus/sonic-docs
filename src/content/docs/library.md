**生效日期：2026 年 11 月 2 日｜版本：1.5**

本页说明「我的音乐」四项内容之管理方式与存储位置。全部资料仅存于您之浏览器，不上传服务器；清空与删除操作见[数据导出与存储](/data-management/)。

## 1. 喜爱与收藏

「我喜欢的」聚合您标记之内容：喜爱歌曲、收藏歌单、收藏专辑、关注歌手与收藏 MV。操作入口：曲目行、专辑页与歌手页之心形按钮。数据存于浏览器 localStorage（`library` 键），即时生效，无需登录。

## 2. 最近播放

播放历史自动记录于浏览器 localStorage（`audio` 键），「最近播放」页按时间倒序呈现；点击即可回放。历史仅存于本机，不与服务端同步。

## 3. 下载列表

在曲目行或底部播放栏点击下载，歌曲连同音质元数据写入浏览器 IndexedDB（`downloaded_music`）；「下载列表」页管理已下载内容，离线状态亦可播放。下载占用浏览器存储配额，配额不足时浏览器会拒绝新下载——请先删除旧下载或清理浏览器存储。

## 4. 本地音乐

「本地音乐」页支持点击添加或拖放音频文件导入浏览器（`local_music`）；导入之文件与在线曲库统一呈现与播放。导入过程完全在浏览器内完成，文件不上传。支持的格式以浏览器解码能力为准；删除单曲仅移除浏览器内副本，不影响您的原始文件。

## 5. 存储位置一览

| 内容 | 存储位置 | 随清除浏览器数据丢失 |
| --- | --- | --- |
| 喜爱与收藏 | localStorage（`library`） | 是 |
| 最近播放 | localStorage（`audio`） | 是 |
| 下载歌曲 | IndexedDB（`downloaded_music`） | 是 |
| 本地音乐副本 | IndexedDB（`local_music`） | 是 |

重要歌单与下载内容请妥善备份：浏览器「清除全部数据」或站点「清除全部本地数据」都会删除上述内容（见[数据导出与存储](/data-management/)）。本地音乐之原始文件仍保留于您的设备。
