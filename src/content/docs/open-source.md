## 2. 专案定位

本专案为非商业开源专案：检索、聚合与播放工具，不存储、不托管音乐文件，不整合绕过付费版权之解灰组件。您使用本服务或自行部署时，应自行确认符合当地法律、上游服务条款与内容授权要求（行为边界见[可接受使用政策](/acceptable-use/)）。

研发与多源聚合实践借鉴并致谢以下开源社群专案：Meting、Meting-API-Serverless、ourcraft-music-api、music-lib、NeteaseCloudMusicApi、QQMusicApi、AMLL TTML API、LRCLIB、GDStudio Music API 与 Linux.do 社群。完整依赖与声明见仓库 `THIRD_PARTY_NOTICES.md`；各上游服务之条款由其各自管辖。

## 4. 自行部署者之法律义务

自行部署之时点起，部署者即为其用户之数据控制者（角色界定见[总览](/overview/)第 2 节），应履行：

1. **告知义务**：向用户告知资料处理事项，可以本站[隐私政策](/privacy-policy/)为基础文本，惟须按自身实际配置删改（未开启之第三方链路应从告知中删除）；
2. **记录与评估**：维持处理活动记录（GDPR 第 30 条），高风险时实施资料保护影响评估（GDPR 第 35 条）；
3. **安全维护**：落实[数据处理与安全维护](/data-security/)第 3 节之措施并接受主管机关监督；
4. **配置一致性**：环境变量之实际值（保留天数、第三方开关、限流）须与你的政策承诺一致；
5. **按辖区补足**：GDPR 之外，按用户所在辖区补足 UK GDPR、LGPD、CCPA-CPRA 等法定要求。

## 5. 本站文档之采用

本站为「通用范本 + 托管实例实文」双轨设计，自部署运营者可采用本站全部文档作为其站点告知与条款之基础：

1. 替换身份信息（域名、联络邮箱、生效日期与版本号）；
2. 复核第三方清单与配置参数之如实披露；
3. 保留「简体中文版为正式版本」或改为你的正式版本语言并全文一致；
4. 正式运营前咨询律师；本站文档不构成法律意见。
