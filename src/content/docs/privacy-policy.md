## 3. 数据概览与来源

| 来源或操作 | 可能处理的数据 | 目的与去向 |
| --- | --- | --- |
| 访问网站或 API | IP、时间、请求路径、浏览器与连接元数据 | 建立连接、限流和安全；实例及基础设施可处理 |
| 阅读文档与页面偏好 | 语言请求头、主题、侧栏状态及文档搜索输入 | 语言入口与本地阅读功能；搜索索引请求仍产生连接信息，见第 4.6 节 |
| Epomail 登录 | 用户标识、邮箱及验证标记、昵称、头像 URL、角色、会话与令牌标识 | 请求的身份功能；由 Epomail 提供，部分存于浏览器 |
| 搜索与内容请求 | 搜索原文、歌曲／艺人／专辑／MV 标识、歌词匹配及资源请求 | 返回所请求内容；可能发送至上游 |
| 候选版个性化与 Auto DJ | 假名标识、播放进度、跳过、收藏、拒绝、搜索及上下文 | 可选画像；默认值不是同意，见第 5 节 |
| 本地使用与候选版雷达 | 收藏、歌单、设置、本地音频及封面图片；雷达专辑及信号 | 音频主体未见上传；部分元数据、封面和上下文可发送，并可能进入共享曲目目录 |
| 上游评论等公开内容 | 他人的昵称、头像、标识、正文、时间及图片 | 展示请求的内容并缓存；公开来源不等于匿名 |
| 联系、举报与权利请求 | 主动提供的联系方式、说明、必要证据和处理记录 | 回应请求、履行法定义务及处理具体争议 |

基本请求需要相应连接信息；不提供登录资料时无法使用需要身份的功能。可选画像不是基本搜索或播放的必要条件。不要在查询、歌单、联系内容或公开 Issue 中提交密码、完整令牌、身份证件、健康信息或他人私密资料；这项提醒不把防止过度收集的责任转移给用户。音乐偏好和查询可能间接揭示敏感特征，不能一概当成非个人资料。

登录资料来自 Epomail；评论和相关资料来自内容提供方及公开来源。间接收集适用 GDPR 第 14 条时，应在法定期限内提供来源、类别及其他必要告知，或记录适用例外与保障。不能仅凭公开可见或用户请求播放，就认定第三方评论作者同意了 Sonic 的再利用。具体来源见[第三方共享与传输清单](/sub-processors/)。

## 4. 代码中的处理与版本差异

### 4.1 登录与会话

候选版 `a75f5cb` 的 Epomail OAuth 使用 state 校验和 PKCE。`sonic_session` 为 HttpOnly 签名会话 Cookie，默认有效期 30 日；`sonic_oauth_state` 和 `sonic_oauth_verifier` 事务 Cookie 约 600 秒，HTTPS 环境设 Secure。签名保护完整性，不是加密；凭证载荷可含邮箱及用户、角色标识。这些源码默认值不是线上期限的证明。

前端 `auth` 本地存储保留部分用户资料，包含邮箱和头像，并有读取旧登录存储的兼容路径；不能说帐号资料只在内存。退出会清理当前 Cookie，但被复制或导出的凭证是否立即撤销，仍依撤销存储、设置和请求结果，不能把退出等同于所有副本即时失效。

旧 `main@ce443c8` 的回调及兼容前端存在经 URL 和 localStorage 传递、保存登录资料与凭证的路径，未具备上述完整 PKCE、签名验证和撤销保护。不得把旧版 README 的描述视为已实现。尚未落实必要保护的部署不应处理真实用户凭证；如发现 URL、截图或日志含凭证，请勿转发，并联系运营者处理。
### 4.2 行为事件、画像与搜索统计

以下行为事件、SQLite 画像及搜索统计路径在候选版中可核实；旧 `main` 未找到相同的完整实现，不能据此假定其已有这些功能。

候选版使用邮箱派生标识或浏览器生成的 `anon_` 标识关联事件，处理播放、收藏、拒绝等行为及艺人、专辑、歌单、MV 的反馈。推荐请求还可能携带本地收藏、最近艺人及搜索上下文。未登录不等于匿名；哈希和随机标识可用于关联，应视为假名化个人资料，不能据“不可逆”排除 GDPR。

智能搜索另行累计查询，公共搜索建议可能显示这些词；仅关闭个性化不停止这条路径。查询可能含姓名、联系方式或敏感信息，次数聚合本身不能使其匿名。在完成必要性、合法依据、过滤、展示阈值、保存与删除控制前，应关闭从用户查询生成公共建议的路径。

### 4.3 浏览器存储与本地文件

| 存储 | 主要内容 | 清理与边界 |
| --- | --- | --- |
| localStorage 的 `audio`、`library`、`global`、`settings` | 队列、收藏、歌单、播放／搜索历史、设置 | 至用户或浏览器清除；不是通用云备份 |
| 候选版 `recommend`、`auth`、雷达及旧登录兼容存储 | 开关、标识、拒绝记录、用户资料、雷达及旧登录状态 | 部分用于网络请求；旧键不一定由每个退出动作清除 |
| IndexedDB `SonicMusicPlayerDB` | 导入的音乐文件、元数据、封面和下载缓存 | 未找到文件主体上传路径；浏览器清理可能永久丢失 |
| 候选版会话与 OAuth Cookie | 身份会话及登录事务 | 见第 4.1 节；设备清理不等于远端删除 |

本地音频文件主体未见上传路径，但歌词匹配、收藏反馈和推荐上下文可发送标题、艺人、专辑或歌曲标识。内嵌封面提取为 data URL 后，也可能随收藏／取消收藏事件发送，并进入远端曲目目录，供全站搜索或公共建议返回；不能保证图片数据始终只在设备上。此目录及可选外部检索／推荐索引不一定随个人画像重置删除，是否仍属个人资料须按可关联性判断。

本地播放历史会自动保留最近最多 100 首，搜索历史最多 20 项；未见单独关闭本地播放历史的开关。关闭远端个性化不是关闭这些本地历史。候选版的评论／回复／点赞写入是本地模拟；上游读入的评论可包含他人资料并被缓存。界面标签不是远端发布或匿名化的证明。

为完成您明确请求的播放、登录或设置而严格必要的终端存取，才可能适用电子隐私规则的必要性例外。可选画像标识和非必要存取应先有有效同意；Cookie、localStorage 和 IndexedDB 都不能仅因“第一方”或保存在设备而自动豁免。具体要求还取决于适用的成员国实施法。

### 4.4 网络、日志与外部资源

实例与基础设施可能处理 IP、路径、时间和连接信息。候选版限流可使用原始 IP 或身份派生键，边缘还可能把地址、会话和上下文转送配置的数据引擎。应用日志的最小化不代表宿主、代理、错误日志、Cloudflare 或接收方均不记录；没有经核验的全链路“零日志”保证。

配置告警 webhook 并触发告警时，接收服务可收到系统计数、发布版本、时间和经凭证脱敏的摘要，也可看到发送节点的出口 IP。常规载荷未自动附加终端用户标识或查询，但管理员备注和错误信息仍可能含个人资料；脱敏不是完全匿名化。实际启用前应最小化内容、核实接收方及保存／传输安排。

音频代理可让上游看到代理出口，但部分请求仍可能携带浏览器信息。MV、封面、头像、字体和直连内容可向外部服务暴露 IP 等元数据。代码加载 Google Fonts，并存在以明文邮箱作为 DiceBear 头像 seed 的路径；运营者应避免自动的非必要外连，并以本地资源或不含邮箱的方式替代该头像路径。部分上游使用 HTTP，不能称全链路端到端加密。实际接收者及可选开关见[第三方共享与传输清单](/sub-processors/)。

### 4.5 不用于何种目的

项目不以出售个人资料、广告投放、跨站广告画像或训练通用 AI 模型为目的；本次代码检查也未发现为 Sonic 获取 Epomail 邮件正文的功能。身份登录不等于授予邮箱内容访问权。推荐算法不意味着内容会发送给通用 AI 提供者；新增用途须先另行评估及告知。

本服务不以收集特殊类别资料或推断敏感特征为目标。若意外收到，应限制访问、评估必要性和适用条件并依法删除或处理，不能仅靠一般同意或正当利益满足 GDPR 第 9 条要求。第三方的独立处理不能由本项目代为保证。

### 4.6 文档站的阅读、偏好与搜索

文档站与播放器不是同一套存储。当前文档源码与所用 Starlight／Pagefind 组件可核对如下：

| 功能或存储 | 内容与用途 | 保存及传输边界 |
| --- | --- | --- |
| `starlight-theme`（localStorage） | 浅色、深色或跟随系统的显示偏好；初始化也可能写入空值 | 至覆盖、用户清除或浏览器回收；未见该键被用于画像 |
| `sl-sidebar-state`（sessionStorage） | 侧栏展开状态、结构标识和滚动位置 | 由浏览器管理的标签页会话内保存；恢复会话可能延续，不作为精确销毁时点 |
| Pagefind 文档搜索 | 输入在浏览器内匹配，按需请求本站静态索引和结果片段 | 未见把原始输入提交至播放器搜索 API 或外部搜索服务；索引路径、访问页面和连接信息仍可能被托管网络记录，不能据此保证搜索行为不可推断 |

语言入口读取 `Accept-Language` 请求头选择入口，不为此设置语言 Cookie。没有在当前文档配置中发现广告或独立统计脚本；这不证明托管网络没有日志。上述偏好仅用于阅读界面，不能因其为第一方就概括认定免同意：只有符合适用终端存取必要性例外时才可不另行取得同意，否则应先取得同意或停用相应存取。清理文档站资料不会自动清理其他域名上的播放器资料。实际托管接收者、控制者、日志期限和权利渠道仍须在采用本政策前确认。

## 5. 目的、法律依据与选择

| 处理 | 目的 | GDPR 适用时的依据及界限 |
| --- | --- | --- |
| 请求的搜索、播放、登录与会话 | 提供所请求功能 | 第 6 条第 1 项第 b 款，仅在有效合同或请求的订约前措施范围内客观必要时适用；无合同不能仅凭访问套用 |
| 可选画像、持续标识和雷达偏好同步 | 个性化推荐 | 第 6 条第 1 项第 a 款及第 7 条；事前、独立、自愿、可撤回的有效同意 |
| 必要连接安全、限流和防滥用 | 保护服务和用户 | 第 6 条第 1 项第 f 款；记录必要性与利益衡量，尊重反对权，不覆盖额外画像 |
| 文档传送、导航和阅读偏好 | 提供请求的文档及阅读界面 | 第 6 条第 1 项第 f 款，在必要性和利益衡量成立的范围内；终端存取是否另须同意仍独立判断 |
| 用户搜索词统计和公共建议 | 改善检索及复用查询 | 即时查询不授权额外公开复用；当前路径缺少已核实的完整条件，应暂停而非宣称已有合法依据 |
| 第三方评论及公共内容缓存 | 展示所请求内容 | 须独立评估依据、最小化和间接告知；观看者的合同不为评论作者的资料自动提供履约依据 |
| 权利请求与依法必要的披露 | 履行具体适用义务 | 第 6 条第 1 项第 c 款；须有实际法律义务，不泛指全部境外请求 |
| 一般支持及具体争议记录 | 回应主动询问、提出或抗辩请求 | 第 6 条第 1 项第 f 款的适度正当利益，或确有合同必要性时第 b 款；不得成为无限保存理由 |

候选版把个性化和 Auto DJ 设为默认开启；默认值、登录和勾选用户条款不证明有效同意。适用欧盟规则的部署须在选择前不作非必要存取或发送，让接受和拒绝同样便捷，提供不捆绑基本服务的选择，并可用不难于给予同意的方式撤回。清空设置后也不能把未选择恢复为同意。当前文档没有证明该机制已实现。

关闭个性化不等于删除既有资料，也不会停止必要请求或另行存在的搜索统计。Auto DJ 有独立开关，仍可能为填充队列发送种子及排除曲目；雷达同步在关闭个性化后仍可能发送偏好载荷，即使服务端因关闭标记拒绝存储。发送、接收和持久保存是不同处理，不能把开关当成全面阻断外传的保证。运营者须按撤回范围停止相关未来处理，并依法处理已收集的数据；不得事后用另一标签追溯合法化原先没有依据的收集。没有足够资源落实可选画像的同意、保存和删除时，可以关闭该功能，而无需建立不必要的企业级系统。

推荐一般根据播放、收藏、拒绝、艺人偏好和内容关联调整排序，并非准确性保证。它属于画像，但审阅用途仅涉及内容推荐，未发现产生法律或类似重大影响的纯自动化决定；若用途改变，应依 GDPR 第 22 条等规则重新评估并事前告知。

旧 `main` 未核实具备相同事件库、保留任务或远端删除路径；不能套用本表的候选版数字。任何实例均须在启用处理前说明实际期限；期限未知不是无限保存的许可，也不能以“视需要而定”代替可理解的标准。

候选版“重置推荐画像”主要删除当前身份的部分事件和反馈，可能遗漏登录前标识、雷达、搜索聚合、共享曲目目录及封面、外部推荐系统、缓存、数据库日志和备份；部分失败还可能没有在界面显示。画像摘要也不是完整个人资料副本或可携导出。需要完整处理时应通过第 9 节提出请求，不能以界面按钮替代法定义务。

依法删除应覆盖实际可关联的资料，并按适用要求通知接收者。备份不能逐项删除时，应停止日常使用、隔离并于明确周期清理，恢复时重新落实已执行的删除，不能让旧数据恢复使用。依法必须保留的部分应说明理由、范围及期限并限制用途。本文未虚构已经上线的备份周期或后台任务。

## 7. 接收者与国际传输

Cloudflare 可提供托管、边缘、隧道及存储；Epomail 提供身份服务；音乐平台、歌词来源及内容 CDN 接收查询或连接信息；Google Fonts、头像服务及配置的推荐／检索或告警提供方可能接收其他数据。公开查询建议、共享曲目目录及上游评论缓存还可能使内容被其他用户访问。Gorse、Meilisearch、告警 webhook 等可选链路是否启用，应以具体实例明确告知为准，不能从示例配置作结论。

实际合同主体、国家和保护措施仍未核实。适用 GDPR 第五章的传输须逐项确认充分性决定或其他有效机制；使用标准合同条款还须相应评估和必要补充保障。供应商认证、政策链接、代理或用户同意本页均不是传输依据本身；不得把特定情形的例外当作日常持续传输的通用方案。依法可向 `privacy@epocanvas.com` 请求保障说明或副本，必要商业秘密可适当遮盖，但不得取消透明义务。详情见[第三方共享与传输清单](/sub-processors/)。

## 8. 年龄与测试资料

项目使用门槛为年满 16 岁，未成年人还须符合所在地行为能力和监护要求。GDPR 第 8 条只针对其规定的儿童同意情形，不是所有合同及处理的统一年龄规则。当前身份字段不能证明年龄，本项目不声称已验证。

监护人可通过隐私邮箱反映不符合年龄要求的资料。开发、演示和学习优先使用明确标示的合成数据、自有测试帐号及授权内容；未满足身份和保护条件前不应开放涉及真实用户资料的测试。公开服务或处理他人资料，不仅因“学习”就属于纯个人或家庭活动。

## 9. 您的权利与操作

适用法律规定的范围内，您可请求确认处理、访问及副本、更正、删除、限制处理和数据可携，反对正当利益处理，并撤回同意。可携权适用于法定范围内基于同意或合同、以自动化方式处理且由您提供的资料，不必然覆盖全部推断或内部记录。撤回不影响此前已有合法依据的处理；删除也有法定例外，须逐项说明，不能概括拒绝。

**反对权：** 对以正当利益为依据的处理，您可基于自身情况随时提出反对；除依法证明优先的强制性正当理由，或为提出、行使或抗辩法律请求所必需外，应停止相应处理。联系 `privacy@epocanvas.com` 即可提出，不以关闭个性化开关为唯一途径。

使用已提供的开关、退出及本地清理工具时，应注意第 6 节限制。本地清理不保证清除 HttpOnly Cookie、旧版 URL／存储凭证或远端数据，亦不等于注销；清空设置后可能恢复默认值，运营者不能据此视为重新同意。无痕模式本身不会阻止请求和事件发送。

完整远端删除、多个身份的关联检查、资料副本或撤回可选处理同意，均可发至 `privacy@epocanvas.com`；撤回同意无需先删除帐号，也可使用已提供且不难于给予同意的撤回方式。写明实例、请求类型和定位资料所必需的识别线索；没有帐号也可提出。不要发送密码、完整令牌或公开私人信息。定位旧假名记录所需线索与额外身份核验不同；仅在对请求者身份有合理疑问时，才索取核实身份所必需的额外信息，不默认要求身份证件。如无法识别某个旧记录，应解释限制并允许您提供适当线索，而非收集不相关资料或一概拒绝。该邮箱须由运营者在采用政策前确认可用，现有文档不证明已收件或已执行请求。

GDPR 适用时，应无不当迟延且原则上在收到后一个月内就请求行动或答复；复杂性或数量确有必要时可延长最多两个月，并在首月内说明理由。原则上免费；收费、拒绝或不采取行动须符合具体法定条件，说明理由并告知投诉及司法救济。不能把一人维护或缺少自动工具作为自动延期理由。
