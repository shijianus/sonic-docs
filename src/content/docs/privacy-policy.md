## 1. 适用范围

本政策适用于您以任何方式使用本服务所生之个人资料，包括：

1. 造访本服务网站（`sonic.epocanvas.tech`、`sonic.epocanvas.com` 或自行部署实例之网域）；
2. 使用网页播放器及开放 API 之第三方客户端接入。

本政策不适用于本服务链接或嵌入之第三方网站与服务；该等第三方各有其隐私政策，由其自行负责。自行部署 Sonic 之运营者，自部署之时点起即为其用户之数据控制者，应自行向其用户履行其所在地适用法律下之告知义务；本政策可作为其告知之基础文本。

## 4. 收集之个人资料

### 4.1 帐户识别资料（经 Epomail 登录）

您以 Epomail 帐号经 OAuth 2.0（PKCE）登录时，本服务自 Epomail 取得：用户标识符、电子邮件地址（须经验证）、昵称、头像链接与帐户角色。本服务不设独立注册系统，不收集电话、真实姓名或支付资料。

电子邮件地址不写入本服务之任何数据库：其仅用于（a）即时派生假名化标识符与限流桶键之 SHA-256 哈希；（b）作为签发予您本人之 API Key 载荷中的 `sub` 声明。派生所得之哈希值无法还原原电子邮件地址。

### 4.2 行为事件

为提供推荐与 Auto DJ 功能，本服务记录与曲目播放相关之行为事件，事件类型包括搜索、搜索点击、播放开始、播放进度、完播、跳过、重播、收藏、取消收藏、拒绝、取消拒绝。每项事件以下列假名化标识符关联：

1. **登录用户**：由电子邮件地址派生之 SHA-256 哈希（`usr_` 前缀）；
2. **匿名参与者**：由您浏览器本地生成之随机标识符经服务端再哈希（`anon_` 前缀）；
3. **公开模式**：个性化关闭时，事件不入库、不存储，直接丢弃。

因网络卡顿、解码失败或试听截断所致之切歌事件权重恒为零且不入库。此外，推荐请求会携带您客户端本地之少量上下文（部分收藏、最近艺人、最近搜索词，均限条数），仅于当次请求内存中使用，不落盘存储。

### 4.3 全局聚合统计

本服务另行维护与任何用户无关之全局聚合统计（热门搜索词计数、曲目共现关系），用于热度榜与相似推荐。该等记录不含个人标识符，不与您的身份关联，亦不随「一键清空画像」之范围呈现（因其本不属于任何用户）。

### 4.4 您浏览器之本地存储

下列资料仅存储于您之浏览器，运营者之服务器不取得完整副本：

| 存储位置 | 内容 |
| --- | --- |
| localStorage | 播放列表与播放历史（`audio`）、收藏与关注（`library`）、主题与语言与搜索历史（`global`）、界面偏好（`settings`）、个性化开关与匿名标识符（`recommend`）、性能模式（`sonic-perf-mode`） |
| IndexedDB | 您导入之本地音乐文件与已下载之歌曲（`SonicMusicPlayerDB`） |

### 4.5 自动处理之技术资料

- **限流**：匿名请求按 IP 分桶限流（每分钟 240 次）；IP 仅以限流键短暂使用（边缘限流器不留存，或以 120 秒自动过期之 KV 记录、60 秒内存窗口暂存），不写入数据库，不写入访问日志。
- **会话**：登录后签发 `HttpOnly; Secure; SameSite=Lax` 之会话 Cookie（有效期至多 30 日），内含签名 API Key；金钥不写入 URL、查询参数或 localStorage。OAuth 过程使用 10 分钟有效期之事务 Cookie。
- **访问日志**：数据面日志仅含请求路径、方法、状态码与耗时，不含查询字符串、IP、User-Agent、Cookie 或请求体。
- **音频代理**：音频流默认经本服务边缘代理取得，上游 CDN 仅见代理服务器之地址；如您主动调用 `?mode=redirect` 直连模式，您的浏览器将与官方 CDN 直接建立连接，您的 IP 对该 CDN 可见（此为 302 重新导向之固有语义）。

### 4.6 本服务不收集之项目

本服务无广告追踪、无跨站 Cookie、无第三方统计或分析脚本、无设备指纹；不收集通讯录、相册、位置或任何与音乐播放无关之设备资料；不出售个人资料，不为广告目的利用个人资料。

## 5. 法律依据与处理目的

各项处理活动之法律依据如下：

| 处理活动 | 目的 | 法律依据 |
| --- | --- | --- |
| Epomail 登录、会话维持、API Key 签发 | 帐户识别与服务接入 | 契约之必要（GDPR 第 6 条第 1 项第 b 款） |
| 行为事件与推荐画像（假名化） | 推荐与 Auto DJ 功能 | 正当利益（GDPR 第 6 条第 1 项第 f 款）；您得随时关闭个性化（第 9 节反对权），关闭后立即停止收集 |
| 全局聚合统计 | 热度榜与相似推荐 | 正当利益（GDPR 第 6 条第 1 项第 f 款）；不关联个人 |
| 匿名标识符事件（匿名参与者） | 推荐功能 | 您之自主选择；关闭个性化即终止 |
| IP 限流、会话安全、滥用防制 | 服务安全与稳定 | 正当利益（GDPR 第 6 条第 1 项第 f 款）；适用时并属法定义务（GDPR 第 6 条第 1 项第 c 款） |

您的个人资料仅用于上列目的及与其密切相关之范围。本服务不为自动化决策（GDPR 第 22 条所指产生法律效果或类似重大影响之决策）利用您的资料；推荐结果之影响限于您看到的播放序列，且您可以关闭。

## 6. 资料保存期限与销毁

| 资料类别 | 保存策略 |
| --- | --- |
| 行为事件 | 自记录之日起 90 日自动销毁（部署者可配置，下限 7 日）；「一键清空画像」立即销毁 |
| 帐户识别资料（电子邮件、昵称） | 不落盘存储；仅存于会话期间 |
| 会话 Cookie | 至多 30 日；登出即时失效 |
| 限流计数 | 边缘限流器不留存；KV 记录 120 秒自动过期；内存窗口 60 秒 |
| 全局聚合统计 | 不含个人标识，随数据库维护策略处理 |
| 浏览器本地存储 | 留存于您之设备，直至您清除或使用「清除全部本地数据」 |

## 7. 与第三方之共享及国际传输

本服务依最小必要原则与第三方共享个人资料，全部情形见[第三方共享与传输清单](/sub-processors/)，要旨如下：

1. **受托处理**：Cloudflare（边缘运算、托管、加密隧道、限流基础设施）；
2. **身份提供方**：Epomail（登录时取得标识符、电子邮件、昵称、头像链接与角色）；
3. **上游内容来源**：网易、QQ、酷狗、酷我、AMLL、LRCLIB 等——请求仅含歌曲查询参数与固定 User-Agent／Referer，不包含您的身份或 IP；
4. **法律要求**：仅于依法定程序受有权机关要求时提供，并于法律允许范围内通知您。

本服务之控制面运行于 Cloudflare 全球边缘网络，您的个人资料可能于运营者所在国境外之节点处理。运营者依 GDPR 第 44 条至第 46 条之保障机制（含欧盟标准合同条款）依托管与受托处理关系管理国际传输，并依赖 Cloudflare 之资料保护措施（SOC 2 Type II、ISO/IEC 27001 认证）。自行部署之运营者应自行评估并确保其国际传输行为符合其所在地之法律要求。

## 8. 儿童之保护

本服务不面向未满 16 岁之儿童，亦不有意收集儿童之个人资料；您所在地法律就信息社会服务之同意年龄另有较低规定者（最低 13 岁，GDPR 第 8 条），从其规定。监护人认为儿童提供个人资料者，得联络运营者请求删除，经核实后即时处理。

## 9. 当事人权利与行使方式

您就您的个人资料享有下列权利：

1. 接近与取得副本（GDPR 第 15 条）；
2. 更正（GDPR 第 16 条）；
3. 删除（GDPR 第 17 条）；
4. 限制处理（GDPR 第 18 条）；
5. 资料可携（GDPR 第 20 条）；
6. 反对（GDPR 第 21 条），包括随时关闭个性化。

行使方式：

1. **自助功能（即时生效）**：「清除推荐画像」即时销毁服务端全部行为事件；「清除全部本地数据」即时清除浏览器本地存储与 IndexedDB；推荐画像概览（事件总数、喜爱与拒绝计数、常听歌手与流派、最近搜索词）可经 `GET /api/sonic/events` 查询；关闭个性化即时停止事件收集；
2. **人工请求**：其馀请求致函 `privacy@epocanvas.com`，运营者于收到请求后一个月内答复（GDPR 第 12 条第 3 项）。

您认为本服务之处理侵害您之权利者，得向运营者请求救济（GDPR 第 79 条），并得向运营者所在地之主管监督机关申诉（GDPR 第 77 条）；位于欧盟与欧洲经济区之用户，得向其惯常居住地、工作地或侵权行为地之监督机关申诉。

## 10. 安全维护措施

运营者依 GDPR 第 32 条建立并持续改善适当之技术与组织措施，防止个人资料被窃取、窜改、毁损、灭失或泄漏：全链路 HTTPS/TLS；HMAC-SHA256 版本化签名 API Key；PKCE OAuth 流程；会话 Cookie 之 HttpOnly／Secure／SameSite 属性与即时撤销；数据面仅绑定回环地址并经加密隧道接入；全链路 SSRF 拦截；假名化标识符；日志最小化。完整清单与残余风险之说明见[数据处理与安全维护](/data-security/)。

## 11. 政策之变更

本政策得因服务或法规变动而修订。重大变更（新增第三方共享对象、变更保存策略或收集范围等）将以站内公告预先通知，并更新本页顶端之生效日期与版本号。变更生效后您继续使用本服务者，视为接受修订后之政策；不同意者得停止使用并清空其资料。历次重大修订随开源代码库之版本记录存档。
