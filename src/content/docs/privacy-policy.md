## 1. 适用范围

本政策适用于您以任何方式使用本服务所生之个人资料，包括：

1. 造访本服务网站（`sonic.epocanvas.tech`、`sonic.epocanvas.com` 或自行部署实例之网域）；
2. 使用网页播放器之全部功能（搜索、播放、歌词、推荐、下载、本地音乐导入）；
3. 经开放 API 接入本服务之第三方客户端。

本政策不适用于本服务链接或嵌入之第三方网站与服务（如上游音乐平台之自有站点）；该等第三方各有其隐私政策，由其自行负责。自行部署 Sonic 之运营者，自部署之时点起即为其用户之数据控制者，应自行向其用户履行其所在地适用法律下之告知义务；本政策可作为其告知之基础文本。

## 4. 收集之个人资料

### 4.1 帐户识别资料（经 Epomail 登录）

您以 Epomail 帐号经 OAuth 2.0（PKCE）登录时，本服务自 Epomail 之 userinfo 端点取得下列字段，此外不取得任何其他帐户资料：

| 字段 | 用途 | 是否落盘 |
| --- | --- | --- |
| 用户标识符（`id`／`sub`） | 会话内身份识别 | 否 |
| 电子邮件地址（须经验证） | 派生假名化哈希；作为签发予您本人之 API Key 载荷中 `sub` 声明 | 否 |
| 昵称或用户名（`name`／`username`／`nickname`） | 界面显示 | 否 |
| 头像链接（`avatar`／`picture`） | 界面显示 | 否 |
| 帐户角色（`role`） | 权限判定 | 否 |

本服务不设独立注册系统，不收集电话号码、真实姓名、住址或支付资料。电子邮件地址仅于登录会话内即时使用：派生假名化标识符（`usr_` 前缀之 SHA-256 哈希，截取 12 个十六进制字符）、派生用户标识哈希与限流桶键；派生所得之哈希值无法还原原电子邮件地址。

### 4.2 行为事件

为提供推荐与 Auto DJ 功能，本服务记录与曲目播放相关之行为事件。事件类型共 11 种：搜索、搜索点击、播放开始、播放进度、完播、跳过、重播、收藏、取消收藏、拒绝、取消拒绝。每项事件以下列假名化标识符之一关联：

1. **登录用户**：由电子邮件地址派生之 SHA-256 哈希（`usr_` 前缀）；
2. **匿名参与者**：由您浏览器本地生成之随机标识符（`anon_` 前缀）经服务端再哈希；
3. **公开模式**：个性化关闭时，事件不入库、不存储，于服务端直接丢弃。

事件上报采用批量方式（单批至多 50 条、请求体上限 64 KB），并于页面隐藏时冲刷待发队列。每项事件记录之内容限于：事件类型、曲目规范标识、歌手标识、流派与语种标签、搜索词（如适用）、播放进度比例与信号权重；不含 IP 地址、不含设备指纹、不含自由文本内容。

噪声与假信号净化：因网络卡顿（network_stall）、解码失败（playback_error）、试听截断（trial_end）、流不可用（stream_unavailable）、缓冲超时（buffer_timeout）或自动切换失败（auto_switch_error）所致之切歌，权重恒为零且不入库；客户端仅在播放正常且收听 0.5 至 25 秒之间时才上报主动跳过。

此外，推荐请求会随附您客户端本地之少量上下文（部分收藏曲目、最近艺人、最近搜索词，各限条数），仅于当次请求之内存中使用用于个性化排序，不落盘存储、不进入日志。

### 4.3 全局聚合统计

本服务另行维护与任何用户无关之全局聚合统计，用于热度榜与相似推荐：

| 统计表 | 内容 | 与个人之关联 |
| --- | --- | --- |
| 搜索词聚合计数 | 搜索词之全局频次统计 | 无 |
| 曲目共现关系 | 曲目被共同收听之全局统计 | 无 |

该等记录不含个人标识符，不与您的身份关联，亦不随「一键清空画像」之范围呈现（因其本不属于任何用户）。

### 4.4 您浏览器之本地存储

下列资料仅存储于您之浏览器，运营者之服务器不取得完整副本；浏览器隐私模式下存储不可用时自动降级为内存暂存：

| 存储位置 | 键 | 内容 |
| --- | --- | --- |
| localStorage | `audio` | 播放列表、当前曲目、播放模式、音量、静音状态、播放历史 |
| localStorage | `library` | 喜爱歌曲、收藏歌单、关注歌手、收藏 MV、收藏专辑、自建歌单 |
| localStorage | `global` | 主题、语言偏好、搜索历史（至多 10 条） |
| localStorage | `settings` | 界面偏好（背景动画、音质偏好等设置项） |
| localStorage | `recommend` | 个性化开关、Auto DJ 开关、匿名标识符、拒绝曲目列表 |
| localStorage | `sonic-perf-mode` | 性能模式开关 |
| IndexedDB | `SonicMusicPlayerDB` | 您导入之本地音乐文件（`local_music`）与已下载之歌曲（`downloaded_music`） |

### 4.5 自动处理之技术资料

- **限流**：匿名请求按 IP 分桶限流（每分钟 240 次，缺省值）；IP 仅以限流键短暂使用——边缘原生限流器不留存数据，或以 120 秒自动过期之 KV 记录暂存，或于 60 秒内存窗口内暂存（至多 4096 桶）；IP 不写入数据库，不写入访问日志。认证请求按电子邮件哈希分桶（每分钟 600 次，缺省值），认证端点另有每分钟每 IP 30 次之专用限流。
- **会话与金钥**：登录成功后签发 `HttpOnly; Secure; SameSite=Lax` 之 `sonic_session` Cookie（有效期至多 30 日），内含签名 API Key；金钥不写入 URL、查询参数或 localStorage。OAuth 过程使用 `sonic_oauth_state` 与 `sonic_oauth_verifier` 事务 Cookie（有效期 600 秒，限 `/api/auth` 路径）。API Key 载荷含 `sub`（电子邮件）、`iat`、`exp`、`jti`、`kid`、`role`、`uid`；`jti` 用于撤销清单与登出即时失效。
- **访问日志**：数据面访问日志为逐行 JSON，仅含请求标识、方法、路径、状态码与耗时；查询字符串、IP、User-Agent、Cookie、Authorization 与请求体一律不记录。异常日志仅含请求标识、错误名称与截断之错误消息。
- **音频代理**：音频流默认经本服务边缘代理取得，上游请求仅携带 User-Agent、按 CDN 配置之官网 Referer 与 Range 标头，并剥离 Set-Cookie 与凭证标头；上游 CDN 仅见代理服务器之地址。如您主动调用 `?mode=redirect` 直连模式，您的浏览器将与官方 CDN 直接建立连接，您的 IP 对该 CDN 可见（此为 302 重新导向之固有语义）；网页播放器不使用该模式。
- **边缘网络**：Cloudflare 依其自身政策处理网络层请求元数据。

### 4.6 本服务不收集之项目

本服务无广告追踪、无跨站 Cookie、无第三方统计或分析脚本、无设备指纹、无行为广告画像；不收集通讯录、相册、位置或任何与音乐播放无关之设备资料；不出售个人资料，不为广告目的利用个人资料，不接入任何广告网络。

## 5. 法律依据与处理目的

各项处理活动之法律依据如下：

| 处理活动 | 目的 | 法律依据 |
| --- | --- | --- |
| Epomail 登录、会话维持、API Key 签发与撤销 | 帐户识别与服务接入 | 契约之必要（GDPR 第 6 条第 1 项第 b 款） |
| 行为事件与推荐画像（假名化） | 推荐与 Auto DJ 功能 | 正当利益（GDPR 第 6 条第 1 项第 f 款）；您得随时关闭个性化（第 9 节反对权），关闭后立即停止收集 |
| 全局聚合统计 | 热度榜与相似推荐 | 正当利益（GDPR 第 6 条第 1 项第 f 款）；不关联个人 |
| 匿名标识符事件（匿名参与者） | 推荐功能 | 您之自主选择；关闭个性化即终止 |
| IP 限流、会话安全、滥用防制 | 服务安全与稳定 | 正当利益（GDPR 第 6 条第 1 项第 f 款）；适用时并属法定义务（GDPR 第 6 条第 1 项第 c 款） |

您的个人资料仅用于上列目的及与其密切相关之范围。本服务不为自动化决策（GDPR 第 22 条所指产生法律效果或类似重大影响之决策）利用您的资料；推荐结果之影响限于您看到的播放序列与榜单排序，且您可以随时关闭。

## 6. 资料保存期限与销毁

| 资料类别 | 保存策略 |

| 金钥撤销清单 | 部署者配置之静态清单（环境变量）或 KV 即时撤销记录 |
| 数据库备份 | 一致性快照含假名化行为数据，应与生产数据同等级保护 |

| 浏览器本地存储 | 留存于您之设备，直至您清除或使用「清除全部本地数据」 |

## 7. 与第三方之共享及国际传输

本服务依最小必要原则与第三方共享个人资料，全部情形见[第三方共享与传输清单](/sub-processors/)，要旨如下：

1. **受托处理**：Cloudflare（Pages 托管、Functions 边缘运算、Tunnel 加密隧道、KV 存储、限流基础设施）；
2. **身份提供方**：Epomail（登录时取得标识符、电子邮件、昵称、头像链接与角色）；
3. **上游内容来源**：网易、QQ、酷狗、酷我、AMLL、LRCLIB 及各官方内容 CDN——请求仅含歌曲查询参数与固定 User-Agent／Referer，不包含您的身份或 IP；
4. **法律要求**：仅于依法定程序受有权机关要求时提供，并于法律允许范围内通知您。

本服务之控制面运行于 Cloudflare 全球边缘网络，您的个人资料可能于运营者所在国境外之节点处理。运营者依 GDPR 第 44 条至第 46 条之保障机制（含欧盟标准合同条款）依托管与受托处理关系管理国际传输，并依赖 Cloudflare 之资料保护措施（SOC 2 Type II、ISO/IEC 27001 认证）。自行部署之运营者应自行评估并确保其国际传输行为符合其所在地之法律要求。

## 8. 儿童之保护

本服务不面向未满 16 岁之儿童，亦不有意收集儿童之个人资料；您所在地法律就信息社会服务之同意年龄另有较低规定者（最低 13 岁，GDPR 第 8 条），从其规定。监护人认为儿童提供个人资料者，得联络运营者请求删除，经核实后即时处理。任何人均不得利用本服务对儿童及少年散布有害其身心健康之内容；相关使用限制见[可接受使用政策](/acceptable-use/)。

您就您的个人资料享有下列权利：

1. 接近与取得副本（GDPR 第 15 条）；
2. 更正（GDPR 第 16 条）；

1. **自助功能（即时生效）**：
