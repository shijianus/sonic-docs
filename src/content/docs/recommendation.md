**修订日期：2026 年 11 月 3 日｜版本：1.9**

本页概述 Sonic 推荐信号、权重、排序及控制。功能核对基于最新公开 RC `rc/sonic-20261031@a75f5cb`（2026-11-01 UTC）；较早默认分支 `main@ce443c8`（2026-10-27 UTC）仅作兼容性对照，不证明 RC 功能已部署，在线版本未知。除下列曲目信号外，核对代码另含艺人、专辑、歌单及 MV 反馈与雷达画像。个性化与 Auto DJ 默认开启；默认值、登录和继续使用都不是明确同意。缺少有效依据的可选画像分析应暂停。见[隐私政策](/privacy-policy/)第 4.2、5 节。

## 1. 行为信号与权重

| 信号 | 权重 | 说明 |
| --- | --- | --- |
| favorite（加入最爱） | +4.0 | 极强正向 |
| replay（重播） | +3.5 | 强正向 |
| play_complete（有效完播） | +2.5 | 标准正向 |
| play_progress（进度聆听） | +0.2 ～ +1.8 | 按收听比例分阶计分 |
| skip（快速跳过） | -0.8 | 听过一半后切歌计 +0.25 |
| dislike（明确拒绝） | -5.0 | 仅在可用身份与功能范围内过滤相符推荐；不承诺永久全面封禁 |

**噪声净化**：网络延迟（network_stall）、解码失败（playback_error）、试听截断（trial_end）、流媒体不可用（stream_unavailable）、缓冲逾时（buffer_timeout）与自动切换失败（auto_switch_error）六类非用户切歌，权重恒为零且不入库。

## 2. 热度模型

站内趋势热榜综合五项因子加权：有效播放（35%）、独立听众（25%）、完播表现（20%）、收藏转化（15%）与成长斜率（5%）；辅以指数时间衰减（24 小时飙升榜与 7 天累计热榜）与贝氏／Wilson Score 平滑，避免低播放高完播的偶发事件异常置顶。

## 3. 会话意图与长期偏好

会话搜索意图与长期信号对排序的影响不同，但不表示搜索从不保留。推荐请求可能传送本地收藏、最近艺人和搜索上下文；智能搜索另行计数搜索原文，即使关闭个性化也可能出现在公开建议，请勿输入私密或敏感信息。假名识别码仍是可能关联个人的数据。

## 4. 多样性重排与 Auto DJ

1. **相似度**：融合歌手关系图谱、流派与语言标签的集合相似度，及音频特征的余弦相似度；
2. **MMR 重排**：以边际相关性平衡“精准”与“新颖”，避免陷入单一歌手或曲风的信息茧房；
3. **Auto DJ**：播放清单自然播完后，依当前曲目风格自动续接可播放曲目；可在设置关闭。其开关独立于个性化，后者关闭时仍可能发送种子及排除曲目。

## 5. 音乐与风格雷达

首页雷达使用搜索意图与偏好信号；代码包含本地雷达状态、画像及远程同步路径，不是完全不改变存储数据的纯显示功能。关闭个性化后仍可能发送含曲目、封面及信号的同步载荷，服务端可能按关闭标记拒绝存储；请求发送与成功保存须分别判断。远程路由可用性有限，也不保证通用云端同步；雷达数据不在事件清理或画像重置的完整涵盖范围。

## 6. 您的控制权

| 控件 | 位置 | 效果 |
| --- | --- | --- |
| 个性化总开关 | 设置 → 隐私与本地数据 | 控制其涵盖的推荐事件，不控制独立搜索统计或每个雷达路径 |
| Auto DJ 开关 | 设置 → 隐私与本地数据 | 控制播完后自动续接；默认开启不成立同意 |
| 重置推荐画像 | 设置 → 隐私与本地数据 | 删除目前身份的部分事件与反馈；可能遗漏旧识别码、雷达、聚合、外部服务及备份，且失败可能未显示 |
| 拒绝曲目 | 播放器内 dislike | 仅在可用身份与功能范围内过滤相符推荐；不承诺永久全面封禁 |

默认 90 日事件设置不是逐笔到期销毁，也不是所有数据类别的期限。浏览器无痕模式不阻止请求或事件；较完整删除或副本请求请联络 `privacy@epocanvas.com`。源代码核对用于修正文件，不能免除错误告知责任或替代合法依据（见[开发指南](/development/)第 4 节）。
