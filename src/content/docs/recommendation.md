**生效日期：2026 年 11 月 2 日｜版本：1.5**

本页完整说明 Sonic 推荐引擎之构成：哪些信号进入模型、如何加权、如何排序，以及您拥有哪些控制权。全部规则公开于源码；资料收集之法律依据与边界见[隐私政策](/privacy-policy/)第 4.2 节与第 5 节。

## 1. 行为信号与权重

| 信号 | 权重 | 说明 |
| --- | --- | --- |
| favorite（加入最爱） | +4.0 | 极强正向 |
| replay（重播） | +3.5 | 强正向 |
| play_complete（有效完播） | +2.5 | 标准正向 |
| play_progress（进度聆听） | +0.2 ～ +1.8 | 按收听比例分阶计分 |
| skip（快速跳过） | -0.8 | 听过半之切歌计 +0.25 |
| dislike（明确拒绝） | -5.0 | 硬过滤并列入黑名单 |

**噪声净化**：网络卡顿（network_stall）、解码失败（playback_error）、试听截断（trial_end）、流不可用（stream_unavailable）、缓冲超时（buffer_timeout）与自动切换失败（auto_switch_error）六类非用户切歌，权重恒为零且不入库。

## 2. 热度模型

站内趋势热榜综合五项因子加权：有效播放（35%）、独立听众（25%）、完播表现（20%）、收藏转化（15%）与成长斜率（5%）；辅以指数时间衰减（24 小时飙升榜与 7 天累计热榜）与贝氏／Wilson Score 平滑，避免低播放高完播之偶发事件异常置顶。

## 3. 会话意图与长期偏好

会话级搜索意图（连续搜索关键词、点击歌手与流派）以高短期权重参与即时排序，与长期偏好分层解耦：仅完播、收藏等高价值行为沉淀至长期档案，偶发搜索不会立即改变您的长期画像。

## 4. 多样性重排与 Auto DJ

1. **相似度**：融合歌手关系图谱、流派与语言标签之集合相似度，及音讯特征之余弦相似度；
2. **MMR 重排**：以边际相关性平衡「精准」与「新颖」，避免陷入单一歌手或曲风之信息茧房；
3. **Auto DJ**：播放列表自然播完后，依当前曲目风格自动续接可播放曲目；可在设置关闭。

## 5. 音乐与风格雷达

完成一次搜索后，首页雷达会依您的搜索意图与偏好信号即时展示匹配结果，与热门单曲样式对齐；雷达仅影响您看到的推荐序列，不改变任何存储数据。

## 6. 您的控制权

| 控制项 | 位置 | 效果 |
| --- | --- | --- |
| 个性化总开关 | 设置 → 隐私与本地数据 | 关闭后事件不再收集，推荐进入纯公共模式 |
| Auto DJ 开关 | 设置 → 隐私与本地数据 | 控制播完自动续接 |
| 重置推荐画像 | 设置 → 隐私与本地数据 | 即时销毁服务端全部行为事件 |
| 拒绝曲目 | 播放器内 dislike | 硬过滤，不再出现在推荐中 |

算法之技术事实随源码演进更新；本文档与源码不一致时以源码为准并修正文档（核对流程见[开发指南](/development/)第 4 节）。
