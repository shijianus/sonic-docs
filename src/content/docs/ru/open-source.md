## 4. Правовые обязанности развернувших

С момента самостоятельного развертывания развернувший становится контролёром данных своих пользователей (распределение ролей приведено в разделе 2 [Обзора](/ru/overview/)) и обязан:

1. **Информировать**: уведомлять пользователей о вопросах обработки данных; за основу можно взять [Политику конфиденциальности](/ru/privacy-policy/) этого сайта, но её следует скорректировать по фактической конфигурации (невключённые сторонние цепочки следует исключить из уведомления);
2. **Вести записи и оценивать**: поддерживать записи видов обработки (статья 30 GDPR), а при высоком риске проводить оценку влияния на защиту данных (статья 35 GDPR);
3. **Обеспечивать безопасность**: реализовать меры из раздела 3 документа [Обработка данных и меры безопасности](/ru/data-security/) и проходить надзор компетентных органов;
4. **Обеспечивать согласованность конфигурации**: фактические значения переменных окружения (срок хранения, сторонние переключатели, ограничение частоты) должны соответствовать обязательствам вашей политики;
5. **Дополнять по юрисдикции**: помимо GDPR, дополнить требованиями права по юрисдикции ваших пользователей — UK GDPR, LGPD, CCPA-CPRA и др.
