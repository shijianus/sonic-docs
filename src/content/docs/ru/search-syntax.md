## 1. Область поиска

Поиск охватывает четыре вида объектов: песни, исполнители, альбомы и плейлисты. На странице результатов используются три вкладки — «Синглы / Плейлисты / MV»; поле поиска находится в верхней части боковой панели и на странице поиска, где интерфейс может показывать популярные поисковые запросы сервиса.

## 2. Правила устойчивости к опечаткам и совпадений

| Правило | Описание | Пример |
| --- | --- | --- |
| Нормализация упрощённых и традиционных начертаний | Можно попробовать оба начертания; фактическое совпадение зависит от индекса и доступности вышестоящих источников | Сравнить ввод «周杰伦» и «周傑倫» |
| Поиск по пиньиню и сокращениям | Можно попробовать полную транслитерацию пиньинем или инициалы; результат не гарантирован для каждого источника | Попробовать «zjl» для песен, связанных с 周杰伦／周傑倫 |
| Симметричное сопоставление псевдонимов | Сайт может связывать китайские и иностранные имена исполнителя; фактический результат зависит от индекса | Поиск иностранного имени может найти исполнителя по китайскому псевдониму |
| Устойчивость к опечаткам по расстоянию редактирования | Приближённая строка может рассматриваться как кандидат; исправление каждой опечатки не гарантируется | Ввести похожую строку и проверить фактический результат |
| Определение версии | Результаты могут различать студийную, концертную, кавер- и другие версии | Ориентироваться на указанную в результате версию |

## 3. Параллельный поиск по нескольким источникам и дедупликация

Запросы отправляются включённым вышестоящим источникам, доступным в момент запроса, после чего результаты объединяются по правилам нормализации. Записи одной и той же песни с одинаковым названием из разных источников могут объединяться в один результат, а адрес воспроизведения выбирается во время запуска с учётом доступности. Список источников и переключатели по умолчанию приведены в разделе 3 [Перечня третьих лиц и международных передач](/ru/sub-processors/).

## 4. Действия с результатами

В каждой строке трека могут быть доступны воспроизведение, переход к MV при наличии, добавление в избранное, загрузка и дополнительные действия; кнопка «Воспроизвести всё» сверху может запускать треки по порядку результатов. Результат-плейлист открывает страницу сведений о плейлисте, а результат MV — список MV; фактические действия зависят от результата и конфигурации экземпляра.

## 5. Поиск и приватность

Поисковые запросы обрабатываются следующим образом:

1. **Локально**: история недавних запросов использует localStorage браузера, но сам запрос передаётся для поиска, а часть истории может сопровождать запросы рекомендаций; локальная очистка не удаляет уже созданные удалённые копии;
2. **Агрегация на сервере**: интеллектуальный поиск может отдельно считать или сохранять исходный текст и показывать его в публичных подсказках; отключение персонализации само по себе не исключает этот путь. Текст может идентифицировать человека без идентификатора аккаунта; не вводите личные или чувствительные данные. Фильтрацию, пороги показа, управление хранением и конфигурацию экземпляра нужно проверять отдельно;
3. **Персонализация**: поисковые запросы и клики могут связываться с псевдонимными идентификаторами. Переключатель персонализации не управляет всеми путями статистики поиска; настройка или сброс на 90 дней не означает, что каждый поисковый агрегат или копия удаляется по тому же графику.
