На этой странице собраны возможности и правила поиска Sonic: что вводить, как обеспечивается устойчивость к опечаткам и как организуются результаты. Расположение в интерфейсе описано в разделе 2 [Руководства по интерфейсу и функциям](/ru/interface/).

## 1. Область поиска

Поиск охватывает четыре вида объектов: песни, исполнители, альбомы и плейлисты. На странице результатов используются три вкладки — «Синглы / Плейлисты / MV»; поле поиска находится в верхней части боковой панели и на странице поиска, где также предлагаются популярные поисковые запросы сервиса.

## 2. Правила устойчивости к опечаткам и совпадений

| Правило | Описание | Пример |
| --- | --- | --- |
| Нормализация упрощённых и традиционных начертаний | Ввод на упрощённом и традиционном китайском считается равнозначным | Ввод «周杰伦» и «周杰倫» даёт одинаковые результаты |
| Поиск по пиньиню и сокращениям | Совпадение определяется по полной транслитерации пиньинем или по инициалам | Ввод «zyy» находит треки, связанные с 周杰伦 |
| Симметричное сопоставление псевдонимов | Китайские и английские псевдонимы исполнителя связаны в обоих направлениях | Поиск английского имени может найти исполнителя по китайскому псевдониму |
| Устойчивость к опечаткам по расстоянию редактирования | Орфографические ошибки исправляются по расстоянию редактирования | Приближённая строка всё ещё может найти нужный объект |
| Определение версии | Различаются студийная, концертная, кавер- и другие версии | В результате указывается соответствующая версия |

## 3. Параллельный поиск по нескольким источникам и дедупликация

Поисковые запросы параллельно отправляются включённым вышестоящим источникам, а результаты нормализуются и объединяются: записи одной и той же песни с одинаковым названием из разных источников объединяются в один результат, а адрес воспроизведения выбирается во время запуска с учётом доступности. Список источников и переключатели по умолчанию приведены в разделе 3 [Перечня третьих лиц и международных передач](/ru/sub-processors/).

## 4. Действия с результатами

В каждой строке трека доступны воспроизведение, переход к MV (если есть), добавление в избранное, загрузка и дополнительные действия; кнопка «Воспроизвести всё» сверху запускает треки по порядку результатов. Результат-плейлист открывает страницу сведений о плейлисте, а результат MV — список MV.

## 5. Поиск и приватность

Поисковые запросы обрабатываются следующим образом:

1. **Локально**: последние поисковые запросы (не более 10) хранятся только в localStorage браузера и удаляются с помощью «Очистить все локальные данные»;
2. **Агрегация на сервере**: запросы входят в глобальный агрегированный счётчик (без личных идентификаторов, для чарта популярных запросов);
3. **Персонализация**: при включённой персонализации клики по результатам поиска записываются как сигналы рекомендаций (псевдонимизированные, на 90 дней); после отключения события не записываются.
