На этой странице полностью перечислены все случаи передачи персональных данных сервисом Sonic (далее «сервис») третьим лицам, включая получателей, затрагиваемые данные и механизмы обеспечения. Страница разворачивает раздел 7 [Политики конфиденциальности](/ru/privacy-policy/); принцип передачи — минимальная необходимость: персональные данные не продаются, не передаются в рекламных целях и не выходят за пределы, необходимые функциям сервиса.

## 1. Обработчики по поручению (постоянно задействованные)

| Получатель | Содержание сервиса | Затрагиваемые данные | Механизм обеспечения |
| --- | --- | --- | --- |
| Cloudflare Pages и Functions | Хостинг фронтенда, граничный API-шлюз, исполнение ограничения частоты запросов | Метаданные запросов, временные записи ограничения частоты | Положения об обработке по поручению статьи 28 GDPR |
| Cloudflare Tunnel | Зашифрованный канал между плоскостью управления и плоскостью данных | Метаданные зашифрованного трафика | Там же |
| Cloudflare KV и ограничитель частоты | Счётчики ограничения частоты (истекают через 120 секунд), записи мгновенного отзыва ключей (если включено) | Ключи ограничения частоты по IP, записи отзыва `jti` | Там же |

Cloudflare в целом обладает сертификациями SOC 2 Type II и ISO/IEC 27001 и покрывает трансграничную передачу стандартными договорными условиями ЕС. Метаданные сетевых запросов, обрабатываемые Cloudflare по собственной политике, описаны в его политике конфиденциальности.

## 3. Вышестоящие источники контента (по поисковым запросам, без данных о личности пользователя)

Запросы к следующим получателям содержат только параметры поиска песен, фиксированный User-Agent и соответствующий Referer официального сайта и **не содержат данных вашей учётной записи, cookie или IP-адреса**:

| Получатель | Содержание сервиса | Примеры доменов | Статус по умолчанию |
| --- | --- | --- | --- |
| NetEase Cloud Music | Поиск, адреса воспроизведения, пословные тексты (YRC), обложки | `music.163.com`, `interface3.music.163.com`; также через вспомогательный контейнер ncm-api во внутренней сети плоскости данных | Включён |
| QQ Music | Поиск, адреса воспроизведения, пословные тексты (QRC), обложки | `c.y.qq.com`, `u.y.qq.com`, `y.gtimg.cn`, `ws.stream.qqmusic.qq.com` | Включён |
| Kugou Music | Поиск, адреса воспроизведения, пословные тексты (KRC) | `m.kugou.com`, `mobilecdn.kugou.com`, `songsearch.kugou.com`, `lyrics.kugou.com` | Включён |
| Kuwo Music | Поиск, адреса воспроизведения, обложки | `www.kuwo.cn`, `m.kuwo.cn`, `search.kuwo.cn` | Включён |
| AMLL | Дополнение пословных текстов (TTML) | `api.amll.dev` | Включён |
| LRCLIB | Дополнение синхронных текстов | `lrclib.net` | Включён |
| Официальные CDN контента | Аудиопотоки и обложки (по умолчанию получаются через граничный прокси сервиса) | `music.126.net`, `ws.stream.qqmusic.qq.com` и др. | Включён |

Примечания:

1. Исходящий IP вышестоящих запросов обозначен замещающим адресом, настроенным оператором развертывания (по умолчанию документационный адрес RFC 5737), а не IP какого-либо пользователя;
2. Аудиопотоки по умолчанию получаются через граничный прокси, и вышестоящий CDN видит только адрес прокси-сервера; при самостоятельном вызове режима прямого подключения `?mode=redirect` ваш браузер соединяется с этим CDN напрямую, и ваш IP становится виден этому CDN (неотъемлемая семантика перенаправления 302); веб-плеер этот режим не использует;
3. Оператор развертывания может подключить каталог по подписке собственными учётными данными (`NETEASE_COOKIE`/`QQ_COOKIE`/`KUGOU_COOKIE`); эти данные относятся к учётной записи оператора развертывания и не касаются конечных пользователей; в коде не встроено cookie реальных учётных записей.

## 5. Передача по требованию закона

Оператор предоставляет персональные данные только по запросам с конкретным правовым основанием: проверяет законность и объём запроса, добровольно не предоставляет содержания сверх запроса и предварительно уведомляет затронутых субъектов в мере, допустимой законом (кроме случаев, когда закон запрещает уведомление). Сервис не принимает произвольного получения данных без правового основания. Ход обработки всех законных запросов регистрируется.

## 6. Международная передача

Плоскость управления сервиса работает в глобальной граничной сети Cloudflare, а события поведения хранятся на узле плоскости данных оператора; ваши персональные данные могут обрабатываться на узлах за пределами страны нахождения оператора. Механизмы обеспечения передачи:

1. По статьям 44–46 GDPR: основой отношений хостинга и обработки по поручению служат решения Европейской комиссии о достаточности защиты (статья 45) или одобренные стандартные договорные условия (статья 46, пункт 2, подпункт "c" GDPR);
2. Сертификации защиты данных Cloudflare (SOC 2 Type II, ISO/IEC 27001) и его приложение об обработке данных;
3. Запросы к вышестоящим источникам контента не содержат персональных данных и не образуют международной передачи персональных данных (см. раздел 3).

Операторы самостоятельного развертывания должны самостоятельно оценить международную передачу в своей форме развертывания и обеспечить соответствие правовым требованиям своего местонахождения (раздел V GDPR или местный аналог).

## 7. Ведение перечня

1. Перед добавлением нового получателя оператор регистрирует его на этой странице и обновляет дату вступления в силу и номер версии; о существенных изменениях заранее объявляется на платформе;
2. При несоответствии перечня конфигурации исходного кода приоритет имеет код, и страница немедленно исправляется;
3. Операторы самостоятельного развертывания должны вести собственный перечень третьих лиц по фактической конфигурации: неиспользуемые цепочки следует исключить из своих уведомлений, избегая избыточного или ложного раскрытия.
