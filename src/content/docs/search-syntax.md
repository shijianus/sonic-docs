本页汇整 Sonic 搜索之能力与规则：输入什么、如何容错、结果如何组织。界面位置见[界面与功能导览](/interface/)第 2 节。

## 1. 检索范围

搜索涵盖四类对象：歌曲、歌手、专辑与歌单。结果页以“单曲／歌单／MV”三类页签组织；搜索入口位于侧边栏顶部与搜索页，界面可能显示站内热门搜索关键词提示。

## 2. 容错与匹配规则

| 规则 | 说明 | 范例 |
| --- | --- | --- |
| 简繁字形归一 | 可用简体或繁体字形尝试检索；实际匹配取决于索引与上游可用性 | 输入“周杰伦”与“周傑倫”进行对照 |
| 拼音与缩写检索 | 可用拼音全拼或首字母缩写尝试命中；不保证所有来源均有结果 | 输入“zjl”尝试检索周杰伦相关曲目 |
| 别名对称匹配 | 站点可能关联歌手的中英文别名；实际结果取决于索引 | 检索英文名可尝试命中中文别名艺人 |
| 编辑距离容错 | 接近的字串可能被视为候选；不保证每个拼写错误都能修正 | 输入近似字串后检查实际结果 |
| 版本识别 | 结果可能区分录音室版、现场版、翻唱等版本 | 以结果中的版本标示为准 |

## 3. 多源并行与去重

搜索请求会发送至已启用且当时可用的上游来源，结果再按标准化规则合并；同名同曲目的多源记录可能合并为单一结果，播放位址则在播放时依可用性取得。上游来源之清单与默认开关见[第三方共享与传输清单](/sub-processors/)第 3 节。

## 4. 结果操作

单曲清单的结果行可能提供播放、MV 入口（如有）、喜爱、下载与更多操作；顶部“播放全部”可能依结果顺序连播。歌单结果进入歌单详情页，MV 结果进入 MV 清单；实际可用操作取决于结果与实例配置。

## 5. 搜索与隐私

搜索词之处理方式：

1. **本地**：最近搜索历史使用浏览器 localStorage，但查询本身会传送供搜索，部分历史也可能随推荐请求传送；本地清理不删除已经产生的远端副本；
2. **服务器端聚合**：智能搜索可能另行计数或保存搜索原文，并可能出现在公开建议，即使关闭个性化也不能据此排除该路径。没有账号识别码的文字仍可能识别个人，请勿提交私密或敏感资料；实际过滤、显示门槛、保存控制与实例配置须另行核实；
3. **个性化**：搜索与点击讯号可由假名识别码关联。个性化开关不控制每个搜索统计路径；90 日设置或重置功能也不代表所有搜索聚合或副本都会按同一期限删除。

详见[隐私政策](/privacy-policy/)第 4 节与[推荐算法说明](/recommendation/)。
