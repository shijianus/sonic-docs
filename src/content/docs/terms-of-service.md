## 1. 定义

1. **本服务**：运行于某一 Sonic 实例上之全部功能，包括网页播放器、边缘闸道、本地协议引擎、开放 API 及相关组件；界面布局与功能位置见[界面与功能导览](/interface/)。
2. **运营者**：部署并运行您所用实例之个人或团队。就托管实例（`sonic.epocanvas.tech`、`sonic.epocanvas.com`）而言，指运营团队；就自行部署实例而言，指其部署者。
3. **您（用户）**：登录或以其他方式使用本服务之自然人或组织。
4. **契约成立**：您于哪一个实例登录，即与该实例之运营者成立契约。本条款为通用范本：托管实例直接适用；自行部署运营者得修改后作为其站点条款，并应依其所在地之适用法律向其用户履行告知义务。
5. **数据面**：为您所用实例提供协议解析与推荐计算之 Linux 节点；其离线不影响您依第 4 节第 2 款获得之降级服务。

## 2. 服务之说明与范围

本服务为检索、聚合与播放工具，不存储、不托管任何音乐文件；音频内容自官方 CDN 及上游开放接口取得，歌词自原生解析与公开歌词库取得。各项功能之范围与资料位置如下：

| 功能类别 | 包含功能 | 资料存储位置 | 是否需要登录 |
| --- | --- | --- | --- |
| 核心功能（匿名可用） | 多源聚合搜索、逐字歌词、音质分级播放、试听标识、排行榜、MV | 浏览器本地（播放状态） | 否 |
| 帐号功能 | 收藏与歌单云同步、个性化推荐与 Auto DJ、行为事件管理 | 服务端仅存假名化行为事件；收藏偏好存于浏览器 | 是 |
| 个人资料功能 | 下载列表、本地音乐导入与管理 | 浏览器 IndexedDB | 否 |
| 开放 API | 第三方客户端经签名 API Key 接入 | 服务端会话与撤销清单 | 是 |

本服务基于开源专案建置并延续开源：源代码公开可审计，您得自行部署取得同等能力。软体本身依「现状」提供，其授权条款与本条款之责任约定相一致（见第 10 节）。

## 3. 帐号之取得与安全

1. **登录方式**：本服务以 Epomail 帐号经 OAuth 2.0（PKCE）登录，不设独立注册系统；您与 Epomail 之间之帐号约定，适用该服务之条款。Epomail 帐号被冻结或注销者，您对本服务之登录随之中止。
2. **资格**：您应年满 16 岁；您所在地法律就信息社会服务之同意年龄另有规定者，从其较低年龄（最低 13 岁），惟您为儿童者仍应取得监护人同意。年龄以您登录之 Epomail 帐号资料为准，本服务未设独立之年龄验证机制。
3. **一人一帐号**：您不得将帐号出借、出租、出售或与他人共用；因共用帐号所生之争议与资料混同，运营者不负责区分与恢复。
4. **凭证保管**：您对 Epomail 帐号凭证、API Key 及会话安全负保管责任。经由您凭证所为之操作，推定为您本人之行为。会话 Cookie 内含签名金钥，请勿于共用设备登录后不登出；发现凭证外泄时，您应立即登出并请求撤销。
5. **会话机制**：登录成功后签发 `HttpOnly; Secure; SameSite=Lax` 之会话 Cookie（有效期至多 30 日）；API Key 不写入 URL、查询参数或 localStorage。您得随时登出，登出即时撤销当前会话与对应金钥识别码（jti）。
6. **金钥签发**：API Key 采 HMAC-SHA256 版本化签名格式，签发有效期 30 日、校验上限 90 日；无签名或已撤销之金钥一律拒绝。您重新签发金钥须提供当前有效金钥。API Key 为您个人使用之凭证，不得转交第三方或嵌入公开发行之客户端。
7. **登录保护**：OAuth 回调经 state、PKCE、授权码与重放四重校验；认证端点设每分钟每 IP 30 次之限流。

## 4. 服务之提供与变更

1. **可用性**：运营者尽合理努力维持可用性，但不承诺特定之可用率、缓冲时效或故障恢复时限，亦不提供服务水平协议（SLA）。
2. **降级机制**：数据面节点连续 3 次失败或单次调用超过 4.5 秒预算时，边缘层熔断并自动切换至降级模式（直接连接公开歌词与检索接口），冷却 30 秒后探活恢复；降级期间界面显示「边缘降级模式」提示，部分功能（如完整音源解析、推荐更新）可能不可用。此属系统设计之容灾行为，非属违约。
3. **音质与试听标识**：播放器之音质徽章（如 SQ 无损、HQ 高品）如实反映当前音频流之实际档位；官方提供之 30 秒试听片段以试听标识明示，不冒充完整曲目。上游音源档位变动时，实际可得音质随之变动，不构成违约。
4. **功能变更**：开源专案持续演进，功能可能新增、调整或移除；涉及资料删除能力之重大变更将预先公告。

6. **实验性功能**：标示实验或处于测试期之功能依现状提供，可能不稳定，并得随时调整或下线。

1. **收藏与偏好**：您建立之收藏、歌单与播放器偏好存储于您浏览器之本地存储；清除浏览器资料或使用「清除全部本地数据」即行删除，运营者不为其丢失负责，重要歌单请自行记录。
2. **本地音乐与下载**：您导入之本地音乐文件与已下载歌曲存储于您浏览器之 IndexedDB；该等内容属您所有，运营者之服务器不存储副本。下载与本地导入之文件仅供您个人聆听，您不得再分发、公开传播或用于商业目的。
