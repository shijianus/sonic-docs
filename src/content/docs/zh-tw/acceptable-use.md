## 1. 適用範圍

1. 本政策適用於您使用託管 Sonic 網頁播放器、公開 API、登入、搜尋、播放、歌詞、推薦和其他公開端點的行為。
2. 自行部署是獨立執行個體。部署者應自行決定其政策、設定、法律和使用者關係；本頁不替自行部署者承擔營運或契約義務。
3. MIT 授權允許對程式碼進行複製、修改、散布和商業使用。本政策保護的是託管執行個體及其資源，不構成對程式碼或所有 Sonic 部署的普遍商業使用禁令。
4. 本機音樂匯入在目前核對中未發現把音訊 Blob 上傳至伺服器的路徑；歌詞和推薦功能仍可能傳送標題、藝人、專輯、時長或識別碼，詳見[隱私權政策](/zh-tw/privacy-policy/)。

## 2. 禁止行為

### 2.1 系統與介面濫用

1. 未經授權取得、使用或分享他人的帳號、工作階段、Cookie、API Key 或服務金鑰，偽造憑證，或繞過託管執行個體的驗證、限流、簽章、SSRF 等存取控制。
2. 未經授權探測或利用託管執行個體的非公開端點、內部位址及憑證材料，或取得、揭露他人私密資料；不得利用公開搜尋建議蒐集、曝光或驗證他人資料。
3. 透過大量擷取搜尋結果、歌詞、播放位址或介面回應占用共享資源，用於未獲允許的轉售、鏡像或資料集；正常個人播放、適度 API 使用和經授權接入不在此限。
4. 將託管代理當作通用網路代理、掃描器或攻擊跳板，或故意製造不必要的並行請求、流量、錯誤和快取壓力。

本政策不禁止閱讀原始碼、在自有本機執行個體上使用合成或授權資料測試，或負責任地通報漏洞。對公開執行個體的主動安全測試應先取得適當授權，避免影響他人、取得其資料或擴大漏洞；可向 `admin@epocanvas.com` 私下提供最小重現，不要公開真實憑證。

### 2.2 內容與權利

1. 不得利用託管服務實施或促進盜版、規避付費或著作權保護、侵犯著作權、商標權、肖像權、人格權、隱私權或其他權利的行為。
2. 不得利用服務傳播違法內容、惡意軟體、兒童性剝削材料或違法的恐怖主義宣傳，或非法、未經授權揭露他人的憑證及個人資料。這不禁止正常登入和必要的私下權利請求；本機音樂匯入也不等於向 Sonic 上傳檔案。

4. 不得提交明知含有他人私密資訊的搜尋詞、留言或檢舉材料。公開留言可能包含其他人的姓名、頭像和文字；本機留言寫入 localStorage 不等於已獲發布許可。

1. 不得騷擾、威脅、誹謗、跟蹤、歧視或攻擊營運者、上游提供者、貢獻者和其他使用者，也不得利用公開快取或建議功能暴露他人資料。

## 3. 資源使用上限

託管執行個體可按未登入或驗證狀態、IP、工作階段、介面和事件批次設定限流；具體值由實際設定決定，不是本站對所有部署的統一契約承諾。超過限制時可能收到 `429`、延遲、拒絕或臨時限制，不必然表示違規。

請使用合理的個人請求頻率，避免並行擷取、重複重試、長時間占用音訊串流和不必要的行為事件上報。限流參數、憑證撤銷和資料保存可能因環境變數、Compose 與原始碼預設值不同而不一致；不能僅憑頁面推斷執行狀態。

## 4. 執行階梯

營運者可依據行為的影響、意圖、重複性、涉及資料和緊急程度採取一項或多項措施，並記錄必要理由：

1. 提醒或要求停止相關行為；
2. 限制介面、並行請求、快取、事件上報或其他資源使用；
3. 暫停帳號、工作階段、憑證或網路來源；撤銷是否即時生效取決於執行個體的撤銷儲存、開關和請求是否成功；
4. 終止託管執行個體的存取，或阻止繼續使用受影響的端點；
5. 在適用法律要求、有效請求或保護他人和系統所必需的範圍內保存必要記錄並提供給有權接收者。

對於正在進行的攻擊、憑證盜用、嚴重安全威脅或明顯違法內容，可以先採取必要的臨時措施，再補充說明和複核。政策處置不替代行為人依法可能承擔的責任，也不承諾自動報警、固定保存期、24 小時人員回應或永久刪除所有相關記錄。

## 5. 申訴與檢舉

- **申訴**：對限制、暫停或終止有異議，可向 `admin@epocanvas.com` 說明帳號、時間、相關端點和理由。營運者會在資源允許的合理期限內複核；這不影響適用法律規定的期限、權利和救濟。不承諾固定時限、專職團隊或必然恢復存取。請不要傳送密碼、完整權杖或無關個人資料。
- **檢舉**：可向同一信箱通報疑似濫用、侵權、安全問題或對他人的傷害。請提供必要事實，不要轉寄違法或敏感材料；營運者會依風險、資料最小化和適用法律判斷是否採取措施或向有權機關揭露。

隱私權、刪除請求和資料外洩通知請使用 `privacy@epocanvas.com`。本政策只約束實際託管資源；自行部署執行個體應提供自己的營運者和申訴管道。
