## 1. 適用範圍

本政策適用於您以任何方式使用本服務之行為，包括：

1. 網頁播放器之全部功能（搜尋、播放、歌詞、推薦、下載、本機音樂匯入）；
2. 經開放 API 之串接，包括您自建之第三方用戶端與腳本；
3. 自行部署執行個體（自行部署營運者得修改本政策後適用，惟不得低於其所在地法律之要求）。

## 2. 禁止行為

### 2.1 系統與 API 濫用

1. 規避或破壞限流、簽章驗證、熔斷機制、SSRF 防禦、網域白名單或其他技術保護措施；
2. 偽造 API Key、重放已撤銷之金鑰識別碼（jti）、盜用他人工作階段或金鑰，或以任何方式繞過 fail-closed 驗證；
3. 以自動化腳本大量擷取本服務之檢索結果、歌詞或播放位址，用於與本服務功能無關之轉售、再散佈或建立鏡像資料集；
4. 偵測、掃描或以其他方式獲取本服務之內部拓撲、服務間金鑰、金鑰材料或非公開端點；
5. 利用本服務之代理端點（`/api/music/stream`、`/api/sonic/forward` 等）作為通用網路代理存取與音樂播放無關之目標。

### 2.2 內容與權利

1. 利用本服務提供之 API 破解、繞過或干擾任何音樂平台之付費與版權保護機制；
2. 散佈侵犯他人著作權、商標權、肖像權或人格權之內容；
3. 上傳或傳播違法內容，包括兒少性剝削素材、恐怖主義宣傳內容；
4. 冒用他人名義或機構識別從事活動，或利用 `epocanvas`、`Sonic` 名稱與識別暗示本服務背書之未經授權用途；
5. 上傳以本服務散佈之違法檔案至本機音樂匯入或下載功能。

### 2.3 他人權益

1. 干擾、破壞本服務或任何相關系統之正常運轉，包括對熔斷器與降級機制之蓄意觸發；
2. 對營運者、上游服務提供者或其他使用者實施騷擾、誹謗或攻擊；
3. 將本服務用於任何違反您所在地法律或上游服務條款之用途；
4. 出售、轉租或以商業轉售為目的提供本服務之存取權。

## 3. 資源使用上限

| 項目 | 上限 | 超限處置 |
| --- | --- | --- |
| 匿名請求 | 每分鐘 240 次（預設值） | 邊緣層直接拒絕（429），不記錄為違規 |
| 驗證請求 | 每分鐘 600 次（預設值） | 邊緣層直接拒絕（429），持續超限進入執行階梯 |
| 驗證端點（登入／金鑰簽發） | 每分鐘每 IP 30 次 | 邊緣層直接拒絕（429） |
| 行為事件上報 | 單批至多 50 筆、請求主體 64 KB | 超限請求整體拒絕 |
| 音訊串流 | 經邊緣代理，或經您主動請求之直連模式 | 異常並行請求進入執行階梯 |

正常個人使用不會觸及上述上限；限流之技術目的為防濫用與服務穩定，非屬處罰。限流參數為部署者可設定項目，自部署執行個體之實際值以其設定為準。

## 4. 執行階梯

營運者發現違規行為時，依情節輕重適用下列措施；每一級處置均記錄理由：

1. **告知**：於播放器內發出警告並說明理由；
2. **限流**：調降該帳號或金鑰之請求配額；
3. **暫停**：臨時封鎖該帳號之工作階段與 API Key（經 `jti` 撤銷清單或即時撤銷機制），資料暫時保留；
4. **終止**：終止使用權；行為資料於保存期限（90 日，下限 7 日）屆滿後銷毀；
5. **證據保存與依法移送**：法律要求時，於必要範圍內保存記錄並經法定程序向有權機關提供。

下列情形不適用分級程序，營運者得立即暫停並移送或檢舉：兒少性剝削素材、恐怖主義宣傳內容、進行中之系統攻擊。

## 5. 申訴與檢舉

- **申訴**：您認為處置有誤者，得致函 `admin@epocanvas.com` 申訴，說明處置所涉帳號與事由；營運者於合理期限內複核並答覆。緊急處置（第 4 節零容忍情形）之申訴同樣受理，複核期間不停止對您本人之誤判救濟。
- **檢舉**：任何人發現違反本政策之行為，得致函前述信箱檢舉；檢舉經核實前對被檢舉人保密。涉及兒少保護之檢舉不受保密承諾限制，依法定程序處理。

營運者依本政策所為之處置，不免除違規行為人依法應負之責任。
