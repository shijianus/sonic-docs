**生效日期：2026 年 11 月 2 日｜版本：1.5**

本頁說明 Sonic 帳戶體系之運作方式與安全使用建議。技術實現之完整說明見[資料處理與安全維護](/zh-tw/data-security/)第 3.2 節；契約約定見[使用者條款](/zh-tw/terms-of-service/)第 3 節。

## 1. 登入方式

本服務以 Epomail 帳號經 OAuth 2.0（PKCE）登入，不設獨立註冊系統。登入流程：點擊側欄帳號入口 → 跳轉 Epomail 授權頁確認 → 返回本服務即完成登入。授權回呼經 state、PKCE、授權碼與重放四重核驗；認證端點限每分鐘每 IP 30 次。

## 2. 工作階段機制

1. **工作階段 Cookie**：登入成功後簽發 `HttpOnly; Secure; SameSite=Lax` 之工作階段 Cookie，有效期至多 30 日；Cookie 內含簽章 API Key，腳本不可讀；
2. **跨分頁同步**：登入狀態在同一瀏覽器之各分頁間自動同步；在任一分頁登出，其餘分頁同步感知；
3. **金鑰邊界**：API Key 不寫入 URL、查詢參數或 localStorage；OAuth 事務 Cookie 有效期僅 600 秒。

## 3. API Key 保管

API Key 為您的個人憑證（格式 `sonic_live_v2.…`，HMAC-SHA256 簽章）：

1. 僅經請求標頭傳遞，永不置於 URL；
2. 不得轉交第三方或嵌入公開發布之用戶端；
3. 重新簽發須出示當前有效金鑰；外洩時立即登出並撤銷（見第 4 節）。

## 4. 撤銷與登出

| 操作 | 位置 | 效果 |
| --- | --- | --- |
| 登出 | 播放器內 | 即時撤銷當前工作階段與金鑰識別碼（jti） |
| 金鑰撤銷 | `POST /api/auth/revoke` | 撤銷當前 API Key |
| 批次作廢 | 部署者設定 | jti 清單、主體清單與全域簽發時間下限 |

## 5. 安全使用建議

1. 於共用裝置使用後務必登出（工作階段 Cookie 內含簽章金鑰）；
2. Epomail 帳號建議啟用兩步驟驗證（於 Epomail 端設定）；
3. 帳號不出借、不共用——共用帳號之資料混同無法區分與復原；
4. 發現異常播放記錄或來源不明之工作階段時，立即登出並致函 `admin@epocanvas.com`；
5. 本服務不蒐集密碼（登入由 Epomail 完成），任何「Sonic 密碼驗證」請求均屬冒名。

## 6. 帳號管理入口

側欄底部之帳號入口顯示當前登入狀態：未登入時提供登入引導；登入後顯示帳戶暱稱並提供帳號管理連結（指向 Epomail 之個人資料與收件匣）。登入狀態跨分頁自動同步。
