## 1. 登入方式

本服務使用 Epomail OAuth 2.0（PKCE），不設獨立註冊：帳號入口 → Epomail 授權 → 返回 Sonic。state、PKCE 與回呼檢查保護流程，驗證端點預設每分鐘每 IP 30 次。登入欄位不證明年齡，年滿 16 歲是使用門檻而非已驗證年齡；可能取得電子郵件地址及驗證標記，但核對程式碼不會因缺少 `email_verified` 標記而拒絕。OAuth 身分驗證不是可選輪廓分析同意，也不自動接受全部條款。

## 2. 工作階段機制

1. **工作階段 Cookie**：`sonic_session` 採 `HttpOnly; Secure; SameSite=Lax`，預設 30 日。其簽章憑證不是加密，可含電子郵件地址、使用者與角色識別碼；HttpOnly 限制腳本讀取 Cookie，不代表其他帳號資料不持久保存；
2. **跨分頁同步**：同一瀏覽器分頁共用登入狀態，不是跨裝置音樂庫備份，也不證明被複製憑證已撤銷；
3. **本機資料與金鑰**：API Key 不應置於 URL；前端 `auth` localStorage 保留電子郵件地址與頭像資訊，目前 DiceBear 頭像路徑可能傳送明文電子郵件 seed。OAuth 交易 Cookie 約 600 秒。

## 3. API Key 保管

API Key 為您的個人憑證（格式 `sonic_live_v2.…`，HMAC-SHA256 簽章）：

1. 僅經請求標頭傳遞，永不置於 URL；
2. 不得轉交第三方或嵌入公開發布之用戶端；
3. 重新簽發須出示目前有效金鑰；外洩時儘速登出並請求撤銷，核驗遠端結果而非假定成功（見第 4 節）。

## 4. 撤銷與登出

| 操作 | 位置 | 效果 |
| --- | --- | --- |
| 登出 | 播放器內 | 清理目前 Cookie；被複製憑證的遠端撤銷依賴設定與請求成功 |
| 金鑰撤銷 | `POST /api/auth/revoke` | 需要支援的撤銷儲存及請求成功，不保證每個執行個體可用 |
| 批次作廢 | 部署者設定 | 靜態 jti／主體清單與簽發時間下限須完成設定及驗證 |

## 5. 安全使用建議

1. 共用裝置使用後登出並清理瀏覽器帳號資料；被複製的憑證仍可能需要營運者協助撤銷，瀏覽器清理不刪除遠端輪廓；
2. Epomail 帳號建議啟用兩步驟驗證（於 Epomail 端設定）；
3. 帳號不出借、不共用——共用帳號之資料混同無法區分與復原；
4. 發現異常播放記錄或來源不明之工作階段時，立即登出並致函 `admin@epocanvas.com`；
5. 本服務不蒐集密碼（登入由 Epomail 完成），任何「Sonic 密碼驗證」請求均屬冒名。

## 6. 帳號管理入口

側欄底部之帳號入口顯示當前登入狀態：未登入時提供登入引導；登入後顯示帳戶暱稱並提供帳號管理連結（指向 Epomail 之個人資料與收件匣）。登入狀態跨分頁自動同步。
