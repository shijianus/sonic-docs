**生效日期：2026 年 11 月 2 日｜版本：1.5**

本頁彙整您在 Sonic 的主要資料：存於何處、目前可查詢什麼、如何清除，以及哪些資料沒有產品內建的下載匯出功能。法律依據與權利框架見[隱私權政策](/zh-tw/privacy-policy/)第 4、6、9 節；技術措施見[資料處理與安全維護](/zh-tw/data-security/)。

## 1. 資料位置總覽

| 資料 | 位置 | 關聯身分 | 保存期限 |
| --- | --- | --- | --- |
| 收藏、歌單、偏好 | 瀏覽器 localStorage | 不上傳 | 至清除為止 |
| 播放歷史 | 瀏覽器 localStorage | 不上傳 | 至清除為止 |
| 下載與本機音樂 | 瀏覽器 IndexedDB | 不上傳 | 至清除為止 |
| 行為事件 | 伺服器端 SQLite（資料面） | 假名化雜湊 | 90 日自動銷毀 |
| 全域聚合統計 | 伺服器端 SQLite | 不關聯個人 | 隨資料庫維護 |
| 搜尋歷史（本機） | 瀏覽器 localStorage | 不上傳 | 至清除為止 |

帳戶識別資料（例如電子郵件）不落盤儲存，僅存於工作階段期間；資料庫沒有 IP 欄位。收藏、歌單與偏好只保留在目前瀏覽器，不提供跨裝置雲端同步。

## 2. 查詢：推薦輪廓摘要

透過 `GET /api/sonic/events`（或設定頁的輪廓區塊）可查詢伺服器端目前輪廓的**摘要**：事件總數、喜愛與拒絕計數、常聽歌手、流派傾向、最近搜尋詞與儲存形式。摘要不是完整個人資料匯出，也不等同於所有事件原始內容的副本；目前沒有可由使用者下載完整服務端事件的產品通道。

## 3. 匯出與備份

1. **瀏覽器資料**：收藏、歌單、偏好、下載與本機音樂只存在您的瀏覽器。本服務未提供通用的 localStorage 或 IndexedDB 匯出工具，也未內建雲端備份或跨裝置匯入；請依需求自行記錄重要歌單、保留原始本機音樂檔案，或使用瀏覽器／作業系統實際提供且您信任的備份能力；
2. **行為事件**：伺服器端僅保存假名化行為事件，目前沒有可供使用者下載的匯出通道。您可以使用第 4 節的清除功能，或透過第 5 節的人工請求管道提出權利要求；
3. **推薦輪廓摘要**：設定頁或 API 可查詢摘要，但摘要不是完整匯出，不能用來宣稱已取得全部個人資料；
4. **本機音樂**：匯入的原始檔案仍在您的裝置上，刪除瀏覽器內副本不會影響原始檔案。

## 4. 清除操作

| 操作 | 範圍 | 生效 |
| --- | --- | --- |
| 重置推薦輪廓與不感興趣記錄 | 伺服器端全部行為事件 | 即時（`DELETE /api/sonic/events`） |
| 清除全部本機資料 | 瀏覽器 localStorage、sessionStorage、IndexedDB + 伺服器端輪廓 | 確認後即時 |
| 瀏覽器清除網站資料 | 同上（瀏覽器端） | 即時 |
| 登出 | 工作階段與金鑰 | 即時 |

## 5. 人工權利請求與自行部署執行個體

若要行使查詢、更正、刪除、限制處理、可攜或反對等權利，或需要釐清摘要與服務端資料的範圍，請致函 `privacy@epocanvas.com`。營運者會依[隱私權政策](/zh-tw/privacy-policy/)第 9 節處理；本頁不把現有摘要查詢或清除功能擴張解釋為完整資料下載。

自行部署執行個體的資料存於部署者的資料面（SQLite 具名磁碟區）；部署者可設定保存天數與落盤路徑（見[部署指南](/zh-tw/deployment/)第 3 節），其備份與告知義務另見[開源與自行部署法律](/zh-tw/open-source/)第 4 節。
