**修訂日期：2026 年 11 月 2 日｜版本：1.8**

本頁功能說明依據公開候選版本（RC）`rc/sonic-20261031@a75f5cb`（2026-11-01 UTC），核對日期為 2026-11-02。較早的公開 `main@ce443c8`（2026-10-27 UTC）不能作為其已具備這些 RC 功能的依據。候選版本不是正式 GitHub Release；線上部署版本與設定仍未核實。

本頁彙整您在 Sonic 的主要資料：存於何處、目前可查詢什麼、如何清除，以及哪些資料沒有產品內建的下載匯出功能。法律依據與權利框架見[隱私權政策](/zh-tw/privacy-policy/)第 4、6、9 節；技術措施見[資料處理與安全維護](/zh-tw/data-security/)。

## 1. 資料位置總覽

| 資料 | 位置 | 關聯身分 | 保存期限 |
| --- | --- | --- | --- |
| 收藏、歌單、偏好 | 主要在瀏覽器 localStorage；雷達另有遠端路徑 | 部分回饋與推薦上下文可能傳送 | 本機副本至清除；遠端另行處理 |
| 播放歷史 | 瀏覽器 localStorage 及另外上報的播放事件 | 事件可能使用可關聯假名識別碼 | 本機清理不刪除遠端事件 |
| 下載與本機音樂 | 瀏覽器 IndexedDB | 未發現本機音訊檔案主體的上傳路徑；標題、藝人、專輯、識別碼及內嵌封面可能傳送 | 至清除或瀏覽器回收；遠端資料另行處理 |
| 行為事件與實體回饋 | 若實際啟用，可能位於伺服器端資料庫或外部服務 | 假名識別碼，不等於匿名 | RC 預設 90 日、下限 7 日；清理不完整且非逐筆到期銷毀，不得承諾全面自動刪除 |
| 搜尋聚合與雷達輪廓 | 遠端搜尋儲存，雷達耐久引擎儲存未確認 | 搜尋原文可能識別個人並公開顯示 | 無經核驗的統一自動期限，重置未完整涵蓋 |
| 共享曲目目錄與可選外部索引 | 伺服器曲目庫及可選推薦／檢索系統 | 使用者事件可帶標題、藝人和內嵌封面；可供全站檢索 | 未隨個人輪廓重置完整清理，按可關聯性處理 |
| 搜尋歷史（本機） | 瀏覽器 localStorage | 查詢也傳送供搜尋，並可能進入統計／上下文 | 本機清理不移除遠端副本 |

電子郵件地址與頭像資訊保留於瀏覽器 `auth`，簽章憑證不是加密。原始 IP 鍵可進入 KV 或限流器，用戶端位址、工作階段及上下文可轉送引擎；表格沒有 IP 欄位不證明沒有 IP 處理。不保證通用跨裝置雲端備份。

## 2. 查詢：推薦輪廓摘要

最新公開 RC 提供 `GET /api/sonic/events`（或設定頁的輪廓區塊）用於查詢伺服器端輪廓摘要；較早的 `main@ce443c8` 僅作相容性對照，不能證明 RC 已部署。即使執行個體提供摘要，它也不是完整個人資料副本或可攜匯出；不得向使用者承諾完整服務端事件下載。

## 3. 匯出與備份

1. **瀏覽器資料**：收藏、歌單、偏好、下載與本機音樂主要保存在您的瀏覽器；部分回饋、中繼資料和上下文另行傳送。本服務未提供通用的 localStorage 或 IndexedDB 匯出工具，也未內建雲端備份或跨裝置匯入；請依需求自行記錄重要歌單、保留原始本機音樂檔案，或使用瀏覽器／作業系統實際提供且您信任的備份能力；
2. **遠端資料**：遠端處理可能涉及事件、實體回饋、搜尋資料與雷達同步路徑，不僅是曲目事件；雷達耐久引擎儲存未確認。摘要不是完整匯出，重置也僅屬部分刪除；完整副本或較完整刪除請透過第 5 節管道請求，必要時涵蓋較早身分；
3. **推薦輪廓摘要**：只有在功能啟用且執行個體提供設定頁或 API 時才可能查詢摘要；線上可用性未核實。摘要不是完整匯出，不能用來宣稱已取得全部個人資料；
4. **本機音樂**：匯入的原始檔案仍在您的裝置上，刪除瀏覽器內副本不會影響原始檔案。

## 4. 清除操作

| 操作 | 範圍 | 生效 |
| --- | --- | --- |
| 重置推薦輪廓與不感興趣記錄 | 目前身分的部分事件與回饋，可能遺漏舊識別碼、雷達、聚合、外部服務及備份 | RC 路由為 `DELETE /api/sonic/events`；失敗可能未顯示，成功不證明完整刪除 |
| 清除全部本機資料 | 請求瀏覽器儲存清理及可能的部分遠端重置；不應假定會清除 Cookie、URL 憑證或登出 | 須分別核對結果；清空設定後重載可能恢復預設狀態，應重查選擇 |
| 瀏覽器清除網站資料 | 僅瀏覽器端資料 | 依瀏覽器控制執行，不刪除遠端資料 |
| 登出 | 清理目前 Cookie，被複製的憑證須伺服器撤銷 | 遠端效果依賴撤銷儲存設定與請求成功 |

## 5. 人工權利請求與自行部署執行個體

自行部署執行個體的使用者，應透過實際營運者公布的聯絡管道聯絡該營運者；本文提出的 Sonic 信箱不是所有獨立控制者的管道。託管執行個體使用者如要行使查詢、更正、刪除、限制處理、可攜、反對或撤回同意等權利，請依[隱私權政策](/zh-tw/privacy-policy/)第 9 節提出請求。本頁不把現有摘要查詢或清除功能擴張解釋為完整資料下載。

自行部署者須盤點實際全部儲存與接收者，不僅是 SQLite 磁碟區。保存設定本身不涵蓋雷達、搜尋資料、日誌與備份；應落實必要期限及經驗證的刪除、隔離備份至到期清理，並在還原後重新套用刪除記錄。見[部署指南](/zh-tw/deployment/)第 3 節與[開源與自行部署法律](/zh-tw/open-source/)第 4 節。
