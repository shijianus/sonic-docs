本頁說明 Sonic 服務（下稱「本服務」）之資料生命週期、各項處理活動之性質、安全維護措施、已知侷限與資料外洩應變程序。本頁是[隱私權政策](/zh-tw/privacy-policy/)第 10 節之展開；技術事實以開源程式碼之實際實現為準，可經原始碼稽核複核。本站法律文件以簡體中文版本為正式版本，本繁體中文版本為對照譯本。

## 1. 資料生命週期

| 階段 | 說明 |
| --- | --- |
| 蒐集 | 經 Epomail OAuth 登入取得帳戶識別資料（不落盤）；經播放器批次上報行為事件（可關閉，單批至多 50 筆、64 KB）；匿名限流暫用 IP |
| 傳輸 | 全程 HTTPS/TLS；控制面與資料面之間經 Cloudflare Tunnel 加密通道，並以服務間金鑰（X-Sonic-Engine-Key）強制驗證；邊緣至引擎之用戶端位址標頭僅於引擎側驗證服務金鑰後方被接受 |
| 儲存 | 資料面 SQLite（WAL 模式），落於具名磁碟區 `sonic-data` 之 `/app/data/sonic-recommend.sqlite`；生產環境開啟失敗時拒絕服務（fail-closed），不靜默降級 |
| 利用 | 假名化識別碼關聯之統計計算（推薦、熱度、相似度）；不為人工資料審核，不作內容審查，不作自動化決策 |
| 共享 | 見[第三方共享與傳輸清單](/zh-tw/sub-processors/)；不出售、不為廣告利用 |
| 刪除 | 行為事件 90 日自動銷毀（按每 1500 次寫入與啟動時點觸發清理）；一鍵清空即時刪除；限流記錄 120 秒過期 |

## 3. 安全維護措施

### 3.1 傳輸與接入

1. **全程加密**：瀏覽器至邊緣、邊緣至資料面均經 TLS；資料面經 Cloudflare Tunnel 加密通道接入，不直接對外公開連接埠，宿主側僅映射 `127.0.0.1:8080`；
2. **服務間驗證**：資料面對全部 `/api`、`/proxy`、`/palette` 路由強制驗證 X-Sonic-Engine-Key；引擎側剝除不可信入站標頭並以通訊端位址重建用戶端位址標頭，偽造一律失效；
3. **降級即明示**：邊緣降級模式下回應標頭標明 `X-Sonic-Degraded: 1`，介面同步顯示降級提示，不靜默切換。

### 3.2 驗證與金鑰

1. **OAuth 流程**：`state` 參數與 PKCE（S256）防授權碼攔截與重放；事務 Cookie 有效期 600 秒且限 `/api/auth` 路徑；回呼時核驗 state、PKCE、授權碼與重放，任何一環缺失或異常一律拒絕；
2. **API Key**：`sonic_live_v2` 版本化格式，HMAC-SHA256 簽章，伺服器端以 Web Crypto `crypto.subtle.verify` 常數時間比對；嚴格檢查版本、`kid`、`iat`／`exp` 與 `jti`；無簽章金鑰與舊版 v1 金鑰一律拒絕（fail-closed）；簽發有效期 30 日、驗證上限 90 日；金鑰僅經請求標頭傳遞，`?api_key=` 查詢參數通道已完全移除，避免金鑰洩漏至存取日誌、瀏覽器歷史或 Referer；
3. **撤銷機制**：登出即時撤銷當前工作階段；`jti` 撤銷清單、主體撤銷清單與全域簽發時間下限（`SONIC_REVOKED_JTIS`／`SONIC_REVOKED_SUBS`／`SONIC_TOKEN_MIN_IAT`）支援批次作廢；繫結 KV 並開啟 `SONIC_ENABLE_KEY_REVOCATION=1` 時支援即時撤銷；未設定即時撤銷時相關端點返回 501 並提示改用清單方式，不假裝撤銷成功；
4. **工作階段屬性**：`HttpOnly; Secure; SameSite=Lax`，有效期至多 30 日；登入回呼重新導向僅攜帶 `?auth=success` 狀態參數，不回傳金鑰。

### 3.3 對外請求防禦

1. **SSRF 攔截**：回環位址、RFC 1918 私有網路、Docker 內部網橋與雲端中繼資料位址（如 `169.254.169.254`）之對外請求一律阻斷，IPv4 與 IPv6 雙堆疊驗證，每次重新導向重新驗證目標與 DNS 解析結果；
2. **網域白名單**：音訊、封面與轉發代理僅允許受控音樂 CDN 網域清單（`SONIC_ALLOWED_MUSIC_DOMAINS`）內之 HTTPS 目標與標準連接埠；
3. **請求淨化**：上游請求剝離 `Set-Cookie` 與憑證標頭，僅攜帶固定 User-Agent、對應官網 Referer 與必要之 Range 標頭；出口 IP 標示為部署者設定之佔位位址（預設 RFC 5737 文件位址），非任何使用者之 IP。

### 3.4 儲存與日誌

1. **假名化儲存**：行為事件以單向雜湊識別碼（`usr_`／`anon_` 前綴之 SHA-256 截斷值）關聯，無明文電子郵件欄位、無 IP 欄位；儲存共 6 張資料表（曲目規範資料、平台曲目映射、全文索引、行為事件、曲目共現、搜尋詞聚合），其中與個人關聯者僅行為事件表；
2. **fail-closed 儲存**：生產環境資料庫開啟失敗時拒絕服務而非靜默降級；記憶體備援僅限開發測試或明確設定 `SONIC_RECOMMEND_ALLOW_MEMORY_FALLBACK=1`；
3. **日誌最小化**：資料面存取日誌為逐行 JSON，僅含請求識別碼、方法、路徑、狀態碼與耗時；查詢字串、IP、User-Agent、Cookie、Authorization 與請求主體一律不記錄；未處理例外僅記錄請求識別碼、錯誤名稱與截斷訊息；日誌歸 Docker 標準輸出，輪替策略隨宿主 Docker 設定；Cloudflare Pages 側無本專案自建之全域存取日誌；
4. **備份**：資料庫備份以一致性快照（VACUUM INTO）配合完整性檢查執行；備份檔案含假名化行為資料，應與生產資料同等級保護；
5. **容器隔離**：資料面運行於 Docker 容器堆疊，ncm-api 輔助容器僅於 compose 內部網路可達（`ncm-api:3000`），不對外公開；`.env` 設定檔權限要求 600。

### 3.5 已知侷限

本服務為開源專案，營運者公開下列已知侷限，持續改善：

1. 未繫結 Cloudflare 原生限流器之部署形態下，限流以 KV 或程序記憶體計數，非嚴格全域精確；
2. DNS rebinding 防護未完全消除，部署者應配套網路層措施；
3. `sonic_session` Cookie 內含簽章 API Key，Cookie 遭竊等同於金鑰遭竊，應配合裝置安全與及時登出；
4. SQLite 為單寫入者架構，不適合高並行寫入之部署形態；
5. 無內建 Prometheus 指標端點，監控需依賴日誌與外部探活。

上述侷限之完整清單見上游儲存庫 `docs/OPERATIONS.md`；自行部署營運者應依其部署形態評估。

## 4. 資料外洩應變

1. **內部記錄**：全部個人資料外洩事件均予記錄（GDPR 第 33 條第 5 項），不因評估為低風險而免於記錄；
2. **通報監督機關**：外洩可能致當事人風險時，於知悉後 72 小時內向營運者所在地之主管監督機關通報，說明外洩性質、涉及資料類別與數量、可能後果與已採取之措施（GDPR 第 33 條第 1 項、第 3 項）；
3. **通知當事人**：外洩可能致當事人高風險時，以站內公告或其他有效方式無不當遲延地通知受影響之當事人，說明外洩性質與建議措施（GDPR 第 34 條）；風險已有效消除致高風險不復存在者，得免於通知，惟決定理由應記錄；
4. **應變措施**：即時隔離受影響系統、撤銷受影響金鑰與工作階段（含 `jti` 清單與全域簽發時間下限）、評估並修復成因、記錄處置全過程。

## 5. 資料保護之設計與預設

本服務於設計階段落實下列措施（GDPR 第 25 條）：

1. **假名化為預設**：行為事件自蒐集之始即以雜湊識別碼關聯，電子郵件地址不落盤，資料庫無 IP 欄位；
2. **零蒐集模式**：個人化關閉時事件不入庫，公開模式於伺服器端直接丟棄，回執中如實標示忽略數量；
3. **最小用戶端資料**：推薦上下文僅攜帶限條數之收藏、最近藝人與搜尋詞，記憶體使用不落盤；播放器不讀寫 `document.cookie`，金鑰不進 localStorage；
4. **預設關閉之高風險鏈路**：第三方聚合上游（GDStudio、Lyriva）與解灰鏈路預設嚴格關閉，需部署者明確開啟（環境變數置 1）方生效；
5. **一鍵清空**：刪除權以自助功能直接落實，無需人工請求；「清除全部本機資料」同時清理伺服器端輪廓、localStorage、sessionStorage 與 IndexedDB。

## 6. 自行部署營運者之義務

您自行部署本服務之時點起，即為您使用者之資料控制者，應履行下列義務：

1. **告知義務**：向您的使用者告知資料處理事項（可以本站[隱私權政策](/zh-tw/privacy-policy/)為基礎文本）；
2. **處理活動記錄**：維持處理活動記錄（GDPR 第 30 條）；
3. **影響評估**：處理可能致高風險時實施資料保護影響評估（GDPR 第 35 條），評估範圍至少包括：匿名裝置識別碼、行為事件、限流 IP 之暫時使用、OAuth 電子郵件之雜湊衍生；
4. **設定核對**：確認下列參數與您的政策承諾一致——行為事件保留天數（`SONIC_RECOMMEND_RETENTION_DAYS`，預設 90、下限 7）、落盤路徑（`SONIC_RECOMMEND_DB_PATH`，設為 `memory` 關閉落盤）、記憶體備援開關（`SONIC_RECOMMEND_ALLOW_MEMORY_FALLBACK`）、第三方鏈路開關（`SONIC_ENABLE_GDSTUDIO` 等）、限流參數（`SONIC_RATE_LIMIT_ANON_RPM`／`SONIC_RATE_LIMIT_AUTH_RPM`）；
5. **安全維護與受監督**：依第 3 節之措施設定（含服務金鑰強度不低於 32 字元、`.env` 權限 600、資料面不對外公開），並依您所在地法律接受主管機關之檢查與監督。
