本頁導覽 Sonic 網頁播放器之介面版面配置與功能位置，說明每項功能之所在與行為。文中截圖取自託管執行個體實際運行畫面（介面語言為簡體中文，產品支援介面語言切換）。介面隨版本演進可能調整，功能之實際可用範圍以執行個體所開啟者為準。本站法律文件以簡體中文版本為正式版本，本繁體中文版本為對照譯本。法律約定見[使用者條款](/zh-tw/terms-of-service/)與[隱私權政策](/zh-tw/privacy-policy/)。

![Sonic 播放器首頁：左側導覽列（探索、我的音樂、系統三區），主區為輪播推薦、智慧推薦與音樂雷達、推薦歌單，底部為迷你播放列](/images/sonic/ui/ui-home.png)

*圖：桌面版首頁。左側邊欄分為「探索」（首頁、MV、排行榜、歌手、新碟上架、搜尋）與「我的音樂」（我喜歡的、最近播放、下載清單、本機音樂）兩區；主區自上而下為輪播推薦位、智慧推薦與音樂雷達、推薦歌單；底部常駐迷你播放列。*

## 1. 首頁與智慧推薦

首頁聚合三個內容區：

1. **輪播推薦位**：顯示新歌與新碟，卡片標有「sonic 新歌」等來源標示，點擊直接進入播放或詳情；
2. **智慧推薦與音樂雷達**：提供「猜你喜歡」「站內趨勢熱榜」「風格探索雷達」三個視圖，附「換一批」與「播放推薦清單」操作。推薦卡片標註推薦理由（如「個人化推薦」徽章與「常聽某歌手」「與你偏愛的曲風相近」等說明），行動裝置首頁並顯示當前工作階段之偏好訊號標籤（如歌手、流派）；推薦依據之訊號類別見[隱私權政策](/zh-tw/privacy-policy/)第 4.2 節；
3. **推薦歌單與熱門單曲**：按全站真實聽歌趨勢生成，播放量標註於卡片。

推薦之排序僅影響您看到的播放序列；您可於設定中關閉個人化（見第 7 節），關閉後推薦切換為純公開模式。

## 2. 搜尋

![Sonic 搜尋結果頁：搜尋「周杰倫」共 52 條結果，單曲、歌單、MV 三類分頁，附播放全部按鈕，結果清單含封面、歌手、專輯、時長與操作欄](/images/sonic/ui/ui-search.png)

*圖：搜尋結果頁。頂部為分類頁籤（單曲／歌單／MV）與「播放全部」；清單列呈現封面、歌曲、歌手、專輯、時長與操作（播放、MV、喜愛、下載）。搜尋框支援簡繁歸一、拼音縮寫與拼字容錯。*

搜尋入口位於左側邊欄頂部與搜尋頁，支援歌曲、歌手、專輯與歌單關鍵詞。多源結果經以正規表示式去重合併後按相關性排序；命中試聽片段之曲目按[音質與試聽標示](/zh-tw/project/#4-音源與歌詞鏈路)如實標示，絕不以試聽冒充全曲。

## 3. 排行榜與官方榜單

![Sonic 排行榜頁：新歌速遞與官方榜單兩頁籤，全部、華語、歐美、日本、韓國五類分榜，榜單清單含名次、封面、歌曲、歌手、專輯與時長](/images/sonic/ui/ui-charts.png)

*圖：排行榜頁。左側為榜單選擇器（新歌速遞／官方榜單，及其下全部／華語／歐美／日本／韓國分類），右側為榜單清單與「播放全部」。榜單資料來自上游官方榜單與站內真實聽歌趨勢。*

首頁之「站內趨勢熱榜」與排行榜頁共用同一熱度模型：有效播放、獨立聽眾、完播表現、收藏轉化與成長斜率五因子加權，輔以指數時間衰減與貝氏平滑（模型說明見[專案介紹](/zh-tw/project/)第 5 節）。

## 4. 歌手與專輯庫

![Sonic 歌手庫頁：類型（全部、男歌手、女歌手、樂團）與地區（華語、歐美、日本、韓國、其他）雙維篩選，首字母 A–Z 與熱門檢索，歌手卡片顯示專輯數量](/images/sonic/ui/ui-artists.png)

*圖：歌手庫頁。以類型、地區、首字母三維篩選歌手；卡片顯示歌手頭像、名稱與專輯數量。進入歌手頁可瀏覽其熱門歌曲與專輯清單，專輯頁進一步列出曲目。*

歌手、專輯與歌曲詳情頁共用統一的封面代理與色溫分析（封面主色隨頁面漸層變化）；全部清單資料自上游官方開放 API 取得，經快取與去重後呈現。

## 5. 播放控制（底部播放列）

![Sonic 底部播放列：播放「晴天」時顯示歌詞預覽行、上一首、播放、下一首、播放模式、音質選單（SQ 無損）、下載與音量控制](/images/sonic/ui/ui-player.png)

*圖：底部播放列於播放中狀態。左為封面與當前曲目資訊及歌詞預覽行；中為播放控制與播放模式切換；右為音質選單（當前徽章「SQ 無損」）、下載、音量滑桿與播放清單入口。點擊封面區域展開全螢幕播放器抽屜。*

底部播放列常駐於所有頁面，提供：

1. **音質選單**：按當前音源實際可用檔位列出（如 SQ 無損、HQ 高品、標準），徽章如實反映當前串流之音質，不虛標；
2. **歌詞預覽行**：顯示當前逐字歌詞之進度句；
3. **播放模式**：清單循環、單曲循環、隨機等模式切換；
4. **下載**：將當前曲目存入瀏覽器（IndexedDB），詳見第 5 節。

## 6. 播放器抽屜與逐字歌詞

![Sonic 全螢幕播放器抽屜：左側為黑膠唱片封面動畫與曲目資訊，右側為捲動歌詞面板，背景隨封面色調漸層變化，右上角為背景與視覺化模式切換](/images/sonic/ui/ui-player-drawer.png)

*圖：全螢幕播放器抽屜。左側為封面展示（黑膠唱片動畫）與播放控制；右側為逐字歌詞捲動面板；背景隨封面主色調即時漸層變化。抽屜於點擊底部播放列封面後展開。*

播放器抽屜提供：

1. **逐字歌詞**：優先呈現 YRC／QRC／KRC 字級時間軸，輔以 AMLL TTML 與 LRCLIB；歌詞面板支援「原文」「譯文」「羅馬音」三路獨立開關（設定中亦可控），點擊歌詞行跳轉播放位置；
2. **封面模式**：黑膠唱片與圓形頻譜等封面動畫模式；
3. **音訊視覺化**：柱狀圖、波形圖、圓形圖等頻譜視覺化模式，作用於抽屜背景或底部播放器（於設定中配置）；
4. **拖曳跳轉**：進度條支援拖曳，歌詞隨播放位置同步捲動。

## 7. 我的音樂

「我的音樂」區包含四項：

| 頁面 | 內容 | 儲存位置 |
| --- | --- | --- |
| 我喜歡的 | 喜愛歌曲與收藏歌單、專輯、歌手、MV | 瀏覽器 localStorage（`library`） |
| 最近播放 | 播放歷史 | 瀏覽器 localStorage（`audio`） |
| 下載清單 | 已下載之離線曲目（含音質中繼資料） | 瀏覽器 IndexedDB（`downloaded_music`） |
| 本機音樂 | 手動匯入之本機音訊檔案（支援拖放上傳至瀏覽器） | 瀏覽器 IndexedDB（`local_music`） |

上述內容均僅儲存於您的瀏覽器，不上傳至伺服器；清除瀏覽器資料或使用「清除全部本機資料」即行刪除。下載與本機匯入之檔案僅供您個人聆聽，不得再散佈（見[可接受使用政策](/zh-tw/acceptable-use/)）。

## 8. 設定

![Sonic 設定頁：主題模式（跟隨系統）、介面語言（中文）、背景類型、音質、底部播放器歌詞、音訊視覺化等設定卡片](/images/sonic/ui/ui-settings.png)

*圖：設定頁以卡片組織全部偏好項目。每張卡片對應一類設定：主題模式（淺色／深色／跟隨系統）、介面語言（中文／English／日本語）、背景類型、音質偏好、底部播放器歌詞顯示、音訊視覺化模式等。*

設定項即時生效並儲存於瀏覽器本機儲存（`settings`、`global` 等鍵），不與帳號綁定、不上傳伺服器。

## 9. 隱私與資料控制

![Sonic 設定頁之隱私與本機資料區塊：瀏覽器本機儲存與 IndexedDB 說明、智慧搜尋與個人化推薦開關、自動連續電台（Auto DJ）開關、重置推薦輪廓與不感興趣記錄按鈕](/images/sonic/ui/ui-privacy.png)

*圖：設定頁「隱私與本機資料」區塊。區塊說明「以下資料只儲存在你的瀏覽器中，不會上傳到伺服器」；「智慧搜尋與個人化推薦」開關描述關閉後立即切換為純公開模式且不再記錄任何行為事件；「重置推薦輪廓與不感興趣記錄」按鈕即時清除伺服器端行為資料。*

本區塊是[隱私權政策](/zh-tw/privacy-policy/)第 9 節所述自助權利之介面落實：

1. **智慧搜尋與個人化推薦開關**：關閉後事件不再蒐集，推薦進入純公開模式；
2. **自動連續電台（Auto DJ）開關**：控制播放清單播完後的自動續接；
3. **重置推薦輪廓與不感興趣記錄**：即時銷毀伺服器端與您關聯之全部行為事件（`DELETE /api/sonic/events`）；
4. **清除全部本機資料**：經確認對話框後清除瀏覽器本機儲存與 IndexedDB 全部內容，並同步重置伺服器端輪廓。

*圖：行動裝置版面配置。卡片標註個人化推薦理由與「常聽」「與你偏愛的曲風相近」說明；偏好訊號以標籤呈現；底部為頁籤導覽與迷你播放列。行動裝置播放器抽屜（PlayerDrawerMobile）提供同等的逐字歌詞與音質選單。*

行動裝置版與桌面版共用同一帳號體系與資料儲存規則；推薦理由之展示遵循與桌面版相同的透明原則。
