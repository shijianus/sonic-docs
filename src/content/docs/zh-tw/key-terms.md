## 1. 法律名詞

| 用語 | 定義 |
| --- | --- |
| 個人資料 | 與已識別或可識別自然人有關的任何資訊（GDPR 第 4 條第 1 項）。IP、Cookie、搜尋詞、頭像 URL、留言中的姓名或文字，以及可關聯的假名識別碼，均可能屬於個人資料。 |
| 處理 | 對個人資料進行的任何操作，包括蒐集、記錄、儲存、查詢、利用、傳輸、公開、限制或刪除（GDPR 第 4 條第 2 項）。 |
| 處理限制 | 在特定情形下暫停資料的利用，同時保留資料（GDPR 第 18 條）。 |
| 使用者輪廓分析 | 對個人特徵或行為進行自動化分析或評估。播放、搜尋、跳過、收藏、拒絕和上下文可能用於推薦；輪廓分析不等於具有法律或類似重大影響的決定。 |
| 假名化 | 不使用額外資訊就不能直接歸屬於某人的處理方式（GDPR 第 4 條第 5 項）。假名化資料仍可能被結合識別，不等於匿名化。 |
| 資料控制者 | 單獨或共同決定處理目的和方式的自然人或法人（GDPR 第 4 條第 7 項）。託管執行個體依實際決定處理目的和方式的人或組織判斷；程式碼作者、貢獻者和營運者不必是同一主體。 |
| 受託處理者 | 代表控制者處理個人資料的自然人或法人（GDPR 第 4 條第 8 項）。是否屬於該角色要看實際目的、指示和安排；Cloudflare、Epomail 或其他供應商不因名稱自動成為受託處理者。 |
| 接收者 | 向其揭露個人資料的自然人或法人（GDPR 第 4 條第 9 項）。瀏覽器直連收到 IP 的服務也可能是接收者。 |
| 第三方 | 不是當事人、控制者、受託處理者或經控制者授權處理人員的主體（GDPR 第 4 條第 10 項）。 |
| 同意 | 自由、特定、知情且明確的肯定表示（GDPR 第 4 條第 11 項、第 7 條），可隨時以不難於給予時的方式撤回。登入、繼續使用或預設開啟不構成可選輪廓分析同意；不能以缺少同意記錄為由拒絕停止無依據的處理。 |
| 資料外洩 | 導致個人資料意外或非法破壞、遺失、改變、未經授權揭露或存取的安全事件（GDPR 第 4 條第 12 項）。 |
| 主管監督機關 | 依法監督資料保護義務的公權力機關。適用 GDPR 時，當事人可向有管轄權的機關申訴（GDPR 第 77 條）。 |
| 國際傳輸 | 向歐盟或歐洲經濟區以外第三國或國際組織傳輸個人資料；須按實際地點、主體和保障判斷，不以伺服器名稱推定。 |
| 特殊類別資料 | 揭示種族或民族、政治觀點、宗教或哲學信仰、工會成員、遺傳資料，或用於唯一識別自然人的生物識別資料、健康、性生活或性傾向等資料（GDPR 第 9 條）。音樂偏好和搜尋詞也可能間接揭示敏感特徵，不能一概當作無風險。 |
| 當事人 | 被處理的已識別或可識別自然人；本頁用「您」指稱提出請求或使用服務的相關自然人。 |

## 2. 技術與產品名詞

| 用語 | 定義 |
| --- | --- |
| 託管執行個體 | 專案營運者實際提供存取的 Sonic 部署；適用範圍、控制者、設定和聯絡方式見[隱私權政策](/zh-tw/privacy-policy/)。 |
| 自行部署 | 由其他人執行的獨立執行個體。部署者獨立評估控制者身分、法律、設定和告知；本專案不因提供 MIT 程式碼而成為其營運者。 |
| 控制面 | 處理網頁、路由、快取、限流或邊緣 API 的部署元件；可能接觸 IP、Cookie、驗證標頭、User-Agent、路徑和上下文。 |
| 資料面 | 執行引擎、推薦計算、資料庫和相關服務的元件。目前稽核發現原始 IP 可能隨 Cookie、驗證標頭或上下文轉送到引擎，不能稱其為只收假名資料。 |
| Epomail OAuth | 透過 Epomail 進行的 OAuth 2.0 登入流程，使用 PKCE；可能回傳使用者識別碼、電子郵件地址及其驗證標記、暱稱、頭像 URL 和角色。 |
| API Key / `jti` | 帶簽章和期限的 API 憑證及其唯一識別碼。簽章驗證不是加密；Cookie、憑證複製和撤銷儲存應分別評估。 |
| fail-closed | 校驗或必要儲存失敗時拒絕請求，而不是靜默降級；是否在實際環境成立須核對設定。 |
| SSRF 防禦與網域白名單 | 對特定內網、回環、雲端中繼資料位址、重新導向或允許網域的對外檢查；不涵蓋瀏覽器直連和所有上游 HTTP。 |
| SQLite / WAL | 可作為資料面持久化儲存的 SQLite 資料庫及其預寫式日誌模式；不代表輪廓、日誌、備份或雷達資料均在同一資料庫或同一期限刪除。 |
| 熔斷器 | 在連續失敗或逾時後暫時改變請求路徑的機制；門檻、降級和是否啟用由實際版本與設定決定。 |
| 行為事件 | 播放、進度、跳過、收藏、拒絕、搜尋或實體回饋等可能用於推薦的訊號。單批限制、雜訊過濾和保存方式依版本與設定。 |
| 公開搜尋建議 | 將歷史或統計搜尋詞提供給其他訪客的功能路徑。目前存在再利用原始搜尋詞的風險，不能僅稱為匿名聚合。 |
| 雷達 | 根據使用者資料或行為產生的探索、推薦或同步功能及其狀態。目前未確認持久化引擎路徑；存在同步或隔離儲存嘗試，不能承諾有或沒有耐久資料庫記錄。 |
| 本機音樂 | 使用者裝置上的檔案或 Blob。未發現把本機音訊 Blob 上傳至伺服器端的路徑；歌詞查詢和推薦上下文仍可能傳送標題、藝人、專輯、時長或識別碼。 |
| 本機留言 | 目前寫入 localStorage 的留言草稿或內容；這不等於已經發布到留言伺服器。讀取留言可能取得其他人的姓名、頭像和文字，並進入公開快取。 |
| 直連 / 代理 | 代理由伺服器端代為請求；直連由瀏覽器向內容 CDN 請求。直連會讓目標服務看到瀏覽器 IP 和連線資訊，且串流請求可能使用瀏覽器 User-Agent，不一定是固定值。 |
| 版本與設定 | 原始碼預設值、`.env`、Compose 和正式環境可能不同。GDStudio 程式碼未設定時預設開啟，但環境或 Compose 可設為關閉；應以實際執行設定核驗。 |

## 3. 解釋基準

1. 法律名詞只在實際要件滿足時使用；「個人專案」「免費」「開源」不是控制者、受託處理者、同意、匿名化或安全合規的同義詞。
2. 技術用語以原始碼、實際環境和供應商請求路徑共同核對；README 設計目標與文件不一致時，不得把目標當成保證。發現原始碼、設定和頁面不一致，應停止較強聲明並修正相應頁面。
3. 本站法律文件以簡體中文版本為維護基準；其餘九種語言為對照版本。翻譯與根目錄版本不一致時，應儘快同步，但強制法律和消費者的清楚、易懂權利不受影響。
4. 核對 RC 的根目錄與播放器 `LICENSE` 均為 MIT；舊 `main@ce443c8` 可核實播放器 MIT 授權，但根目錄缺少 `LICENSE`，不得以 RC 授權反推全部歷史程式碼。本頁定義不限制實際授權允許的複製、修改、散布或商業使用。託管執行個體的[可接受使用政策](/zh-tw/acceptable-use/)只約束其實際託管資源和服務行為。
