**生效日期：2026 年 11 月 1 日｜版本：1.4**

本頁定義本站法律文件所用之法律名詞與技術名詞。同一用語於全部文件中含義一致；有定義者依定義解釋，未定義者依其通常語義。法律名詞以歐盟《一般資料保護規範》（GDPR）之定義為基礎。本站法律文件以簡體中文版本為正式版本，本繁體中文版本為對照譯本。

*圖：本站用語之兩族結構。法律名詞族錨定 GDPR 第 4 條之定義；技術名詞族以原始碼實現為準，隨版本更新核對。*

## 1. 法律名詞

| 用語 | 定義 |
| --- | --- |
| 個人資料 | 與已識別或可識別自然人相關之任何資訊（GDPR 第 4 條第 1 項）；在 Sonic 中例如登入識別碼、行為事件記錄 |
| 處理 | 對個人資料所為之任何操作，包括蒐集、記錄、儲存、利用、傳輸、刪除等（GDPR 第 4 條第 2 項） |
| 處理限制 | 於特定情形下暫停處理、資料仍予保留之狀態（GDPR 第 4 條第 3 項、第 18 條） |
| 使用者輪廓 | 以自動化處理評估個人特徵並據此決策或分析之行為（GDPR 第 4 條第 4 項）；本服務僅於推薦功能必要範圍內為之，且您得一鍵清空 |
| 假名化 | 以額外資訊方可識別特定當事人之方式處理個人資料（GDPR 第 4 條第 5 項）；Sonic 以加鹽 SHA-256 截斷雜湊實現 |
| 資料控制者 | 決定處理目的與手段之自然人或法人（GDPR 第 4 條第 7 項）；託管執行個體為營運團隊，自部署執行個體為部署者 |
| 受託處理者 | 為控制者處理個人資料之自然人或法人（GDPR 第 4 條第 8 項），例如 Cloudflare |
| 接收者 | 取得個人資料之自然人或法人（GDPR 第 4 條第 9 項），無論是否為第三方 |
| 第三方 | 當事人、控制者、受託處理者及經授權處理權限者以外之主體（GDPR 第 4 條第 10 項） |
| 同意 | 當事人依自由意思、明確知悉而作之肯定表示（GDPR 第 4 條第 11 項、第 7 條）；得隨時以不低於給予時之便利方式撤回 |
| 資料外洩 | 導致個人資料遭意外或非法破壞、丟失、竄改、未經授權揭露或接近之安全事件（GDPR 第 4 條第 12 項） |
| 主管監督機關 | 依法監督資料保護義務履行之公權力機關（GDPR 第 4 條第 19 項）；歐盟使用者得向其所在地之監督機關申訴（GDPR 第 77 條） |
| 國際傳輸 | 個人資料向歐盟與歐洲經濟區以外之第三國或國際組織之傳輸（GDPR 第五章） |
| 特殊類別資料 | 揭露種族、政治觀點、健康、性生活等敏感屬性之個人資料（GDPR 第 9 條）；本服務不蒐集 |
| 當事人 | 個人資料所識別或可識別之自然人（GDPR 第 4 條第 25 項），即您 |

## 2. 技術名詞

| 用語 | 定義 |
| --- | --- |
| 控制面 | 運行於 Cloudflare Pages Functions 之邊緣閘道，負責路由、限流、快取與熔斷 |
| 資料面 | 運行於營運者自有 Linux 節點之 Docker Compose 堆疊，負責協定解析、推薦計算與儲存 |
| sonic-engine | 資料面之主容器（Node.js 22），強制驗證服務間金鑰 X-Sonic-Engine-Key，宿主側僅繫結回環位址 |
| ncm-api sidecar | 內網封閉之網易協定輔助容器（`ncm-api:3000`），僅經 compose 內部網路可達 |
| OAuth 2.0 + PKCE | 授權碼模式加代碼交換證明（S256）之登入流程；本服務以 Epomail 為身分提供者 |
| API Key | 格式 `sonic_live_v2.<header>.<payload>.<signature>` 之 HMAC-SHA256 版本化簽章金鑰；酬載含 `sub`／`iat`／`exp`／`jti`／`kid`／`role`／`uid`；僅經請求標頭傳遞 |
| jti | API Key 酬載中之金鑰識別碼，用於撤銷清單與登出即時失效 |
| fail-closed | 驗證失敗即拒絕服務之安全策略；Sonic 對無簽章金鑰、舊版金鑰與生產環境儲存故障均採 fail-closed |
| SSRF 防禦 | 對回環位址、RFC 1918 私有網路、Docker 網橋與雲端中繼資料位址之對外攔截，IPv4／IPv6 雙堆疊驗證，重新導向時重新驗證 |
| 網域白名單 | 音訊、封面與轉發代理僅允許受控音樂 CDN 網域清單（`SONIC_ALLOWED_MUSIC_DOMAINS`）內之 HTTPS 目標 |
| SQLite WAL | 資料面行為事件與實體權重之持久化儲存，採 Write-Ahead Logging 模式，落於具名磁碟區 `sonic-data` |
| 熔斷器 | 三態狀態機（CLOSED／OPEN／HALF_OPEN）；連續 3 次失敗或超過 4.5 秒預算進入熔斷，冷卻 30 秒後探活恢復 |
| 邊緣降級模式 | 資料面離線時，邊緣層直接連接公開歌詞與檢索 API 之災難備援狀態；回應標頭標明 `X-Sonic-Degraded: 1`，介面顯示降級提示 |
| 邊緣快取 | 以 `sonic:*` 為鍵之邊緣快取，新鮮期 8 分鐘，過期後進入災難備援延長狀態 |
| Range 206 | HTTP 分段載入機制；音訊串流預設經邊緣代理以 206 Partial Content 回應 |
| 直連模式 | `?mode=redirect` 之 302 重新導向，由您的瀏覽器與官方 CDN 直接建立連線；網頁播放器不使用 |
| YRC／QRC／KRC | 網易、QQ、酷狗之逐字歌詞格式；本服務原生解析其加密與壓縮封裝（XOR + Deflate） |
| TTML | AMLL 逐字歌詞之時間軸標記語言格式 |
| LRCLIB | 全球開放同步歌詞庫，作為本地歌詞缺失時之補位來源 |
| 試聽偵測 | 對音訊實體長度與中繼資料之偵測，識別官方 30 秒試聽截斷並以標示明示 |
| 跨源補齊 | 試聽曲目觸發之跨平台全曲匹配機制，預設開啟，匹配成功即標明替代來源 |
| 行為事件 | 播放、完播、跳過、收藏、拒絕等推薦訊號記錄；單批至多 50 筆、64 KB；雜訊事件（延遲、試聽截斷切歌）不入庫 |
| 一鍵清空輪廓 | `DELETE /api/sonic/events` 立即銷毀您在推薦引擎中之全部行為特徵與記錄 |
| 推薦輪廓概覽 | `GET /api/sonic/events` 返回之輪廓摘要：事件總數、喜愛與拒絕計數、常聽歌手、流派傾向、最近搜尋詞、儲存形態 |
| X-Sonic-Context | 推薦請求隨附之用戶端本機上下文（限條數之收藏、最近藝人、最近搜尋詞），僅記憶體使用不落盤 |
| 雜訊過濾 | 伺服器端對 6 類非使用者原因切歌（network_stall／playback_error／trial_end／stream_unavailable／buffer_timeout／auto_switch_error）權重歸零不入庫之機制 |

## 3. 解釋基準

1. 法律名詞之解釋以 GDPR 官方文本為基準；技術名詞之解釋以原始碼實現為準，原始碼與本文件不一致時，應修正文件並向程式碼庫提報 Issue。
2. 本站法律文件以簡體中文版本為正式版本；英文與日文版本中術語之譯名以本頁對應關係為準。
