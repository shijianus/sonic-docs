本頁說明「我的音樂」四項內容的本機儲存。未發現本機音訊檔案主體的上傳路徑，但內嵌封面可能隨收藏事件傳送並進入遠端共享曲目目錄，供全站搜尋或公開建議回傳；中繼資料、回饋及推薦上下文也可能傳送。本機儲存不證明沒有遠端處理，也不是通用雲端備份。清理與刪除限制見[資料管理與儲存](/zh-tw/data-management/)。

## 1. 喜愛與收藏

「我喜歡的」聚合您標記之內容：喜愛歌曲、收藏歌單、收藏專輯、關注歌手與收藏 MV。操作入口：曲目列、專輯頁與歌手頁之心形按鈕。資料存於瀏覽器 localStorage（`library` 鍵），即時生效，無需登入。

## 2. 最近播放

「最近播放」頁從 localStorage（`audio`）依時間倒序讀取自動保存的最近最多 100 首，未找到單獨關閉該本機歷史的開關；關閉遠端個人化也不會關閉本機歷史。另外的播放事件與最近藝人上下文可能傳送供推薦，本機歷史清單不表示伺服器沒有記錄。個人化預設開啟不是同意；瀏覽器無痕模式不阻止事件傳送。

## 3. 下載清單

在曲目列或底部播放列點擊下載，歌曲連同音質中繼資料寫入瀏覽器 IndexedDB（`downloaded_music`）；「下載清單」頁管理已下載內容，離線狀態亦可播放。下載佔用瀏覽器儲存配額，配額不足時瀏覽器會拒絕新下載——請先刪除舊下載或清理瀏覽器儲存空間。

## 4. 本機音樂

「本機音樂」頁將選取或拖放的音訊檔案匯入 IndexedDB（`local_music`）。未發現本機音訊檔案主體的上傳路徑，但歌詞比對、收藏回饋及推薦上下文可能傳送標題、藝人、專輯或歌曲識別碼。內嵌封面可能隨收藏事件進入遠端共享曲目目錄，供全站搜尋或公開建議回傳；個人輪廓重置不保證清理該目錄。格式依瀏覽器解碼能力；刪除本機副本不影響原始檔案，也不刪除相關遠端資料或授予內容權利。

## 5. 儲存位置一覽

| 內容 | 儲存位置 | 隨清除瀏覽器資料遺失 |
| --- | --- | --- |
| 喜愛與收藏 | localStorage（`library`） | 是 |
| 最近播放 | localStorage（`audio`） | 是 |
| 下載歌曲 | IndexedDB（`downloaded_music`） | 是 |
| 本機音樂副本 | IndexedDB（`local_music`） | 是 |

重要歌單與下載內容請妥善備份：瀏覽器「清除全部資料」或網站「清除全部本機資料」都會刪除上述內容（見[資料匯出與儲存](/zh-tw/data-management/)）。本機音樂之原始檔案仍保留於您的裝置。
