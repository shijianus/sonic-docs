本頁功能說明依據公開候選版本（RC）`rc/sonic-20261031@a75f5cb`（2026-11-01 UTC），核對日期為 2026-11-02。較早的公開 `main@ce443c8`（2026-10-27 UTC）不能作為其已具備這些 RC 功能的依據。候選版本不是正式 GitHub Release；線上部署版本與設定仍未核實。

本頁說明 Sonic 在手機瀏覽器上的版面與使用要點。行動端與桌面端共用同一執行個體與帳號體系，功能對等；介面版面隨螢幕寬度自動切換，無需安裝任何應用程式。

## 1. 版面與導覽

行動端以底部頁籤導覽取代桌面側邊欄：首頁、搜尋、最近播放、設定四個入口；當前播放以底部迷你播放列常駐，點擊展開行動版播放器抽屜（PlayerDrawerMobile）。

## 2. 播放器抽屜

行動版播放器抽屜提供與桌面端對等之能力：逐字歌詞（原文／譯文／羅馬音）、音質選單、播放模式與下載。抽屜背景隨封面主色調漸層變化，支援拖曳進度與歌詞跳轉。

## 3. 首頁與雷達

行動端首頁與桌面端一致：輪播推薦、智慧推薦與音樂雷達（搜尋後展示偏好匹配）、推薦歌單。卡片推薦理由與偏好訊號標籤在行動端同樣透明呈現，版面縱向堆疊。

## 4. 儲存與同步邊界

行動與桌面瀏覽器儲存彼此獨立，不保證通用跨裝置雲端同步、備份或匯出。未發現本機音訊檔案主體的上傳路徑，但內嵌封面可能隨收藏事件進入遠端共享曲目目錄，標題、中繼資料、回饋及推薦上下文也可能傳送。雷達另有可用性受限的遠端同步路徑；關閉個人化後仍可能傳送偏好酬載，但伺服器可能拒絕儲存。登入依各瀏覽器維持；瀏覽器或裝置遷移依各工具能力，不能假定還原全部 Sonic 資料。見[隱私權政策](/zh-tw/privacy-policy/)。

## 5. 使用建議

1. 將網站加入主畫面可獲接近應用程式的啟動體驗；
2. 背景播放受行動瀏覽器媒體策略影響：切換應用程式後播放可能被系統暫停，回到頁面即可繼續；
3. 省電模式與資料節省模式（Data Saver）可能限制背景音訊，屬瀏覽器行為而非本服務限制；
4. 無痕瀏覽可能在工作階段結束時丟棄本機資料，但不阻止請求或事件。個人化與 Auto DJ 預設開啟不是明確同意；其控制及部分重置與桌面端有相同限制，失敗也可能未顯示。
