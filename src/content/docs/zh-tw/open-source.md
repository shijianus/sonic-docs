## 2. 專案定位

本專案為非商業開源專案：檢索、聚合與播放工具，不儲存、不託管音樂檔案，不整合繞過付費版權之解灰元件。您使用本服務或自行部署時，應自行確認符合當地法律、上游服務條款與內容授權要求（行為邊界見[可接受使用政策](/zh-tw/acceptable-use/)）。

## 3. 第三方致謝與依賴

研發與多源聚合實踐借鑑並致謝以下開源社群專案：Meting、Meting-API-Serverless、ourcraft-music-api、music-lib、NeteaseCloudMusicApi、QQMusicApi、AMLL TTML API、LRCLIB、GDStudio Music API 與 Linux.do 社群。完整依賴與聲明見儲存庫 `THIRD_PARTY_NOTICES.md`；各上游服務之條款由其各自管轄。

## 4. 自行部署者之法律義務

自行部署之時點起，部署者即為其使用者之資料控制者（角色界定見[總覽](/zh-tw/overview/)第 2 節），應履行：

1. **告知義務**：向使用者告知資料處理事項，可以本站[隱私權政策](/zh-tw/privacy-policy/)為基礎文本，惟須按自身實際設定刪改（未開啟之第三方鏈路應從告知中刪除）；
2. **記錄與評估**：維持處理活動記錄（GDPR 第 30 條），高風險時實施資料保護影響評估（GDPR 第 35 條）；
3. **安全維護**：落實[資料處理與安全維護](/zh-tw/data-security/)第 3 節之措施並接受主管機關監督；
4. **設定一致性**：環境變數之實際值（保留天數、第三方開關、限流）須與你的政策承諾一致；
5. **按轄區補足**：GDPR 之外，按使用者所在轄區補足 UK GDPR、LGPD、CCPA-CPRA 等法定要求。

## 5. 本站文件之採用

本站為「通用範本 + 託管執行個體實文」雙軌設計，自部署營運者可採用本站全部文件作為其網站告知與條款之基礎：

1. 替換身分資訊（網域、聯絡信箱、生效日期與版本號）；
2. 複核第三方清單與設定參數之如實揭露；
3. 保留「簡體中文版為正式版本」或改為你的正式版本語言並全文一致；
4. 正式營運前諮詢律師；本站文件不構成法律意見。
