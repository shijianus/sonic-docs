## 1. 適用範圍

本政策適用於您以任何方式使用本服務所生之個人資料，包括：

1. 造訪本服務網站（`sonic.epocanvas.tech`、`sonic.epocanvas.com` 或自行部署執行個體之網域）；
2. 使用網頁播放器之全部功能（搜尋、播放、歌詞、推薦、下載、本機音樂匯入）；
3. 經開放 API 串接本服務之第三方用戶端。

本政策不適用於本服務連結或嵌入之第三方網站與服務（如上游音樂平台之自有網站）；該等第三方各有其隱私權政策，由其自行負責。自行部署 Sonic 之營運者，自部署之時點起即為其使用者之資料控制者，應自行向其使用者履行其所在地適用法律下之告知義務；本政策可作為其告知之基礎文本。

## 4. 蒐集之個人資料

### 4.1 帳戶識別資料（經 Epomail 登入）

您以 Epomail 帳號經 OAuth 2.0（PKCE）登入時，本服務自 Epomail 之 userinfo 端點取得下列欄位，此外不取得任何其他帳戶資料：

| 欄位 | 用途 | 是否落盤 |
| --- | --- | --- |
| 使用者識別碼（`id`／`sub`） | 工作階段內身分識別 | 否 |
| 電子郵件地址（須經驗證） | 衍生假名化雜湊；作為簽發予您本人之 API Key 酬載中 `sub` 宣告 | 否 |
| 暱稱或使用者名稱（`name`／`username`／`nickname`） | 介面顯示 | 否 |
| 頭像連結（`avatar`／`picture`） | 介面顯示 | 否 |
| 帳戶角色（`role`） | 權限判定 | 否 |

本服務不設獨立註冊系統，不蒐集電話號碼、真實姓名、住址或支付資料。電子郵件地址僅於登入工作階段內即時使用：衍生假名化識別碼（`usr_` 前綴之 SHA-256 雜湊，擷取 12 個十六進位字元）、衍生使用者識別雜湊與限流桶鍵；衍生所得之雜湊值無法還原原電子郵件地址。

### 4.2 行為事件

為提供推薦與 Auto DJ 功能，本服務記錄與曲目播放相關之行為事件。事件類型共 11 種：搜尋、搜尋點擊、播放開始、播放進度、完播、跳過、重播、收藏、取消收藏、拒絕、取消拒絕。每項事件以下列假名化識別碼之一關聯：

1. **登入使用者**：由電子郵件地址衍生之 SHA-256 雜湊（`usr_` 前綴）；
2. **匿名參與者**：由您瀏覽器本機生成之隨機識別碼（`anon_` 前綴）經伺服器端再雜湊；
3. **公開模式**：個人化關閉時，事件不入庫、不儲存，於伺服器端直接丟棄。

事件上報採批次方式（單批至多 50 筆、請求主體上限 64 KB），並於頁面隱藏時排清待發佇列。每項事件記錄之內容限於：事件類型、曲目規範識別碼、歌手識別碼、流派與語種標籤、搜尋詞（如適用）、播放進度比例與訊號權重；不含 IP 位址、不含裝置指紋、不含自由文字內容。

雜訊與假訊號淨化：因網路延遲（network_stall）、解碼失敗（playback_error）、試聽截斷（trial_end）、串流不可用（stream_unavailable）、緩衝逾時（buffer_timeout）或自動切換失敗（auto_switch_error）所致之切歌，權重恆為零且不入庫；用戶端僅在播放正常且收聽 0.5 至 25 秒之間時才上報主動跳過。

此外，推薦請求會隨附您用戶端本機之少量上下文（部分收藏曲目、最近藝人、最近搜尋詞，各限條數），僅於當次請求之記憶體中使用用於個人化排序，不落盤儲存、不進入日誌。

### 4.3 全域聚合統計

本服務另行維護與任何使用者無關之全域聚合統計，用於熱度榜與相似推薦：

| 統計表 | 內容 | 與個人之關聯 |
| --- | --- | --- |
| 搜尋詞聚合計數 | 搜尋詞之全域頻次統計 | 無 |
| 曲目共現關係 | 曲目被共同收聽之全域統計 | 無 |

該等記錄不含個人識別碼，不與您的身分關聯，亦不隨「一鍵清空輪廓」之範圍呈現（因其本不屬於任何使用者）。

下列資料僅儲存於您之瀏覽器，營運者之伺服器不取得完整副本；瀏覽器隱私模式下儲存不可用時自動降級為記憶體暫存：

| 儲存位置 | 鍵 | 內容 |
| --- | --- | --- |
| localStorage | `audio` | 播放清單、當前曲目、播放模式、音量、靜音狀態、播放歷史 |
| localStorage | `library` | 喜愛歌曲、收藏歌單、關注歌手、收藏 MV、收藏專輯、自建歌單 |
| localStorage | `global` | 主題、語言偏好、搜尋歷史（至多 10 筆） |
| localStorage | `settings` | 介面偏好（背景動畫、音質偏好等設定項目） |
| localStorage | `recommend` | 個人化開關、Auto DJ 開關、匿名識別碼、拒絕曲目清單 |
| localStorage | `sonic-perf-mode` | 效能模式開關 |
| IndexedDB | `SonicMusicPlayerDB` | 您匯入之本機音樂檔案（`local_music`）與已下載之歌曲（`downloaded_music`） |

### 4.5 自動處理之技術資料

- **限流**：匿名請求按 IP 分桶限流（每分鐘 240 次，預設值）；IP 僅以限流鍵短暫使用：邊緣原生限流器不留存資料，或以 120 秒自動過期之 KV 記錄暫存，或於 60 秒記憶體視窗內暫存（至多 4096 桶）；IP 不寫入資料庫，不寫入存取日誌。驗證請求按電子郵件雜湊分桶（每分鐘 600 次，預設值），驗證端點另有每分鐘每 IP 30 次之專用限流。
- **工作階段與金鑰**：登入成功後簽發 `HttpOnly; Secure; SameSite=Lax` 之 `sonic_session` Cookie（有效期至多 30 日），內含簽章 API Key；金鑰不寫入 URL、查詢參數或 localStorage。OAuth 過程使用 `sonic_oauth_state` 與 `sonic_oauth_verifier` 事務 Cookie（有效期 600 秒，限 `/api/auth` 路徑）。API Key 酬載含 `sub`（電子郵件）、`iat`、`exp`、`jti`、`kid`、`role`、`uid`；`jti` 用於撤銷清單與登出即時失效。
- **存取日誌**：資料面存取日誌為逐行 JSON，僅含請求識別碼、方法、路徑、狀態碼與耗時；查詢字串、IP、User-Agent、Cookie、Authorization 與請求主體一律不記錄。例外日誌僅含請求識別碼、錯誤名稱與截斷之錯誤訊息。
- **音訊代理**：音訊串流預設經本服務邊緣代理取得，上游請求僅攜帶 User-Agent、按 CDN 設定之官網 Referer 與 Range 標頭，並剝離 Set-Cookie 與憑證標頭；上游 CDN 僅見代理伺服器之位址。如您主動呼叫 `?mode=redirect` 直連模式，您的瀏覽器將與官方 CDN 直接建立連線，您的 IP 對該 CDN 可見（此為 302 重新導向之固有語義）；網頁播放器不使用該模式。
- **邊緣網路**：Cloudflare 依其自身政策處理網路層請求中繼資料。

### 4.6 本服務不蒐集之項目

本服務無廣告追蹤、無跨站 Cookie、無第三方統計或分析腳本、無裝置指紋、無行為廣告輪廓；不蒐集通訊錄、相簿、位置或任何與音樂播放無關之裝置資料；不出售個人資料，不為廣告目的利用個人資料，不接入任何廣告網路。

## 5. 法律依據與處理目的

各項處理活動之法律依據如下：

| 處理活動 | 目的 | 法律依據 |

## 7. 與第三方之共享及國際傳輸

本服務依最小必要原則與第三方共享個人資料，全部情形見[第三方共享與傳輸清單](/zh-tw/sub-processors/)，要旨如下：

1. **受託處理**：Cloudflare（Pages 託管、Functions 邊緣運算、Tunnel 加密通道、KV 儲存、限流基礎架構）；
2. **身分提供者**：Epomail（登入時取得識別碼、電子郵件、暱稱、頭像連結與角色）；
3. **上游內容來源**：網易、QQ、酷狗、酷我、AMLL、LRCLIB 及各官方內容 CDN——請求僅含歌曲查詢參數與固定 User-Agent／Referer，不包含您的身分或 IP；
4. **法律要求**：僅於依法定程序受有權機關要求時提供，並於法律允許範圍內通知您。

本服務之控制面運行於 Cloudflare 全球邊緣網路，您的個人資料可能於營運者所在國境外之節點處理。營運者依 GDPR 第 44 條至第 46 條之保障機制（含歐盟標準契約條款）依託管與受託處理關係管理國際傳輸，並依賴 Cloudflare 之資料保護措施（SOC 2 Type II、ISO/IEC 27001 認證）。自行部署之營運者應自行評估並確保其國際傳輸行為符合其所在地之法律要求。

## 8. 兒童之保護

本服務不面向未滿 16 歲之兒童，亦不有意蒐集兒童之個人資料；您所在地法律就資訊社會服務之同意年齡另有較低規定者（最低 13 歲，GDPR 第 8 條），從其規定。監護人認為兒童提供個人資料者，得聯絡營運者請求刪除，經核實後即時處理。任何人均不得利用本服務對兒童及少年散佈有害其身心健康之內容；相關使用限制見[可接受使用政策](/zh-tw/acceptable-use/)。

## 9. 當事人權利與行使方式

您就您的個人資料享有下列權利：

1. 接近與取得副本（GDPR 第 15 條）；
2. 更正（GDPR 第 16 條）；
3. 刪除（GDPR 第 17 條）；
4. 限制處理（GDPR 第 18 條）；
5. 資料可攜（GDPR 第 20 條）；
6. 反對（GDPR 第 21 條），包括隨時關閉個人化；
7. 不受僅基於自動化處理之決策約束（GDPR 第 22 條），本服務不進行此類決策。

1. **自助功能（即時生效）**：
   - 「清除推薦輪廓」：即時銷毀伺服器端與您關聯之全部行為事件（`DELETE /api/sonic/events`）；
   - 「清除全部本機資料」：即時清除瀏覽器 localStorage、sessionStorage 與整個 IndexedDB 資料庫，並同步銷毀伺服器端輪廓；此為清除操作，不是本機資料匯出；
   - 推薦輪廓概覽查詢：經 `GET /api/sonic/events` 取得您當前輪廓之摘要（事件總數、喜愛與拒絕計數、常聽歌手、流派傾向、最近搜尋詞、儲存形態）；此摘要不是完整個人資料匯出，服務端事件目前沒有提供下載匯出通道；
   - 關閉個人化：設定頁開關即時生效，待發佇列清空、後續事件不再蒐集；
   - 登出：即時撤銷當前工作階段與金鑰識別碼。
2. **人工請求**：其餘請求致函 `privacy@epocanvas.com`，營運者於收到請求後一個月內答覆（GDPR 第 12 條第 3 項）；情事複雜時得再延長兩個月，並於首個月內告知延長理由。

## 10. 安全維護措施

營運者依 GDPR 第 32 條建立並持續改善適當之技術與組織措施，防止個人資料被竊取、竄改、毀損、滅失或洩漏：全程 HTTPS/TLS；HMAC-SHA256 版本化簽章 API Key 與常數時間比對；PKCE OAuth 流程與事務 Cookie 限時；工作階段 Cookie 之 HttpOnly／Secure／SameSite 屬性與即時撤銷；資料面僅繫結回環位址並經加密通道接入；全程 SSRF 攔截與網域白名單；假名化識別碼與無 IP 資料庫設計；日誌最小化；fail-closed 之金鑰驗證。完整清單、處理矩陣與已知侷限之說明見[資料處理與安全維護](/zh-tw/data-security/)。
