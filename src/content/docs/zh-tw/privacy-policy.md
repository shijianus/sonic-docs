## 4. 程式碼中的處理與版本差異

### 4.1 登入與工作階段

候選版 `a75f5cb` 的 Epomail OAuth 使用 state 驗證和 PKCE。`sonic_session` 為 HttpOnly 簽章工作階段 Cookie，預設有效期 30 日；`sonic_oauth_state` 和 `sonic_oauth_verifier` 交易 Cookie 約 600 秒，HTTPS 環境設 Secure。簽章保護完整性，不是加密；憑證酬載可含電子郵件地址及使用者、角色識別碼。這些原始碼預設值不是線上期限的證明。

前端 `auth` 本機儲存保留部分使用者資料，包含電子郵件地址和頭像，並有讀取舊登入儲存的相容路徑；不能說帳號資料只在記憶體。登出會清理目前 Cookie，但被複製或匯出的憑證是否立即撤銷，仍依撤銷儲存、設定和請求結果，不能把登出等同於所有副本即時失效。

舊 `main@ce443c8` 的回呼及相容前端存在經 URL 和 localStorage 傳遞、保存登入資料與憑證的路徑，未具備上述完整 PKCE、簽章驗證和撤銷保護。不得把舊版 README 的描述視為已實作。尚未落實必要保護的部署不應處理真實使用者憑證；如發現 URL、螢幕截圖或日誌含憑證，請勿轉傳，並聯絡營運者處理。
### 4.2 行為事件、輪廓分析與搜尋統計

以下行為事件、SQLite 輪廓及搜尋統計路徑在候選版中可核實；舊 `main` 未找到相同的完整實作，不能據此假定其已有這些功能。

候選版使用電子郵件地址衍生識別碼或瀏覽器產生的 `anon_` 識別碼關聯事件，處理播放、收藏、拒絕等行為及藝人、專輯、歌單、MV 的回饋。推薦請求還可能攜帶本機收藏、最近藝人及搜尋上下文。未登入不等於匿名；雜湊和隨機識別碼可用於關聯，應視為假名化個人資料，不能據「不可逆」排除 GDPR。

智慧搜尋另行累計查詢，公開搜尋建議可能顯示這些詞；僅關閉個人化不會停止這條路徑。查詢可能含姓名、聯絡方式或敏感資訊，次數聚合本身不能使其匿名。在完成必要性、合法依據、過濾、顯示門檻、保存與刪除控制前，應關閉從使用者查詢產生公開建議的路徑。

只有為完成您明確請求的播放、登入或設定而嚴格必要的終端存取，才可能適用電子隱私規則的必要性例外。可選輪廓分析識別碼和非必要存取應先有有效同意；Cookie、localStorage 和 IndexedDB 都不能僅因「第一方」或保存在裝置而自動豁免。具體要求還取決於適用的會員國施行法。

### 4.4 網路、日誌與外部資源

執行個體與基礎架構可能處理 IP、路徑、時間和連線資訊。候選版限流可使用原始 IP 或身分衍生鍵，邊緣還可能把位址、工作階段和上下文轉送至所設定的資料引擎。應用程式日誌的最小化不代表主機、代理、錯誤日誌、Cloudflare 或接收者均不記錄；沒有經核驗的全鏈路「零日誌」保證。

設定告警 webhook 並觸發告警時，接收服務可收到系統計數、發布版本、時間和憑證已遮蔽的摘要，也可看到傳送節點的出口 IP。一般酬載未自動附加終端使用者識別碼或查詢，但管理員備註和錯誤資訊仍可能含個人資料；遮蔽處理不等於完全匿名化。實際啟用前應最小化內容、核實接收者及保存／傳輸安排。

音訊代理可讓上游看到代理出口，但部分請求仍可能攜帶瀏覽器資訊。MV、封面、頭像、字型和直連內容可向外部服務揭露 IP 等中繼資料。程式碼載入 Google Fonts，並存在以明文電子郵件地址作為 DiceBear 頭像 seed 的路徑；營運者應避免自動的非必要外部連線，並以本機資源或不含電子郵件地址的方式替代該頭像路徑。部分上游使用 HTTP，不能稱為全鏈路端對端加密。實際接收者及可選開關見[第三方共享與傳輸清單](/zh-tw/sub-processors/)。

### 4.5 不用於何種目的

專案不以出售個人資料、廣告投放、跨站廣告輪廓分析或訓練通用 AI 模型為目的；本次程式碼檢查也未發現供 Sonic 取得 Epomail 郵件內文的功能。身分登入不等於授予信箱內容存取權。推薦演算法不意味著內容會傳送給通用 AI 提供者；新增用途須先另行評估及告知。

本服務不以蒐集特殊類別資料或推斷敏感特徵為目標。若意外收到，應限制存取、評估必要性和適用條件並依法刪除或處理，不能僅靠一般同意或正當利益滿足 GDPR 第 9 條要求。第三方的獨立處理不能由本專案代為保證。

### 4.6 文件站的閱讀、偏好與搜尋

文件站與播放器不是同一套儲存。當前文件原始碼與所用 Starlight／Pagefind 元件可核對如下：

| 功能或儲存 | 內容與用途 | 保存及傳輸邊界 |
| --- | --- | --- |
| `starlight-theme`（`localStorage`） | 淺色、深色或跟隨系統的顯示偏好；初始化也可能寫入空值 | 至覆蓋、使用者清除或瀏覽器回收；未見該鍵用於輪廓分析 |
| `sl-sidebar-state`（`sessionStorage`） | 側欄展開狀態、結構識別碼和捲動位置 | 由瀏覽器管理的分頁工作階段內保存；恢復工作階段可能延續，不作為精確銷毀時間 |
| Pagefind 文件搜尋 | 輸入在瀏覽器內比對，按需請求本站靜態索引和結果片段 | 未見把原始輸入提交至播放器搜尋 API 或外部搜尋服務；索引路徑、存取頁面和連線資訊仍可能被託管網路記錄，不能保證搜尋行為不可推斷 |

語言入口讀取 `Accept-Language` 請求標頭選擇入口，不為此設定語言 Cookie。當前文件設定中未發現廣告或獨立統計腳本；這不證明託管網路沒有日誌。上述偏好僅用於閱讀介面，不能因其為第一方就概括認定免同意：只有符合適用終端存取必要性例外時才可不另行取得同意，否則應先取得同意或停用相應存取。清理文件站資料不會自動清理其他網域上的播放器資料。實際託管接收者、控制者、日誌期限和權利管道仍須在採用本政策前確認。

候選版把個人化和 Auto DJ 設為預設開啟；預設值、登入和勾選使用者條款不證明有效同意。適用歐盟規則的部署須在選擇前不作非必要存取或傳送，讓接受和拒絕同樣便捷，提供不與基本服務綁定的選擇，並可用不難於給予同意的方式撤回。清空設定後也不能把未選擇恢復為同意。目前文件沒有證明該機制已實作。

關閉個人化不等於刪除既有資料，也不會停止必要請求或另行存在的搜尋統計。Auto DJ 有獨立開關，仍可能為填充佇列傳送種子及排除曲目；雷達同步在關閉個人化後仍可能傳送偏好酬載，即使伺服器因關閉標記拒絕儲存。傳送、接收和持久保存是不同處理，不能把開關當作全面阻斷外傳的保證。營運者須按撤回範圍停止相關未來處理，並依法處理已蒐集的資料；不得事後用另一標籤追溯合法化原先沒有依據的蒐集。沒有足夠資源落實可選輪廓分析的同意、保存和刪除時，可以關閉該功能，而無須建立不必要的企業級系統。

推薦一般根據播放、收藏、拒絕、藝人偏好和內容關聯調整排序，並非準確性保證。它屬於輪廓分析，但審閱用途僅涉及內容推薦，未發現產生法律或類似重大影響的純自動化決定；若用途改變，應依 GDPR 第 22 條等規則重新評估並事前告知。
