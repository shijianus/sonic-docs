## 1. 專案定位

Sonic 是一套獨立研發的多源音樂串流平台與聚合閘道，以「Cloudflare 邊緣控制面 + Linux 本地協定引擎資料面」雙層架構運行，專為高音質串流、毫秒級逐字歌詞與自主可控的推薦體驗而建。專案為開源軟體，原始碼公開發布，任何人得自行部署。

## 3. 技術架構概覽

### 3.1 控制面（Cloudflare 邊緣）

控制面運行於 Cloudflare Pages 與 Pages Functions，承擔以下職責：

1. **路由與驗證**：API 請求之統一入口，驗證檢查與簽章金鑰核驗；
2. **分級限流**：匿名請求每分鐘 240 次、驗證請求每分鐘 600 次（預設值，可設定），驗證端點另有每分鐘每 IP 30 次之專用限流；
3. **多層級快取**：以 `sonic:*` 為鍵之邊緣快取，新鮮期 8 分鐘，過期後進入災難備援延長狀態；
4. **三態熔斷器**：連續 3 次失敗或呼叫超過 4.5 秒預算即進入 OPEN 熔斷，後續請求不再等待已熔斷的資料面，嘗試邊緣直連備援（QQ／酷狗公開檢索 API 與 AMLL／LRCLIB），實際網路仍有延遲；冷卻 30 秒後進入 HALF_OPEN 探活，成功後閉合。降級期間回應標頭標明 `X-Sonic-Degraded: 1`，播放器頂部亮起降級提示膠囊。

### 3.2 資料面（Linux 協定引擎）

資料面為營運者自有 Linux 節點上之 Docker Compose 堆疊：

| 元件 | 說明 |
| --- | --- |
| sonic-engine 主容器 | Node.js 22 HTTP 服務，監聽 8080 連接埠，宿主側僅映射 `127.0.0.1`；全部 `/api`、`/proxy`、`/palette` 路由強制驗證服務間金鑰（X-Sonic-Engine-Key） |
| ncm-api 輔助容器 | 網易雲協定輔助服務，僅於 compose 內部網路可達（`ncm-api:3000`），不對外公開 |
| SQLite 3（WAL 模式） | 行為事件與實體權重之持久化儲存，落於具名磁碟區 `sonic-data`（容器內 `/app/data/sonic-recommend.sqlite`）；備份以一致性快照（VACUUM INTO）配合完整性檢查執行 |
| 原生協定模組 | 純 TypeScript 實現之網易 linuxapi/eapi、QQ、酷狗 KRC、酷我協定解析 |

控制面與資料面之間經 Cloudflare Tunnel 加密通道通訊，資料面不直接對外公開連接埠。

### 3.3 音訊串流路徑

音訊串流通常經同源位元組範圍邊緣代理取得，支援 HTTP `Range` 與 `206 Partial Content`，使該上游連線看到代理位址。這不保護全部流量：`?mode=redirect`、MV、封面、外部圖片、頭像及字型可能直連並揭露您的 IP。目前程式碼載入 Google Fonts，且可能以明文電子郵件地址作為頭像 seed 傳送給 DiceBear；部分上游請求使用 HTTP，並非所有鏈路都加密。見[隱私權政策](/zh-tw/privacy-policy/)第 4.4 節。

## 4. 音源與歌詞鏈路

| 來源 | 佔比定位 | 狀態 |
| --- | --- | --- |
| 本地原生解析（網易／QQ／酷狗／酷我官方 API + ncm-api） | 主鏈路（逾 90%） | 預設啟用 |
| AMLL TTML 逐字歌詞 + LRCLIB 同步歌詞庫 | 歌詞補位（約 10%） | 預設啟用 |
| GDStudio／Lyriva 第三方聚合上游 | 可選路徑 | GDStudio 程式碼未設定時預設開啟，環境／Compose 範例為關閉，須核驗實際開關 |

試聽偵測對音訊實體長度與中繼資料進行偵測，識別官方 30 秒試聽截斷；識別結果以試聽標示在前端透明呈現，並可觸發跨平台全曲匹配（匹配對象為 QQ／酷狗／酷我之免費全曲），匹配成功即平滑切換並標明替代來源。本專案不整合任何繞過付費版權之解灰元件。

## 5. 智慧推薦引擎

核心推薦引擎運行於資料面；可選外部提供者與雷達同步依設定及路由可用性而定。曲目訊號權重公開於原始碼，另有藝人、專輯、歌單及 MV 回饋：

| 訊號 | 權重 | 說明 |
| --- | --- | --- |
| favorite（加入最愛） | +4.0 | 極強正向 |
| replay（重播） | +3.5 | 強正向 |
| play_complete（有效完播） | +2.5 | 標準正向 |
| play_progress（進度聆聽） | +0.2 ～ +1.8 | 按收聽比例分階計分 |
| skip（快速跳過） | -0.8 | 聽過半之切歌計 +0.25 |
| dislike（明確拒絕） | -5.0 | 硬過濾並列入黑名單 |

雜訊與假訊號淨化：因網路延遲（network_stall）、解碼失敗（playback_error）、試聽截斷（trial_end）、串流不可用（stream_unavailable）、緩衝逾時（buffer_timeout）或自動切換失敗（auto_switch_error）所致之切歌，權重恆為零且不入庫。

熱度模型綜合有效播放（35%）、獨立聽眾（25%）、完播表現（20%）、收藏轉化（15%）與成長斜率（5%），輔以指數時間衰減（24 小時飆升榜與 7 天累計熱榜）、貝氏與 Wilson Score 平滑；相似度計算融合歌手關係圖譜與音訊特徵餘弦，並以 MMR 邊際相關性重排平衡精準與多樣。工作階段意圖與長期訊號分別加權，不表示搜尋從不保留；即使關閉個人化，獨立搜尋原文計數仍可能出現在公開建議。

## 6. 安全設計概覽

1. **驗證**：最新公開 RC 使用 OAuth state 與 PKCE，OAuth 交易 Cookie 有效 600 秒；實際部署仍須核驗，舊 `main@ce443c8` 僅作相容性對照；
2. **API Key**：RC 實作 `sonic_live_v2` 簽章憑證及版本、簽章、時間和所設定的撤銷校驗；預設簽發 30 日，驗證器最大允許生命週期 90 日不等於預設期限。簽章不是加密，憑證不得放入 URL、日誌或公開用戶端；線上設定和撤銷傳播仍須核驗；
3. **撤銷**：登出、撤銷端點和即時失效依實際路由、儲存、開關及請求結果；RC 程式碼提供撤銷路徑，但尚未證明對所有部署即時生效；
4. **工作階段**：Cookie 屬性、有效期和伺服器端狀態依實際部署核驗；前端 `auth` 可能保留電子郵件地址及頭像資料；
5. **SSRF 防禦**：RC 包含針對特定路由的回環、私有網路、雲端中繼資料目標、IPv4／IPv6 位址、DNS 解析及重新導向檢查；僅涵蓋呼叫這些校驗的路徑，不涵蓋所有請求或瀏覽器直連。

## 7. 隱私設計概覽

1. **假名化**：電子郵件衍生及瀏覽器產生的識別碼仍可能是可關聯的個人資料；電子郵件地址與頭像資訊也保留於瀏覽器 `auth` 儲存；
2. **個人化開關**：個人化與 Auto DJ 目前預設開啟，不是有效的明確同意。Auto DJ 開關獨立於個人化，仍可能傳送種子及排除曲目；關閉個人化不會停止獨立的公開搜尋詞再利用，也未必停止每個雷達路徑；缺少有效依據的可選處理應暫停；
3. **重置與清理**：重置刪除目前身分的部分事件與回饋，未必涵蓋舊匿名識別碼、雷達資料、搜尋聚合、共享曲目目錄及內嵌封面、外部提供者或備份，錯誤也可能未顯示；清除本機不等於完整遠端刪除；
4. **日誌最小化**：應用程式存取日誌最小化欄位，但錯誤、主機、代理與提供者仍可能處理請求資料；原始 IP 限流鍵可進入 KV，用戶端位址也可能轉送引擎。

隱私承諾之完整表述見[隱私權政策](/zh-tw/privacy-policy/)，技術措施見[資料處理與安全維護](/zh-tw/data-security/)。

## 8. 適合誰與不適合誰

適合：希望以自有 Epomail 帳號登入、在意推薦輪廓透明與可刪除性之個人聽眾；需要多源聚合搜尋與逐字歌詞之重度樂迷；具備 Linux 與 Docker 基礎、願意自行承擔營運者責任之自部署使用者。

不適合：尋求商業音樂目錄授權保障的情境。本服務不提供音樂目錄授權或內容再授權，但存在代理、快取與瀏覽器本機儲存，不能稱為完全不儲存或傳輸音樂。亦不適合期待服務水準協議（SLA）或商業支援的團隊，以及無法接受「試聽片段透明標示、跨源補齊盡力而為」的使用者。

## 12. 常見疑問

**本服務收費嗎？有廣告嗎？**
這是個人維護、免費、無廣告、無內購的非營利測試專案；非營利身分不免除資料保護或消費者義務。

**不登入可以使用嗎？**
可以。搜尋、播放、歌詞及排行榜等核心功能無需登入，但未登入不等於匿名。登入不保證跨裝置雲端同步，也不證明年齡或輪廓分析同意。

**我的資料存在哪裡？**
收藏、歌單和偏好主要在瀏覽器儲存，電子郵件地址與頭像資料存於 `auth`；本機音訊檔案主體與內嵌封面儲存在 IndexedDB，但內嵌封面也可能隨收藏事件傳送並進入遠端共享曲目目錄，供全站搜尋或公開建議回傳。中繼資料、回饋及推薦上下文可能傳送；本機播放歷史最多保留 100 首，搜尋歷史最多 20 項；關閉個人化不會關閉本機歷史。遠端資料另有雷達輪廓和搜尋統計。90 日是部分事件清理設定，不是全面自動刪除。見[隱私權政策](/zh-tw/privacy-policy/)第 4、6 節。

**如何刪除我的行為輪廓？**
設定 → 隱私與本機資料 → 「重置推薦輪廓與不感興趣記錄」，或 `DELETE /api/sonic/events`，可請求目前身分的部分重置；不是完整遠端刪除，失敗也可能未顯示。清除本機不證明遠端已刪除；較完整請求請聯絡 `privacy@epocanvas.com`。介面位置見[介面與功能導覽](/zh-tw/interface/)第 9 節。

**推薦會追蹤我嗎？**
推薦使用假名化行為輪廓，而非匿名資料。個人化與 Auto DJ 預設開啟，不是有效同意；關閉個人化不會停止獨立搜尋詞計數及可能的公開建議。無痕模式不會阻止網路請求或事件。

**為什麼有些歌只有 30 秒？**
那是上游平台的試聽截斷。播放器標示試聽，啟用跨來源補齊時嘗試比對可用全曲並標示來源；技術可用不授予內容權利。

**音質徽章可信嗎？**
徽章旨在反映可用串流檔位，實際音質依上游資源而定。見[使用者條款](/zh-tw/terms-of-service/)第 4 節。

**自行部署有什麼責任？**
責任依您實際決定處理的角色及適用法律判斷。公開處理前應落實身分告知、合法依據、經驗證的保存與刪除、安全及必要的傳輸保障。純個人測試與公開服務須分別評估，不能只憑部署推定 GDPR 適用或伺服器所在國家。見[資料處理與安全維護](/zh-tw/data-security/)。

**本服務支援哪些語言？**
播放器內建簡體中文、English、日本語；本站文件提供 10 種語言版本。
