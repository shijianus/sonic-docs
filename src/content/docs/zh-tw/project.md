## 1. 專案定位

Sonic 是一套獨立研發的多源音樂串流平台與聚合閘道，以「Cloudflare 邊緣控制面 + Linux 本地協定引擎資料面」雙層架構運行，專為高音質串流、毫秒級逐字歌詞與自主可控的推薦體驗而建。專案為開源軟體，原始碼公開發布，任何人得自行部署。

| --- | --- |

| 自行部署執行個體 | 任何個人或組織依開源程式碼部署於自有伺服器之私有執行個體；部署者即為該執行個體之營運者與資料控制者 |

## 3. 技術架構概覽

### 3.1 控制面（Cloudflare 邊緣）

控制面運行於 Cloudflare Pages 與 Pages Functions，承擔以下職責：

1. **路由與驗證**：API 請求之統一入口，驗證檢查與簽章金鑰核驗；
2. **分級限流**：匿名請求每分鐘 240 次、驗證請求每分鐘 600 次（預設值，可設定），驗證端點另有每分鐘每 IP 30 次之專用限流；
3. **多層級快取**：以 `sonic:*` 為鍵之邊緣快取，新鮮期 8 分鐘，過期後進入災難備援延長狀態；
4. **三態熔斷器**：連續 3 次失敗或呼叫超過 4.5 秒預算即進入 OPEN 熔斷，後續請求 0ms 立即改走邊緣直連備援（QQ／酷狗公開檢索 API 與 AMLL／LRCLIB）；冷卻 30 秒後進入 HALF_OPEN 探活，成功後閉合。降級期間回應標頭標明 `X-Sonic-Degraded: 1`，播放器頂部亮起降級提示膠囊。

### 3.2 資料面（Linux 協定引擎）

資料面為營運者自有 Linux 節點上之 Docker Compose 堆疊：

| 元件 | 說明 |
| --- | --- |
| sonic-engine 主容器 | Node.js 22 HTTP 服務，監聽 8080 連接埠，宿主側僅映射 `127.0.0.1`；全部 `/api`、`/proxy`、`/palette` 路由強制驗證服務間金鑰（X-Sonic-Engine-Key） |
| ncm-api 輔助容器 | 網易雲協定輔助服務，僅於 compose 內部網路可達（`ncm-api:3000`），不對外公開 |
| SQLite 3（WAL 模式） | 行為事件與實體權重之持久化儲存，落於具名磁碟區 `sonic-data`（容器內 `/app/data/sonic-recommend.sqlite`）；備份以一致性快照（VACUUM INTO）配合完整性檢查執行 |
| 原生協定模組 | 純 TypeScript 實現之網易 linuxapi/eapi、QQ、酷狗 KRC、酷我協定解析 |

控制面與資料面之間經 Cloudflare Tunnel 加密通道通訊，資料面不直接對外公開連接埠。

### 3.3 音訊串流路徑

音訊串流預設經邊緣代理（同源位元組範圍代理）自官方 CDN 擷取，支援 HTTP `Range` 與 `206 Partial Content` 分段載入：上游 CDN 僅見代理伺服器之位址，不接觸用戶端 IP。`?mode=redirect` 之 302 直連模式僅為明確呼叫之 API 使用者提供（網頁播放器不使用）；直連模式下您的瀏覽器與官方 CDN 直接建立連線。

## 4. 音源與歌詞鏈路

| 來源 | 佔比定位 | 狀態 |
| --- | --- | --- |
| 本地原生解析（網易／QQ／酷狗／酷我官方 API + ncm-api） | 主鏈路（逾 90%） | 預設啟用 |
| AMLL TTML 逐字歌詞 + LRCLIB 同步歌詞庫 | 歌詞補位（約 10%） | 預設啟用 |
| GDStudio／Lyriva 第三方聚合上游 | 應急備用 | 預設嚴格關閉 |
| ListenBrainz／MusicBrainz 相似藝人增強 | 可選增強 | 預設關閉 |

試聽偵測對音訊實體長度與中繼資料進行偵測，識別官方 30 秒試聽截斷；識別結果以試聽標示在前端透明呈現，並可觸發跨平台全曲匹配（匹配對象為 QQ／酷狗／酷我之免費全曲），匹配成功即平滑切換並標明替代來源。本專案不整合任何繞過付費版權之解灰元件。

## 5. 智慧推薦引擎

推薦引擎完全運行於資料面本地，行為訊號權重公開於原始碼：

| 訊號 | 權重 | 說明 |
| --- | --- | --- |
| favorite（加入最愛） | +4.0 | 極強正向 |
| replay（重播） | +3.5 | 強正向 |
| play_complete（有效完播） | +2.5 | 標準正向 |
| play_progress（進度聆聽） | +0.2 ～ +1.8 | 按收聽比例分階計分 |
| skip（快速跳過） | -0.8 | 聽過半之切歌計 +0.25 |
| dislike（明確拒絕） | -5.0 | 硬過濾並列入黑名單 |

雜訊與假訊號淨化：因網路延遲（network_stall）、解碼失敗（playback_error）、試聽截斷（trial_end）、串流不可用（stream_unavailable）、緩衝逾時（buffer_timeout）或自動切換失敗（auto_switch_error）所致之切歌，權重恆為零且不入庫。

熱度模型綜合有效播放（35%）、獨立聽眾（25%）、完播表現（20%）、收藏轉化（15%）與成長斜率（5%），輔以指數時間衰減（24 小時飆升榜與 7 天累計熱榜）、貝氏與 Wilson Score 平滑；相似度計算融合歌手關係圖譜與音訊特徵餘弦，並以 MMR 邊際相關性重排平衡精準與多樣。工作階段級搜尋意圖與長期偏好分層解耦：僅完播、收藏等高價值行為沉澱至長期檔案。

## 6. 安全設計概覽

1. **驗證**：Epomail OAuth 2.0 授權碼模式，`state` 參數與 PKCE（S256）防授權碼攔截與重放；OAuth 事務 Cookie 有效期 600 秒；
2. **API Key**：`sonic_live_v2.<header>.<payload>.<signature>` 版本化格式，HMAC-SHA256 簽章，酬載含 `sub`／`iat`／`exp`／`jti`／`kid`／`role`／`uid`；簽發有效期 30 日、驗證上限 90 日；伺服器端以 Web Crypto 常數時間比對，無簽章金鑰與舊版金鑰一律拒絕（fail-closed）；金鑰僅經 `X-Sonic-Key` 或 `Authorization` 請求標頭傳遞，URL 查詢參數通道已完全移除；
3. **撤銷**：登出即時撤銷當前工作階段與金鑰識別碼（jti）；支援 jti 撤銷清單、主體撤銷清單與全域簽發時間下限，繫結 KV 時支援即時撤銷；
4. **工作階段**：`HttpOnly; Secure; SameSite=Lax` 之 `sonic_session` Cookie，有效期至多 30 日；金鑰不寫入 URL、localStorage 或頁面腳本可及之處；
5. **SSRF 防禦**：對回環位址、RFC 1918 私有網路、Docker 內部網橋與雲端中繼資料位址（如 `169.254.169.254`）之對外請求一律阻斷，IPv4 與 IPv6 雙堆疊驗證，每次重新導向重新驗證目標與 DNS 解析結果。

## 7. 隱私設計概覽

1. **假名化為預設**：行為事件自蒐集之始即以單向雜湊識別碼關聯，電子郵件地址不落盤；
2. **個人化自主開關**：播放器設定中可隨時關閉個人化；關閉後事件不入庫，公開模式直接丟棄；
3. **一鍵清空**：設定頁「清除推薦輪廓」即時銷毀伺服器端全部行為事件；「清除全部本機資料」即時清除瀏覽器本機儲存與 IndexedDB；
4. **日誌最小化**：資料面存取日誌僅含路徑、方法、狀態碼與耗時。

隱私承諾之完整表述見[隱私權政策](/zh-tw/privacy-policy/)，技術措施見[資料處理與安全維護](/zh-tw/data-security/)。

## 8. 適合誰與不適合誰

適合：希望以自有 Epomail 帳號登入、在意推薦輪廓透明與可刪除性之個人聽眾；需要多源聚合搜尋與逐字歌詞之重度樂迷；具備 Linux 與 Docker 基礎、願意自行承擔營運者責任之自部署使用者。

不適合：尋求商業音樂服務授權保障之場景——本專案不儲存、不託管音樂，亦不授予任何內容再授權；期待服務水準協議（SLA）或商業支援之團隊；無法接受「試聽片段透明標示、跨源補齊盡力而為」之使用者。

## 9. 內容與版權邊界

Sonic 是檢索、聚合與播放工具，不儲存、不託管任何音樂檔案。錄音、歌詞、封面、藝人圖像等內容之權利歸屬各自權利人；本專案不授予任何音樂內容之再授權。合法會員曲目由部署者以自有授權憑證掛載（如 `NETEASE_COOKIE`，為部署者帳戶而非終端使用者帳戶），公開曲目遵循官方開放協定。

您使用本服務時應遵守[可接受使用政策](/zh-tw/acceptable-use/)；部署者應自行確認其使用場景符合當地法律、上游服務條款與內容授權要求。

## 10. 部署形態

| 形態 | 組成 | 要點 |
| --- | --- | --- |
| Cloudflare Pages 邊緣閘道 | 前端 SPA + Pages Functions | 建置後經 `wrangler pages deploy` 發布；需設定 `SONIC_SECRET`、`SONIC_ENGINE_SECRET`、`SONIC_LOCAL_ENGINE_URL` |

兩種形態共同構成完整服務；僅部署邊緣閘道而無資料面時，服務自動運行於邊緣降級模式。環境變數之完整清單見上游儲存庫 `.env.example` 與 `docs/OPERATIONS.md`。

## 12. 常見疑問

**本服務收費嗎？有廣告嗎？**
免費、無廣告、無內購；託管執行個體之營運成本由營運團隊承擔。本服務不蒐集任何用於廣告目的之資料。

**不登入可以使用嗎？**
可以。搜尋、播放、歌詞、排行榜等核心功能匿名可用（限流較嚴）；登入後解鎖收藏雲端同步、個人化推薦與 Auto DJ。

**我的資料存在哪裡？**
分三處：收藏、歌單、播放器偏好存於您瀏覽器之本機儲存；下載與本機音樂存於您瀏覽器之 IndexedDB；伺服器端僅存假名化行為事件（90 日自動銷毀）。電子郵件地址不落盤。詳見[隱私權政策](/zh-tw/privacy-policy/)第 4 節。

**如何刪除我的行為輪廓？**
設定 → 隱私與本機資料 → 「重置推薦輪廓與不感興趣記錄」，或直接呼叫 `DELETE /api/sonic/events`，即時生效；「清除全部本機資料」同時清空瀏覽器與伺服器端資料。介面位置見[介面與功能導覽](/zh-tw/interface/)第 9 節。

**推薦會追蹤我嗎？**
推薦僅服務於播放排序，無跨站追蹤、無廣告輪廓；個人化可隨時關閉，關閉後進入純公開模式且不再記錄任何事件。

**為什麼有些歌只有 30 秒？**
那是官方平台之試聽截斷，播放器以試聽標示如實標註，絕不冒充全曲；開啟跨源補齊時會自動嘗試匹配免費全曲並標明來源。

**音質徽章可信嗎？**
可信。徽章反映當前音訊串流之實際檔位；上游檔位變動時即時隨之，不虛標（見[使用者條款](/zh-tw/terms-of-service/)第 4 節第 3 款）。

**自行部署有什麼責任？**
自部署之時點起，您即為該執行個體之資料控制者：需向您的使用者履行告知義務、維持處理記錄、必要時實施影響評估並落實安全維護。起點見[資料處理與安全維護](/zh-tw/data-security/)第 6 節。

**本服務支援哪些語言？**
播放器內建簡體中文、English、日本語；本站文件提供 10 種語言版本。
