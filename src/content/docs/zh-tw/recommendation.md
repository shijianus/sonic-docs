本頁概述 Sonic 推薦訊號、權重、排序及控制。除下列曲目訊號外，核對程式碼另含藝人、專輯、歌單及 MV 回饋與雷達輪廓。個人化與 Auto DJ 預設開啟；預設值、登入和繼續使用都不是明確同意。缺少有效依據的可選輪廓分析應暫停。見[隱私權政策](/zh-tw/privacy-policy/)第 4.2、5 節。

## 1. 行為訊號與權重

| 訊號 | 權重 | 說明 |
| --- | --- | --- |
| favorite（加入最愛） | +4.0 | 極強正向 |
| replay（重播） | +3.5 | 強正向 |
| play_complete（有效完播） | +2.5 | 標準正向 |
| play_progress（進度聆聽） | +0.2 ～ +1.8 | 按收聽比例分階計分 |
| skip（快速跳過） | -0.8 | 聽過半之切歌計 +0.25 |
| dislike（明確拒絕） | -5.0 | 僅在可用身分與功能範圍內過濾相符推薦；不承諾永久全面封鎖 |

**雜訊淨化**：網路延遲（network_stall）、解碼失敗（playback_error）、試聽截斷（trial_end）、串流不可用（stream_unavailable）、緩衝逾時（buffer_timeout）與自動切換失敗（auto_switch_error）六類非使用者切歌，權重恆為零且不入庫。

## 2. 熱度模型

站內趨勢熱榜綜合五項因子加權：有效播放（35%）、獨立聽眾（25%）、完播表現（20%）、收藏轉化（15%）與成長斜率（5%）；輔以指數時間衰減（24 小時飆升榜與 7 天累計熱榜）與貝氏／Wilson Score 平滑，避免低播放高完播之偶發事件異常置頂。

## 3. 工作階段意圖與長期偏好

工作階段搜尋意圖與長期訊號對排序的影響不同，但不表示搜尋從不保留。推薦請求可能傳送本機收藏、最近藝人和搜尋上下文；智慧搜尋另行計數搜尋原文，即使關閉個人化也可能出現在公開建議，請勿輸入私密或敏感資訊。假名識別碼仍是可能關聯個人的資料。

## 4. 多樣性重排與 Auto DJ

1. **相似度**：融合歌手關係圖譜、流派與語言標籤之集合相似度，及音訊特徵之餘弦相似度；
2. **MMR 重排**：以邊際相關性平衡「精準」與「新穎」，避免陷入單一歌手或曲風之資訊繭房；
3. **Auto DJ**：播放清單自然播完後，依當前曲目風格自動續接可播放曲目；開關獨立於個人化，個人化關閉時仍可能傳送種子及排除曲目。

## 5. 音樂與風格雷達

首頁雷達使用搜尋意圖與偏好訊號；程式碼包含本機雷達狀態、輪廓及遠端同步路徑，不是完全不改變儲存資料的純顯示功能。關閉個人化後，雷達仍可能傳送含曲目、封面及訊號的同步酬載，但伺服器可能依關閉標記拒絕儲存；傳送不等於持久保存。遠端路由可用性有限，也不保證通用雲端同步；雷達資料不在事件清理或輪廓重置的完整涵蓋範圍。

## 6. 您的控制權

| 控制項 | 位置 | 效果 |
| --- | --- | --- |
| 個人化總開關 | 設定 → 隱私與本機資料 | 控制其涵蓋的推薦事件，不控制獨立搜尋統計或每個雷達路徑 |
| Auto DJ 開關 | 設定 → 隱私與本機資料 | 控制播完後自動續接；預設開啟不成立同意 |
| 重置推薦輪廓 | 設定 → 隱私與本機資料 | 刪除目前身分的部分事件與回饋；可能遺漏舊識別碼、雷達、聚合、外部服務及備份，且失敗可能未顯示 |
| 拒絕曲目 | 播放器內 dislike | 僅在可用身分與功能範圍內過濾相符推薦；不承諾永久全面封鎖 |
