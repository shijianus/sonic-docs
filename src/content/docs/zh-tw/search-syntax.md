本頁彙整 Sonic 搜尋之能力與規則：輸入什麼、如何容錯、結果如何組織。介面位置見[介面與功能導覽](/zh-tw/interface/)第 2 節。

## 1. 檢索範圍

搜尋涵蓋四類對象：歌曲、歌手、專輯與歌單。結果頁以「單曲／歌單／MV」三類頁籤組織；搜尋入口位於側邊欄頂部與搜尋頁，介面可能顯示站內熱門搜尋關鍵詞提示。

## 2. 容錯與匹配規則

| 規則 | 說明 | 範例 |
| --- | --- | --- |
| 簡繁字形歸一 | 可用簡體或繁體字形嘗試搜尋；實際匹配取決於索引與上游可用性 | 輸入「周杰伦」與「周傑倫」進行對照 |
| 拼音與縮寫檢索 | 可用拼音全拼或首字母縮寫嘗試命中；不保證所有來源都有結果 | 輸入「zjl」嘗試搜尋周傑倫相關曲目 |
| 別名對稱匹配 | 網站可能關聯歌手的中英文別名；實際結果取決於索引 | 檢索英文名可嘗試命中中文別名藝人 |
| 編輯距離容錯 | 接近的字串可能被視為候選；不保證每個拼字錯誤都能修正 | 輸入近似字串後檢查實際結果 |
| 版本識別 | 結果可能區分錄音室版、現場版、翻唱等版本 | 以結果中的版本標示為準 |

## 3. 多源並行與去重

搜尋請求會傳送至已啟用且當時可用的上游來源，結果再依標準化規則合併；同名同曲目的多源記錄可能合併為單一結果，播放位址則在播放時依可用性取得。上游來源之清單與預設開關見[第三方共享與傳輸清單](/zh-tw/sub-processors/)第 3 節。

## 4. 結果操作

單曲清單的結果列可能提供播放、MV 入口（如有）、喜愛、下載與更多操作；頂部「播放全部」可能依結果順序連播。歌單結果進入歌單詳情頁，MV 結果進入 MV 清單；實際可用操作取決於結果與實例設定。

## 5. 搜尋與隱私

搜尋詞之處理方式：

1. **本機**：最近搜尋歷史使用瀏覽器 localStorage，但查詢本身會傳送供搜尋，部分歷史也可能隨推薦請求傳送；本機清理不刪除已產生的遠端副本；
2. **伺服器端聚合**：智慧搜尋可能另行計數或保存搜尋原文，並可能出現在公開建議，即使關閉個人化也不能據此排除該路徑。沒有帳號識別碼的文字仍可能識別個人，請勿提交私密或敏感資料；實際過濾、顯示門檻、保存控制與實例設定須另行核實；
3. **個人化**：搜尋與點擊訊號可由假名識別碼關聯。個人化開關不控制每個搜尋統計路徑；90 日設定或重置功能也不代表所有搜尋聚合或副本都會按同一期限刪除。
