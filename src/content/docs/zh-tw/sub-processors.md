## 1. 基礎架構與受託處理關係

| 對象 | 功能 | 可能涉及的資料與設定邊界 |
| --- | --- | --- |
| Cloudflare Pages 與 Functions | 託管、邊緣 API、快取與限流 | IP、請求路徑、標頭及連線中繼資料；具體記錄依執行個體和供應商設定 |
| Cloudflare Tunnel | 邊緣與資料面之間的通道 | 請求流量及連線中繼資料；通道不使所有內部或上游 HTTP 路徑自動加密 |
| Cloudflare KV 與限流器 | 限流、憑證撤銷等可設定儲存 | IP 或身分衍生鍵、撤銷識別碼；是否啟用及期限須核實 |
| 資料面主機或託管提供者 | 引擎、資料庫及日誌所在環境 | 引擎可能收到邊緣轉送的原始 IP、Cookie、驗證標頭和上下文；主機提供者身分與節點國家未核實 |

是否屬於受託處理，取決於誰決定目的、誰依指示處理及實際安排，不能只憑產品名稱判斷。GDPR 適用且存在受託處理關係時，應落實第 28 條要求的安排；此處不聲稱已簽署或核驗任何契約。控制者完整身分和可送達資料仍須補充，見[隱私權政策](/zh-tw/privacy-policy/)第 2 節。

## 2. 身分提供者（登入所必需）

Epomail（`mail.epocanvas.com`）提供 OAuth 登入。瀏覽器與身分服務互動，Sonic 交換授權碼、查詢使用者資料，可能取得使用者識別碼、電子郵件地址及其驗證標記、暱稱、頭像 URL 和角色；部分資料保存在瀏覽器 `auth` 儲存及簽章工作階段中，不是「只在記憶體」。

Epomail 不因登入接入或共同品牌而自動成為 Sonic 的受託處理者。其帳號體系的獨立處理和受指示處理應按實際目的及安排分別判斷；Sonic 仍須對自己決定的接收、保存和後續揭露負責。

## 3. 上游內容來源與瀏覽器直連

| 來源 | 主要用途 | 可能傳遞或取得的資料 |
| --- | --- | --- |
| 網易雲音樂、QQ 音樂、酷狗、酷我及相關 CDN | 搜尋、音訊、MV、封面和內容資料 | 搜尋原文、內容識別碼與中繼資料；代理出口或瀏覽器直連的連線資訊 |
| AMLL、LRCLIB | 歌詞查詢與補位 | 歌曲識別碼或標題、藝人等比對資訊，以及連線中繼資料 |
| Google Fonts | 字型載入 | 瀏覽器 IP、User-Agent 等連線資訊 |
| DiceBear | 外部頭像 | 目前路徑可能在 URL 的 seed 中包含明文電子郵件地址，並暴露瀏覽器連線資訊 |

音訊代理可使內容 CDN 看到代理出口，但不代表所有請求均不含個人資料。串流請求可能使用瀏覽器 User-Agent，而非統一固定值；MV、封面、字型和頭像可能直接由瀏覽器請求。部分提供者使用 HTTP，不能保證全鏈路 TLS。DiceBear 電子郵件 seed 應改為本機頭像或不含電子郵件地址的識別碼。

上游留言含其他人的姓名或暱稱、頭像和文字，並可能進入公開快取；其目的包括展示所請求 MV 的留言。留言作者不是本服務登入契約的當事人，不能僅以 GDPR 第 6 條第 1 項第 b 款處理其資料。GDPR 適用時，公開來源不自動免除第 14 條的間接蒐集告知要求；營運者應評估並記錄獨立處理依據、保存期限及告知例外，在法定時限內提供適用告知；必要保障未落實時應停用擷取或公開快取，不承諾總能逐一聯絡每位作者。本機撰寫的留言目前僅保存在 localStorage，未發現向留言伺服器發布的路徑。

未發現本機音訊檔案主體的上傳路徑，但歌詞比對或推薦上下文可能傳送標題、藝人、專輯、時長或識別碼。內嵌封面擷取為 data URL 後，也可能隨收藏事件傳送並進入遠端共享曲目目錄，供全站搜尋或公開建議回傳；個人輪廓重置不保證清理該目錄及其外部索引。因此，音訊檔案主體未上傳，不代表內嵌封面或相關資訊不會離開裝置。

## 4. 可選鏈路與開關差異

| 鏈路 | 用途與可能涉及的資料 | 核對邊界 |
| --- | --- | --- |
| GDStudio（`music-api.gdstudio.xyz`） | 聚合檢索、跨來源補齊；查詢或內容識別碼 | 未設定開關時原始碼預設開啟，環境範例與 Compose 設定為關閉；實際狀態須核驗 |
| Lyriva（`api.lyriva.xyz`） | 歌詞備用來源；內容識別碼或比對參數 | 受 `SONIC_ENABLE_LYRIVA` 等設定控制 |
| Musixmatch（`apic-desktop.musixmatch.com`） | 歌詞補位 | RC 保留實作，但 `isSourceEnabledByPolicy` 沒有 Musixmatch 分支，實際呼叫受 false 門檻阻止；舊 `main` 歌詞 fallback 可能可呼叫，須按實際部署確認；不能視為 RC 已啟用或可由一般開關啟用 |
| 營運者設定的告警服務 | 僅在設定有效的 `SONIC_ALERT_WEBHOOK_URL` 且觸發告警時，傳送系統計數、發布版本、時間、憑證遮蔽摘要及傳送節點出口 IP | 是否啟用、接收者、角色、傳輸及保存期限依執行個體核實；管理員備註和錯誤資訊可能含個人資料，遮蔽不等於匿名化 |
| ListenBrainz / MusicBrainz | 相似藝人增強；藝人或錄音識別碼 | 受 `SONIC_ENABLE_LISTENBRAINZ` 等設定控制 |
| Gorse | 外部推薦；假名識別碼、行為回饋、時間、曲目識別碼、標籤與標題等目錄中繼資料 | 按 `SONIC_GORSE_URL` 等設定接入；目前重置不保證同步刪除外部回饋或曲目記錄 |
| Meilisearch | 可選檢索服務；原始查詢及目錄資料 | 是否接入和保存期限按執行個體核實，不能視為匿名查詢 |
| 跨來源補齊 | 跨平台內容比對；歌曲中繼資料 | 實際請求依比對路徑；功能可用不等於已獲內容授權 |

開關設定不等於使用者同意。目前個人化及 Auto DJ 預設開啟的同意缺口見[隱私權政策](/zh-tw/privacy-policy/)第 5 節；未落實必要依據與選擇的可選處理應暫停，不應靠更換第三方名稱繞過要求。

## 5. 法律要求下的共享

收到調取要求時，應核實請求者身分、管轄權、具體依據與範圍，只提供依法必要的資料，並記錄處理理由。是否通知個人依適用法律及有效限制判斷；檢舉、懷疑違規或終止服務不自動導致向警方共享全部資料。

揭露所依賴的法律義務也不能替代國際傳輸要求。向公開 Issue 或社群提交問題前，請移除個人資料、憑證和他人留言中的私密資訊。

## 6. 國際傳輸

GDPR 的適用依第 3 條判斷，不因免費、非營利或僅可從歐盟存取就自動排除或成立。若 GDPR 第五章適用於具體個人資料傳輸，本站才按實際接收者、地點和處理角色逐項確認第 44 條要求、適用的充分性決定（第 45 條）或其他有效保障（第 46 條）；不能把所有海外 IP 或內容請求一概寫成 GDPR 第五章傳輸。本站不把全部 GDPR 制度作為全球統一契約保證，也未核實控制者所在地、資料面國家或全部請求的目的地，不能推定託管在臺灣或由某一固定法域管轄。

1. 適用 GDPR 的第三國傳輸應逐項滿足第 44 條要求，核實是否有適用的充分性決定（第 45 條）或其他有效保障（第 46 條）。
2. 使用標準契約條款時，仍須確認適用主體、處理範圍、傳輸評估及必要補充措施；供應商公開提供條款不代表本執行個體已經落實。
3. ISO／SOC 認證、供應商隱私權政策或同意本頁本身均不自動構成合法傳輸依據；搜尋文字、IP 和假名識別碼也不能籠統排除在個人資料之外。
4. 依法可透過 `privacy@epocanvas.com` 請求有關保障的說明或副本；必要商業秘密可適當遮蔽，但不能以保密為由取消法定透明義務。

發現清單與實際處理不一致時，應更正告知並處理不當傳輸，而非簡單宣布「以程式碼為準」。自行部署者的責任來自實際法律與授權，不因本頁被複製而產生對專案作者的額外契約義務。回饋：`privacy@epocanvas.com`。
