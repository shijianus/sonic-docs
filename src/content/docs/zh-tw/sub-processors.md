## 1. 受託處理者（持續在用）

| 對象 | 服務內容 | 涉及資料 | 保障機制 |
| --- | --- | --- | --- |
| Cloudflare Pages 與 Functions | 前端託管、邊緣 API 閘道、限流執行 | 請求中繼資料、限流暫存記錄 | GDPR 第 28 條受託處理條款 |
| Cloudflare Tunnel | 控制面與資料面之加密通道 | 加密流量中繼資料 | 同上 |
| Cloudflare KV 與限流器 | 限流計數（120 秒過期）、金鑰即時撤銷記錄（如啟用） | IP 限流鍵、`jti` 撤銷記錄 | 同上 |

Cloudflare 整體持有 SOC 2 Type II 與 ISO/IEC 27001 認證，並以歐盟標準契約條款涵蓋跨境傳輸。Cloudflare 依其自身政策處理之網路層請求中繼資料，見其隱私權政策之說明。

下列對象接收之請求僅含歌曲查詢參數、固定 User-Agent 與對應官網 Referer，**不包含您的帳戶資料、Cookie 或 IP 位址**：

| 對象 | 服務內容 | 代表網域 | 預設狀態 |
| --- | --- | --- | --- |
| 網易雲音樂 | 檢索、播放位址、逐字歌詞（YRC）、封面 | `music.163.com`、`interface3.music.163.com`；另經資料面內網 ncm-api 輔助容器 | 開啟 |
| QQ 音樂 | 檢索、播放位址、逐字歌詞（QRC）、封面 | `c.y.qq.com`、`u.y.qq.com`、`y.gtimg.cn`、`ws.stream.qqmusic.qq.com` | 開啟 |
| 酷狗音樂 | 檢索、播放位址、逐字歌詞（KRC） | `m.kugou.com`、`mobilecdn.kugou.com`、`songsearch.kugou.com`、`lyrics.kugou.com` | 開啟 |
| 酷我音樂 | 檢索、播放位址、封面 | `www.kuwo.cn`、`m.kuwo.cn`、`search.kuwo.cn` | 開啟 |
| AMLL | 逐字歌詞（TTML）補位 | `api.amll.dev` | 開啟 |
| LRCLIB | 同步歌詞補位 | `lrclib.net` | 開啟 |
| 各官方內容 CDN | 音訊串流與封面（預設經本服務邊緣代理擷取） | `music.126.net`、`ws.stream.qqmusic.qq.com` 等 | 開啟 |

說明：

1. 上游請求之出口 IP 標示為部署者設定之佔位位址（預設 RFC 5737 文件位址），非任何使用者之 IP；
2. 音訊串流預設經邊緣代理取得，上游 CDN 僅見代理伺服器之位址；您主動呼叫 `?mode=redirect` 直連模式時，您的瀏覽器與該 CDN 直接建立連線，您的 IP 對該 CDN 可見（302 重新導向之固有語義）；網頁播放器不使用該模式；
3. 部署者得以自有會員憑證（`NETEASE_COOKIE`／`QQ_COOKIE`／`KUGOU_COOKIE`）掛載其授權目錄；該憑證為部署者之帳戶資料，與終端使用者無關，程式碼不內建任何真實帳號 Cookie。

## 4. 可選鏈路與預設狀態

**預設開啟的跨來源補齊**：試聽曲目的跨平台全曲匹配（QQ／酷狗／酷我免費全曲），僅使用歌曲中繼資料（時長、標題、歌手），不涉及身分資料。這是預設開啟的查詢鏈路，不屬於下方的預設關閉服務。

**預設關閉的服務**：GDStudio、Lyriva、ListenBrainz／MusicBrainz 與 Gorse 僅在部署者明確開啟後發生。下表為這些服務的獨立開關表；首列為表格說明，不代表實際服務鏈路。

| 對象 | 服務內容 | 涉及資料 | 開關與預設值 |
| --- | --- | --- | --- |
| **預設關閉服務與開關表** | **僅以下服務需明確開啟** | **所涉資料以各列說明為準** | **預設值均為關閉** |
| GDStudio（`music-api.gdstudio.xyz`） | 第三方聚合檢索與跨來源補齊備選 | 僅歌曲識別碼、類型與來源參數 | `SONIC_ENABLE_GDSTUDIO`，預設 0 |
| Lyriva（`api.lyriva.xyz`） | 歌詞備用來源 | 僅歌曲識別碼參數 | `SONIC_ENABLE_LYRIVA`，預設 0 |

| Gorse（部署者自建推薦引擎） | 外部協同過濾 | 假名化雜湊識別碼（`subject_key`）與行為回饋 | `SONIC_GORSE_URL`，預設為空 |

## 5. 法律要求下之共享

營運者僅於請求具體法律依據時提供個人資料：核實請求之合法性與範圍，不自願提供超出請求範圍之內容，並於法律允許範圍內先行通知受影響之當事人（法令禁止通知者除外）。本服務不接受無法律依據之任意調取。全部法定請求之處理過程均予記錄在案。

## 6. 國際傳輸

本服務之控制面運行於 Cloudflare 全球邊緣網路，行為事件儲存於營運者之資料面節點；您的個人資料可能於營運者所在國境外之節點處理。傳輸保障機制：

1. 依 GDPR 第 44 條至第 46 條：以歐盟委員會充分性認定（第 45 條）或經核准之標準契約條款（第 46 條第 2 項第 c 款）為依託管與受託處理關係之基礎；
2. 依賴 Cloudflare 之資料保護認證（SOC 2 Type II、ISO/IEC 27001）與其資料處理附錄；
3. 上游內容來源之請求不包含個人資料，不構成個人資料之國際傳輸（見第 3 節）。

自行部署之營運者應自行評估其部署形態下之國際傳輸，並確保符合其所在地之法律要求（GDPR 第五章或其當地對應法制）。
