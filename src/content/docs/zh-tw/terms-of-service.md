## 1. 定義

1. **本服務**：運行於某一 Sonic 執行個體上之全部功能，包括網頁播放器、邊緣閘道、本地協定引擎、開放 API 及相關元件；介面版面配置與功能位置見[介面與功能導覽](/zh-tw/interface/)。
2. **營運者**：部署並運行您所用執行個體之個人或團隊。就託管執行個體（`sonic.epocanvas.tech`、`sonic.epocanvas.com`）而言，指營運團隊；就自行部署執行個體而言，指其部署者。
3. **您（使用者）**：登入或以其他方式使用本服務之自然人或組織。
4. **契約成立**：您於哪一個執行個體登入，即與該執行個體之營運者成立契約。本條款為通用範本：託管執行個體直接適用；自行部署營運者得修改後作為其網站條款，並應依其所在地之適用法律向其使用者履行告知義務。
5. **資料面**：為您所用執行個體提供協定解析與推薦計算之 Linux 節點；其離線不影響您依第 4 節第 2 款獲得之降級服務。

## 2. 服務之說明與範圍

本服務為檢索、聚合與播放工具，不儲存、不託管任何音樂檔案；音訊內容自官方 CDN 及上游開放 API 取得，歌詞自原生解析與公開歌詞庫取得。各項功能之範圍與資料位置如下：

| 功能類別 | 包含功能 | 資料儲存位置 | 是否需要登入 |
| --- | --- | --- | --- |
| 核心功能（匿名可用） | 多源聚合搜尋、逐字歌詞、音質分級播放、試聽標示、排行榜、MV | 瀏覽器本機（播放狀態） | 否 |
| 帳號功能 | 收藏與歌單本機管理、個人化推薦與 Auto DJ、行為事件管理 | 伺服器端僅存假名化行為事件；收藏偏好僅存於目前瀏覽器，不跨裝置同步 | 是 |
| 個人資料功能 | 下載清單、本機音樂匯入與管理 | 瀏覽器 IndexedDB | 否 |
| 開放 API | 第三方用戶端經簽章 API Key 串接 | 伺服器端工作階段與撤銷清單 | 是 |

本服務基於開源專案建置並延續開源：原始碼公開可稽核，您得自行部署取得同等能力。軟體本身依「現狀」提供，其授權條款與本條款之責任約定相一致（見第 10 節）。

## 3. 帳號之取得與安全

1. **登入方式**：本服務以 Epomail 帳號經 OAuth 2.0（PKCE）登入，不設獨立註冊系統；您與 Epomail 之間之帳號約定，適用該服務之條款。Epomail 帳號遭凍結或註銷者，您對本服務之登入隨之中止。

3. **一人一帳號**：您不得將帳號出借、出租、出售或與他人共用；因共用帳號所生之爭議與資料混同，營運者不負責區分與恢復。
4. **憑證保管**：您對 Epomail 帳號憑證、API Key 及工作階段安全負保管責任。經由您憑證所為之操作，推定為您本人之行為。工作階段 Cookie 內含簽章金鑰，請勿於共用裝置登入後不登出；發現憑證外洩時，您應立即登出並請求撤銷。
5. **工作階段機制**：登入成功後簽發 `HttpOnly; Secure; SameSite=Lax` 之工作階段 Cookie（有效期至多 30 日）；API Key 不寫入 URL、查詢參數或 localStorage。您得隨時登出，登出即時撤銷當前工作階段與對應金鑰識別碼（jti）。
6. **金鑰簽發**：API Key 採 HMAC-SHA256 版本化簽章格式，簽發有效期 30 日、驗證上限 90 日；無簽章或已撤銷之金鑰一律拒絕。您重新簽發金鑰須提供當前有效金鑰。API Key 為您個人使用之憑證，不得轉交第三方或嵌入公開發行之用戶端。
7. **登入保護**：OAuth 回呼經 state、PKCE、授權碼與重放四重核驗；驗證端點設每分鐘每 IP 30 次之限流。

2. **邊緣代理**：音訊串流預設經邊緣代理取得，上游 CDN 不接觸您的 IP 位址；如您主動使用 `?mode=redirect` 直連模式，您的瀏覽器將與官方 CDN 直接建立連線，您的 IP 對該 CDN 可見。

1. **您終止**：您得隨時停止使用本服務；以「一鍵清空輪廓」刪除行為記錄，登出撤銷工作階段。Epomail 帳號本身之註銷適用 Epomail 之規則。
