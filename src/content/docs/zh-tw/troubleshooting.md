**生效日期：2026 年 11 月 2 日｜版本：1.5**

本頁列出常見問題之識別與處置。若此處未能解決，致函 `admin@epocanvas.com` 或於 GitHub 程式碼庫提報 Issue。

## 1. 播放問題

| 現象 | 原因 | 處置 |
| --- | --- | --- |
| 曲目標示「試聽」且 30 秒後停止 | 官方試聽截斷，並非故障 | 開啟跨來源補齊，自動匹配免費全曲；或改播其他來源版本 |
| 音質徽章顯示較低檔位 | 如實反映上游實際簽發檔位 | 切換音質選單嘗試其他檔位；上游檔位會隨可用性變動 |
| 播放中斷後無法續播 | 上游直連位址已過期 | 重新點擊曲目即可重新解析 |

## 2. 降級模式

介面頂部出現「邊緣降級模式」琥珀色提示時：資料面節點暫時離線或逾時，邊緣層已自動切換直連公開 API——搜尋與歌詞仍可用，完整音源解析與推薦更新可能受限。通常數十秒內自動恢復（熔斷冷卻 30 秒後探活）；已載入曲目不受影響，無需重新整理。

## 3. 搜尋問題

1. **搜尋無結果**：多為上游 API 瞬時不可用，稍候重試；降級模式下搜尋經邊緣直連公開 API，覆蓋面可能略窄；
2. **結果重複或缺失**：多源去重按規範識別碼合併，上游中繼資料異常時可能漏並——可提報 Issue 附關鍵詞。

## 4. 登入問題

1. **登入後立即退回未登入**：多為瀏覽器阻止第三方 Cookie 或 Cookie 遭安全擴充功能清除——將網站加入允許清單後重試；
2. **Epomail 端帳號遭凍結**：登入隨之中止，請先處理 Epomail 端帳號狀態；
3. **共用裝置他人可播放**：工作階段 Cookie 至多保留 30 日，共用裝置使用後請登出（見[帳戶與安全指南](/zh-tw/account-security/)第 5 節）。

## 5. 儲存問題

1. **收藏或下載遺失**：瀏覽器「清除網站資料」或隱私模式會刪除本機儲存（見[資料匯出與儲存](/zh-tw/data-management/)第 1 節）；重要歌單請自行記錄；
2. **下載失敗**：瀏覽器儲存配額已滿——刪除舊下載或清理瀏覽器儲存後重試；
3. **本機音樂匯入失敗**：檔案格式超出瀏覽器解碼能力，或檔案過大超出配額。

## 6. 限流與錯誤碼

| 現象 | 含義 | 處置 |
| --- | --- | --- |
| 429（匿名） | 超出每分鐘 240 次匿名限流 | 登入可獲更高配額（600 rpm） |
| 429（已驗證） | 持續超出每分鐘 600 次 | 檢查用戶端是否存在循環請求 |
| 501（撤銷類操作） | 執行個體未設定即時撤銷 | 由部署者設定 KV 或清單方式 |
| 反覆登出 | 金鑰遭撤銷或全域簽發時間下限調整 | 重新登入取得新金鑰 |

## 7. 仍未解決

提報 Issue 時請附：發生時間、使用的頁面與操作、介面提示（如降級提示截圖）、瀏覽器與版本。請勿附工作階段 Cookie 或 API Key。
